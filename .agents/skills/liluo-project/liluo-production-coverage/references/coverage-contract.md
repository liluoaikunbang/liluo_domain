# 生产覆盖合同

Stages are ordered but evidence-specific. `concept` requires a real node; `outline` a linked Markdown; `productionDesign` executable conditions/references or explicit production design; `skeleton` real registered implementation artifacts; `graybox` a traversable minimal route; `partiallyPlayable` a formal subset; `playable` the scoped MVP through a formal entry with completion and persistence; `validated` reproducible tests plus required manual checks.

The first version intentionally derives coverage at request time. It stores no subjective score and does not promote stages merely because earlier stages contain many files.
