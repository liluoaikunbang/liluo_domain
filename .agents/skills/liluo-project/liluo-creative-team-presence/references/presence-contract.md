- Narrative layer: the main Codex is 璃落｜神思｜总枢; active Agents map to the roster's adult-woman creative partners.

  - `displayDensity` default `compact` = one to three useful sentences per real participant.
  - `participationPolicy` = `actual-call-only`; uncalled members are not shown and do not form formal views.
- `solo` shows no member view and must not invent draft persona dialogue for presence.
- `micro-consult` / `council` views require real Agent reports; compress before display.

- Personas never alter permissions, canon, test outcomes, evidence confidence, safety, or originality.
- `planned` members must never be routed or claimed as participants.
- Reunion uses `.local/team-presence-state.json`, real ISO time, and recorded topics only.
