# 授权维护合同

- 执行权威：`.codex/rules/*.rules`；追踪：`.codex/approval-decisions.json`；摘要：`docs/运行规范/Codex命令批准分级表.md`。
- 单次/会话不持久化；项目长期决定可在同一任务自动同步；全局外部写入必须另有明确授权。
- `allow` 只接受精确低风险项目命令。网络、Git 写入、依赖、删除、发行、项目外路径、凭据、解释器与复杂 shell 不自动 allow。
- `codex execpolicy` 是字面前缀匹配，不是命令终止匹配；以更具体的严格规则保护已知危险参数。
- TUI 审计只读用户规则、只保存脱敏快照，不自动删除或修改用户级规则。
- 若管理员规则、平台沙箱和项目规则冲突，以更严格控制为准。
- 常规检查、测试、构建、索引和 Skill 脚手架优先走受测试的精确 npm 聚合入口；不得以减少弹窗为由允许任意解释器或 shell。
