# 效用导向构思示例

## A：虚假对话选项

“勇敢地进去 / 谨慎地观察 / 冷静地思考”全部淘汰：它们只有态度，缺少行动、可观察反馈和后果差异。

若工具、旧值日表和管理员都已存在或被允许合理加入，可改为：用工具卡住电梯门（检查夹层，工具可能损坏）；按旧值日表的楼层顺序乘坐（验证规律，但主动触发异常楼层）；找管理员共同乘坐（即时风险下降，但暴露调查目的并改变其态度）。三项分别改变行动、风险/资源和关系；示例不构成璃落固定设定。

## B：随机拼接

“保存记忆的组织、乘坐消耗记忆、管理员是过去时间线守门人”若无前置证据，全部淘汰。组织、记忆、时间线和身份反转的并列不是效用。

## C：合法的不新增

已有三个选项分别覆盖调查、冒险与撤退时，建议不再增加：继续添加大概率只会形成措辞不同、后果相近的伪分支。

## D：旧课桌细节

合格候选要写明璃落检查了什么、玩家看到或听到什么、得到的线索或状态，以及为什么它属于旧课桌而不是任意容器。“感受到岁月痕迹”没有行动、反馈和变化，应淘汰。
