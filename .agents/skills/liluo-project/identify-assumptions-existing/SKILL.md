# Existing-Content Assumption Method

来源：`phuryn/pm-skills`，MIT，commit `18468a95b427e70e258b51389796367c6f684e7d`；原始快照见 `external-knowledge/sources/skill/planning/phuryn-pm-skills/current/pm-product-discovery/skills/identify-assumptions-existing/SKILL.md`。

对每个通过初筛的候选检查：Value（是否改善玩家体验、剧情或表现）、Usability（玩家能否理解行动、线索与反馈）、Viability（是否符合世界观、角色定位和项目方向）、Feasibility（地图、代码、CG、音频与维护成本是否可接受）。只报告会影响取舍的假设；不为 Micro 任务制作完整风险报告。
