# 撰写检查

- 先核对 `status`：主线任务使用“主线备忘”，普通节点才判断成熟度并套用故事条目模板。
- 普通节点位于主线之下时，沿 `parentKey` 读取相关主线备忘；核对已确认方向是否落实、推荐内容是否仍只作为参考、当前相关待定项是否已询问或登记。
- 核对用户说明、JSON、Markdown、世界选项、父子节点及真实引用。
- 保持 `key`，验证标题/文件名、世界目录和 `parentKey`。
- 普通节点的当前成熟度必须覆盖对应层级要求；主线任务不得写入 `isTemplated`、`missingItems`、`scope`、`moduleType`、进入/完成条件、状态变化、玩法规则、资源引用、最小可玩版本或制作验收。
- 只写真实存在或明确新增的 ID/path。
- 普通节点的 `missingItems` 使用“类型｜所属模块｜具体缺少内容”；主线备忘把未决方向写入正文的“留待正式主线设计时确认”，不进入结构化缺口队列。
- 运行故事测试、UTF-8 检查和内容验证。
