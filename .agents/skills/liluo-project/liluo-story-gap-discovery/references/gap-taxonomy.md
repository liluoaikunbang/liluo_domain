# Gap taxonomy

- `structure`: missing opening/motivation, abrupt transition, absent middle/climax/ending/aftermath, unrecovered setup, unexplained state change or disconnected neighbors.
- `narrative-function`: result without process, capture without observation/negotiation/agency, exploration without resistance, conflict without relationship change, no branch/failure/consequence/countermove or normal-life contrast.
- `scene`: repetitive locations, unused place affordances, missing movement/public/enclosed/natural/social/safe/world-specific scenes.
- `character`: repeated functions, missing ally/foil/guide/rival/resident/goals/relationship change or protagonist choice.
- `gameplay`: defined but unused gameplay, repeated loop, absent narrative causality, missing exploration/chase/puzzle/resource/stealth/escape variation, no failure route or state consequence.
- `visual-production`: missing event-bearing CG/pixel performance/map change/state difference/before-after image, or production cost exceeding story value.
- `theme-coverage`: world identity underused, cross-world reskin, concept without daily/social structure, missing world-specific mechanism.
- `redundancy`: same opening/capture/escape/location function/supporting role/state change, or different titles with the same story function.

Never infer a gap from keyword counts alone. Require story-function and relation evidence; mark intentional blank or deferred production separately.
