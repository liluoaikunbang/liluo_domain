# Analysis modes

## Node

Analyze one node, its local tree or an undeveloped title. Cover setup, transition, exploration, relationships, resistance, failure/exit, aftermath, map, gameplay, CG and state changes. Return 3–5 candidates.

## Series

Analyze a story series, medium dungeon or one world line. Compare rhythm, functions, locations, relationships, gameplay, CG, states, branches, transitions, aftermath and repeated structures. Return 5–8 high-value candidates.

## World

First return a gap report covering dominant functions, theme coverage, repeated modes, underused gameplay/maps/relationships, daily-life balance, event scale and visual opportunities. Then return only 8–12 directions; never dozens of weak ideas.
