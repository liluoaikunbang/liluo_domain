# Originality rules

Extract general mechanisms, prefer multiple sources, remove source characters/proper nouns/distinctive settings/dialogue/order, and redesign causality, environment, relationships and resolution around verified 璃落 canon. Use new wording.

Do not copy sentences, rename characters in reused prose, reproduce complete event order/signature lines, or imitate one author. Record only abstractions and source locations. Treat rename-only or long matching runs as high risk. Common genre terms alone are not copying.

Before formal externally informed long text is written, run `npm run external:knowledge:copy-check -- --input <file>` and rewrite medium/high results. Candidate cards themselves contain no long source prose.
