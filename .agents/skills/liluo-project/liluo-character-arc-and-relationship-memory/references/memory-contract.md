# 长期记忆合同

Required: `kind`, `subjectId`, `scope`, `lasting: true`, `change`, `effectiveFrom`, non-empty `evidence`; relationship records also require `counterpartId`. Stable identity is derived from kind, subjects and effective position. Evidence must be a formal project path/key.

Do not record every scene, approval discussion, mood, clothing change or temporary alliance. The file is continuity knowledge, not an event log and not a replacement for runtime saves.
