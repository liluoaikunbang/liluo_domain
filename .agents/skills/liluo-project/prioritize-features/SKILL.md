# Candidate Prioritization Method

来源：`phuryn/pm-skills`，MIT，commit `18468a95b427e70e258b51389796367c6f684e7d`；原始快照见 `external-knowledge/sources/skill/planning/phuryn-pm-skills/current/pm-product-discovery/skills/prioritize-features/SKILL.md`。

按以下顺序筛选：目标契合、玩家体验差异、因果完整性、璃落与当前世界契合、已有素材/系统复用、非重复性、制作成本、假设风险、新增世界观负担、后续扩展价值。允许结论为“不建议新增”；排序不是为所有候选背书。
