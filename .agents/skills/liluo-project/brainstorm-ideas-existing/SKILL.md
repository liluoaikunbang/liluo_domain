# Existing-Content Brainstorming Method

来源：`phuryn/pm-skills`，MIT，commit `18468a95b427e70e258b51389796367c6f684e7d`；原始快照见 `external-knowledge/sources/skill/planning/phuryn-pm-skills/current/pm-product-discovery/skills/brainstorm-ideas-existing/SKILL.md`。

仅在已经确认内容缺口后使用。按叙事、交互与制作三个视角，从当前节点事实、角色目标、地图、状态、玩法、素材和未充分使用线索生成候选；不从新增组织、人物、规则或专有名词起步。初始候选一次只改变一个主要变量，并交回 `liluo-purpose-driven-ideation` 做硬测试与筛选。
