# 治理契约

## 职责分层

- `AGENTS.md`：最高层跨任务规则与工作流路由。
- `docs/系统说明/`：当前有效结构、用法与契约。
- Skill：可重复执行流程；Agent：只读调查或验证角色合同。
- `docs/用户命令目录.md`：用户可发现的自然语言入口与长期命令。
- `docs/功能更新/`：某次实现了什么，不承担当前完整规范。
- `docs/设计记忆/`：为什么作出重要决定，以及重新评估条件。
- `project-index/`：导航和派生摘要，不替代权威源。
- Git：精确变更历史，不替代当前说明。

## 单一事实源

一条长期规则只在一个权威文档完整维护。消费者只保留自身职责所需的局部约束、一句摘要和路径引用。治理注册表只登记跨文档、长期且确实需要追踪的关系，不登记每份历史文档或每句话。

## Token 边界

普通任务只做轻量持久性判断。治理任务先读三份注册表，再读一份权威文档和最多三份直接消费者；只有深度审计才扩大范围。不默认读取全部功能更新，不默认运行全文相似度扫描，不默认调用策展 Agent。

## 安全边界

确定性校验可以报告错误、警告和信息，但不自动删除或压缩正文。未经用户确认，不把候选决策标为 accepted；不把聊天流水账、AI 隐藏推理或临时偏好写入长期记忆。
