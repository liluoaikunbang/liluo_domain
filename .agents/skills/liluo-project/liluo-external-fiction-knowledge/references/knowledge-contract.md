# Knowledge contract

- Scope is always `external-fiction-reference`; `canonical` is always `false`.
- Sources under `external-knowledge/sources/fiction-bondage/` are immutable inputs.
- Derived data uses repository-relative paths and retains source ID, segment ID and line range.
- Text formats are indexed; unsupported binaries are cataloged without decoding.
- Query output is a locator, not a substitute for source verification or project canon.
- `project-index/` supplies canonical constraints; external knowledge supplies abstract inspiration only.
