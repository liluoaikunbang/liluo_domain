- 正面和背面帧的人物左右边距较小，人物看起来饱满
- 侧面帧虽然更窄，但仍需保持圆润体积，不能画得过薄

风格要求：
- 日式可爱 chibi 像素风
- 纯像素绘制
- 像素边缘清晰
- 不要抗锯齿
- 适合直接作为 RPG Maker / 瓦片地图人物行走图使用
- 风格统一，四个方向的人物身材粗细必须一致

背景要求：
- 透明背景
- 不要场景
