# 模块定位与体验目标

“重返校园”是玩家在都市线第一次获得地图控制的模块。它承接《病房苏醒》，从荆南大学校门口开始，让玩家亲自走过校园公共区域、观察安全规则、与普通师生进行短交互，并通过校园论坛发现后续异常事件的入口。

本模块不再重复医院苏醒、保护性拘束和梦境种子植入。它的目标是建立现实校园的正常基准：同学相处正常，教师愿意回应学生，学校重视安全事件，公开社团有明确规则。只有先让玩家体验这种可预测的日常，后续《舞蹈教室》和《宿舍旧楼》的空间异常与旧日伤害才会形成落差。

# 故事体量与核心差异

本条为 10 至 15 分钟的短篇地图序章，复用真实地图 `city_jingjiang_school`，主要活动范围为校门入口、通往公共教学区的主路、可查看校园信息的位置和社团招新区域。

它与纯过场式“主角复学”不同：玩家需要通过移动、观察和短对话确认校园如今如何运转，并主动打开论坛查看异常传闻。论坛内容只产生梦境种子的轻微共鸣，不在本条提前进入里世界，也不把普通校园探索变成恐怖追逐。

# 玩家进入与离开

## 进入条件

玩家已完成《病房苏醒》。璃落已经知情同意植入梦境种子，许知遥确认她可以通过恢复日常生活逐步适应，沈芷转为不过度干预的暗中保护，并继续避免用自己掌握的荆锁会内幕干扰璃落恢复记忆。

## 初始位置与初始状态

玩家在地图 `city_jingjiang_school` 的校门入口区域获得控制，角色为正常行走状态，朝向校园内部。当前地图使用 `role` 作为默认出生层；正式制作事件时需要在不改动原始 `map.json` 的前提下，为校门入口补充稳定出生点配置。

璃落已经解除医院保护性拘束，可以正常移动、调查、对话和使用菜单。梦境种子处于“已植入、未激活”状态，不改变地图控制。

## 完成条件

玩家完成必要的校园环境确认，查看校园论坛中“深夜小巷的无脸人”和“舞蹈教室加训事故”相关帖子，并沿任务引导抵达社团招新区域。本条在紧缚社团展台进入交互范围时结束，后续由《加入紧缚社团》接管。

## 失败、中断与返回

本模块没有战斗与失败结局。中途保存后从最近的校园安全位置继续。普通师生短对话可以重复查看，复学确认与首次论坛共鸣属于一次性事件；再次返回时保留校园开放状态，不重复播放开场。

# 游戏流程

## 阶段一：从校门进入校园

- 玩家目标：熟悉移动、调查和任务引导，确认璃落已经正式复学。
- 所在区域：荆南大学校门入口及主路。
- 必须交互：查看校门或校园导览信息；与负责复学引导的功能型 NPC 完成短对话；沿主路进入校园。
- 自动事件：璃落简短回想许知遥的恢复建议，梦境种子状态保持稳定。
- 状态变化：写入“已进入荆南大学”。
- 阶段结束条件：抵达公共教学区的任务检查点。

## 阶段二：确认现在的校园日常

- 玩家目标：通过环境和人物反馈建立安全校园基准。
- 所在区域：公共教学区与校园主路可开放部分。
- 必须交互：查看一处校园安全公告；与至少一名同学和一名教师交谈；观察公开活动或社团招新指引。
- 自动事件：对话体现同学相处正常、教师愿意听取意见、学校对安全问题有明确反馈渠道。
- 状态变化：完成复学环境确认。
- 阶段结束条件：获得查看校园论坛的任务提示。

## 阶段三：浏览校园论坛

- 玩家目标：从普通校园信息中识别与空白记忆产生共鸣的异常传闻。
- 所在区域：校园公告终端、手机界面或其他可打开论坛的位置。
- 必须交互：打开论坛；阅读“深夜小巷的无脸人”和“舞蹈教室加训事故”的关键摘要。
- 自动事件：文字短暂重影，环境音压低，梦境种子产生轻微共鸣后恢复；不切换地图，不限制玩家行动。
- 状态变化：记录两条校园怪谈线索。
- 阶段结束条件：关闭论坛后出现前往社团招新区域的引导。

## 阶段四：抵达社团招新区域

- 玩家目标：找到紧缚社团展台，为下一模块建立自然入口。
- 所在区域：社团招新区域。
- 必须交互：沿校园指引抵达招新区域；进入紧缚社团展台的触发范围。
- 自动事件：璃落注意到展台与其他公开社团一样有明确活动说明和安全规则，没有受到周围人的异样对待。
- 状态变化：解锁《加入紧缚社团》。
- 阶段结束条件：将流程控制交给下一节点。

# 地图与探索设计

## 地图区域与连接

本条复用 `city_jingjiang_school`，不新建并行校园入口。首轮只要求打通“校门入口 → 公共教学区 → 论坛查看点 → 社团招新区域”的最小路线。地图中其他区域可以继续存在，但不强制玩家在序章中全部探索。

现有地图已注册校舍、室外道路、跑道、旧宿舍、社团等素材，但 `events.json` 与 `dialogues.json` 当前均为空。本大纲只说明需要新增的交互方向，不把尚未创建的事件或对话 key 写入 YAML。

## 可调查物与环境互动

- 校门与校园导览：确认地点和基础方向。
- 校园安全公告：体现当前学校处理安全问题的公开流程。
- 普通课程或活动信息：表现校园日常仍在正常运行。
- 校园论坛入口：记录两条后续异常线索并触发轻微共鸣。
- 社团招新指引：把玩家引到下一模块，不在本条提前展开社团剧情。

## 道路限制与状态限制

璃落处于正常控制状态。首轮路线限制只能使用课程、报到流程或活动区域尚未开放等现实理由，不使用异常循环、空气墙式恐怖效果或身体限制。

## 场景氛围与环境变化

校园保持白天、明亮、有人活动的氛围。论坛共鸣只短暂改变文字、音量或画面色温，结束后立即恢复正常。该变化用于证明梦境种子会回应现实线索，而不是在本条正式激活。

# 角色与 NPC 安排

- 璃落：唯一确定的主要角色，由玩家从校门口开始控制。
- 复学引导 NPC：功能型角色，负责确认报到和指向公共区域；当前没有稳定姓名，不写入 YAML `characters`。
- 普通同学：提供校园生活和社团招新信息，反应自然，不围绕璃落制造异常关注。
- 普通教师：回应安全公告与学生求助渠道，体现学校现在愿意处理问题。
- 社团招新成员：本条只作为远处展台或入口提示，林雨薇、陈思雨的正式出场留给《加入紧缚社团》。

# 玩法设计

## 核心玩法

核心循环为“沿校园路线移动 → 调查环境信息 → 与师生短对话 → 在论坛中识别异常线索 → 前往下一活动区域”。这是后续复杂异常调查前的基础探索教学。

## 辅助玩法

论坛提供少量可选普通帖子，用于增加校园生活感；只有两条指定异常传闻属于主流程。普通帖子不写入任务状态，也不需要伪装成大型资料库。

## 成功条件、失败条件与反馈

完成必要环境确认、阅读两条传闻并抵达社团区域即成功。走错路线不会失败，任务指引可以重新显示。关键反馈包括任务目标更新、论坛线索进入记录，以及社团节点解锁。

# 对话与玩家选择

师生对话只提供观察角度和校园信息，不产生剧情分支。玩家可以决定先与谁交谈，但必须至少完成一名同学和一名教师的必要信息确认。

论坛阅读顺序自由。梦境种子只对指定帖子产生同样的轻微共鸣，不因阅读顺序改变后续主线。

# 前后章节与世界状态衔接

前置《病房苏醒》提供梦境种子与身体原主记忆规则，本条不重复解释治疗过程。后续《加入紧缚社团》从社团招新区域直接开始，并通过旧器材和求助暗号继续把安全日常与荆锁会线索连接起来。

本条记录的论坛传闻将在《舞蹈教室》正式触发异常。后续必须保留“本条只有轻微共鸣、尚未进入里世界”的状态边界。
