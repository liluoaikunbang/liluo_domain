# 模块定位与体验目标

《荆江第七异能适应学校》插入《小小女仆团》与《浮华剧场》之间，是“重返荆江市”主线第一次集中展示合法异能者日常社会的章节。前一章证明璃落已经被地下猎人盯上，本章则让她看到异能者并不只存在于犯罪组织、异常副本和外勤机构中，也需要学习控制能力、适应普通生活并承担现实责任。

本章以夸张校园喜剧承载世界观教学。璃落不是正式教师，而是由苏婉儿推荐进入七校的普通志愿者；成年适应班原教师临时请假后，她被请去暂时维持一节“异常自救实践课”。学生不认可这个没有教师资格、又看起来容易欺负的临时代课者，于是用多种异能协作整蛊，试图夺走课堂控制权。

# 故事体量与核心差异

本条为 20 至 30 分钟的主线短篇，首版只开放志愿者接待区、教学走廊和一间成年适应班教室。学校未来可以承载其他异能者情节，但本章只处理璃落首次到访与一节临时代课，不提前扩张宿舍、社团、考试和校外实训。

七校不是战斗学院，也不是矫治机构。它的核心职能是帮助异能者控制能力、理解法律边界、恢复职业与社会生活。入学与离校均属自愿，学生可以质疑教师，学校不会用评分、门禁或治疗话术剥夺人格；这使它与《静默矫治中心》的制度性控制形成明确对照。

# 玩家进入与离开

## 进入条件与初始状态

《小小女仆团》结束后，璃落已经知道合法异能者社会与地下猎人体系同时存在。苏婉儿认为她需要接触普通异能者生活，也希望她分享多次异常脱困的经验，于是推荐她到七校参加一次志愿活动。

玩家以正常行动状态从学校接待区开始。璃落最初只负责整理自救课程材料和协助课堂，不拥有正式教师权限；教务志愿协调员在原教师临时请假后，才将一节课的临时课堂权限交给她。

## 完成、失败与返回

璃落完成课程目标、识别学生协作能力并重新取得课堂控制权后，本章结束。她不会以处罚学生作为胜利，而是带领全班复盘每种异能如何制造误判、能力协作为何容易升级成真实事故，并让发起者承担恢复教室与整理器材的责任。

错误判断会提高课堂失控程度并触发更强整蛊，但不进入终局失败。失控程度达到上限时，本轮教学阶段从最近的课程目标重新开始，同时保留已经确认的能力线索，避免喜剧短篇因一次误判整段重来。完成后学校保持开放，可以返回接待区和已开放教室查看后续对话。

# 游戏流程

## 阶段一：志愿者报到

璃落在接待区登记志愿服务，了解七校对外使用“荆江市第七职业进修学校”名称，对内负责成年异能者的能力适应与社会生活教育。玩家通过公告、课程表和短对话确认学校不是异常灾害处理组织的训练基地，也不是强制收容设施。

教务志愿协调员说明成年适应班原教师临时请假，请璃落暂时看班并完成一节异常自救实践课。璃落可以检查教学材料、课堂安全规则和学生能力申报表，但申报表只记录能力类别，不直接揭示谁会在课堂中使用哪一种手段。

## 阶段二：课堂试探

课程开始后，学生先用低风险恶作剧测试璃落：粉笔和教案被空间置换，教室里出现模仿璃落声音的错误命令，座椅或讲台短暂改变重力、附着力，虚假的求救信号把她引向预设位置。

玩家需要在“继续教学、观察异常、询问学生、处理环境”中选择行动。继续教学推进课程目标，但可能错过新的能力线索；观察和询问帮助锁定能力来源；处理环境可以立即解除一种整蛊，却可能让真正的组织者趁机升级另一项能力。

## 阶段三：课堂控制权争夺

学生确认璃落不会立刻求助教务后，开始把能力组合起来。声音模仿掩盖真正指令，空间置换移动关键教具，重力或黏附效果限制璃落走位，假警报迫使她在维持课堂与处理紧急情况之间选择。

璃落在部分行动受到限制时仍需完成教学目标。玩家通过已收集线索判断当前异能由谁发动、哪两种能力正在配合，并选择先打断能力链、保护教学器材或利用整蛊结果反过来演示自救规则。错误指认会降低学生信服度并提高失控程度，正确拆解能力组合则恢复课堂控制权。

## 阶段四：反客为主的实践课

璃落识别主要能力组合后，不直接终止课程，而是把整蛊改造成正式演练：让学生分别说明能力边界、停止条件和误伤风险，再要求全班在不使用原组合的情况下帮助她恢复行动、归位教具并完成剩余课程。

学生发现璃落没有依靠教师身份压制他们，也没有因受困而放弃教学，最终承认她有资格完成这节课。课后复盘写入七校的能力事故记录，璃落获得学校长期访问资格，并从本章尚待确定的具体线索续接《浮华剧场》。

# 地图与探索设计

## 首版区域

- **志愿者接待区**：完成登记，调查学校公开说明、志愿任务板和课程表。
- **教学走廊**：观察成年适应班教室、能力安全标识和紧急停用装置，建立学校日常氛围。
- **成年适应班教室**：承载授课、异能整蛊、行动限制、能力识别和课后复盘，是本章唯一核心玩法区域。

首版不创建宿舍、训练场或完整校园地图。学校后续扩展必须通过独立故事节点开放具体区域，不能仅在本章用文字宣称无限扩张。

## 环境互动与限制

教案、粉笔、讲台、座椅、广播、能力申报表和紧急停用装置既是校园物件，也是判断异能来源的线索。整蛊升级后，玩家移动范围、交互距离或可用指令会短暂变化；任何能力限制都必须有可观察反馈、解除条件和安全停止规则。

# 角色与 NPC 安排

- **璃落**：唯一主要控制角色，以志愿者身份进入学校并临时代课。
- **苏婉儿**：负责推荐璃落接触七校，不替她处理课堂事件。
- **七校教务志愿协调员**：完成入校说明、临时授权和课后评价，不在课堂失控时立即代替玩家解决问题。
- **成年适应班学员**：均为成年人，通过不同异能协作整蛊并测试临时代课者；具体姓名、能力归属和组织者仍需下一轮确定。

# 事件与状态变化

# 玩法设计

## 核心循环

核心循环为“观察课堂异常 → 收集声音、位置和环境反馈 → 判断能力来源与协作关系 → 选择继续教学或处理整蛊 → 更新课程目标与失控程度”。每轮只需要处理一个主要异常，但连续判断错误会让学生把两种能力组合起来，增加环境干扰和行动限制。

课程目标与课堂失控构成两条压力轴。推进教学可以更快完成章节，却会减少调查机会；花时间观察能够降低误判风险，但会让未处理的课堂目标积压。具体阈值、每种能力的线索表和错误反馈保留为制作前缺口。

## 成功、失败与反馈

- 正确判断能力来源：显示能力边界线索，削弱对应整蛊并提高学生信服度。
- 错误判断：学生用新的能力效果掩护真正发动者，课堂失控程度上升。
- 成功处理能力组合：恢复一种被限制的操作，并允许把该组合转化为自救教学案例。
- 失控达到上限：从当前课程阶段重新开始，保留已确认线索，不回退整个章节。
- 完成全部课程目标并通过课后复盘：章节完成，七校成为可返回地点。

本条暂不编造 `gameplayRefs`。若后续确认该循环与现有玩法目录没有足够接近的正式玩法，再单独建立或扩展玩法条目。

# 对话与玩家选择

课堂对话的选择重点不是惩罚轻重，而是璃落如何回应学生挑战：直接维持秩序、顺势把恶作剧变成案例、要求学生解释能力边界，或先承认自己并非正式教师。不同表达改变学生信服度和课后对话，但不产生互斥主线结局。

结尾必须明确整蛊的安全边界。璃落认可学生质疑临时代课者的权利，但要求他们对能力失控、误伤和教室损坏负责；学校也不能因为璃落成功处理事件，就把无资质志愿者长期当成廉价正式教师。

# 前后章节与世界状态衔接

前置《小小女仆团》让璃落确认自己已被地下异能者猎人盯上，本章用七校展示合法异能者社会的日常面，补足她对能力边界与多人协作异能的认识。七校与异常灾害处理组织保持合作，但不承担外勤封印和强制监管职能。

本章后继调整为《消失的夜班车》。课后，一名成年适应班学员向璃落提出私人求助：其同住者在荆江工业园下夜班后失踪，厂方却声称对方已经自愿跨厂调岗。该求助让璃落把课堂中学到的能力边界判断带入真实城市调查，并在完成首案后解锁《城市调查员》支线。

# 最小可玩版本

1. 志愿者接待区、教学走廊和成年适应班教室三个区域。
2. 志愿登记、临时接课和课后复盘三段必要对话。
3. 一节包含三个课程目标的异常自救实践课。
4. 空间置换、声音模仿、重力或黏附、假求救信号四类整蛊表现。
5. 能力线索收集、来源判断、课堂目标与失控程度循环。
6. 至少一次组合异能造成的行动限制，以及明确解除方式。
7. 完成后解锁七校长期访问、学员对话和后续主线入口。

# 后续扩展

学校后续可以通过独立 `side` 节点开放能力失控实训、宿舍交换事故、校庆能力展演或新生适应委托。每个扩展必须拥有独立进入条件、核心能力规则和结束点；本章不预先创建这些节点，也不把未来可能性写成已经实现的内容。
