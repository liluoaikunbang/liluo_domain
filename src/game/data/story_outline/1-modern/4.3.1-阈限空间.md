# 模块定位与体验目标

阈限空间不是某一名异能者主动建造的领域，而是所有异能者的能力在无意间相互串联，最终形成的异能网络。每名异能者的能力都可能在网络中留下一个区域、规则或通道，因此它可以随着新异能者和新故事长期扩展。

永拘迷宫只是阈限网络的一部分，由其中一名异能者的能力建立。故事节点上，璃落是在永拘迷宫中第一次无意间发现该网络；世界结构上，则是永拘迷宫包含在阈限空间之中。这次偶然误入会让璃落掌握一条超出永拘迷宫原有规则的通路，并在该主线后续发挥奇效。

# 故事体量与核心差异

本条不设定一次性的固定体量和层级上限，而是一个可无限扩展的支线探索区域。当前只需立住“所有异能无意串联的网络”“永拘迷宫是其中一个子域”与“后室式大迷宫”三个核心特征，不预先写死所有楼层、实体和规则。

# 游戏流程

第一次进入发生在永拘迷宫主线中。璃落独自行动时无意间穿过永拘迷宫的能力边界，进入异能网络的其他层级。她不知道这里是什么，只能根据空间重复、布局错位、环境异常和出口痕迹判断前进方向。

首次进入时，璃落仍保留永拘迷宫主线中的永久拘束状态：双臂无法使用，双腿并拢束缚，只能跳跃移动。玩家需要在这种移动方式下完成第一次探索，并找到一个可用的出口。这次经历不只是额外探索，她发现的跨域通路会在永拘迷宫后续主线中起到奇效。

永拘迷宫主线结束后，阈限空间改为可随时进入和离开的长期支线区域。玩家每次进入前可自行选择璃落的拘束组合，但不允许无拘束进入。找到当前探索路线的出口后即可离开，没有死亡、任务失败或强制清空进度条件。

# 地图与探索设计

阈限空间是可无限扩展的大型迷宫网络，而不是需要现在一次定完的固定关卡。后续可随新异能、新人物或新怪谈逐步增加无尽办公室、空商场、黄墙走廊、泳池空间、无人酒店和错误现实层级等区域。

新增区域只需遵守共同逻辑：它是某种异能在网络中留下的结果，应具有可辨识的空间规则、出口判断和对当前拘束状态的影响。不要为了补完本条而提前写死层级数量、连接顺序或所有实体。

# 玩法设计

主要玩法引用“连续迷宫探索”（gameplay-002），核心参考后室：进入一个异常层级，观察空间规则与重复变化，在当前拘束状态下继续前进，最终找到出口并决定离开或进入下一段探索。

- 首次剧情状态：双臂不可用，双腿并拢束缚，只能跳跃移动。
- 通关后自选状态：可选择不同拘束组合，但至少保留一项拘束。
- 目标：每次探索只需找到一个有效出口，不设唯一终局。
- 失败条件：无。迷路、循环或进入错误层级都是探索过程，不进入失败结算。
- 进出规则：首次由永拘迷宫中的偶然误入触发；该主线结束后，可随时进入，并在找到出口后随时离开。
