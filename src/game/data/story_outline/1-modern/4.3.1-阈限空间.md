# 模块定位与体验目标

阈限空间不是某一名异能者主动建造的领域，而是所有异能者的能力在无意间相互串联，最终形成的异能网络。每名异能者的能力都可能在网络中留下一个区域、规则或通道，因此它可以随着新异能者和新故事长期扩展。

永拘迷宫只是阈限网络的一部分，由其中一名异能者的能力建立。建立者知道阈限网络存在，并会主动借用其他异能区域强化监禁。她只能对已经留下永久拘束标记的目标封闭、复制和移动空间，不能凭空创造阈限网络。她受到国外夜栈会及其在国内扶持的某家大型企业犯罪链驱动，为其建立绝对无法逃脱的异能者收藏空间；这家企业同时涉及人口贩卖等犯罪。建立者试图进一步封锁璃落时，两个异能区域发生短暂重叠，使璃落第一次意外穿过永拘迷宫的能力边界。

这次误入最终让璃落从现实中的废弃建筑离开网络。此前没人能从永拘迷宫里出来，外界也就始终无法准确定位它；璃落却仍带着建立者留下的永久拘束标记。她先找到姐姐沈芷，再共同组织一次接近都市线大结局规模的群像救援：异常灾害处理组织负责稳定入口，紧缚社团成员负责在迷宫中寻找并照顾受害者，过去获救的异能者提供内部情报，重要角色也借此集中登场。众人依据标记与施术者之间的联系反向定位永拘迷宫，重新进入并营救仍被困在里面的人。

# 故事体量与核心差异

本条不设定一次性的固定体量和层级上限，而是一个可无限扩展的支线探索区域。当前只需立住“所有异能无意串联的网络”“永拘迷宫是其中一个子域”与“后室式大迷宫”三个核心特征，不预先写死所有楼层、实体和规则。

# 游戏流程

第一次进入发生在永拘迷宫主线中。建立者试图借用其他异能区域强化封锁，却造成两个区域短暂重叠。双臂无法使用的璃落不能用手开门，只能以身体撞击墙面寻找薄弱处；其中一面墙突然失去实体，她来不及停下，直接跌入阈限网络的泳池空间。

首次进入时，璃落仍保留永拘迷宫主线中的永久拘束状态：双臂无法使用，双腿并拢束缚，只能跳跃移动。泳池空间中的积水会改变跳跃移动，玩家需要利用漂浮物调整路线并寻找出口。璃落最终从现实世界的一座废弃建筑离开网络，随后寻找外援并设法返回永拘迷宫救人。

群像救援打破永拘迷宫的封锁后，建立者失去对迷宫的控制，却趁阈限网络混乱逃入更深处。她没有在本次事件中被捕，也不会只作为一次性漏网者退场，而会成为后续支线中持续追踪、反复交锋的长期 Boss。她藏身的层级、每次交锋形式和最终结局暂不在本条中确定。

永拘迷宫主线结束后，阈限空间改为可随时进入和离开的长期探索区域。建立者失去控制后，璃落身上的永久拘束标记不再具有强制控制效果，只保留永拘迷宫的空间坐标功能。该坐标可用于确认旧迷宫位置，但璃落后续探索不必固定从这里进入，阈限网络还可以开放其他入口。玩家每次进入前可自行选择璃落的拘束组合，但不允许无拘束进入。找到当前探索路线的出口后即可离开，没有死亡、任务失败或强制清空进度条件。已发现层级、可靠出口、规则笔记、收集物、现实出口位置以及不同拘束组合的通关记录都会长期保留；迷宫路线可以变化，但已经验证的规则不会被清空。

# 地图与探索设计

阈限空间是可无限扩展的大型迷宫网络，而不是需要现在一次定完的固定关卡。当前首个确认层级是泳池空间：积水影响璃落的跳跃移动，漂浮物可以用来改变可行路线。水位变化、漂浮物的具体操作、出口辨识方式与本层结束点仍需补充。后续可随新异能、新人物或新怪谈逐步增加其他区域。

新增区域只需遵守共同逻辑：它是某种异能在网络中留下的结果，应具有可辨识的空间规则、出口判断和对当前拘束状态的影响。不要为了补完本条而提前写死层级数量、连接顺序或所有实体。

# 玩法设计

主要玩法引用“连续迷宫探索”（gameplay-002），核心参考后室：进入一个异常层级，观察空间规则与重复变化，在当前拘束状态下继续前进，最终找到出口并决定离开或进入下一段探索。

- 首次剧情状态：双臂不可用，双腿并拢束缚，只能跳跃移动。
- 首次层级变化：泳池积水会改变跳跃路线，玩家需要借助漂浮物移动。
- 主线返回方式：以璃落身上的永久拘束标记为联系，反向定位标记施加者所在的永拘迷宫。
- 建立者能力边界：只能对已有永久拘束标记的目标封闭、复制和移动空间，不能创造阈限网络。
- 通关后自选状态：可选择不同拘束组合，但至少保留一项拘束。
- 目标：每次探索只需找到一个有效出口，不设唯一终局。
- 失败条件：无。迷路、循环或进入错误层级都是探索过程，不进入失败结算。
- 进出规则：首次由永拘迷宫中的偶然误入触发；该主线结束后，可随时进入，并在找到出口后随时离开。

# 群像救援与结局

本次反攻发生在都市线接近大结局的位置，承担让既有角色再次登场的群像段落。异常灾害处理组织维持从永久拘束标记反向定位出的空间入口；紧缚社团成员进入迷宫寻找散落的受害者，并在撤离过程中照顾身体和精神状态不稳的人；过去获救的异能者根据自身经历提供内部情报。璃落与沈芷共同参与核心推进。

救援破坏永拘迷宫的控制结构后，建立者失去迷宫控制权并逃入阈限网络深处。她背后的夜栈会与国内大型企业犯罪链仍未完全瓦解。建立者此后作为支线长期 Boss，在不同层级和相关犯罪链事件中持续出现；本次获救者范围、首次追捕线索、后续交锋阶段与国内企业身份继续保留为后续决定。

# 长期探索记录

阈限空间的长期进度包括：已经发现的层级、确认可靠的出口、玩家整理出的空间规则笔记、带回现实的收集物、现实出口位置，以及不同拘束组合下的通关记录。后续再次进入时，空间路线可以重新组合，但已经确认的规则与记录继续可用，让每次探索都建立在过去的发现之上。
