# 游戏流程

## 原稿已确认内容

璃落在兼职群里发现一份报酬丰厚的工作邀请：道具展示拍摄任务。工作内容包括绳缚展示和束缚服装试穿，约定当天到场，坐他们自己的车去一处郊外废墟处拍一组废弃楼房中的绳艺照片。璃落决定接受这个委托。
赴约当天，璃落只简单通知朋友自己外出办事后便按约定前往集合地点。上车后不久，她察觉路线越来越偏僻，正要询问情况时却被绑匪用扎带反绑双手。为保护自身安全，璃落选择暂时配合以麻痹绑匪警惕性。
行进途中遭遇大雨，汽车陷入泥泞道路抛锚。趁着混乱，璃落迅速挣脱束缚并踢开看守成功逃脱。慌不择路之下选择了林间路径，雨势渐停时因地面湿滑接连摔倒，不仅弄丢鞋子还沾满泥浆。这副狼狈模样反而给了绑匪可乘之机，他们迅速将璃落制服并这次连双腿也一并捆缚。嫌恶璃落身上的泥污，绑匪选择直接拖拽她返回据点。（因为是泥地，不会受伤，只是会很狼狈）
因抛锚事故全员被迫在当地过夜，但作为逃跑的惩罚，璃落被严密束缚在灯光下整夜不得动弹。雨后的丛林中，还暴露在灯光下，蚊虫很多，璃落开始时还可以通过晃动身体驱赶蚊虫，结果被绑匪看到后竟然把璃落全身上下除手指脚趾外都捆绑严密，导致只能任由蚊虫叮咬，整个背部几乎落满蚊子都丝毫没有办法。
深夜当绑匪放松警惕之际，璃落忍受着满身蚊虫叮咬带来的不适感，悄悄取出藏在衣物内的折叠刀，成功割断部分绳索获得行动能力。
然而逃亡路上并不顺利。璃落不慎触发村民设置的捕猎陷阱被巨网罩住吊在半空。逃脱希望渺茫，她被迫再次落入绑匪手中。这次绑匪用扎带将她捆缚得更加严密，甚至不放过手指这样的细节部位。
返回途中遭遇山体滑坡事件，绑匪注意力被转移之际，璃落抓住机会挣脱控制，连同身上的网具一起滚下山崖逃脱。虽然全身仍被束缚，但至少暂时摆脱了绑匪控制。
