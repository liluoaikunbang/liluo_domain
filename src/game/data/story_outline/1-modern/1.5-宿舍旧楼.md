# 模块定位与体验目标

荆锁会事件3，对应璃落被校园霸凌事件。

## 已确认方向：宿舍旧楼的纵向时间电梯

旧校区宿舍楼的电梯不按楼层升降，而是在同一地点的不同年份之间停靠。璃落与林沐遥每次进入旧案，都从这部电梯抵达过去的宿舍楼：门外可能是十年前的装修现场，也可能是多年后的废弃楼层，或一处从未出现在现行校园图纸上的地下层。

电梯抵达的历史时间层中，校园仍使用“荆江大学”这一旧校名；现实中的校园仍为荆南大学。时间电梯是本旧案的主要调查入口，玩家通过比对同一空间在不同年代留下的痕迹，逐步确认校园霸凌旧案与荆锁会的关联。原有旧案人物、废弃厂房追查和结局方向保持不变；各年代的具体停靠规则、证据与可玩流程留待后续设计确定。

## 原稿已确认内容

进入旧案的正式入口调整为宿舍旧楼电梯。旧版“从拆迁小巷进入旧校舍”的段落保留其作为异常引发与现实调查背景的价值，但不再作为每次进入旧案时间层的主要方式；具体如何与电梯首次开启衔接，待后续流程设计确定。

过渡：林沐遥起夜下床时不小心踩到璃落，她被踩醒后顺手拍了对方小腿一下，对方也笑着用脚在她身上踩了几下，正好被来串门的班长撞见。班长立刻制止，说现在学校对校园霸凌查得很严，小心被人举报。舍友却笑嘻嘻地说是在“奖励璃落”，惹得一屋子女生起哄，顺口调侃璃落是不是有奇怪的爱好。璃落心里确实有点偏爱林沐遥柔软的小脚，却只能装作嫌弃。
话题很快被班长岔开，大家讨论间说起这条严厉校规当年就是为了防止旧校舍里那位“跳楼学姐”的悲剧重演，宿舍里你一言我一语地把当年的传说翻出来，现在那里已经成了校园十大灵异传说之一。只是，刚刚经历了舞蹈教室的灵异事件的璃落此时没法再对所谓传说一笑置之了。当日午睡时，也许是日有所思夜有所梦，璃落做了一个浅浅的梦，梦里自己站在旧校舍顶层的走廊，灯光忽明忽暗，窗外风声很重，她还没看清细节就被惊醒，只记得旧楼的走廊、楼梯的角度，和一股压抑的窒息感。
醒来时却发现自己正站在一条狭窄的小巷里，校服还穿着，她却完全不记得自己怎么走到这里来的。林沐遥气喘吁吁跟在后面，一脸后怕地说她刚才像梦游一样从床上起身，一路朝旧校舍方向走来，她不敢贸然叫醒，只能一路跟着保护。两人想往回走，却很快发现小巷像迷宫一样不断把她们绕回原地，手机导航失效，信号消失，天色还以肉眼可见的速度暗下来，街区仿佛被整块从城市里切割出去，周围的墙皮比记忆中更破败，空气安静到只剩脚步声和呼吸声回响。那种被封闭空间困住的压迫感，让璃落一下子想起初中时的那次霸凌：几名女生打着“支持沈芷、打倒私生女”的旗号，把她双手绑住拖进这片拆迁区，丢在这条巷子里任她自生自灭，她在黑暗里一圈圈摸墙找出口，哭到嗓子哑，也没人来救，最后靠着对转角和矮墙的记忆，绕了一整夜才爬出去，从此染上幽闭恐惧。如今同样的孤独感再度袭来，却也逼着她冷静下来，她沿路回忆当年走过的每一个岔口，确认这条巷子和当时几乎一致，便干脆按旧路线带着林沐遥折返，翻过一处半塌的矮墙，顺着只在本地人才知道的简易通道钻出去。墙那边，正是旧校舍背面的空场，她们一脚踩上去，才发现天已经彻底黑了下来，整栋旧楼像一块单独立在暗处的影子，成为后来所有正式调查与催眠回溯的入口。
翻出矮墙后，身后的小巷像被整块吞进黑暗，连刚才翻墙的位置都辨不出来了。璃落一脚踩在旧校舍后院的水泥地上，腿还在发软，本能想原路退回去，却发现手机完全没信号、时间显示也出现卡顿，整片拆迁区安静得诡异，只有旧楼侧门那一盏应急灯在远处忽明忽暗。她一想到自己小时候就是从这片方向被拖走、关在小巷里一夜，幽闭感立刻压上来，脚下像被钉住。反倒是林沐遥先冷静下来，她一边牵住璃落的手，一边很实际地判断：现在天色将暗，身后是整片无人的拆迁地和刚才怎么也走不出去的小巷，往回走风险更大，从旧校舍穿过去至少有保安和监控，出事也好求援。她安抚璃落“先进楼，从前门绕回教学区”，硬是拉着人往应急灯方向走。
推开侧门，旧校舍内部比想象中完整，走廊空荡却没有刚才小巷那种窒息感。林沐遥一边用手机微光照亮前路，一边嘴上碎碎念缓解气氛，同时把每一层的楼梯口和安全出口位置记在心里，以防真出事时可以迅速撤离。璃落本来只想尽快从一楼穿过去，眼角却在抬头时扫到楼顶旗杆的轮廓，心口莫名一紧，总觉得那里有什么东西在“等着她想起来”。她停下脚步，顺着这种熟悉又压抑的感觉抬头盯了几秒，忽然说不清缘由地拉了拉林沐遥，让她先别去前门，陪自己上楼看一眼。两人于是改道，从侧楼梯一层层往上爬，越靠近顶层，璃落的心跳越乱，脑海里浮出断断续续的画面：昏黄天光下的旗杆底座、被人围着的背影、有人蜷缩在地上。等她们推开通往天台的小铁门，冷风卷着铁件撞击声扑面而来，空旷的平台上只有一根挂在栏杆上的绳子在风中晃动，绳结的位置隐约留着勒痕，角落水泥地上有被水渍冲刷不掉的暗色斑点。璃落盯着那根绳子发怔，记忆被彻底戳穿：当年她就是被几个打着“支持沈芷、对付私生女”名义的女生哄骗到旧校舍，在旗杆旁看到一位学姐被绑在底座边，校服破烂、通身是伤，嘴里全是血，她悄悄给对方喂水，手刚摸到绳结，楼道那头就传来脚步和笑声，学姐用尽力气把她推开，让她“赶紧跑”。她那时照做了，逃命的本能盖过一切，之后把这段记忆连同内疚一起封死。如今站回同一处天台，风声和铁链声把那一夜全数推回她脑中，也让她想起来：当时所谓“跳楼学姐”的新闻，大概就发生在她回去之后没几天。
站在旗杆下，璃落记忆彻底贯通，想起当年那位学姐在被人松绑前最后一刻还抓住她的手，让她去找治安官，去抓“年级主任杜铮”。她把这个名字低声说给林沐遥听。学姐的残影没有攻击任何人，只把脚边的影子一次次拖向旧楼外侧；两人循着方向穿过废土，进入与旧校舍隔墙相邻的一座废弃厂房继续找线索。

厂房里盘踞着几个附近的小混混。领头的是一名黄毛杀马特女孩，她平日做的只是带着小弟闲逛、占地方和向闯进来的人收一点所谓“保护费”，从未接触过杀人之类的事情。她拦住璃落时装得很凶，璃落不想耽误查案，问清价钱便干脆付了。黄毛女孩反而被她的爽快弄得一愣，随即一本正经地表示收钱就要开收据。她摸遍口袋才发现没带纸笔，只好先保证一会儿补上，再带着小弟离开。所谓收据只是她亲手写的纸条，没有任何法律意义；但她把这套莫名认真的流程当作正经规矩，也成为她看似胡闹、实际并不坏的第一处反差。

璃落和林沐遥在厂房旧物中找到一块锈蚀的小金属牌。牌面刻着简化的锁孔、编号和一道代表“废弃样本”的斜划，与璃落锁骨暗纹的结构近似。线索重新指回宿舍旧楼，两人回到楼内准备报警，却在楼梯口被跟踪而来的杜铮撞回墙上。他一眼认出璃落，挥拳时林沐遥本能地把璃落往后一推，自己挨了一记，被砸在栏杆边昏了过去，只来得及将手机塞进璃落手里，让她“先跑”。璃落很快在侧楼道被追上，被杜铮用扎带反剪双手、捆住脚踝，拖到旧楼后一块废土边的浅坑旁。他一边填土，一边咒骂“当年就该一并处理掉”。

璃落抓紧金属牌拖延时间，旧楼里的灯光、风声和旗杆绳索随学姐残影出现异常，却只能警示、指证和干扰，不能替她击倒现实中的凶手。真正打断凶案的是去找纸笔后折返回来的黄毛女孩。她本来只是惦记着漏开的手写收据，刚到旧校舍便看见杜铮正在伤害自己刚收钱答应保护的人，当场觉得这既欺负人又砸了自己的招牌。她带着小弟冲上去拉开杜铮；几个人都只是普通小混混，靠人数、吵闹和突然介入让杜铮措手不及，阴差阳错阻止了凶案，并立即救开璃落、查看林沐遥的伤势和报警。

杜铮被控制后，学姐的影子仍没有散去。她无法直接抬手指路，只能让脚边的影子反复朝旧校舍外墙的某个角落拖拽，连风吹旗杆绳的方向都在那一块墙上打弯。众人顺着痕迹找到一间被混凝土和木板封堵的小房间。木板的一角已经被风雨掀开，水泥封堵下方存在细微塌陷。治安官赶到并接管现场后，从下方发现被草草覆土的白骨和一个锈死的铁箱；箱里装着几名女孩的学生证、破损校服碎片、一次性扎带、药瓶，以及数枚同类封印编号牌。最上面的学生证属于那位学姐，背面的“在读”被划掉，改成了“已毕业”。
璃落这才意识到，学姐并非单纯的校园受害者，而是和自己一样，曾被荆锁会以体检数据筛选为试验品，失去价值后被丢给杜铮“处理”。杜铮在这片废弃区域长期囚禁、折磨这些被判废弃的女孩，直到她们自尽，这片荒地底下埋着不止一具尸骨。治安官逐一登记铁箱里的学生证时，璃落隔着警戒线念出每一个名字，郑重承诺自己会继续追查荆锁会，不让她们再被当作“个案”掩盖。学姐的影子随后与几道对应学生证的模糊轮廓一起在晨光中淡去。就在璃落以为一切结束时，脚踝忽然传来冰冷收紧的触感；她低头发现自己双脚上多了一对与手腕灵锁同款的镣铐，冷调玫瑰金环扣住脚踝，外侧刻着荆棘与编号，内侧有尚未完全显形的咒纹轻轻发痒。
后续的事情就不归璃落管了，姐姐说杜铮杀过那么多人，死刑是免不了的，现在就看治安官机构那边能从他嘴里挖出多少组织的信息了。
