# 主线定位

“重返荆江市”不是立即进入最终决战，而是让璃落带着此前积累的经验重新进入熟悉城市。主线依次展示地下异能者猎人、合法异能者日常社会、普通企业犯罪与异常空间，使最终敌对组织不只表现为单一超自然反派，而是能够利用公司、机构、运输链和异能者执行者长期运作的城市网络。

# 已确认方向

- 《小小女仆团》让璃落确认自己被地下异能者贩卖势力盯上。
- 《荆江第七异能适应学校》展示合法异能者的教育与日常生活，避免把异能者等同于犯罪者或异常灾害。
- 《消失的夜班车》以工业园失踪案作为第一宗完整城市调查，引出璃落的独立调查员身份。
- 《城市调查员》作为长期支线入口，收纳丝袜厂、金属厂等由普通人或异能者制造的人为案件。
- 异常灾害处理组织主要负责灵异、异常空间和灾害级事件，不负责一般企业犯罪；只有调查对象升级为异常灾害时才作为专业外援介入。
- 后段仍通过《浮华剧场》《静默矫治中心》《永拘迷宫》逐步接近罪恶异能者组织及都市线大结局。

# 推荐主线阶段

1. **重新暴露在猎人视野中**：小小女仆团事件揭示公司买凶与夜栈关系。
2. **认识合法异能者社会**：七校补足普通异能者生活与能力边界。
3. **第一次主动调查人祸**：夜班车失踪案让璃落完成接案、取证、潜入、救援和移交。
4. **城市网络逐渐汇合**：工厂支线提供可选证据和受害者关系，主线继续追查更大的机构与异常空间。
5. **反攻永拘迷宫**：多方盟友共同救援受害者，建立者失去控制后逃入阈限网络深处，成为后续支线的长期敌人。

# 留待正式主线设计时确认

城市调查支线收集到的证据会以何种方式影响最终主线，金属厂等后续工厂各自涉及何种犯罪，以及《消失的夜班车》与《浮华剧场》之间使用哪条直接线索衔接，仍需在相应普通节点中确认。
