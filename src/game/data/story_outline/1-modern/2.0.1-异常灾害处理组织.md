# 游戏流程

## 原稿已确认内容

封印过后，协会让璃落去医院查一查，毕竟接触了那么久的阴气，总会出现一些身体不适的症状，虽然医学解决不了根本，但也可以养一养身体的。

结果璃落到了医院后就在这里遇到了大型灵异事件。与病娇女孩一起合作破坏了对方的计划，当然病娇女孩主要的目的是救她心爱的医生小姐姐。这里可以有璃落穿护士装被绑的情节，穿护士装的契机就是志愿帮忙时需要

石膏固定，适合放到医院灵异事件中

这件事情后，三人经常一起出去玩，因为璃落加入了她们的两人小团体，让病娇女孩感到了危险。这次三人被绑架，起因是璃落，医生小姐姐和病娇女孩是被误绑的，这次绑架让病娇女孩认为璃落会给她的爱人带来危险。（这里面可以有一个情节就是璃落帮病娇女孩解开了束缚，但病娇女孩却不帮璃落解开，还会给她加固束缚，当然最后璃落还是被救了，因为病娇女孩还是报了警，这也体现了她病娇不严重并不是想害人，只是在报复璃落）

胶水，捆舌头，自己捆自己（绑架璃落朋友，让璃落自己捆自己）等玩法都可以放在那里

气味调教方面，可以自产自销，一边挠痒一边让她闻自己的袜子。驷马跷跷板，拽头发和脚掌，且腰疼。

玩到璃落哭出来，才给她解开安慰她，安慰好了之后接着玩

最后医生朋友及时回来组织了病娇女孩，璃落才发现病娇女孩非常听医生的话，哪怕让她穿上拘束衣也很乖。璃落表示不介意病娇女孩的绑架，她们的故事线以璃落参加她们的婚礼结束。之后她们正式确立了关系，病娇女孩对璃落的敌意就不那么大了。

后面璃落是要做病娇女孩的伴娘的，是她亲自邀请的，也可以理解为对璃落的道歉。不过婚礼上时她身为女方唯一的伴娘被大家玩的很惨
