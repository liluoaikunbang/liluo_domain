# 模块定位与体验目标

“病房苏醒”是都市线第一个普通剧情模块，承接“荆锁会事件”主线容器。它不再只是一次常规会诊，而是一段安全等级因事件而改变的住院恢复故事。璃落初醒时攻击性低，病房内只使用不包含束手套和束脚套的基础保护，并可在封闭活动区进行较轻约束的放风。她为恢复身体原主记忆接受梦境种子植入后，才因副作用首次看见女鬼，并在无法判断威胁的恐惧中胡乱伤人。

误伤事件使医院升级保护措施：“病房约束”回到同一构图，但叠加束手套和束脚套两个现有差分，让玩家一眼看出她从低风险观察转为严密保护。后续不再回到宽松的封闭放风，而是在加强约束、近距离陪同与固定路线下尝试室外放风。璃落通过重新辨识女鬼、提前求助与停止攻击，逐步证明自己能够与新感知共处。

梦境种子原本只负责帮助璃落接近身体原主被创伤封锁的记忆，“看见鬼魂”并不在预期疗效之内，而是植入后才出现的副作用。它没有制造鬼魂，但让璃落能够感知原本就存在的灵体。训练中同时出现三种容易混淆的对象：现实里真实存在的人、只会重复旧日动作的记忆残影，以及能够察觉并回应璃落的真正鬼魂。玩家要和璃落一起建立辨识规则，而不是在会诊里被动听完全部设定。

沈芷仍掌握荆锁会的大部分内幕，却担心预先给出答案会污染璃落恢复出的记忆。许知遥负责治疗边界与风险控制；无名女鬼则成为本条的异常核心，她似乎认识身体原主，但只通过注视、动作和少量回应留下后续线索。

# 故事体量与核心差异

本条为 35 至 45 分钟的短篇序章，使用市医院单人病房、封闭活动区和室外庭院三组场景图，按“安全基线—植入—失控—加固—重新外出”六阶段推进。本条始终以互动小说的场景图切换、文本选择、CG 与代码闪回演出完成。

它与普通失忆序章的核心差异，是先用两组现有 CG 建立“璃落原本并不危险”的基线，再让玩家亲历副作用导致的突变。病房约束 CG 的基础图与两层约束差分被当作同一构图的前后对照，而非三张没有因果的收藏图。

# 玩家进入与离开

## 进入条件

沈芷已经组织人员完成对荆锁会据点的秘密救援。璃落经过紧急检查后在荆江市市医院恢复意识，剧情从她第二次稳定醒来开始，不重演据点战斗与撤离。

## 初始位置与初始状态

璃落位于市医院单人病房，穿着保护性拘束衣，行动范围受观察规则限制。此时她尚未植入梦境种子，也看不见鬼魂。玩家可以推进文本、观察床边环境、查看身体状态并回应沈芷；尚不能自由离开病房。

## 完成条件

璃落完成植入后的病房辨识与严密约束下的室外适应，确认自己能够看见鬼魂，并能区分现实人物、记忆残影与真正鬼魂。梦境种子开始稳定记录现实共鸣，许知遥确认她可进入更长期的恢复评估，后续由《重返校园》承接。

## 失败、中断与返回

本模块没有永久失败结局。辨识错误会触发璃落惊慌、头痛或短暂退出记忆空间，随后从本阶段最近的观察点重试；中断后从当前阶段恢复。通关后可从剧情回看重新观看三组 CG，不重复写入状态。

# 游戏流程

## 阶段一：低攻击性的病房观察

- 玩家目标：确认自己已经获救，并理解当前保护措施。
- 状态基线：璃落穿着基础保护性拘束衣，但手指和脚趾尚未加装专用护套；她能正常回应医护，没有主动伤人倾向。
- 演出：场景动画从监护仪和床边环境转入“精神病院-病房约束”基础 CG，基础图不启用束手套与束脚套差分。
- 阶段结束条件：许知遥将她评估为低攻击风险，批准一次封闭放风。

## 阶段二：植入前的封闭放风

- 玩家目标：在封闭活动区完成简短走动与常规评估。
- 约束级别：相比病房允许更多移动，仍由医护陪同，但不使用束手套和束脚套。
- 演出：移动动画衔接“精神病院-放风时间”CG，强调璃落能安静观察他人、遵循路线并正常返回。
- 阶段结束条件：她连续完成指令，许知遥与沈芷才开始讨论梦境种子。

## 阶段三：梦境种子植入与女鬼惊现

- 玩家目标：理解梦境种子只用于建立记忆入口，并由璃落本人同意植入。
- 闪回画面：许知遥执行植入时，用代码制作光效、失真、暂停与黑场切镜，让霸凌系列 CG 以短促碎片快速闪回，表现梦境种子触及身体原主的创伤记忆。现有素材已足够，无需新增一张完整 CG。
- 突发事件：无名女鬼在现实人物背后突然出现，并向璃落靠近。璃落无法判断只有自己能看见她，把试图安抚的人当成与女鬼同伙。
- 叙事处理：画面在女鬼靠近时失焦并切黑，误伤只由文字带过，不描写具体攻击动作，也不播放误伤 CG 或动作动画。
- 阶段结束条件：文字说明璃落在惊慌中误伤靠近的工作人员，画面直接跳转至事后的加固病房。

## 阶段四：惊慌误伤与约束升级

- 玩家目标：从紧急制止后的碎片画面中理解“看见女鬼—恐惧失控—误伤他人—升级保护”的完整因果。
- 演出方式：本阶段从事后开始，用简短文字回顾医护疏散、沈芷呼唤和紧急制止；不回放误伤过程，不为误伤新增 CG 或动画。
- 演出：回到“精神病院-病房约束”同一构图，同时启用“束手套”与“束脚套”两层差分，表现手指与脚趾都无法再直接伤人。
- 状态变化：写入“梦境种子产生看见鬼魂的副作用”“曾因鬼魂惊慌误伤他人”和“医院保护级别升级”。

## 阶段五：加强约束下的重新辨识

- 玩家目标：在病房内用可验证的方法区分现实人物、记忆残影与真正鬼魂。
- 必须交互：用视线选择对象，观察动作是否重复、是否留下现实反馈、是否能回应只有璃落知道的信息。
- 限制作用：玩家无法移动或进行攻击动作，但可以停止观察、闭眼、呼唤许知遥或请求沈芷重复事实。
- 阶段结束条件：璃落不再把女鬼的靠近自动理解为现实人物要伤害自己，解锁“灵异辨识：基础”。

## 阶段六：严密约束的室外放风

- 玩家目标：在更开阔的环境中面对女鬼重现，使用停步、辨识和求助替代攻击。
- 安全条件：束手套与束脚套保留，增加近距离陪同、固定路线和随时中止的返回点；这是误伤后的首次室外放风，不是早期封闭放风的延续。
- 演出：庭院动画转入“精神病院-外出放风”CG，定格严密保护下的第一次远距离重逢；“脱鞋”差分不进入本条主线，因其与当前严密约束的安全逻辑不一致，仅保留在 CG 回看中。
- 阶段结束条件：璃落完成固定路线，女鬼靠近时没有攻击他人，并能复述自己看见的与现实中发生的不同之处。

# 场景呈现

无可行走地图不等于无场景图。互动小说中的每个剧情场景都必须有对应场景图，场景图承担地点、时间、光线、气氛和人物所处环境，CG 只负责定格关键瞬间，不能长时间替代场景图。

- 市医院单人病房场景图：用于初醒、植入说明、植入执行与误伤后辨识；可通过明暗、失焦和监护仪光效表达前后状态，无需为同一房间拆成多张。
- 封闭活动区场景图：用于植入前的轻度约束放风，画面应能容纳医护陪同和其他活动人员的站位。
- 市医院室外庭院场景图：用于误伤后的严密约束外出放风，需保留陪同人员、女鬼与璃落之间的距离层次。

三组场景图之间只通过文本章节、过渡特效和 CG 衔接，不设置自由行走或空间搜索。

# 角色与 NPC 安排

- 璃落：玩家角色。从无法判断所见真伪，到能够记录证据、套用辨识规则并主动回应鬼魂。
- 沈芷：救援组织者和主要照护者。她相信璃落的感受，但继续隐瞒可能污染记忆恢复的荆锁会内幕。
- 许知遥：负责创伤评估、梦境种子植入和逐级暴露训练；她用可验证反馈帮助璃落建立规则，不把灵异感知简单诊断成幻觉。
- 无名女鬼：本条异常核心。能够跨越现实与记忆层回应璃落，似乎认识身体原主，但身份、死因和目的继续保留为伏笔。

# 玩法设计

## 主要玩法

### 互动小说（gameplay-119）

- 使用阶段：六个阶段的背景切换、信息查看、辨识选择、CG 播放和断点续接。
- 基础循环：观察对象 → 获取现实或记忆反馈 → 判断对象类型 → 查看结果 → 进入下一观察点。
- 采用变体：线性章节推进、场景图切换、章节 CG 播放、信息顺序选择和阅读断点续接。
- 本条调整：会诊不再承担主循环，只在辨识前后提供规则与反馈；错误判断允许在当前阶段重试，不产生主线分支。
- 成功条件：完成加强约束下的首次辨识，并在室外阶段用求助替代攻击。
- 失败与返回：没有永久失败；错误会触发短暂惊慌或退出记忆层，随后返回最近观察点。
- 状态反馈：写入梦境种子鬼魂副作用、基础辨识和现实共鸣记录状态，解锁《重返校园》。

## 辅助玩法

辨识通过文本信息顺序选择完成。玩家依据是否重复、是否产生现实反馈、是否能够回应璃落三条规则辨识对象，规则会在后续校园异常中继复用。

## 成功条件、失败条件与反馈

成功条件是正确完成三类对象辨识，并在室外放风记忆覆盖现实后仍能到达终点、回应他人。没有死亡或坏结局；失败只表现为本阶段重试和角色状态反馈。

# 对话与玩家选择

对话选择围绕“我看见了什么”“它有没有回应”“这段景象属于现在还是过去”展开。玩家可以决定先观察还是先询问，也可以在最后选择点头或开口回应女鬼，但两种选择都收束到接受自身感知，不产生主线分叉。

沈芷不会否定璃落，也不会直接说出女鬼身份；许知遥不会把无法解释的现象包装成确定医学结论。正式台词仍需后续编写并登记对话 ID。

# CG 与关键画面

## 闪回演出组织规则

现有三组精神病院 CG 统一采用“场景动画进入记忆层 → CG 定格关键瞬间 → 场景动画恢复操作”的结构，但服务于不同时间点：基础病房与封闭放风建立植入前基线，病房差分回访呈现失控后的约束升级，外出放风表现后续严密保护。误伤过程不进入该结构，只以文字带过。

- 进入动画：保留璃落在当前空间中的位置，用光线、环境音、背景细节和 NPC 动作逐层替换现实信息，让玩家看见记忆覆盖正在发生。
- CG 定格：只承担本阶段最需要强调的身体状态、空间关系或鬼魂位置；CG 出现前后的角色站位必须连续。
- 返回动画：从 CG 同一构图附近恢复场景，播放鬼魂或残影的一个明确动作，再交还文本观察与判断选择。
- 中断处理：玩家跳过动画时可直接到达 CG，跳过 CG 时则回到返回动画；无论怎样跳过，都不能遗漏本阶段的辨识状态写入。

梦境种子植入不再要求新制作正式 CG。该画面位于“放风时间”之后、女鬼惊现之前，由代码特效与霸凌系列 CG 快速闪回组成，负责建立“植入完成 → 副作用出现”的因果起点。

### CG 1：精神病院-病房约束

- 首次出现：植入前的低风险观察。只显示基础图，不启用束手套和束脚套差分。
- 第二次出现：误伤后画面从切黑恢复，回到同一构图并同时叠加束手套与束脚套，用图像差异代替对升级约束的冗长解说。

### CG 2：精神病院-放风时间

- 出现时机：植入前的封闭放风。
- 具体内容：璃落在较少约束下安静走动，能理解指令并正常返回。该 CG 是“植入前没有主动伤人倾向”的证据，不出现女鬼。

### CG 3：精神病院-外出放风

- 出现时机：误伤后第一次恢复室外放风。
- 具体内容：璃落在束手套、束脚套、近距离陪同和固定路线下外出。女鬼接近时，她通过停步和求助继续推进；“脱鞋”差分不进入本条主线，仅保留于 CG 回看。

### 可制作闪回：梦境种子植入

该演出已具备制作素材，只差代码组装。制作时以当前病房为现实锚点，用短促白闪、色偏、失真、画面暂停和黑场串联霸凌系列 CG，每张只停留足以辨认的瞬间，再回到植入结束后的病房。女鬼在闪回结束后才出现，误伤只由文字带过。鬼魂并非种子凭空制造，但看见鬼魂的能力是此次植入带来的副作用。
