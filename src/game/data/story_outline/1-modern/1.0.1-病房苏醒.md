# 模块定位与体验目标

“病房苏醒”是都市线第一个普通剧情模块，承接“荆锁会事件”主线容器，负责交代璃落获救、身体原主记忆封闭、沈芷与顾棠的立场分歧，以及梦境种子的来源。

本模块不制作市医院可移动地图，也不把身体拘束转换成尚未确定的操作玩法。玩家通过线性互动小说推进对话、查看真实存在的医院与精神病院主题 CG，并在会诊阶段逐步理解：需要恢复的是这具身体原主被创伤切断的记忆，不是凭空为当前璃落补写一段经历。

体验重点是“从被救回的身体中重新建立自我位置”。沈芷代表保护与避免二次伤害，顾棠代表案件真相与其他受害者仍需追查，许知遥则负责把双方立场转化为可理解的医疗风险。最终决定必须由璃落本人明确作出。

# 故事体量与核心差异

本条为 10 至 15 分钟的短篇序章，只使用市医院病房、走廊和会诊空间的剧情背景，不建立自由探索地图。

它与普通“失忆主角醒来听设定”的区别在于，叙事必须通过身体状态、记忆碎片 CG、人物立场冲突和会诊问答逐层确认事实。三组精神病院 CG 表现的是身体原主在荆锁会设施中的破碎记忆，不是把安全的市医院再次画成恐怖机构。

# 玩家进入与离开

## 进入条件

沈家与顾棠已经完成对荆锁会据点的秘密救援。璃落经过紧急检查后在荆江市市医院恢复意识，剧情从她第二次稳定醒来开始，不重演据点战斗和撤离过程。

## 初始位置与初始状态

画面从市医院单人病房开始。璃落穿着医院用于保护性观察的拘束衣，手指和脚趾也处于限制状态。该状态只用于本模块的 CG 与剧情演出；玩家尚未获得地图移动控制，只能推进文本、查看画面和选择询问信息。

## 完成条件

璃落听完许知遥对记忆封锁与治疗风险的说明，确认梦境种子只提供进入身体原主记忆的通道，不直接制造或改写记忆。她在没有主线分支的前提下明确同意植入。治疗完成后，许知遥确认她可以进入以日常生活和复学为主的恢复阶段。

## 失败、中断与返回

本模块没有失败结局。中断后从当前对话段或最近一张 CG 前继续。会诊中的询问只改变信息展开顺序，不允许永久拒绝治疗，也不产生另一条主线。通关后可从剧情回看与 CG 图鉴重新观看，不重复写入状态。

# 游戏流程

## 阶段一：在安全病房醒来

- 玩家目标：确认璃落已经离开荆锁会据点，以及当前陪伴者的身份。
- 所在界面：市医院病房互动小说背景。
- 必须交互：推进沈芷的确认对话；查看璃落当前身体状态；确认自己只能记起孤儿、大学、数次绑架和精神病院折磨等零散信息。
- CG：以“精神病院-病房约束”及其现有差分短暂闪回身体原主曾经的病房状态，随后立即切回光线稳定的市医院。
- 状态变化：写入“已获救”和“身体原主关键记忆封闭”。
- 阶段结束条件：许知遥完成基础检查并确认可以解除当前保护性限制。

## 阶段二：听见走廊争论

- 玩家目标：弄清沈芷与顾棠为什么对恢复记忆持不同意见。
- 所在界面：市医院走廊剧情背景。
- 必须交互：听完两人的核心立场；由璃落主动现身，要求参与关于自己身体和记忆的决定。
- 自动事件：顾棠说明遗失记忆关联多起灵异事件与其他受害者；沈芷强调强行回忆可能造成二次伤害。
- 状态变化：开放会诊说明。
- 阶段结束条件：三人进入许知遥负责的会诊。

## 阶段三：确认身体原主的记忆问题

- 玩家目标：理解当前璃落、身体原主记忆与创伤防御之间的关系。
- 所在界面：会诊室互动小说背景。
- 必须交互：询问记忆属于谁、普通治疗为何无效、梦境种子会做什么、异常共鸣可能带来什么风险。
- CG：以“精神病院-放风时间”和“精神病院-外出放风”表现尚未形成连续叙事的身体记忆碎片；画面不替玩家直接确认碎片中的全部因果。
- 自动事件：许知遥说明荆锁会长期使用药物、催眠和痛苦实验，使身体原主的记忆形成严密的创伤防御。顾棠补充璃落对灵异现象的异常敏感可以成为进入这些记忆的媒介。
- 状态变化：确认梦境种子的目的为“在现实共鸣出现时打开记忆通道”。
- 阶段结束条件：所有必要说明完成。

## 阶段四：植入梦境种子

- 玩家目标：由璃落本人作出治疗决定。
- 所在界面：会诊室与治疗演出。
- 必须交互：玩家可按任意顺序看完补充问题，最终选择唯一推进项“我愿意试试”。
- 自动事件：沈芷确认不会在璃落拒绝继续时强迫深入；顾棠承诺只把恢复出的真实信息用于调查；许知遥执行植入并监测状态。
- 状态变化：写入“梦境种子已植入但尚未激活”。
- 阶段结束条件：璃落生命体征稳定，画面过渡到复学准备，并解锁《重返校园》。

# 地图与探索设计

本模块不使用 Phaser 地图。病房、走廊和会诊室只作为互动小说背景与镜头空间，避免为一次线性会诊新建无法复用的医院地图。

探索感由“可选择查看的信息”承担：玩家可以先查看拘束衣、床边物品、沈芷留下的照护痕迹，或先询问记忆和救援经过。所有必要信息最终都会收束，不因查看顺序产生分支。

# 角色与 NPC 安排

- 璃落：玩家视角角色；当前意识完整，但无法主动读取身体原主遭受荆锁会实验期间的关键记忆。
- 沈芷：完成救援的重要组织者与主要照护者；反对在风险不清楚时强行恢复记忆，但尊重璃落最终决定。
- 顾棠：治安官，也是负责处理灵异受害者与异常案件的成员；她知道遗失记忆关系到荆锁会和其他受害者，主张在安全边界内追查。
- 许知遥：市医院年轻女医生，负责璃落的创伤评估、会诊说明与梦境种子植入监测。她不属于荆锁会，也不代替璃落作决定。

# 玩法设计

## 核心玩法

核心玩法是线性会诊问答。玩家决定先了解哪类信息，以自己的阅读顺序建立事件全貌；主线结果固定为璃落在知情后同意治疗。

## 辅助玩法

记忆碎片 CG 回看用于区分“当前安全病房”和“身体原主过去的精神病院经历”。玩家可以重新查看已经出现的碎片，但碎片本身不直接提供未经剧情确认的案件结论。

## 成功条件、失败条件与反馈

看完必要说明并确认治疗即完成。没有错误选项和失败结局；遗漏的必要信息会由许知遥提醒。完成反馈包括梦境种子状态写入、复学阶段开放和《重返校园》节点解锁。

# 对话与玩家选择

会诊提供“记忆属于谁”“普通治疗为什么无效”“梦境种子如何作用”“可能遇到什么风险”四类询问。玩家可以自由选择顺序，也可以返回继续询问。

所有必要内容读完后只出现一个主线推进选择：“我愿意试试。”不存在拒绝后进入另一条剧情的分支。沈芷、顾棠和许知遥都不能替璃落确认。

# CG 与关键画面

- `精神病院-病房约束`：病房醒来时的第一段身体记忆闪回；差分用于表现手部和脚部限制细节，播放后返回安全市医院病房。
- `精神病院-放风时间`：会诊中解释身体原主记忆并非完全消失时出现，表现可见场景仍缺少连续因果。
- `精神病院-外出放风`：解释记忆会被现实共鸣重新唤起时出现，播放后回到许知遥的说明。
- 梦境种子植入：目前没有已确认 CG，只使用镜头淡出、声音和状态提示，不编造 `cgRefs`。

# 前后章节与世界状态衔接

前置为“荆锁会事件”主线容器开启。完成后进入《重返校园》，玩家第一次获得地图控制时已经知道梦境种子的用途，也知道恢复目标是身体原主记忆。

后续《舞蹈教室》触发梦境时必须沿用“现实共鸣打开记忆通道”的规则，不能把梦境种子改写成自动生成幻觉或外部角色强行操纵璃落的工具。

# 最小可玩版本

1. 一张安全市医院病房背景与一张会诊背景。
2. 病房醒来、走廊争论、会诊说明和植入演出四段线性剧情。
3. 接入三组现有精神病院 CG 作为身体原主记忆碎片。
4. 提供四类可排序询问和一个最终确认选项。
5. 写入获救、身体原主记忆封锁、梦境种子植入三个核心状态，并解锁《重返校园》。
