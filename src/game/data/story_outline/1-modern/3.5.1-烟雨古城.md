# 游戏流程

## 原稿已确认内容

民国系列

入口机制：旧物、旧地、旧案三种锚点

1. 旧物入口

璃落触碰某件旧物，被卷入物品对应的历史现场。

可以用：

1. 一张民国旧照片。
2. 一只旧式手铐。
3. 一张装甲列车车票。
4. 一封未寄出的情书。
5. 一本女校日记。
6. 一件戏服。
7. 一只旧皮箱。
8. 一枚租界巡捕徽章。
9. 一份报馆底片。
10. 一条红绳。
11. 一张军阀通缉令。
12. 一把洋楼钥匙。
13. 一份卖身契或戏班契书。
14. 一份失踪人口档案。
15. 一张西北探险地图。

比如：

璃落在现代旧货市场买到一只被红绳缠住的戏箱。打开后，里面是一件旧戏服和一张民国报纸。她再抬头时，自己已经站在一座灯火昏黄的旧戏院后台。

这就可以直接进入 梨园戏影。

2. 旧地入口

璃落进入某个现代废墟，空间发生折叠。

可以用：

1. 老戏院后台。
2. 租界洋楼衣帽间。
3. 废弃女校宿舍。
4. 旧火车站候车厅。
5. 码头冷库。
6. 旧报馆地下印刷室。
7. 军阀公馆地下室。
8. 民国医院手术室。
9. 老照相馆暗房。
10. 防空洞深处。
11. 旧银行保险库。
12. 旧教堂钟楼。

比如：

现代璃落调查一座将被拆除的旧女校。夜里她听见废弃宿舍传来上课铃声，走进走廊后，墙上的霉斑变成校规，窗外变成民国旧街。

这就进入 女校旧案。

3. 旧案入口

璃落先在现代接触到一桩悬案，调查过程中逐步被拖入民国。

可以用：

1. 现代连环失踪案，源头是民国人口交易旧案。
2. 现代老宅闹鬼，源头是军阀灭门案。
3. 现代戏院事故，源头是旧戏班冤案。
4. 现代学校怪谈，源头是女校学生失踪案。
5. 现代码头黑帮案，源头是民国船帮密约。
6. 现代考古失踪，源头是民国探险队旧档。
7. 现代异能组织，源头是民国异人局。

这个入口最适合长期主线。

它可以这样设计：

现代璃落调查一系列被称为“旧都回声”的事件。每次事件都会留下民国物证。她以为自己是在查历史，后来发现自己查到某一步时，会被历史反向拉进去。

烟雨旧都：民国线主线目录建议

1. 租界迷城

关键词：洋楼、巡捕房、租界、报馆、黑帮、舞厅、领事馆。

璃落进入一座被租界、商会、军阀、黑帮、报社共同撕裂的旧都。这里表面灯红酒绿，实则每条街都分属不同势力。

可写内容：

1. 租界巡捕房误抓璃落，把她当成某个失踪密探。
2. 洋楼舞会中发生枪杀案，璃落因为站在角落看见关键线索。
3. 报馆女记者追查人口失踪案，与璃落结伴。
4. 黑帮控制码头、赌场、仓库、戏院和拘押点。
5. 璃落被卷入“租界治外法权”带来的灰色地带。
6. 拘束元素可用手铐、封条、审讯椅、押送车、黑帮绳索、密室软禁。
7. 核心主题：现代法律来了，但并没有真正保护所有人。

2. 军阀铁城

关键词：军阀、装甲列车、军火库、旧式军营、铁路、情报站。

这条可以承接柴油朋克风。

可写内容：

1. 军阀控制铁路，把列车变成移动堡垒。
2. 璃落被误认为敌方密使，被押上装甲列车。
3. 女军官表面冷酷，实际想阻止一场屠城。
4. 军火库爆炸案牵出外国军火商。
5. 铁路线沿途有小镇、车站、兵营、废矿、边境关卡。
6. 装甲列车可作为大型移动副本。
7. 拘束元素偏军用：皮带、手铐、军规绑缚、审讯室、车厢押送。
8. 核心主题：乱世里，秩序常常只是枪口换了名字。

3. 梨园戏影

关键词：戏班、名伶、戏服、后台、戏台命案、真假身份。

民国风非常适合梨园线，而且和璃落的“身体被装扮、被规训、被观看”主题很契合。

可写内容：

1. 璃落躲进戏班，被迫暂时扮成小旦或随行丫鬟。
2. 戏班后台发生命案，死者身上的绳结与某出旧戏有关。
3. 名伶表面风光，实际被班主、金主、黑帮和旧契约束缚。
4. 戏服、长袖、水袖、凤冠、勒腰、戏台规矩都能形成华丽压迫感。
5. 某出禁戏藏着前朝秘闻或军阀罪证。
6. 戏班巡演路线可以串联城市、县城、码头、军营。
7. 拘束元素偏审美化：戏服限制、后台软禁、道具绳、舞台机关。
8. 核心主题：台上唱的是命，台下也逃不出命。

4. 女校旧案

关键词：女子学校、新思想、旧礼教、宿舍、校规、失踪学生。

这条能补足民国女性成长、都市怪谈和悬疑感。

可写内容：

1. 璃落进入女校避难，发现校内有学生接连失踪。
2. 校长提倡新思想，但背后与旧家族、教会或军阀有交易。
3. 学生分为新派、保守派、秘密社团、进步组织。
4. 宿舍夜谈、禁书、旧礼堂、地下通道都可做小副本。
5. 一个学生被家族强行带走，璃落卷入营救。
6. 校规看似现代，其实仍然延续旧式身体规训。
7. 拘束元素可用校规禁足、宿舍锁门、礼仪训练、秘密押送。
8. 核心主题：新时代的门开了，但很多女孩仍被关在门槛上。

5. 谍海暗线

关键词：特务、密码本、电台、暗号、双面身份、审讯。

这条是民国线最适合做互动小说分支的部分。

可写内容：

1. 璃落意外拿到一份密码本，被多方势力追捕。
2. 她不知道谁是好人，报馆、商会、巡捕房、军统式组织、外国间谍都在撒谎。
3. 电台密码、报纸暗语、香烟牌、旗袍扣子、戏票都可作为线索。
4. 一个温柔的女特务救她，但也在利用她。
5. 璃落可能被迫扮作舞女、学生、护士、戏班小厮传递情报。
6. 拘束元素偏冷峻：审讯室、手铐、眼罩、密室、转运车。
7. 核心主题：在谍战里，真实身份本身就是最危险的东西。

6. 民俗志怪

关键词：纸人、冥婚、旧祠堂、风水局、狐仙、河神、阴宅。

这条能和都市灵异、古风志怪连接。

可写内容：

1. 旧都边缘村镇发生纸人迎亲事件。
2. 璃落被误认为适合祭祀的人，被卷入河神婚约。
3. 旧祠堂里供奉的不是祖先，而是被封住的异物。
4. 一个风水先生表面骗钱，实际知道旧城地下的镇物。
5. 民国新警察不信鬼，老百姓不信警察。
6. 拘束元素可用红绳、纸符、嫁衣、祭祀绳、棺木封缚，但重点放在恐怖仪式和逃脱。
7. 核心主题：现代灯光照不散所有旧影。

7. 考古西行

关键词：古墓、沙漠、佛窟、探险队、文物争夺、盗墓者。

盗墓摸金 / 秘境夺宝模块

你有遗迹残片和考古探险，但“盗墓流 / 摸金流 / 秘境夺宝”本身是很典型的类型壳，比普通遗迹更有一套固定玩法。

核心是：

墓道、机关、风水、陪葬品、盗墓团伙、诅咒、粽子、黑市文物、墓主真相。

适合都市、民国、古风、魔幻、科幻先驱遗迹。

璃落可以被盗墓团伙当成开墓钥匙，也可以作为考古队随行者被迫与盗墓者合作。她娇小身体适合穿过狭窄墓道，但手臂旧伤和束缚状态会让逃生更困难。

束缚元素可以是墓室机关、石棺封缚、祭祀绳、陪葬人偶、盗墓者押送。
这个模块很适合做解谜型 RPG。

这条可以连接你已有的都市考古、古风遗迹和魔幻沙漠。

可写内容：

1. 一支中外混合探险队邀请璃落同行。
2. 目标是西北古城、沙漠佛窟、雪山遗迹或地下王陵。
3. 队伍里有教授、军官、翻译、盗墓贼、洋人赞助商、护卫。
4. 文物背后可能是命锁谕令留下的旧世界碎片。
5. 探险队内部不断有人失踪，地图被篡改。
6. 拘束元素可用盗墓机关、石室封闭、探险绳、押送、祭祀遗留装置。
7. 核心主题：他们以为自己在发掘过去，其实过去也在挑选他们。

8. 海港黑潮

关键词：码头、船帮、鸦片、黑市、海盗、旧上海式黑帮。

这条更偏黑帮与犯罪。

可写内容：

1. 璃落被卷入码头人口交易案。
2. 船帮、黑帮、巡捕、商会互相勾结。
3. 海港仓库是重要地图：货箱、暗门、地下水道、冷库。
4. 一个女黑帮头目既残酷又守规矩。
5. 海上走私线连接东南亚、岛国、租界和军阀。
6. 拘束元素偏犯罪押送：仓库绑票、船舱软禁、麻袋转运、码头交货。
7. 核心主题：海风吹来新世界，也吹来更隐蔽的买卖。

9. 旧都异人局

关键词：异能者、术士、机关师、现代与玄术混合。

这条可以把民国风和都市异能连接。

可写内容：

1. 政府秘密成立异人局，收编术士、异能者、机关师。
2. 璃落因为特殊体质被列为观察对象。
3. 旧式符箓与新式电磁设备结合，形成民国魔导感。
4. 异人局中有人想保护她，有人想研究她。
5. 上海式霓虹、电台、符阵、机关手铐、封印电椅可以混合。
6. 核心主题：现代国家机器开始接管神秘力量。
