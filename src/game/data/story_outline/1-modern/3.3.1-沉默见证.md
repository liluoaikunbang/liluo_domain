# 游戏流程

## 原稿已确认内容

一、人设与世界背景  
闻澜 三十岁出头, 全国知名调查记者, 以冷静理性和敢写敢发闻名, 长期追踪高层金融腐败与官商勾结案件。世界背景为近未来都市现实, 科技与医疗稍微超前, 出现少量半植入式医疗与感官调控技术, 但仍处在“试验与灰色应用”阶段。

二、导火索事件  
闻澜围绕一位掌控金融、基建和媒体资源的权势人物展开长期调查, 已掌握多条资金链、死亡事故与权力寻租的关键线索, 准备在跨媒体联合报道中投放。爆料前夕, 线人神秘死亡, 关键原始证据被人为销毁, 她本人在一次“车祸”“抢劫未遂”等日常事故场景中被秘密劫走, 对外被宣告重伤失语。剧情整体结构参考调查记者与强权对抗类作品, 由完整调查走向人身消音。

三、秘密拘禁与身体封印  
闻澜被送往反派控制的地下医疗机构, 被告知可以“保住性命”, 实际接受的是专门为封口设计的全身功能封印手术。  
手部: 双手在标准握拳姿势下戴上量身定制的金属五指铐, 指根与指节均有极细金属环和手背脊骨, 内侧焊死。术中在皮下绕入高强度生物纤维, 再注入软性高韧凝胶, 将皮肤、纤维和金属固定成整体, 永久定格握拳姿势, 只能做粗略摆臂, 不能展开手掌、握笔或敲键。  
足部: 双脚戴上趾环加足背链的脚趾铐, 脚趾自然并拢微弯, 皮下同样以纤维与软凝胶缝合趾间和前足, 保留行走与站立, 彻底剥夺用脚夹物、写字、打字的能力。  
发声: 声带周围注入发声软限凝胶, 声带仍可开合保证呼吸与吞咽, 但无法形成稳定振动, 唯一输出变成微弱气声与咳嗽。口唇与舌根进行“构音精度削减”处理, 不影响吃喝, 但嘴型模糊无序, 无法形成可读唇语。  
头颈: 戴上贴合颈线的金属项圈, 内部限位结构与肌电调制抑制大幅快速点头和摇头, 只允许缓慢小幅转动, 消解通过头部动作传递清晰“是”“否”的可能。  
眼睛: 通过局部神经调制提高快速眨眼的能量门槛, 日间几乎无法自动频繁眨眼, 每次闭眼与睁眼都缓慢吃力, 但仍能自主闭眼睡眠。配戴医疗级高保水隐形镜与诱发泪液机制, 角膜长期处于难受但安全的湿润状态, 既杜绝眨眼电码, 又不造成不可逆失明。感官输入全部保留, 视觉和听觉清晰, 认知完好。

四、伪装善后与“合法”身份  
手术结束后, 反派安排她以“罕见脑损伤合并严重运动失用与构音障碍”的名义送往正规医院, 病历中写满专业术语, 包括既往车祸、脑损伤瘢痕等, 让一切看似是“意外后的极端后遗症”。她被登记为重度残疾患者, 在精心控制的信息环境中被安置于长期护理机构, 以“精神状态尚可但表达障碍严重”的标签从公共视野中消失。

五、主角团队的发现与营救  
主角团队中有人因旧案或亲属关系留意到闻澜的“意外”, 在复盘她最后几篇报道与失踪时间时, 发现多条线索指向同一权势人物与一条被硬生生终止的调查。通过获取护理机构外泄的小视频与医疗记录, 他们逐步怀疑这是人为封口改造, 不是自然病变。团队以公益法律援助和媒体同行探访为由接触闻澜, 在确认其意识清醒、反应敏锐后, 通过法律与舆论施压争取到将她转移到更“人道”的康复中心, 实际由团队控制照护环境。

六、医学评估与封印不可逆的判定  
团队联系独立神经科和康复专家进行全套评估, 发现她的大脑功能、记忆力和理解力接近正常人, 但周身存在大量极难移除的金属与软凝胶结构, 移除风险包括大面积皮肤破坏、感染、关节废用等, 基本意味着要以截肢和彻底毁容换取部分解封。多学科讨论后结论是在当前条件下无法安全逆转, 任何激进行动都有可能直接致残甚至致命。团队放弃拆除封印, 转而讨论如何在尊重她意愿和身体安全的前提下, 安排其后半生和重新就业。

七、沟通规则与能力边界的重建  
为避免把她再次置于高风险状态, 主角团队制定严格沟通规则: 不试图通过复杂编码从她身上“榨出完整故事”, 不建立摩斯电码、字母表等高带宽系统, 只允许在有限选项中做简单选择。具体做法是, 每次交互时只摊开少量备选文件或陈述, 由他人朗读要点, 让她通过缓慢移动车里的握拳、按住某一页、轻敲某一份材料等方式表示“更重要”“有问题”“大致正确”。此类选择动作难以被精细控制成句子, 但可以表达相对判断。她的残余动作被限定在“筛选与校对”, 而非自由叙述。

八、新工作一: 内部证据筛查顾问  
团队为她设定正式岗位, 例如“调查部资料筛查顾问”。日常工作流程为: 调查记者先完成一轮初筛, 剔除明显无关材料, 将剩余的关键组团按案件分批放到她面前。每批只放三到五份文件或几段视频摘要, 同事简要朗读内容或摘要, 观察她视线停留和拳头移动, 询问“哪一份更值得跟进”, 由她用拳头按住或轻敲某一份表示选择。被她选中的材料会被标记为重点线索, 后续由团队继续独立深挖, 不依赖她提供具体细节。她凭多年记者直觉对文本和话语的敏感, 在大量阅读中完成实际筛查劳动, 对调查效率产生真实贡献。

九、新工作二: 事实核对与时间线校对  
在重大报道成稿前, 团队会将整理出的时间线和关键陈述打印成条目, 分段念给她听, 让她在“正确”“不确定”“错误”三类中做选择。桌面上划定三个区域, 她每听完一句, 便缓慢将握拳按在某一格上保持数秒, 由旁人记录。团队据此调整叙事顺序与措辞, 在不强求她说出“真正经过”的前提下用她的判断校正偏差。她在署名页内部被标记为事实核对顾问, 获得合理报酬, 以劳动者身份参与新闻生产链条。

十、生活自理与团队照护  
在团队与康复医生的设计下, 闻澜的居所被改造成高度简化但尽量接近日常生活的空间。衣物采用拉链与套头设计, 餐具与牙刷固定在护腕或支架上, 卫生间配置智能马桶与自动冲洗装置, 淋浴间以大面积防滑与少数可用扶手为主。她可以在缓慢节奏下完成吃饭、如厕、简单洗漱与更衣, 但仍需要每日巡查和定期协助洗头、清理皮肤与检查眼睛。她保有步行能力, 可以在团队办公区安静走动与旁听会议, 但任何外出行动都由队友陪同。

十一、心理变化与团队关系  
闻澜在获救后的初期有强烈愤怒与自责, 对自己无法亲口指证反派感到痛苦, 也对团队试图“利用”她的判断保持戒备。随着时间推移, 她逐渐确认团队坚持不以她的残余动作强行拼制造口供, 而是把她当长期同事, 按小时和项目付费, 允许她拒绝某些案件。她也逐渐接受自己从“发声者”转变为“沉默判别者”的角色变化, 在每一次选出关键材料、纠正错误时间点时获得稀薄但真实的成就感, 同时也清楚意识到自己再也没有机会完整讲述当年的真相。
