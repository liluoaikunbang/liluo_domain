# 游戏流程

## 原稿已确认内容

这里规定是允许法庭上禁止犯人辩护的，会给犯人堵嘴，于是璃落被强迫安排了罪名，之后被关进了监狱。

在监狱中璃落遇到的惩罚之一，就是压腿铐。先关在只能蜷缩着的小黑屋里面，像图片这样铐住后，给手肘上也上一道手铐，然后用绳索将手肘的手铐链接到屋顶，站不起来又坐不下，无比难受，璃落只坚持了几个小时就不得不求饶了。
![压腿铐](src\assets\game\outlines\1-modern\leg_press_cuff.jpg)

第一次入狱时官方不重视她，只是为了破坏交易，所以判了5年把她扔到普通监狱就算了，通过缩骨功得到狱霸赏识，在她组织的越狱行动中出力很大，璃落也就此逃离了监狱，还顺便将当时被官方抓走的那些被贩卖的女孩中的大部分也一起救了出去，后面她们都暂时在缄枷会落脚。但璃落也做不到将所有人都救走，有一些女孩还是留在了监狱，在璃落之后被抓严格监管后负责照顾她
