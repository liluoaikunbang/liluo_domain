# 游戏流程

## 原稿已确认内容

一、缄枷会的小头目把璃落拖进靠近码头的仓库，当场把她双脚分别固定在容器里，直接浇入混凝土。湿冷的浆体裹住脚面与脚踝，砂石摩擦带来刺痛与沉坠感，璃落很快意识到这不是吓唬，是把她从“能跑”变成“只能等”的处置流程。

二、小头目不急着下手，反而把等待硬化当作拷问计时。他让璃落保持清醒与可说话，一遍遍确认她藏匿的东西在哪里，逼她在混凝土逐步定型的过程里做选择。璃落拒绝交代，同时用零碎回答拖延时间，试图把局势拖进自己预设的备援节奏。

三、混凝土开始成型后，璃落的脚踝活动被一点点抹平，挣扎只会换来更明确的无用感。小头目当着她的面拨通林沐遥，开门见山要人要物，给出唯一条件，交出来就停，交不出来就走到最后一步。璃落趁通话夹进只有林沐遥听得懂的暗号，让他别按对方节奏交付，并把后续行动指向更安全的外部选项。

四、混凝土彻底固定后，小头目把璃落连同沉重的“鞋”一起拖上车，直奔码头。码头灯下，他把璃落推到栈桥边缘，让林沐遥在电话里听到海风与链条声，明确倒数式威胁，只要再拖，璃落就会被推进湖里，留给林沐遥的只剩“交”或“看她沉下去”。

五、林沐遥在电话里拖延，假装准备交付，暗地把璃落的暗号转成行动，可能是向治安官求援引流，可能是把关键内容向更大范围同步，迫使缄枷会从灭口转为止损。小头目因不确定证据是否已外泄而急躁，码头现场的处置节奏被打乱，他一边催促手下推进璃落，一边反复确认上级指令，暴露出更多组织层级与联络痕迹。

六、冲突在码头爆发。要么外部力量赶到迫使小头目撤离，璃落在被救走的同时留下指向缄枷会处置链条的关键线索；要么小头目为抢时间强行推进，反被迫在众目与混乱里留下可追溯证据。无论结局是哪一种，这一夜都把暗痕追迹从单点追查推向对“处置网络”和“执行小头目”的全面反制。
