# 模块定位与体验目标

《消失的夜班车》是“重返荆江市”主线中的第一宗完整城市调查案，也是璃落从偶然卷入事件转向主动接受委托的起点。案件来源是企业、外包劳务和地下运输方共同制造的人祸；异能者只可能作为受雇对手参与遮掩，不构成异常区域，也不由异常灾害处理组织主导。

本章用一宗具体失踪案示范后续调查支线的共同流程：接触求助者、核验口供、比对纸面记录、进入现场、识别人为干扰、保全证据、呼叫合适的外援并完成救援。结案后才解锁《城市调查员》，避免把职业起点写成抽象的功能介绍。

# 玩家进入与离开

七校志愿活动结束后，一名成年适应班学员私下请求璃落寻找同住者。失踪者在荆江工业园下夜班后没有回家，厂方却拿出签字齐全的自愿调岗单，警方暂时只能按普通劳务纠纷和成年人失联处理。

璃落先以私人协助者身份调查，没有执法权，也不能强行搜查厂区。她必须从公开区域、委托人持有的材料和当事人自愿提供的信息开始。完成救援并把完整证据交给有权处理的部门后，本章结束；工业园保留为后续委托可再次进入的城市区域。

# 游戏流程

## 阶段一：确认失踪

璃落分别检查失踪者的排班信息、聊天记录、工资到账时间和厂方提供的调岗单。玩家需要区分正常劳务纠纷、主动离开与被迫转运的迹象。关键矛盾是失踪者明明已经打卡下班，调岗文件却记录其在同一时间到另一家工厂完成入职。

## 阶段二：追查夜班车

璃落前往工业园，观察不同工厂的换班时间、班车编号和临时停车点。多家工厂共用外包劳务公司，车辆却频繁更换标识，以“跨厂调岗”为名把特定工人带离正常路线。玩家通过班车时刻表和门岗记录缩小目标车辆范围。

## 阶段三：潜入劳务办公点

公开调查受到阻挠后，璃落进入外包劳务办公点寻找原始单据。普通保安、管理人员和一名受雇异能者共同销毁或替换记录；异能只负责制造错误目击、混淆车辆特征或拖延追踪，不把现场变成超自然灾害。玩家需要在继续搜集完整名单和提前离开保住已有证据之间取舍。

## 阶段四：截停转运

璃落确认当晚仍有一辆夜班车准备离开工业园。证据充分时，她可以准确说明车辆、路线和涉案人员，让外援直接封住出口；证据不足时则必须先跟踪车辆，并承担被发现和反制的风险。两条路线最终都救出本案失踪者，但只在证据完整时保留下能够继续追查跨厂链条的名单。

## 阶段五：调查员起点

结案后，求助者把璃落愿意追查“没人管得清”的城市案件一事传开。璃落明确自己不是警察，也不属于异常灾害处理组织，只接受寻找失踪者、核实企业异常和收集可移交证据等委托；遇到现实危险、刑事案件或异常灾害时，仍需联系对应机构。

# 地图与探索设计

- **七校访客区**：接受私人求助，核验失踪者资料。
- **工业园公共道路**：观察换班、车辆与厂区出入口，不能自由进入所有厂房。
- **外包劳务办公点**：调查合同、排班和车辆登记，是核心潜入区域。
- **夜班车停车区**：完成车辆辨认、跟踪准备和最终截停。

# 玩法设计

核心循环为“获得一份记录 → 与时间、地点或另一份记录对照 → 标记矛盾 → 选择新的调查地点”。考勤证明失踪者最后出现的位置，班车记录确定移动路线，劳务单揭示谁在制造合法外观；三类证据必须互相支持，单独一类都不足以确认犯罪链。

取证完整度和救援紧迫度构成两条压力轴。继续调查可以扩大后续追查范围，却可能让车辆提前离开；提前救援能优先保护眼前受害者，但幕后人员可能销毁其他名单。本章不设置因选择救援而导致受害者死亡的惩罚，两种路线都完成本案，只改变后续情报量和对话。

# 前后章节与世界状态衔接

前置《荆江第七异能适应学校》提供委托人与合法异能者社会关系，让璃落第一次从熟人求助进入人为案件。后续主线仍连接《浮华剧场》；与此同时，本章旁出长期支线《城市调查员》，专门容纳丝袜厂、金属厂及其他企业调查。

异常灾害处理组织不负责日常企业犯罪调查。只有案件产生异常空间、灵异污染或灾害级扩散风险时，该组织才作为专业外援介入；普通罪犯和异能者犯罪仍由调查、取证、救援与司法移交处理。

# 最小可玩版本

1. 七校访客区、工业园道路、劳务办公点和停车区四个调查区域。
2. 考勤、班车和劳务单三类可对照证据。
3. 一次受雇异能者制造的调查干扰及对应识破线索。
4. 取证完整度与救援紧迫度两条压力轴。
5. 停车区直接截停与离园后跟踪两种结算路线。
6. 结案后解锁《城市调查员》支线入口。
