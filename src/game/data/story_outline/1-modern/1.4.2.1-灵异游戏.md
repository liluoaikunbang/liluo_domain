# 模块定位与体验目标

《灵异游戏》是《绳仙游戏》旁的独立侧支，用来收纳荆锁会遗留的各类灵异游戏小任务。每项游戏都有独立的怪谈规则、调查方式与结束条件，但共同构成压制满怨古树的仪式网络。

# 故事体量与核心差异

本条目是长期补充的校园灵异支线集合，而不是把所有内容混成同一场游戏。绳仙游戏只保留为其中一项；后续新增的小任务需要各自说明规则、压制作用与完成后的校园变化。

# 游戏流程

## 已确认方向

璃落在校园中接触不同的灵异游戏，逐步发现它们并非单纯流传的怪谈，而是荆锁会留下的定期仪式。完成、修复或正确结束某项游戏，都会让满怨古树暂时稳定；仪式长期失衡或被中断，则会令树的怨气重新向校园蔓延。

# 地图与探索设计

各小任务将分别落在与其规则相符的校园区域或异常空间中。具体地点、区域连接与返回变化尚未确定。

# 玩法设计

每项灵异游戏必须拥有独立规则、调查方式与解除条件，避免只替换怪谈外观。具体操作循环留待首批小任务确定后补充。
