# X战警世界
X战警世界中的束缚：手腕与脚踝的骨内爱德曼锁骨环由阿布拉罕 科内利厄斯设计并完成植入，安装时全身麻醉，外表仅保留一圈贴肤铐环作为接口，铐环与骨内齿环一体咬合，无法转动也无法拆除，任何人都可随时将金属链条扣接其上实施束缚。

万磁王以磁力将爱德曼金属成形为手套与袜套，手套把每根手指的关节角度锁死在握拳状态，指节无法伸展；脚趾不会被压迫，但璃落的脚趾也失去了分开与移动的能力。

（第二次进入）由北极星用爱德曼金属绳完成五花大绑，将腕环与踝环及四肢关键节点逐段锁入既定姿势，绳结与铐环的锁槽冷焊定型，金属冷却后璃落保持被紧缚固定的姿态，手指脚趾彻底不能动弹，长期无法自行解开。

璃落的能力：

璃落是变种人，能力为短暂复原触媒。她必须接触目标，才能在短时间内让目标恢复到可用状态，包括让濒死者暂时维持生命体征直至救援，让受损机械与供能系统短暂恢复运行，以及让门锁短暂回到未锁定的工作状态以完成开启；一旦她撤掉能力或持续时间结束，目标会回到原本状态。她自身也默认受到能力影响，理论上能够永远保持她觉醒能力时的20岁状态。
