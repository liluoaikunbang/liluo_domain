# 游戏流程

## 原稿已确认内容

静默矫治中心归属于「浮光掠影」下的「禁域长廊」模块，是现代都市线中的成人封闭式监管机构。它可以映射现实中臭名昭著的戒网瘾学校、行为矫正营和封闭式疗养机构，但在设定上应明确改为面向成年人的监管与矫治中心。它对外宣称帮助成年人摆脱网络成瘾、社交障碍、异常依赖、冲动行为或生活失序，实际却通过隔离、评分、惩戒和档案控制，制造一批顺从、沉默、容易管理的人。

静默矫治中心与黑蔷薇疗养院的区别在于，它没有英伦哥特的旧宅、遗产和慈善伪装，而是更现代、更冷硬、更制度化。它位于城市郊区、废弃职校、疗养园区或封闭训练基地之中，拥有围墙、门禁、监控、统一宿舍、训练操场、心理评估室和行为观察室。这里的压迫不来自雾、阁楼和家族律师，而来自摄像头、表格、评分系统、治疗同意书、家属授权书和所谓专业化管理流程。

璃落进入静默矫治中心的方式，可以设计为调查一起成年人失踪案时被反派陷害。她被伪造委托书、诊断记录或家属授权，被登记为需要封闭干预的对象。进入中心后，她的手机、身份证、外部联系方式和个人物品被收走，所有解释都被记录为狡辩，所有反抗都被标记为治疗抵抗。她必须在无法与外界联系的情况下寻找失踪者，同时弄清这所机构真正训练的并不是康复者，而是可被操控的顺从人格。

静默矫治中心的核心恐怖感来自现代话术对暴力的包装。限制通讯被称为数字戒断，强制集合被称为作息重建，惩罚训练被称为行为矫正，隔离禁闭被称为情绪稳定，公开检讨被称为认知重塑。机构不需要承认自己在伤害人，因为它总能用表格、流程和评估报告证明一切都是为了对象变好。璃落越是试图证明自己不属于这里，越会被系统认定为更需要干预。

这个模块的束缚切口可以围绕现代监管工具展开。定位腕环、宿舍门禁、安全带、束缚椅、行为积分、禁言课程、观察记录、矫治服、隔离室和治疗同意书，都可以成为剧情与玩法元素。与黑蔷薇疗养院的“监护权枷锁”不同，静默矫治中心的枷锁更像一套现代管理系统。它不强调古典礼仪，而强调服从训练、通讯剥夺、群体压力和评分惩罚。

静默矫治中心适合放在都市中前期或禁域长廊支线中，最好与精神病院、监狱、地下研究院等模块并列。它可以出现在璃落经历“酒店惊魂”“人贩子”“槐湾村”等事件之后，作为都市线对现代制度性监禁的进一步展开。前面的事件偏个人犯罪和区域性困境，而静默矫治中心则把压迫升级为有牌照、有文件、有流程的机构性陷阱。

静默矫治中心还可以与异常灾害处理组织或灰巷线产生连接。表面上它只是普通康复机构，实际上可能在筛选具有异常适应力的人，或者替某个地下组织训练可控人质、实验对象和顺从型劳动力。璃落在中心里发现的名单、转运记录和黑色资助方，可以把剧情引向灰巷黑市、地下研究机构或更大的都市犯罪网络。
