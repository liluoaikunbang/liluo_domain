# 游戏流程

## 原稿已确认内容

小长假第一天，调察院办治安官宣传日，对公众开放。场内设有逮捕流程体验区，普通体验者只戴一次性练习手铐拍照就结束。活动方案里还有一条很少启用的细则，愿意自愿撰写详细体验报告，且评估合格者，可适用高拟真强化体验流程，使用正式器具，完整走一遍押解演示流程。

璃落当场报名。她在问卷里勾选柔韧性好、无幽闭恐惧、可接受较强束缚感，又在备注写希望尽量贴近真实，以便写出完整体验记录。登记人员看她冷静、配合、还愿意写长反馈，直接把她安排到最高拟真等级。半封闭体验区内，她按高风险对象标准上具，先上真金属手铐，再加腰链把双手锁死在腰前，脚镣限制步幅，最后用连接链把腰链与脚镣挂成一体式拘束。执行员一边操作一边讲流程，为了让她写得更细，还特地带她在走廊押解演示一小段，链条声一路叮当。

人群里混着本校新闻系女生程见薇，从扣上手铐开始就举着手机偷拍。手铐、腰链、脚镣、连接链每一步都拍到，脚踝与镣铐的特写、袜子踩地的小动作也都录进镜头。

强化体验结束，执行员给璃落解具时发现锁芯异常。标准钥匙与备用钥匙都对不上，手铐、腰链、脚镣、连接链的锁芯全部打不开。其他体验者都已解开离场，璃落却只能保持全套拘束站在原地。她嘴上仍然配合，说没关系，本来就想多体验一会儿。为避免现场尴尬，她被转入调察院内部休息室看守，等技术员来处理。

当天下午，楼内押解一名女性嫌疑人至讯问区途中发生暴力反抗，走廊警报响起，访客被锁进房间或匆忙疏散，后台区域也被卷入。璃落因器具无法解除，被临时看守在休息室，门外有两名执行员盯着，屋内另有一名同样被押来的年轻女孩安置在角落，手上也戴着手铐。璃落原本只把她当成普通嫌疑人，直到她亲眼看见对方肩胛与锁骨一收，手腕角度一折，整个人用缩骨功挤出手铐的束缚范围，硬生生把一只手从铐圈里脱出来。（实际上这里就是苏婉儿，只是她易容了，所以除了璃落都没有发现是她。）

女孩几乎没有犹豫，脱手后先把自己的另一只手也处理干净，紧接着冲向璃落。璃落双手被腰链锁死，脚镣又限制步幅，来不及躲闪就被女孩拽到身前。女孩一手勒住璃落的肩颈位置，一手去抓她的腰链与连接链，把她拖到门口当人质。璃落本能去动手指摸锁，被女孩当场按住。女孩从衣袖里摸出宽幅扎带，先把璃落上臂与躯干捆在一起，再把小腿与脚镣固定，顺手把腰链与连接链再收紧几扣，璃落的肩臂与膝踝几乎都被封死。看守为了安全检查曾松过璃落鞋带，楼梯转角一拉扯，一只鞋被链条带飞，璃落被迫一脚穿鞋、一脚穿袜子踩地，被女孩拖着小步挪动。

璃落仍想用指尖试探锁芯，女孩察觉得很快，她弯了弯眼，语气轻松。她看着璃落这副把整套拘束都戴齐的样子，语气玩味地说自己准备了那么多拘束具，想在大家体验的时候制造些混乱方便逃跑，没想到这只小倒霉蛋能把她暗中准备的所有打不开的拘束具都戴上。
这样说着，她抬手从袖中取出拇指铐，慢条斯理地把璃落两只拇指扣在一起，又顺势把拇指铐贴到手铐链上，用宽幅扎带绕了几圈固定收紧，让拇指铐的位置无法滑动，指尖也难再做细小动作。至此，璃落身上成了全套正式镣铐加扎带加手指铐的叠加拘束，几乎所有关节都被封死。走廊远处，程见薇与几名旁观者又偷录到一段，镣铐拖地、袜底磨地砖、扎带一圈圈收紧的过程都被拍下。

她压着璃落拐进旁边的工具间，反手关门，用牵引丝把璃落拖到墙边的金属栏杆前。她挑了栏杆上最稳的横杆，把连接链绕过去扣死，又用扎带把扣位与链节缠紧加固，防止璃落靠扭动把链子滑开。璃落双臂仍反剪在背后，手指被拇指铐与扎带固定，脚镣限制步幅，整个人被牢牢铐在栏杆旁，只能小幅挪动。

女孩确认璃落无法自行脱困后，转身走到工具间后侧的垃圾通道门前，掀开内侧隔板，从狭窄通道钻了进去。她肩胛与胸廓一收，缩骨功用到极致，身体贴着通道壁滑行，很快消失在黑暗里。门板回落时几乎没有声响，只留下璃落被全套镣铐、扎带与手指铐固定在工具间内，等待外面的人循声找来。

事情结束后，上级为保护隐私与控制舆论，决定将璃落与其他几名女性罪犯统一押解至指定机构，一律佩戴黑色头套。璃落此时仍保持全套金属拘束加扎带加手指铐。由于之前鞋子不小心掉了，她只能穿着浅色袜子拖着镣铐走完押解路线。远景视频里，一个被头套遮脸、全身链条作响、只能小步挪动的“神秘小囚犯”形象固定下来。

网络上很快出现了两条视频，一条是体验翻车，一条是押解远景，“神秘小囚犯”成了小长假期间本城热梗。璃落借转发链与账号信息锁定程见薇，决定当面处理。假期中段，璃落跟拍摄者程见薇约好见面。

程见薇原以为会面对严肃的删视频谈判，带了道歉稿与法条准备。她抬头看到璃落神色平静，动作却明显受看不见的金属限制，杯子拿不高，起身要先调整腿部与腰前链条，才意识到视频里的那些东西并未随着活动结束消失。璃落开门见山提出两点，公开视频希望下架，避免继续给调察院添麻烦，所有原始素材希望完整保存一份给她自己收藏。她随即提出合作，让程见薇帮她拍一个长期系列，不仅是镣铐，以后还可能有绳子、拘束衣、各类约束家具的日常片段，账号她出镜，程见薇负责拍摄、剪辑与运营。程见薇在震惊与新闻敏感的驱动下答应。
