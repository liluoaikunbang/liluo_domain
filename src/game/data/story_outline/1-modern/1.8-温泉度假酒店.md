# 游戏流程

## 原稿已确认内容

社团前往翡翠岛温泉度假酒店游玩。因是淡季且预订了整个温泉区，社团成员可以自由活动不受限制。
大家换好泳装进入温泉池时，陈思雨已经准备好了大量绳索。璃落担心湿绳捆绑会很痛，林雨薇解释大部分时间都在水中不会有太大问题，并透露只有输掉比赛的人才会一直保持捆绑状态不被解开。其他人闻言纷纷向璃落投去促狭眼神。璃落不甘示弱表示自己绝对不会输。
第一场捆绑游泳比赛采用三局两胜制。比赛规则是在双手五花大绑的情况下游泳前进。璃落虽对各种泳姿都很熟悉，自信即使被缚也能应付自如。赛前其他女生给参赛者们买来奶茶补充能量，却在璃落即将饮用时被林雨薇换成了深喉式口塞堵住了嘴巴。璃落想抗议却只能发出含糊不清的声音。
随后璃落又被套上脚趾铐限制足部活动，并被其他女生合力推入泳池。因手脚都无法自如活动，璃落最终输掉首局比赛，受到双手双脚严密束缚后乘坐水滑梯直入死海温泉惩罚。虽然入水时呛了几口水，璃落很快适应并浮出水面，其他成员也纷纷跳入水中与她玩水嬉戏。尽管璃落处于束缚状态行动不便，仍积极拍打水面回应大家。
第二场温泉喷水挠痒比赛中，所有人都被固定在温泉底部强力出水口位置，同时嘴里叼着高脚杯保持品酒姿势。璃落特制待遇包括：固定位置离出水口更近导致水流冲击更强；双手被束缚到脑后无法保护自己；身高原因只能头部露出水面呼吸。其他日式捆绑的女孩们则获得了活动手臂的能力，可以互相挠痒玩耍，同时也能专门攻击璃落暴露在外的腋窝等部位。在多重不利条件下，璃落再次输掉比赛，接受全身严密包裹后由其他成员针对性按摩阴蒂和乳头直到强制高潮。
第三场冲浪平衡挑战赛中，因已连输两场，璃落在标准束缚基础上额外佩戴重达三公斤的脚镣，并在脚踝间加挂铁球限制移动范围。尽管璃落抗议这种区别对待太过分，其他女生都表示最喜欢欺负她而不予理会。这些额外负重使璃落在水中难以保持平衡，甚至被迫向后移动，导致私密部位反复与粗糙绳结产生强烈摩擦，最终在这种刺激下达到了高潮。比赛结束后璃落受到捆绑漂流惩罚，因双手被缚在背后无法有效舀水防御，加上众人刻意攻击，很快导致小船倾覆沉没。混乱中游泳技术最佳的陈思雨及时救起了璃落。
最后一场桑拿挑战采用大字型束缚姿势，涂抹特制山药汁增加痒感。璃落特制待遇包括：涂抹浓度更高的浓缩山药汁；手心涂满后额外包裹限制解绑；全身包裹保鲜膜防止药效挥发。这些措施使璃落受到远超其他人的强烈痒感刺激，在坚持一段时间后崩溃求饶。按规则她是最后一名完成比赛的人。
所有活动结束后，大家移步沙滩准备篝火晚会。璃落因连续四场失利获得特殊奖励：被严密束缚后半埋入温暖沙地中，仅露出头部胸部和四肢末端，接受社团成员们的美食投喂和穿袜足部踩踏服务，成为整晚篝火晚会的独特娱乐项目。
