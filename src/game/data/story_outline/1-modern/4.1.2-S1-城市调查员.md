# 支线定位

《城市调查员》是“重返荆江市”阶段的长期支线入口，而不是主线中的抽象职业教学。璃落在《消失的夜班车》中已经完成第一宗实际案件，本支线只负责汇集之后出现的独立委托。

案件以人为灾祸为核心，包括企业掩盖、失踪、非法拘禁、人口贩运、地下运输与异能滥用。对手可以是普通管理者、保安、犯罪团伙或受雇异能者；超自然力量不是每宗案件的前提。

# 委托结构

每宗工厂调查都是本节点内部的一次委托章节，拥有独立的问题、生产环境、取证方式、反制手段和结案结果，不能只替换厂房名称与拘束材料。它们不继续拆成故事树节点，以免长期支线随着案件增加变成大量平铺条目。

## 已确认委托：丝袜厂调查

璃落循着工人求助与异常出货记录潜入丝袜厂，调查厂方试图掩盖的人为犯罪。调查暴露后，她被厂方人员反制，由生产线上的丝袜一层层紧缚、包裹成丝袜人偶；在行动受限的情况下，她仍需保护已经取得的证据，并设法将线索传出厂区。

本案不是异常灾害事件。对手以普通管理者、保安或个别受雇异能者为主，丝袜生产环境既是调查现场，也是暴露后的拘束与脱困空间。厂方具体犯罪、委托人身份、进入核心生产区的方式，以及丝袜人偶状态下的取证和脱困机制仍待确认。

## 后续委托方向

### 已确认委托：金属厂调查

璃落潜入金属厂调查人为案件后遭厂方人员抓获。对方利用厂内的手铐、脚镣和锁链逐步限制她的四肢与移动范围，并把关键连接处封合，使束缚无法再靠寻找锁孔或普通拆卸手段自行解除。璃落只能拖着整体金属拘束继续保护证据、寻找能够向外传递线索的位置，并争取需要外部设备才能完成的解除与救援。

本案的犯罪核心、委托来源、厂区路线、施害者是否包含异能者，以及证据如何藏在金属拘束状态下仍待确认。正式展开时不描述现实可模仿的焊接参数或操作步骤，只表现拘束被永久封合后的调查困境。

其他工厂继续记录在《城市调查员》内部。只有在设计对应案件时补充各自的犯罪核心、环境玩法和调查流程，不再为每家工厂创建下级节点。

# 机构边界

- **璃落**：以独立调查员身份接受委托、核实线索并保全证据，没有执法权。
- **警方及对应司法机构**：负责刑事案件的抓捕、搜查与正式处理。
- **异常灾害处理组织**：只处理灵异、异常空间和灾害级扩散，不承接普通工厂犯罪。
- **苏婉儿及其他熟人**：可以提供情报、技术或救援协助，但不替璃落经营调查组织。

# 通用调查循环

玩家先阅读委托并确认失踪、伤害或异常经营迹象，再进入工厂外围观察生产与换班规律，随后通过公开走访或潜入取得证据。调查暴露后，案件转入受限取证、脱困或救援阶段；结算分别记录受害者是否安全、证据是否完整以及幕后链条是否继续开放。

每宗案件可以偏向普通犯罪或包含异能者对手，但只有出现异常区域、灵异污染或灾害风险时，才联络异常灾害处理组织。

# 首版范围

首版只需要一个支线入口和丝袜厂调查委托。金属厂等方向不以空白案件占位；待其核心犯罪与调查差异确定后，直接扩写进本节点的委托列表。
