# 模块定位与体验目标

异能者决战，璃落被永久拘束后投入迷宫中。迷宫以心理态分区，并以核心怨念树维持锁域；后续收束依赖满怨古树吸收该核心，与群像救援并行。

本次补充只确认心理态房间划分、核心怨念树与满怨古树吸收方向，不追加未确认的操作循环、房间数量或制作方案。

# 故事体量与核心差异

已确认主要区域类型为六种心理态房间——期待、羞耻、恐惧、安心、依赖、反抗——以及维持迷宫的核心怨念树。各态房间的具体数量、连接规则与相较相似模块的机制差异仍待后续确定。

现有资料确认的内容方向为：异能者决战，璃落被永久拘束后投入迷宫中；迷宫不是普通建筑，而是用城市碎片拼成的混乱锁域。

# 游戏流程

## 原稿已确认内容

异能者的决战状态固化炸弹，制造永久拘束，如果爆炸前取悦绑匪还能换个轻松点的姿势，璃落通过给探员传递消息激怒绑匪导致被更加加固，被固定炸弹，有人推门就会爆炸，直到探员来的前一刻，如果不是有时间限制还会加固。

之后大家都被带着自己的束缚扔到一个迷宫中，璃落会在迷宫中经历冒险。

永拘迷宫不是普通建筑，而是异能者组织用荆江市地下交通、旧校区、酒店、医院、灰巷记忆拼出来的混乱锁域，每个房间之后都有可能是城市中的什么其他地方的房间。

迷宫内每个房间对应一种心理状态：期待、羞耻、恐惧、安心、依赖、反抗。房间如何具体改写探索与拘束体验仍待玩法层确认，但分区依据已固定为上述六态。

迷宫的核心是一棵核心怨念树，锁域的维持与之相关。接近都市线大结局的群像救援中，荆锁会事件里校园地下的满怨古树吸收这棵核心怨念树，与救援行动并行，瓦解迷宫核心；建立者仍可在控制结构崩溃时趁乱逃入阈限网络，成为后续支线长期 Boss（细节见子节点《阈限空间》）。吸收的触发时机、可见过程，以及对满怨古树自身的即时后果，仍待后续确定。
