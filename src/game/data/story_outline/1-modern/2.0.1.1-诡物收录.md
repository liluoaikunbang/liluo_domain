# 游戏流程

## 原稿已确认内容

分成两个种类的事件，一个是类似SCP的各种需要收容的物品：
诅咒物回收 / 道具灾害模块（其实就是SCP）

和黑市、收容不同，它偏“每件道具都有故事”。

核心是：

一件件诅咒物、失控法器、异常道具被回收，每件道具形成一集。

璃落作为回收员，接触各种会限制身体或改写身份的物品。

束缚切口：自动缠绕的绳、锁住影子的铃、让人无法拒绝命令的手套、封住声音的项圈。

还有一个是要作为猎魔人解决各种灵异事件：
都市传说猎人 / 怪异清道夫模块

这和天师不同，更现代、更职业化。

核心是：

专门猎杀、封存、清理城市怪异的灰色职业团队。

束缚切口：异常运输袋、封存带、清道夫临时拘束、任务后隔离检查。
