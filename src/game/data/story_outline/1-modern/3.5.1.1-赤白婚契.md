# 游戏流程

## 原稿已确认内容

赤白婚契是旧都回声下的民国婚礼劫持模块，核心是中式婚礼与西式婚礼在时代交替中的碰撞。旧都某个商会家族或军阀家族试图利用婚约吞并女继承人的财产、地契、矿权或遗迹钥匙。按照旧式宗族规矩，必须完成红嫁衣拜堂，婚书才能写入族谱，嫁妆密库才会开启；按照租界新法，又必须完成白婚纱婚礼、报纸公示或登记签字，财产转移才具有现代法律效力。因此，这场婚礼不是爱情仪式，而是一场由旧礼、新法、财产和身份共同构成的双重契约陷阱。

璃落卷入此事的方式可以是身份误认、替身新娘、伴娘劫持或证人调包。真正的新娘已经察觉婚约背后的政治交易并逃走，反派为了不让婚礼中断，临时将身形相近的璃落推上仪式。璃落并不需要真的结婚，她的任务是在两套仪式完成前找出真相、保护真正的新娘、破坏婚书与登记文件，并从这场被包装成喜事的交易中逃离。

第一阶段发生在旧宅深院与祖祠喜堂。璃落被换上红嫁衣、凤冠和盖头，困在闺房、花轿、喜堂与祠堂之间。这里的束缚不是普通看押，而是婚礼礼制本身。红绳被称为合婚结，禁足被称为新娘守礼，守卫被称为护礼，婚书则是能将身份写入族谱的枷锁。她必须在不暴露身份的情况下拖延拜堂，寻找真正新娘留下的暗号，并阻止祖祠承认这场婚约。

第二阶段转入租界教堂、新式礼堂或洋楼酒店。反派发现旧礼没有完全生效，于是试图用西式婚礼与现代登记补足契约。璃落被迫换上白婚纱、头纱、长手套和束腰礼服，在宾客、记者、律师和神父面前继续扮演新娘。这里的恐怖感不再来自深宅，而来自公开场合中的无处求救。她越是反抗，反派越能用婚前惊恐、精神不稳或旧宅受惊来解释她的挣扎。

赤白婚契的关键反转在于两套仪式互相矛盾。中式婚礼需要她是族谱承认的新娘，西式婚礼需要她是法律文件上的本人。反派为了同时骗过旧宅长辈和租界律师，必须伪造两套身份。璃落可以利用婚书、签名、照片、印章、嫁妆钥匙和族谱记录之间的差异，让旧礼与新法互相冲突。最终，婚礼不是被简单逃跑打断，而是在所有宾客面前变成一场身份骗局与财产阴谋的公开崩塌。

这个模块的主题是：旧时代用礼法绑人，新时代用文件绑人。红嫁衣代表宗族、祖祠、婚书和家法；白婚纱代表教堂、报纸、律师和登记。璃落在两套婚服之间辗转，不是为了走向婚姻，而是为了撕开婚礼作为权力交易的外壳。她最终逃离的不是某个新郎，而是一整套试图把女性身份、财产和命运写进契约里的制度。
