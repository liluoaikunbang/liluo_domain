# 游戏流程

## 原稿已确认内容

注意：和之前比较火的模拟人生小游戏一样，每个游戏用文字表示，按年推进，每年一句话这样。重点是看璃落在不同的人生里面的处境和结局（因为分类线不可能把各个出身都体现出来，桥段可以加，出身就只能在这个模拟人生器里面来做了），可以做成互动小说模式。

后面可以，分类可以选，初始人生需要刷，有专门的能百分百刷出没有见过的初始人生的道具，而已经出现过的初始人生则记录下来，可以随时选择进行里面其他分支的推进。

模拟器人生 / 多周目推演模块

这和时间循环不同。

核心是：

系统让主角模拟不同人生路线，失败后带回情报或少量能力。

璃落可以看到自己在不同路线里被收容、被拯救、被背叛、被供奉、被当作钥匙。她要用模拟情报避开最糟路线。

束缚切口：模拟身份锁、失败结局回收、命运预设、每轮都被安排成不同角色。

举例：
├ 都市收容线
├ 末日庇护线
├ 古风养女线
├ 西幻供奉线
├ 科幻实验线
├ 灰巷背叛线
├ 宗门钥匙线
└ 帝国宠姬线
