# 游戏流程

## 原稿已确认内容

两年间璃落一直在死域中循环，几乎探索过了那里所有的地方。也在这里遇到过其他幸存者，但都死去或失散了。而璃落不知道什么原因，区域中的触手不会伤害她，每一次触犯规则后，她只会被狠狠玩弄到失去意识后被丢到不知道哪个角落。（这一部分内容略写，具体冒险过程放到番外）
璃落以为自己会一直在这里待下去，直到一团触手深处的“意识”醒来。那是一具诡异的形体：上半身是一位少女的模样，正是末世初期曾照顾过璃落、早已失踪的学姐。那张脸熟悉得令璃落窒息，只是她的眼总是半睁半闭，声音软绵，像永远睡不醒。
长长的裙摆拖地，底下却是一片仿佛无尽蔓延的触手海。她伸出一根湿润的触手，轻轻缠绕住璃落的手腕，柔声低语：
“璃落……你终于来了……娜芙好想你呀。”
她自称娜芙，并在璃落面前保持着一种暧昧而依恋的姿态——困倦、亲昵，甚至……带着某种无法遮掩的情欲与执着。璃落叫她“学姐”，像是某种逃避，也像是一种缅怀。
在“缚神”的牵引下，璃落最终收服了娜芙。而娜芙则以一种亲密得几近融合的方式回应她——将身体化为一件柔软且生有触须的“衣”，紧紧贴合在璃落身上，缠绕着她的腰肢、后背、手臂，成为她的铠甲、伙伴，乃至……某种活体情绪的投影。
就这样，璃落穿着“娜芙”，离开了那座城市。
当她终于归来，熟悉的一切早已面目全非。璃落想顺着记忆中的路线往回走，但是发现到处都是能见度不足五米的黑雾。寻找方向时听到了一辆汽车的声音，璃落循着声音走到了站牌前，发现终点站是之前建立的幸存者城市，于是上了那辆破旧的汽车。司机是一个死尸状的男人，让璃落想起了曾经的丧尸，不过他似乎可以交流，让璃落投币上车。璃落自然不知道要投什么币，于是让璃落用器官代替，屡次被拒绝后暴起伤人，然后被从璃落身后探出的触手扔了出去。触手本来是想吃掉这个家伙的，但璃落威胁她不要用吃过这种恶心东西的触手来捆她。
驾驶位上有一个空白的公交车司机驾驶证，坐在驾驶位上后，道路前的黑雾慢慢散去，露出宽敞的马路，但是周围仍然被黑雾笼罩看不到风景。璃落开着公交，一路到站也并未停下，直接开到了终点站幸存者基地停下。
下了车，璃落发现曾经熟悉的城市变成了一个由各种城市元素拼接而成的迷宫，回去的路已经消失，离开雾后她似乎直接被送到了城市中的某个角落，而身后的破旧公交也早已消失。
璃落正想四处逛逛，一个熟人叫住了她，是以前的伙伴老陆，只是他骨瘦嶙峋双眼凹陷，看起来老了至少二十岁。老陆和璃落说起了这两年的情况。开始时基地越变越好，大家都有希望将这个世界重新夺回来。但就在璃落消失半年后，神秘的诡异世界降临在了这方千疮百孔的世界中，开始时只是一些由白雾笼罩的禁区，进入其中的人会被拉进诡异副本，虽然比较难但完美通关后这些区域会消失，后来李雪在参加一次副本时失踪了，而失去了弹压的鬼影教会将诡异视为神明，不知道用什么办法彻底让诡异降临，吞没了这座城市。现在这座城市的几乎所有功能建筑都变成了副本，而幸存的人们只有通关后才能获得有限的生存物资，而且还要将其中大部分上交给鬼影教会，如果有幸获得能克制诡异的东西也要上交给他们（那些人会在副本通关后的出口等着），未通关的人则会成为低级诡异们的口粮，至于能彻底清除污染的完美通关则在鬼影教会成员的压制下彻底成了不可能的天方夜谭。幸存者们就这样浑浑噩噩地活着。
