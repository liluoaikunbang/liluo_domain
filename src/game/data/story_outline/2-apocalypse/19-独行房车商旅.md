# 主线定位

《独行房车商旅》保存末日主线结束后璃落生活方向的后日谈构想，是“寂土挽歌”的最后一个主线备忘节点。它用于以后拆写具体旅行章节时参考，不代表房车、路线、交易系统和地图已经完成制作设计。

# 已确认方向

- 时间位于末日主线最终危机结束之后，世界仍在恢复，道路与聚居地没有突然回到灾前状态。
- 这次只有璃落一名人类旅行者，不采用姐姐或固定人类同伴同行的结构。
- 璃落驾驶一辆全车智能房车，房车 AI 负责驾驶辅助、生活管理、能源与安全提醒，并成为旅途中的长期交流对象。
- 璃落会穿行重建聚居地、末世遗址及其他仍有末日痕迹的地方。
- 到站后可以打开房车后门卖货，也可以捎货、送信或传递消息，让灾后断裂的人与道路重新产生联系。
- 整体气质由生存危机转向独行、见闻、重建与长期旅行，但仍保留末日留下的荒凉和风险。

# 推荐展开方式

后续可以把不同目的地分别拆成普通剧情节点。每一站从当地真实需求出发，形成“抵达—了解环境—打开后门交易或接受委托—处理当地事件—继续上路”的松散商旅结构。

房车既是移动住处，也是璃落在末日结束后主动选择的生活方式。AI 可以提供路线、库存和危险建议，但目的地、是否停车、与谁交易及是否帮助陌生人仍由璃落决定。

# 与都市房车后日谈的区别

都市线《紧缚环游世界》以璃落和姐姐共同改造旧房车、体验风土人情与摄影收藏为核心；《独行房车商旅》只有璃落一个人类，重点是全智能房车、AI 陪伴、灾后道路和流动商店。两者可以共享“房车旅行”的意象，但人物关系与旅行目的不同。

# 前后主线衔接

前接末日最终节点《裂界灾临》。终局应至少留下某些重新可通行的道路、聚居地之间的物资需求或跨灾域联系，使璃落的旅行不是突然出现的独立生活。

本节点作为末日线收束后的开放尾声，不要求设置封闭终点。未来新增的聚居地、遗址与短途委托可以逐站挂接在这份备忘下，再分别使用普通故事条目模板设计。

# 留待正式主线设计时确认

- 全智能房车的来源、改造过程与房车 AI 的既有身份。
- 第一批旅行地点及其先后关系。
- 各站具体卖什么、交换什么，以及是否需要独立经营玩法。
- 车辆维护、路线风险、聚居地关系和长期旅行记录如何进入游戏状态。

这些问题只作为以后拆写具体节点时的参考，不在主线容器中登记 `missingItems` 或提前写成可执行规则。
