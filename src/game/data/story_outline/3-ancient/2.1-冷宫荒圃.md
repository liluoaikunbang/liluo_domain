# 模块定位与体验目标

璃落被打入无人照应的冷宫后，与贴身侍女清出荒地、种植作物，以收成维持生活。种地并非脱离宫廷冲突的闲置日常：两人在反复劳作中建立信任，也把这片荒圃保留下来，成为之后能够随旅途延续的田地。

# 故事体量与核心差异

本节点以冷宫中的长期生活与经营为核心，区别于一般家园农场：田地起于被弃置的冷宫，既承受身份失势带来的匮乏，也承载璃落与侍女关系转向的过程。

# 游戏流程

## 原稿已确认内容

璃落与侍女开垦冷宫荒地，以种地补足无人照应后的生活。离宫机会尚未确定，因此这段生活会持续一段时间；田地不会在离开冷宫后被放弃，而会在后续“和亲北行”中迁入传承空间。

# 地图与探索设计

现有资料确认场景为冷宫与其中可开垦的荒地。冷宫内部区域、可用水源和其他人物对荒圃的影响仍待正式设计。

# 玩法设计

承接既有“农场经营”方向，确定的古代种田循环包括清地、取水、播种、照料和收获。田块规模、作物、季节和失败反馈尚未确定，不提前补造规则。
