# 游戏流程

## 原稿已确认内容

炼气后期时，交换会上孙甲和璃落看上了同一个法器，璃落看出是妙桐曾经用过的蝴蝶状储物法器便抢先购买，他却非要以更高的价格抢买，本来这也没什么，但孙甲的嘴不干净，还用璃落曾被魔修抓住或已失身的事情刺激她。璃落果然一点就炸，当场把孙甲打了一顿，而刑堂的人却迟到了，直到璃落几乎将孙甲废了才出现。殴打同门弟子是大忌，更不用说这位孙甲还是和璃落一样的亲传弟子，因此她最轻的处罚也是被送进思过崖……之后璃落被刑堂的人捆着押走，她的法衣和靴子都被剥下，只剩下薄薄的中衣，还穿着白色裤袜的脚丫踩在地上。
思过崖中，璃落正站在没过腰腹的寒潭之中，在刺骨寒风下瑟瑟发抖。身上的绳子已经都换成了锁链，甚至还一上一下吊着她的手臂和双脚，不让她离开寒潭，她的手指也被寒蛛丝包裹，在这里她只能拼命调动自身的灵气抵挡寒意，在灵气见底时还必须在自己冻僵之前修炼回足够的灵力。
想起白天的事，璃落发现了不少疑点，孙甲为什么会突然说起她被魔修绑架的事情，而且她当时突然那样失去理智也很不对，还有两个刑堂弟子出现的时机也太巧了，刚好就在她废掉孙甲之后，璃落怀疑这一切都是设计好的……思考间又是一阵寒风吹过，璃落打了个哆嗦不敢分心，赶紧用起灵力保护自己。思过崖已经上百年没有人被罚来了，这里的寒风和寒潭都积攒到了顶点，刑堂的心偏的太明显了。被魔门抓到过的弟子，如果不能给予信任，干脆当时不要收她，却又不舍得灵根近满的天才弟子，随意扔到内门不管不顾，真的不知道那些蠢货是怎么想的。
六个月的思过崖终于熬了过去，璃落从刑堂出来，无视其他人的各种目光，径直回了她自己的房间。璃落不想惹事，现在她要考虑的只是想办法接一些宗门任务，换一些灵石和筑基需要的丹药。正考虑着，门口禁制被触动，璃落挥手让人进来，却发现是孙甲，他虽然当日被璃落冲动之下割破丹田，但毕竟是门下的天才弟子，宗门还是给他用回元丹治好了伤。
对这个让她受思过崖寒冷折磨的罪魁祸首，璃落完全不想理，当场就要轰人，孙甲却抢先跟她说他当时也是被人挑拨，因为身边朋友一直跟他说璃落这种被魔修抓住过的人最后都免不了堕入魔道，再加上那天他也不知道怎么就会说出那样的话，好像被身边人教唆着话赶话之间便说出了伤人的话，而且被打时他的灵气也突然消失……当日过后，孙甲也越想越不对，与后找来的纾慧一起推演了一遍后终于发现了身边朋友的不对，上报师父严查之下才发现对方果然已经在不知不觉间被魔修利用，因此今天才来道歉，也给璃落带了一颗上品筑基丹作为补偿。误会解开，对方既然给了足够的补偿，璃落也不是刻薄之人，欣然接受了他的道歉。孙甲走后，璃落躺在床上，继续思考着这件事，凌云宗估计都被魔修渗透成筛子了。想了想，璃落准备明天去找妙桐商量一下，让她也注意一些。决定了之后，璃落闭目准备休息，然而很快禁制再次被触动，这次来的却又是璃落避之不及的刑部弟子……
孙甲死了，死在她住处不远处的竹林，插在他心脏的凶器正是璃落入门时选择的法器细叶剑……牢房之中，再次被捆紧的璃落给自己辩解，她的储物袋还在刑堂押着，还没来得及去取，可堂主顾文若却说今天刑堂值守的两名执事弟子也被杀了，他们所在的地方没有任何打斗痕迹，显然死于熟人之手。虽然执事弟子已经是筑基，但是璃落在入门之前便已经杀过一个筑基期的魔修……璃落闭嘴了，这显然是有预谋的栽赃，顾文若本就对她有偏见，现在虽然没有直接证据指向璃落，可她的嫌疑确实最大。

刑堂最终也没有找到璃落杀人的证据，再加上妙桐给她作保，两天之后刑堂不得不放了璃落，但是她却必须时刻戴着刑堂提供的连体镣铐，而且她依然不能携带带有灵力的物品，不要说储物袋了，法衣都不能穿，甚至连普通的鞋子都不可以穿，只能光着脚或只着袜子在外行走，顾文若美名其曰这样可以防止她逃远，毕竟不到筑基无法御空，不穿鞋子的袜脚加上镣铐限制根本走不远。然而璃落感觉顾文若就是在针对她，因为现在作为半个犯人的她根本不可能走出宗门，更不用说跑远了，可她却连鞋子都不让她穿。
更重要的是，顾文若要求璃落在没有任务时必须待在属于自己的那个露天地牢中，那完全就是一个上面带有铁栅栏的地坑，仅仅足够璃落躺下，高度刚好够她侧面躺下，甚至她翻身都有些艰难。而且地牢是露天的，璃落不得不面对风吹日晒，只有出任务时会被暂时放出来。更让璃落确认是顾文若的偏见的是，地牢是临时建立的，就在弟子们上课的广场旁边，所有人路过都能看到她这个“囚犯”，而且即使做任务都不能穿鞋还戴着镣铐的状态更是对门派中的所有人提醒她现在就是一个被所有人监督的囚犯。
宗门任务五花八门，璃落又无法拒绝那些筹劳少任务重得帮师兄师姐们打下手的活，只能不断顶着旁人的异样眼光忙碌于各个部门，只有夜晚回到自己房间才可以短暂地修炼几个时辰……不过借着这些任务，璃落倒是学习了不少画符制阵炼器的基础知识，虽然与真正学习它们的弟子们相比只能算是皮毛，但也算能自己独立地做出一些东西。
虽然日子过得不太好，璃落也很快凭借着不错的天赋和孙甲送的上品筑基丹成功筑基。也已经筑基不久的妙桐很快赶来庆贺，虽然只有她一个人，璃落也感觉很高兴。璃落继续着这样的生活，期待等她和妙桐的修为再高一些，多一些话语权之后，再想办法给自己挣得自由。
这天璃落便收到了一封飞书传信，是连天峰峰主魏武的，他给璃落安排了到坊市给他送东西的任务，而且还帮璃落把出宗的手令安排好了。魏武此人璃落并不了解，虽然奇怪这种简单的送货任务为什么要大费周章地让她去完成，却也没法拒绝元婴真人的安排，只能乖乖地到外事堂领了东西，出宗令牌和法衣靴子，换好之后便戴着镣铐来到坊市。反正已经戴着镣铐在宗里走了几年了，她也不在意坊市其他人的目光，径直来到魏武说的房间。
与魏武在一起的是一个眼神阴翳的灰袍男人，璃落总到货之后本想赶紧离开，却被魏武拦住了，甚至直接用捆仙绳将她密密麻麻地紧缚了起来。随后他开始给吴印介绍璃落，说起她是接近满值的水灵根，说起她只是被宗里半放弃的小弟子，而且筑基的修为刚好够吴印采补，最关键的是，吴印的堂弟吴天浩就是当年抓住璃落却被她反杀的那个魔修……璃落哪还不知道他们的打算，然而被紧缚的她只剩下惊恐的眼神可以移动，却根本不可能反抗一个元婴一个结丹圆满的修士，只能眼睁睁看着他们把她按斤按两卖掉，最终被吴印装入乾坤布袋打包带走。两天之后，璃落在送货途中逃跑，堕入魔门血影宗的消息在凌云宗传开，同一天，妙桐也悄悄离开了凌云宗……
璃落被关入了血影门的地牢之后，第一个看到的竟然是曾经的好师姐妙桐。明明从选中她入宗到遭遇袭击时为救她受伤到宗内受到不公平对待时的安慰都是这位师姐，璃落无论如何也想不到她竟然是魔宗派去的卧底。
