# 模块定位与体验目标

这不是第一次兽猎的重复。璃落已以公主身份站在秋盟猎场的观猎席附近，发现整座猎苑也能被人用作外交事故的舞台。她与赫连·阿勒珂从被人观看的猎物，转为共同阻止一场会把南北推向互相指责的危机。

# 故事体量与核心差异

本节点的核心是危机处置与查案。阿勒珂本能处理惊马，却在看到璃落抢过侍卫的马追来后，想看看她能做到什么程度。璃落利用熟悉的猎苑，将惊马引入旧围栏旁的缓冲沙地，使危机停下；她的行动让阿勒珂确认她不是只能被安排的和亲筹码。

# 游戏流程

## 已确认内容

惊马由人刻意制造，目的是让南北互相指责，而非直接刺杀阿勒珂。事后，阿勒珂推荐璃落以当事人身份协查；年轻的大理寺评事陆怀瑾主持查验。璃落在查案中与陆怀瑾建立友谊。

档案库中，璃落看见母亲的名字出现在旧东宫变故后的失踪名册。陆怀瑾认出那是太子妃。璃落只称那是“旧人”，没有说明母女关系；她由此怀疑自己的公主身世另有隐情，却仍缺乏确证，也暂时没有追查的意愿。

皇帝因这次表现开始留意璃落。与旧东宫相关、由皇后主导且太后知情或默许的势力因此感到威胁，并向早已安插在璃落身边的侍女发出后续监视与传讯的命令。
