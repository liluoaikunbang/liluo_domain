整体递进可以定为：

内宅为婢 → 宫廷为局 → 江湖为路 → 仙途为劫

璃落在这一大篇中的身份不是简单升级，而是每换一次身份，就进入一套更大的束缚体系：

1. 丫鬟卷：被卖身契和主仆规矩束缚。
2. 公主卷：被血脉、礼制、国策和婚约束缚。
3. 武侠卷：被江湖名声、恩仇、门派和朝廷追捕束缚。
4. 修仙卷：被灵根、禁制、因果、天道和命格束缚。

卷一：丫鬟难为

核心定位

这一卷是古风线的低位起点。璃落不是一开始就知道自己有特殊身份，而是以一个小丫鬟的身份进入大宅院，在规矩、家法、主仆秩序和内宅阴谋中求生。

这一卷的重点不是宏大世界，而是：

一座宅院就是一个小型王朝。

主子、主母、姨娘、小姐、管事嬷嬷、账房、药房、绣房、柴房，每个地方都有规矩，每条规矩都可能成为困住璃落的锁。

推荐正史主线

1. 入府为婢

璃落因身世不明、家道变故或被人转卖，进入世家大宅，成为低等丫鬟。

她最初的目标很小：活下去、少犯错、攒一点钱、弄清自己的卖身契到底在谁手里。

这一阶段负责建立：

- 主仆身份差距。
- 内宅规矩。
- 卖身契的重要性。
- 璃落娇小、聪明、会忍、会观察的性格优势。

2. 贴身侍女

璃落因为机灵、嘴严、手巧，被调到府中小姐或姨娘身边，成为贴身侍女。

她的地位看似提高，实际风险更大。她开始接触主家的秘密，也被迫成为传话人、替身、挡箭牌和试探工具。

这一阶段负责建立：

- 内宅派系。
- 女眷之间的斗争。
- 璃落从“被动挨罚”变成“学会看局”。
- 她对衣带、帷帐、绳结、暗门、账册等细节的敏锐。

3. 绣楼旧案

府中发生一桩旧案重现：旧丫鬟冤死、小姐失踪、祠堂闹鬼、账册被盗、嫁妆被调包，璃落被卷入其中。

她不是侦探身份，而是因为地位低、容易被牺牲，所以不得不查清真相自保。

这一阶段负责建立：

- 悬疑主线。
- 璃落的推理能力。
- “规矩杀人”的主题。
- 古风宅斗与轻微志怪的融合。

4. 陪嫁风波

府中小姐出嫁，璃落作为陪嫁丫鬟进入另一座府邸，或者随婚队前往京城。

这个阶段可以把故事从内宅推向更大的政治格局。璃落发现这场婚事不是普通婚约，而是牵涉朝堂、边关、宫廷旧案。

这一阶段负责建立：

- 从宅院到朝堂的过渡。
- 璃落离开原府。
- 她的身世线开始浮现。
- 公主卷的引子。

5. 卖身契真相

璃落终于查到自己的卖身契有问题：契书来源不明、年岁对不上、卖主身份伪造，甚至牵涉一桩宫廷旧案。

卷一结尾不建议直接说“她就是公主”，可以先揭示：

她不是普通丫鬟，而是某个被刻意藏起来的人。

这样公主卷会更自然。

卷一结尾建议

卷一结尾可以有三种走向，推荐第一种作为正史：

正史走向：被带入宫

璃落因卖身契真相和旧案证物，被宫中女官、暗卫或权臣势力带入京城。她还不知道自己会被推成公主，只知道自己从一个宅院，被送进了更大的牢笼。

分支走向：陪嫁入京

她作为陪嫁丫鬟进京，意外被宫廷势力认出。

黑暗走向：被灭口转卖

她查到真相后被原府抛弃，途中被劫，随后被宫廷暗线救走或利用。
