# 模块定位与体验目标

北方主战派不愿续盟，在接亲路上刺杀阿勒珂，试图让婚约破裂并把矛盾推回南北边境。璃落与阿勒珂被迫共险；这不是一次单纯的护送意外，而是婚约、王位与边境立场正面撞在一起。

# 故事体量与核心差异

本节点将此前的身份疑云推到人物关系的正面。璃落在协助处理阿勒珂的伤口时确认她是女性；阿勒珂的隐瞒、点名和亲与第一次兽猎起持续存在的身份困境一并浮出水面。

# 游戏流程

## 已确认内容

刺杀来自北方主战派，目的是破坏续盟。璃落与阿勒珂共同脱险后，璃落得知她一直以男性王子身份示人。

二人都没有真正拒绝和亲的余地，婚礼仍按既定政治安排进行。冲突不在于当下是否成婚，而在于璃落已看清阿勒珂的隐瞒与和亲并非自由选择；这份隔阂进入她们之后的婚姻与王庭生活。
