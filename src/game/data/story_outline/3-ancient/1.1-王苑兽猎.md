# 游戏流程

## 原稿已确认内容

北方王子赫连·阿勒珂以观摩秋前狩猎、与南朝皇子交游和试探续盟为名随使团到访。她公开维持年轻王子的姿态，不能以外国使臣身份干涉南朝皇族的游戏，也不能让外交风波逼近自己一直隐藏的身份。

她在观猎席上看见的并非普通骑猎：南朝皇子把平民、奴仆和获罪者投入猎苑，任由猛兽追逐取乐。璃落也被当作猎物。她发现猛兽受高处铜铃、血腥诱饵与栅门机关牵引，便利用地形反向带开兽群；她本可独自逃走，却折返救下无法行动的同伴，并试图让其他被投入猎苑的人一同离开危险区域。

阿勒珂不能替璃落完成脱险，只以北方驯兽口哨短暂扰乱猛兽。璃落察觉这声口哨不是偶然，抓住稍纵即逝的空隙完成救人和脱险，却不知道暗助者是谁。

脱险后，璃落曾在兽苑边缘短暂见过一名北地少年使用一柄常用短刀，因而记住那把刀。她不知道对方就是阿勒珂，只将其视作看不惯猎场、却只能暗中帮忙的异族少年；这份好感里也留着不满。

「王苑兽猎」的主题是：王权把生命变成猎物。璃落在此证明的不是蛮力，而是在王权、猛兽与礼法的压迫下，仍选择救人并寻找让更多人活下来的出口。
