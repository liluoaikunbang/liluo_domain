# 游戏流程

## 原稿已确认内容

「王苑兽猎」适合放入古风、魔幻、王庭、部落、帝国边境等世界。它的核心是古典贵族将狩猎视为身份、血统、勇武和统治权的展示。猎场可以是皇家禁苑、山林围场、斗兽谷、祭祀猎场、魔兽林或边境王苑。参与狩猎的不只是猎人和野兽，还有王公贵族、骑士、祭司、猎犬、驯兽师、侍从和负责维持礼仪的猎场官。猎场本身是一座被礼法、等级和禁令划分出来的封闭空间，普通人一旦误入，就会被视为猎物、祭品、诱饵或破坏狩猎秩序的罪人。

璃落进入王苑兽猎的方式，可以是误闯禁苑、被贵族当成猎神祭品、被绑作诱饵，或者被某个反派故意推入猎场，成为贵族赌局中的特殊猎物。她娇小、灵活，适合钻入树洞、兽穴、石缝和猎场暗道，但体力和正面对抗能力有限，因此这一版的重点不是战胜猛兽，而是利用地形、陷阱、兽性规律和贵族礼法寻找生路。她既要躲避猎犬、箭矢、猎网和骑兵围猎，也要避开被驱赶出来的猛兽、妖兽或献祭兽。

王苑兽猎的前半段可以强调误入与追逃。璃落起初并不理解猎场规则，只知道自己被系上了象征猎物身份的标记缎带，猎犬能顺着气味追踪她，贵族席上的宾客则把她的挣扎当成余兴节目。她可以在密林、溪谷、兽笼、猎人营地和祭台之间逃亡，一边寻找解除标记的方法，一边发现猎场中还有其他被当成诱饵的人。猎场并非单纯让贵族猎兽，而是用人来引出更危险的异兽，或者用献祭者完成猎神仪式。

王苑兽猎的中段可以引入更强的礼法压迫。贵族们不认为自己在作恶，因为在他们眼中，猎场就是世界秩序的缩影。猎人代表高贵者，猎物代表被支配者，猛兽代表需要被征服的野性。璃落如果被捕获，不会被当成普通囚犯，而是会被带回观礼台、祭坛、兽笼或斗兽场，成为下一轮仪式的中心。猎场官会宣布她的身份、积分、用途和处置方式，把个人的求生完全转化成贵族社交中的谈资。

这一版的束缚切口偏古典和仪式化。猎网、绳套、标记缎带、兽笼、木枷、祭祀绳、猎犬气味标记、鸣铃脚环、诱兽香囊都可以成为剧情道具。璃落可能被系上象征猎物身份的红带，只有狩猎结束后才能被解除；也可能被迫戴上铃铛或香囊，使猎犬能够追踪她的位置。贵族们会把这些限制解释成猎场规则，而不是囚禁。她越是反抗，越会被视为“有趣的猎物”。

王苑兽猎的高潮可以从单纯逃亡转为破坏仪式。璃落可以利用猎场地形诱导猛兽冲破贵族席位，也可以反向利用猎犬追踪暴露幕后主使，还可以在祭礼最关键时破坏猎物标记，使猎场无法完成献祭。她不需要靠蛮力打败所有人，而是让猎场礼法本身失效。当贵族们发现自己建立的规则无法保护他们，王苑狩猎就会从权力展示变成一场公开丑闻。

「王苑兽猎」的主题是：王权把生命变成猎物。它适合写出古典压迫感、礼仪残酷感和人与兽共处的原始危险。璃落在这一版中的核心成长不是成为强大的猎人，而是学会在王权、猛兽和礼法三重压力下找到规则漏洞，把自己从被观赏的猎物变成破坏猎场秩序的变量。
