# 游戏流程

## 原稿已确认内容

是一个偏乡土民俗恐怖与古风疑案的支线模块。它的灵感来源于瓦罐坟、弃老旧俗与活封传说，但在剧情中不再单纯沿用“弃老”的逻辑，而是改写为一种被村庄长期掩盖、后来逐渐变形的封灾仪式。表面上，这是一座偏僻山村为了镇压灾厄而保留下来的古老规矩；实际上，它是族老、巫祝与地方势力用来掩盖失踪案、压制异议、转移恐惧的残酷制度。

璃落进入这个山村，最初是为了调查一连串失踪案。近几年，村中陆续有人无故消失，外来商旅、逃难女子、孤身老人和与村规发生冲突的人，都会在某个夜晚后被抹去踪迹。村民对山后的旧窑闭口不谈，只说那里是祖辈留下的禁地，孩子们却会唱一首古怪的童谣，提到“红绳绕腕，瓦门合上，灾星睡去，村人无恙”。璃落顺着童谣和旧案线索追查，逐渐发现村中所谓早已废止的瓦罐坟旧俗并没有真正消失，而是被改造成了“替村还仓”的封灾仪式。

村中族老和巫祝为了维持权威，一直宣称村庄受到山神、祖坟或旧鬼的惩罚，每逢瘟疫、旱灾、井水变黑、祠堂异响，便必须选出一个“命轻、身净、无族亲庇护”的人承接灾厄。璃落作为外来女子，没有本地宗族保护，又在调查中触碰了太多禁忌，正好成为最合适的替罪羊。她身上的锁印气息在夜里与旧窑下方的封印产生共鸣，被巫祝解释成“灾星显形”，而她追查真相的行为，也被族老歪曲成惊扰山神、引灾入村。

真正的阴谋在于，所谓封灾并不是为了拯救村庄，而是为了让旧罪永远沉入瓦墙之后。多年前，村中曾因争夺水源、族产和祭田发生过一场惨案，许多被牺牲的人都被封入山后旧窑。后来失踪案延续至今，每一次灾异都只是巫祝与族老用来制造恐惧的借口。璃落查到旧窑与历代失踪者有关后，反而被他们当成必须除掉的证人。为了让村民相信封灾合理，族老安排假神谕、伪造异象，并在祠堂公议中宣布璃落是山神送来的“还仓之人”。

仪式当夜，璃落被带到山后旧窑。村民们以为这是救村的古礼，少数知情者则沉默不语。她被送入狭小的窑室后，才发现窑壁并非空白，上面刻满了前代被封者留下的划痕、名字、日期和断续的求救语。更重要的是，这些痕迹中隐藏着真正的线索：每一个被封者都不是灾星，而是曾经接近真相的人。璃落由此意识到，真正被封住的不是灾厄，而是这个村子一代代不敢面对的罪。

后续剧情可以围绕“封闭空间中的破案”展开。璃落在被封入旧窑后，并不是单纯等待救援，而是借助窑壁刻痕、残留物件、旧符纸和前人遗言，拼出多年失踪案的真相。外部则可以安排同伴、捕快、女道士或曾被璃落救下的村中少女察觉异样，追查封窑仪式的真正地点。内外两线并行，一边是璃落在狭小空间中寻找脱困与传递信息的办法，一边是外界逐步撕开村中族老和巫祝编织的谎言。

这个模块的核心主题是“以救村之名封人，以古礼之名灭口”。瓦窑封灾不是单纯的残酷刑罚，而是一种由恐惧、宗族、迷信和权力共同维持的乡土牢笼。璃落被封，不是因为她真的有罪，而是因为她是外来者、调查者、见证者，也是最容易被村庄推上祭台的人。她最终要破解的不只是眼前的砖墙和封窑，而是整个村子将罪恶包装成传统、将牺牲包装成安宁的旧秩序。
