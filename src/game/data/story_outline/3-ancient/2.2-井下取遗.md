# 模块定位与体验目标

璃落离开冷宫后重返曾囚困她的古井，取回当日只能记住位置的遗物。遗物需以璃落的血开启；开启后，她确认其中容纳着实体田地，也牵出自身家族的修仙传承秘辛。它是后续璃落借助遗物与判断翻盘的起点，而不是立刻解决宫廷旧案的万能答案。

璃落已知母亲曾以太子妃身份失踪；井下另一半遗物与她留下的护身物相合，使这条身世线第一次留下可由璃落亲手确认的实物证据。

# 故事体量与核心差异

本节点把悬井吊牢中的受限观察转成主动取证。核心不是重复受困，而是璃落带着先前留下的井下记忆重返现场，取得能够改变后续行动的传承遗物。

# 游戏流程

## 原稿已确认内容

古井仍可直接进入。璃落必须先获得离开冷宫的机会，才能返回井下取遗；取回后以自身血液开启传承空间，发现其可容纳实体田地，并知晓它关联家族修仙传承。具体离宫机会、下井过程和遗物的其他用途尚未确定。

# 地图与探索设计

现有资料确认古井为重返地点，璃落此前已记住井壁痕迹、声音与遗物位置。井下通路、井底环境和可调查线索仍待正式设计。
