# 主线定位

《乱世游侠》承接《塞外和亲》，保存璃落从宫廷身份进入武侠江湖、再由武侠转入仙侠的总体方向。这里不是一个可直接制作的模块，而是以后拆写具体主线章节时使用的参考底稿。

璃落在武侠阶段的长处不应是突然拥有压倒性的正面武力，而应偏向观察、手上技巧与隐秘行动。开锁技术和偷窃技术共同构成她的主线特长：进入不该进入的地方，取得正面冲突拿不到的东西，并尽量不留下痕迹。

# 已确认方向

- 开锁最初是璃落逃离关押、打开箱锁和寻找退路的求生手段。
- 偷窃主要服务于取证、摸取钥匙或令牌、调包、拓印和事后归还，不以劫掠普通人为核心。
- 两项技术会从零散求生技巧逐渐成长为璃落稳定、可延续到后续世界的个人特长。
- 正面战斗可以保护她撤离，却不能替代潜入、调查和取证在这段主线中的作用。
- 武侠阶段末尾出现凡俗技术无法破解的灵力禁制，使璃落意识到自身技巧的上限，并成为转入仙侠的契机。

# 推荐主线阶段

1. 亡国出逃：璃落失去宫廷身份保护，第一次以发簪、碎铁片或旧钥匙开锁脱困。
2. 破庙结伴：她进入江湖小队，手稳、观察细的特点被同伴发现，并开始系统认识锁舌、暗扣和机关箱。
3. 镖局押送：围绕货箱、封条、钥匙和内鬼展开，让“打开后恢复原状”第一次成为重要能力。
4. 六扇门旧案：璃落潜入档案库，摸取令牌、调包案卷并归还原物，以证据推动翻案。
5. 山寨与义军：她从匪首、贪官联络人或军需账房处取得账册、印信和赃银流向，并重新认识官匪与百姓的边界。
6. 武林大会：在人群和多方势力中使用贴身取物、反扒与调包，完成单靠战斗无法做到的调查。
7. 魔教圣坛：凡俗技巧仍可打开外围密室，但核心入口属于修仙禁制，由此接入仙门遗迹。

推荐的大方向为：亡国出逃 → 破庙结伴 → 镖局押送 → 六扇门旧案 → 山寨义军 → 武林大会 → 魔教圣坛 → 仙门遗迹开启。

# 能力成长参考

- 初期：观察锁具、利用随身小物脱困、辨认钥匙与封条是否被替换。
- 中期：无损开锁、钥匙拓印、摸取令牌、藏匿物证、调包与原位归还。
- 后期：在人群与多势力监视下完成取证，并把技巧用于旧案、政治与江湖冲突。
- 仙侠衔接：保留观察、潜入和调换物件的思路，但将对象逐步扩展为阵眼、储物禁制、洞府和法器；具体规则留给对应仙侠章节确定。

# 前后主线衔接

前接《塞外和亲》：璃落过去接触箱锁、印匣、钥匙和近身服侍的经验，在失去宫廷保护后转化为求生技术。

后接仙门遗迹及后续修行线：魔教圣坛让璃落第一次明确遇到“知道入口在哪里，却没有能力打开”的限制。转入仙侠后，这项特长不会消失，而会成为她学习禁制、阵法与潜入洞府的个人切入点。

# 留待正式主线设计时确认

- 璃落最初向谁系统学习开锁与偷窃，以及此人与宫廷经历的联系。
- 贯穿镖局、六扇门、山寨和武林大会的核心旧案与关键物证。
- 各阶段最终拆成哪些普通剧情节点，以及每个节点的地图、事件、玩法和状态变化。
- 技巧失败、目标警觉与替代路线的具体规则。

这些内容在后续拆写对应普通剧情节点时再进入游戏大纲或制作设计，不在主线容器中预先定稿。
