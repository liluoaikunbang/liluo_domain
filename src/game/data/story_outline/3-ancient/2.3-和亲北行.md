# 模块定位与体验目标

北方王子赫连·阿勒珂因续盟与王庭压力需要一桩南北王室婚约。璃落没有强大母族、已在南朝失势，是两边都容易谈妥的人选；阿勒珂因此点名璃落。璃落在离开皇宫前，以已开启的传承空间收起冷宫中亲手开垦的田地；这既是对冷宫生活的收束，也让种田支线能随她前往北方，并在之后持续开放。

# 故事体量与核心差异

本节点不将“离宫”处理为单纯的告别演出，而是让此前长期经营的田地发生可见的迁移。玩家保留下来的不是抽象奖励，而是冷宫阶段亲自开垦和照料的实体土地。

# 游戏流程

## 原稿已确认内容

璃落已取回并以血开启遗物，确认其中的传承空间可容纳实体田地。与井下取遗相隔一段主线后，和亲北行已定，她将冷宫田地迁入其中，再从皇宫进入“塞外和亲”主线。和亲诏令、离宫安排与侍女去留尚未确定。

# 地图与探索设计

现有资料确认皇宫、冷宫与已开垦田地。北方旅途与和亲车队属于后续“塞外和亲”主线，不在本节点提前展开。

# 玩法设计

沿用既有“农场经营”作为长期支线基础。本节点只确认田地可迁入传承空间并随旅途延续；迁入操作和跨地图维护规则仍待正式设计。
