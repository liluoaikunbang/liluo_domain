# 游戏流程

## 原稿已确认内容

樱岚幕府是位于东海之外的和风古代异域小世界，适合归入「尘寰问道」下的古风异域分支。这里由幕府、藩国、神社、忍众与妖异势力共同维系秩序，表面是武家礼法、刀术道场、樱花祭典与神社仪轨，暗处则潜藏着妖刀、百鬼、封印神木与忍者密令。它不属于中原古风本土，而是一个独立的异国古代舞台，用来承载武士与刀、巫女神社、忍者潜入、百鬼夜樱等具有鲜明和风美术风格的剧情。

璃落前往樱岚幕府的契机，可以由一桩「东海妖刀案」引出。中原沿海不断出现怪异事件，渔村海滩漂来带血樱瓣、断裂绘马、异国刀鞘与刻着陌生咒文的注连绳。凡是接触过这些物件的人，都会在梦中看见一座开满夜樱的神社，醒来后手腕浮现红绳般的锁痕。璃落随宗门、官府或镖局调查此案，发现这些异象并非普通志怪，而是来自东海彼岸的樱岚幕府。那里封印着一棵名为「神樱」的古老妖树，而流落中原的妖刀与绘马，正是神樱封印松动后漂出的碎片。

璃落之所以会被卷入，是因为她对锁印、封印绳与命运契约有特殊感应。中原一方希望借她的感应能力查明东海异象，樱岚神社的巫女则认为她能够重新稳定神樱封印；忍者众把她视为开启妖刀秘藏的「钥姬」，武家藩主想利用她作为与神社谈判的筹码，百鬼势力则认为她的到来意味着旧封印即将崩坏。因此，璃落前往樱岚幕府并不是单纯游历，而是被妖刀案、神樱封印和多方势力共同推入异国漩涡。

剧情入口可以设计为一段东渡事件。璃落押送妖刀、绘马或封印残片前往沿海港口，途中遭到潜入中原的忍者袭击。忍者用烟雾、符线和机关箱将她带上海船，准备送回樱岚国献给幕后主君。海上突遇妖雾与百鬼夜行，船队失散，璃落醒来时已经漂流到樱岚国近海。她最初被神社巫女收留，却很快发现所谓收留也带有看押意味，因为神社不敢让这个与神樱封印产生共鸣的异国少女随意离开。

樱岚幕府的主要冲突，可以围绕幕府、神社、忍众与百鬼四方展开。幕府想维持武家统治，压制神社和妖异传闻；神社想守住神樱封印，却内部也有人希望借璃落重塑神权；忍众受不同藩主雇佣，在暗处争夺妖刀与钥姬；百鬼则等待封印崩坏，准备借樱花祭重返人间。璃落夹在这些势力之间，一边寻找返回中原的方法，一边逐渐发现神樱封印背后隐藏着更古老的命锁痕迹。

束缚元素可以自然融入樱岚幕府的文化与规则之中。神社线可使用注连绳、御币结界、符纸封印、巫女净身仪式与神前看守；忍者线可使用捕缚绳、机关箱、暗器锁、烟雾迷阵与潜入押送；武家线可使用家法、藩规、刀狩令、道场惩戒与武士押解；百鬼线则可使用妖丝、鬼面、樱枝咒缚、祭品红绳和神隐结界。这些束缚不只是单纯拘束，而是与身份、仪式、封印、献祭和权力秩序相连，能够突出和风古代世界的独特压迫感。

樱岚幕府可以拆分为几个子模块：其一是「武家刀影」，聚焦武士、藩主、浪人、道场、御前比武与妖刀争夺；其二是「神社巫祝」，聚焦巫女、神社、御神体、祭典、神隐与封印仪式；其三是「忍影密令」，聚焦忍者潜入、暗杀、替身、密探、机关屋敷与押送任务；其四是「百鬼夜樱」，聚焦狐妖、鬼族、式神、夜樱祭、妖怪村落与神樱崩坏；其五是「城町烟火」，作为茶屋、温泉旅馆、町人街、市井委托和樱花灯会等日常支线区域。

整体定位上，樱岚幕府是「尘寰问道」中的和风古代异域篇章。它与「浮光掠影」下的大正浪漫不同，大正浪漫偏近代旧城、学生制服、电车、报社、侦探与华族宅邸，而樱岚幕府偏封建武家、神社祭仪、忍者密令、妖刀传说与百鬼夜行。前者是近代和风，后者是古代和风。若需要建立联系，可以让大正浪漫中的旧刀、绘马、神社档案或华族秘史，成为后续追溯樱岚幕府旧因果的线索。
