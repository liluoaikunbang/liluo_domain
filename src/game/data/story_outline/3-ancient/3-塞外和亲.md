4. 和亲国策

宫廷为了稳定边境，把璃落推上和亲之路。

这里也不冲突。她不是同时又变成另一种公主，而是作为“被承认但仍被利用的公主”，被送去完成国策。

和亲线可以是公主卷的中后段大地图章节：

- 京师。
- 驿站。
- 边城。
- 草原王庭。
- 敌国宫帐。
- 边塞战场。

这一阶段负责建立：

- 公主身份的工具性。
- 国与国之间的利益交换。
- 璃落从被送走的人，逐渐变成能谈判的人。

5. 质子与双国棋局

和亲之后不一定真的进入婚姻线。更适合处理成政治质子线：

璃落被留在敌国或边塞王庭，名义是贵客，实则是人质。她同时被本国、敌国、边境部族、暗中第三方利用。

这一阶段负责建立：

- 双国政治。
- 边塞局势。
- 敌我关系模糊化。
- 璃落开始主动使用公主身份。

6. 亡国或摄政抉择

公主卷结尾可以在两个方向中选一个。

方向A：亡国公主

本国政变或战败，璃落的公主身份从护身符变成追杀令。她被迫逃入江湖，开启武侠卷。

这是最适合衔接武侠卷的正史选择。

方向B：摄政公主

皇室衰微，璃落被推到台前，短暂参与政局，甚至掌握部分权力。但她发现朝堂比内宅和宫廷更大，也更难改变。最终她主动或被迫离开权力中心，进入江湖寻求真相。

这个方向更偏权谋。

卷二推荐正史线
