4. 和亲国策

北方王子赫连·阿勒珂因续盟与北方王庭、部族的成婚压力，需要一桩南北王室婚约。她先从政治可行性出发点名璃落：璃落无强大母族、已在南朝失势，也曾在秋盟中证明自己不会只是被动摆设。南朝朝廷则把她视作容易送出的公主。

这里也不冲突。她不是同时又变成另一种公主，而是作为“被承认但仍被利用的公主”，被送去完成国策。

和亲线可以是公主卷的中后段大地图章节：

- 京师。
- 驿站。
- 边城。
- 草原王庭。
- 敌国宫帐。
- 边塞战场。

这一阶段负责建立：

- 公主身份的工具性。
- 国与国之间的利益交换。
- 璃落从被送走的人，逐渐变成能谈判的人。

北方王庭中的普通下人和同辈会因璃落的南朝出身、平民经历与礼法差异排斥她。另有一名仰慕阿勒珂的部族女子，她并不知道阿勒珂的真实性别、也没有正式婚约，却会煽动这份排斥。知晓阿勒珂身份的保密派则因王位与继承风险另行设法逼走璃落；两股敌意彼此独立。

阿勒珂从王苑兽猎起就以男性王子身份隐藏自己。她与璃落在接亲路上共同遭遇北方主战派刺杀；璃落在处理她的伤口时得知真相。二人都没有真正拒绝和亲的余地，婚礼仍按政治安排完成，隐瞒与被安排的隔阂则留入之后的婚姻与王庭生活。

冷宫遗物与北方田地

璃落在此前的“井下取遗”中确认遗物藏有家族修仙传承的秘辛，并在“和亲北行”完成田地迁入。冷宫的种田生活因此不只是困境中的自救，也成为能随旅途继续开放的长期支线。

5. 质子与双国棋局

和亲之后不一定真的进入婚姻线。更适合处理成政治质子线：

璃落被留在敌国或边塞王庭，名义是贵客，实则是人质。她同时被本国、敌国、边境部族、暗中第三方利用。

这一阶段负责建立：

- 双国政治。
- 边塞局势。
- 敌我关系模糊化。
- 璃落开始主动使用公主身份。

6. 亡国或摄政抉择

公主卷结尾可以在两个方向中选一个。

方向A：亡国公主

本国政变或战败，璃落的公主身份从护身符变成追杀令。她被迫逃入江湖，开启武侠卷。

这是最适合衔接武侠卷的正史选择。

方向B：摄政公主

皇室衰微，璃落被推到台前，短暂参与政局，甚至掌握部分权力。但她发现朝堂比内宅和宫廷更大，也更难改变。最终她主动或被迫离开权力中心，进入江湖寻求真相。

这个方向更偏权谋。
