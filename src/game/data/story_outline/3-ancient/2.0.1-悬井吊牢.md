# 模块定位与体验目标

这段事件承接秋盟猎苑的查档结果，把身世疑点转成真实危险。璃落在枯井中无法自救，只能留下足够清楚的观察；侍女的选择则第一次把两人的关系从监视与被监视推向同一阵线。

# 核心冲突

旧东宫势力试图把璃落的失踪伪装成投井自尽。她既没有可靠的庇护，也无法证明自己遭人陷害；救出井口后，宫廷仍能以扰乱宫规为由把责任压回她身上。

# 已确认事件链

璃落因接近太子妃失踪线索被紧缚后悬困在井口狭窄的古井中。她在井下受困数日，发现能与母亲护身物合拢的另一半遗物，却无法当场取走，只能记住位置与井壁、井口的线索。

贴身侍女原本奉命监视璃落。她在相处中逐渐动摇，察觉璃落失踪后违背命令找到古井并完成救援。救援未能立即改变宫廷的处置：璃落随后被反咎，和侍女一同被送入冷宫。

# 前后章节衔接

《秋盟惊猎》中的档案发现使璃落暴露在旧东宫势力视野中；本节点结束时，她失去宫廷中的表面安全。后续《冷宫荒圃》从两人在无人照应的冷宫里开荒、维持生活开始。井下遗物不在本节点取回，留待《井下取遗》处理。

# 待后续设计

井下的受限观察、侍女的外部救援和宫廷反咎尚未拆成可执行流程；在这些内容明确前，本节点保持“灵感”状态。
