# 模块定位与体验目标

《反向移民监狱》位于《拘束具店铺》之后，是律序乐园从“古怪但可以适应的秩序社会”翻转为制度化人口输出体系的核心模块。璃落不是因为欠债、外貌不合格或无力缴费入狱，而是在街头看见外星人口贩子抓捕本地居民后出手阻止。

人口贩子持有由律序乐园正式核发的跨星抓捕手续。当地法律严禁任何人干涉其他星球依照合规手续抓捕本星球居民；由于案件牵涉外星主体和跨星协议，即使璃落有钱，也不能像本地行政违规那样缴费免除处罚。她第一次碰到这个社会绝不允许财富绕开的红线：不能妨碍它向外输出人口。

# 故事体量与核心差异

本模块覆盖街头干涉、涉外审理、入监、奴隶训练、身体改造体系调查和待定脱困结局。它与紧缚学校的温和同化、拘束具店铺的消费陷阱不同，直接展示前两者最终服务的制度底层。

监狱不是普通惩教设施，而是完整的奴隶训练场。所有涉及性器化或动物化训练的囚犯均作为成年角色处理；大纲记录制度功能、角色处境与长期后果，不在当前阶段虚构具体手术步骤或露骨过程。

# 玩家进入与离开

璃落完成拘束具店铺事件后回到街区，目击一名或数名本地居民被外星人口贩子带走。她确认现场存在强迫和恐惧后出手干预，却很快被本地执法系统判定为阻碍合法跨星抓捕。

涉外执法站拒绝罚款、担保或追加转账。璃落被快速判入反向移民监狱。离开方式尚未确认：可以是越狱、外援救援、转运途中脱困或找到手续漏洞；无论采用哪一种，离开前必须让她取得足以证明监狱与人口输出体系相连的证据。

# 游戏流程

## 阶段一：打抱不平

街头事件先让玩家看到“抓捕”本身，再逐步发现对方拥有完整手续。人口贩子不需要躲避摄像头，反而会主动要求璃落远离执法区域。被抓居民是否曾在某份合同、学校结业文件、债务条款或审美复核中交出权利，留待手续设定确认。

玩家可以询问、阻挡运输、保护被抓者或尝试报警，但本地主动响应的警力最终站在人口贩子一方。璃落的行为被记录为干涉跨星合法事务。

## 阶段二：不能用钱解决的审理

璃落在涉外执法站尝试理解罪名。系统承认她可以支付高额罚款，却明确说明此案不适用金钱豁免，因为放走她会损害另一星球已经取得的合法权益。

狱警或涉外审核员向她解释“反向移民星球”的官方说法：律序乐园欢迎居民以工人、伴侣、宠物、实验对象或其他身份前往外星定居，理论上身份不限；但实际输出中占绝大多数的是奴隶。工作人员不会把这当作丑闻，而会把人口持续外流描述成开放、就业与跨星融合。

## 阶段三：奴隶训练场

入监后，璃落被取消普通居民或游客权限，换成待训练资产编号。监区按照未来用途而非罪名分区，训练内容包括服从口令、受限行动、展示姿态、长期拘束适应、身份称谓替换和对购买者指令的响应。

玩家需要在表面完成最低训练要求与暗中观察之间取舍。完全公开反抗会提高看守强度，完全服从则会推进资产评估和外输排期。具体数值与失败恢复仍待玩法确认。

## 阶段四：性器化与动物化改造

更深层区域把成年女性囚犯按未来用途进行身体商品化。性器化改造强调把身体重新定义为服务、展示或刺激接口；动物化改造则可能改变外观、姿态、行动方式、感官反馈与身份认知，使囚犯被归类为宠物、坐骑、展示品或其他非平等身份。

这里借用“泰德堡”作为用户指定的气质参考，但项目内暂无足够资料支撑更具体对应。当前只确认监狱存在广泛、系统化的性器化和动物化改造，并将其作为奴隶训练的一部分；具体项目、可逆性、璃落遭遇到何种程度及受害者后续状态均留待确认。

## 阶段五：没有老去的女性

璃落在监区档案、外输名单和囚犯年龄记录中发现异常：律序乐园公共社会里几乎看不到真正变老的女性。当地人可能把它解释为美容科技、主动移民或生活方式选择，但监狱资料暗示，女性会在变老之前被筛选、改造、注销原身份或送往其他星球。

具体原因不能在证据不足时提前定死。模块应让玩家确认“女性消失”与反向移民体系有关，再把准确机制留给后续调查或用户定稿。

## 阶段六：证据与去向

璃落需要在被正式列入外输名单前取得手续样本、训练分类或改造档案，并寻找离开监狱的机会。最终脱困方式及与《仿生迷途》的连接尚待确定，因此本阶段只保留方向，不虚构既定援军或技术出口。

# 地图与探索设计

地图由街头抓捕点、涉外执法站、入监登记区、基础训练区、资产评估走廊、身体改造区和外输候运区构成。各区域的门禁依据资产等级、训练进度和未来用途开放，不只依靠钥匙。

公开路线要求璃落按训练日程移动；调查路线则利用点名、转区、医疗评估或清洁维护的短暂窗口接近档案和手续终端。地图应让玩家逐层看到文明表面、惩教设施和人口商品化流水线之间的关系。

# 角色与 NPC 安排

- 璃落：因保护被抓居民而入狱，在无法花钱解决后必须正面面对制度核心。
- 外星人口贩子：持有本地认可手续，不需要隐藏抓捕行为；具体个人身份与购买目的待定。
- 被抓捕的本地居民：街头冲突的直接对象，其签约、负债或被指定过程是调查手续合法性的关键。
- 狱警：以“反向移民”为荣，把奴隶身份视为合法定居类别，并真诚认为监狱在提供跨星就业训练。
- 成年女性囚犯：来自学校筛选、审美执法、债务、合同或其他渠道，展现同一体系对不同人的处理结果。

# 事件与状态变化

街头干涉使璃落获得跨星球干涉罪记录，并暂时失去以金钱解决本地违规的路径。入监后记录她的训练阶段、看守警觉、外输排期和已取得证据；具体字段与数值在玩法确认前不命名。

模块结束至少应保留人口贩运手续证据、反向移民制度认知和女性消失线索。璃落是否遭受永久改造、救出哪些囚犯以及监狱是否继续运作，都需要在结局方案确定后写入状态变化。

# 玩法设计

核心循环为“执行最低训练要求 → 借转区观察制度 → 判断手续或档案价值 → 隐藏证据 → 延缓自身外输排期”。玩家不能只靠账户余额清除风险，也不能把每次公开反抗当成无代价选项。

身体改造以进度、选择压力和后果呈现，不设计可现实复刻的操作步骤。玩家的重点是决定何时伪装服从、保护哪些囚犯、优先取得哪类证据，以及如何避免在脱困前被转入更深层训练。

# 对话与玩家选择

街头选择决定璃落以何种方式介入，但不改变她触碰制度红线的主结果。入狱后，玩家可以质问狱警“奴隶为何算定居”，狱警则会用跨星迁居率、岗位匹配和身份自由等统计语言回答。

与囚犯交流时，需要区分主动接受某种外星身份的人、被合同欺骗的人和从未真正同意的人。模块批判的是把不平等身份包装成普遍自愿，并用合规手续消除外界干涉权，而不是否认所有角色可能作出的个人选择。

# 前后章节与世界状态衔接

前接《拘束具店铺》：璃落刚体验完金钱、AI 代决策和债务条款构成的消费控制，随后发现真正受跨星协议保护的是人口输出本身。她过去能够追加转账摆脱债务，这次却因涉外权益无法用钱脱身。

后接《仿生迷途》：监狱的身份改造、动物化技术或外输档案应成为进入仿生主题的桥梁，但具体连接事件尚未确认，不在本模块中擅自定稿。

# 最小可玩版本

1. 完成一次街头持证抓捕事件，并允许玩家查验部分手续后选择介入方式。
2. 在涉外执法站确认案件不适用金钱豁免，并听到“反向移民星球”的官方解释。
3. 进入监狱，完成一次基础奴隶训练并发现用途分区。
4. 潜入或被带入身体改造评估区，确认性器化与动物化改造属于制度流程。
5. 找到女性外输或身份注销线索，并取得至少一份可带走的制度证据。
6. 推进到待定脱困/转运终局，为《仿生迷途》留下明确待补衔接。
