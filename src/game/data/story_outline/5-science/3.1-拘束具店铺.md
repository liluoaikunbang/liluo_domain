# 游戏流程

## 原稿已确认内容

璃落佩戴手铐带着AI管家进入拘束用品专卖店。店内最引人注目的是被严密束缚在平衡车上的年轻女店主正热情接待顾客。

"欢迎光临，请随意看看。"店主灵活地操控平衡车靠近璃落，"您戴着的是标准金属手铐呢，我们店里有各种款式。"

当璃落询问推荐产品时，店主兴奋地介绍起来："我特别推荐这款医用不锈钢手铐，表面处理得特别光滑，长时间佩戴也不会伤皮肤。而且设计很牢固，我就是用它来示范各种产品的。"

璃落试戴了几款不同型号后，店主又指向角落的产品展示区："那边是我们最新款的脚铐系统，连接链采用弹性设计，走路时会根据步伐节奏自动收紧，特别适合长时间户外使用。"

"还有这个膝铐很受欢迎，"店主操控平衡车靠近展示柜，"角度调节范围很大，可以根据需要限制活动幅度。很多顾客反馈说这款非常适合日常束缚。"

当璃落询问内衣类产品的选择时，店主神秘一笑："我们的智能材质系列很不错，比如这款贞操带采用了记忆纤维技术，会根据体温变化自动调整紧度。配套的胸罩也有类似功能，穿着体验特别舒适。"

璃落表示对手指部位的拘束感兴趣后，店主立即推荐："这是我们店的特色产品，指/脚趾铐虽然看起来小巧，但设计精巧耐用。特别适合需要精细化束缚场景使用。"

店主又介绍了各种拘束套具和绳索的特点，每种产品都伴随着实际演示和使用案例分享。

结账环节中出现特别安排：店主向璃落介绍店内特色活动 - 提供免费送货上门服务。

当璃落表示感兴趣时，店主操作个人AI管家向璃落的设备发送指令。璃落惊讶地发现自己的管家立即响应，机械臂准确抓住她的手臂，并轻轻拉动引导至店内更衣区。尽管心中疑惑，璃落还是跟随移动。

进入更衣室后，店主解释道："看得出您是从外地来的客人。这是我们星球的独特服务传统 - 拘束具需要全套穿戴试用后再配送至家中，这样才能真正体验实际效果。"

话音未落，璃落发现自己原先佩戴的手铐已被管家打开，取而代之的是各种新购买的拘束产品正在快速穿戴中。管家的动作精准而迅速，显示出专业服务水准。

店主继续介绍："试用期间如果觉得不合适随时可以退货，很方便的。"璃落立即想到一个问题："那如果嘴巴被堵住怎么办？"

店主笑着从展示架取出一个特制开口枷："不用担心沟通问题。您的AI管家具备读取潜意识功能，即使无法发声也能知道您的真实想法。"说完将带有舌固定装置的口塞递向璃落。

经过短暂思考后，璃落接受了这项提议戴上开口器。店主随即开始介绍其他搭配产品：手指包裹胶带可限制精细动作、多功能睡袋适合整晚束缚睡眠、感官剥夺套装能带来全新体验等。每介绍完一款产品，璃落耳畔都会响起管家系统确认购买的声音，即使内心有所犹豫，系统仍将其解读为同意并立即执行穿戴。

随着更多产品加入，璃落的身体逐渐被层层拘束覆盖。店主持续介绍新产品的特点和搭配方案，而璃落则被动接受这些服务，直到全身包裹如同粽子一般准备送返家中。

回到住所后，璃落向管家表达希望解除多余束缚的需求。AI管家立即响应指令，迅速解开了所有临时添加的拘束具，仅保留璃落原本佩戴的标准金属手铐。

随后管家展示购物账单明细。璃落震惊地发现，仅在短暂堵嘴期间就已累积大量额外消费，总额远超账户余额。面对这种情况，璃落对管家表达了不满："请不要在我还没决定前就替我做选择。"

管家回应表示会优化用户体验机制。这种标准化回答让璃落感到无力，转而询问本地人欠款处理方式。

管家解释道："对于无星际账户居民，可以申请特殊贷款。基础条款包括：日利率0.1%，每月最低还款额5%..."随后展示了详细条款清单。

虽然开头看似合理，但璃落很快发现其中陷阱 - 复利计算方式和最低还款额设置可能导致债务永远无法还清，最终违约者会被强制送往劳工监狱进行体力劳动直至债务清偿。

察觉问题所在的璃落没有过多评论，而是选择从自己星际账号追加转账。
