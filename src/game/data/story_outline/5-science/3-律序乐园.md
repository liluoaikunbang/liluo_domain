# 主线定位

《律序乐园》保存璃落进入一个把紧缚制度化、日常化并包装成文明秩序的科技社会后的总体方向。当地居民对入境分类、长期训练、身体适应改造、审美审查和违规收押习以为常，真正的不适感来自这些规则在本地看起来完全合理。

# 已确认方向

- 外来者入境时必须申报“游客”或“定居”。预计停留超过一年者原则上按定居者处理。
- 长期居留者必须先进入为期一年的紧缚学校，学习被缚常识，并通过每周一次的轻度身体改造逐渐适应当地紧缚生活。
- 富裕者可以缴费免除学校教育，形成公开合法的阶层豁免。
- 法律会严格规定居民的“貌美程度”；未达到法定标准的人可能被送入监狱或矫正体系。本地人大多已经习惯，外来者才会意识到其中的荒诞与残酷。
- 制度不直接宣称排斥移民，却用漫长学校、身体改造、审美门槛与高额豁免费暗示这里并不欢迎外来定居者。
- 主线第一个普通模块是《紧缚学校》，《拘束具店铺》位于其后。
- 《拘束具店铺》之后，璃落因阻止持有本地合规手续的外星人口贩子抓捕居民而被捕。跨星球干涉案不接受金钱解决，她由此进入《反向移民监狱》。
- 律序乐园自称“反向移民星球”，鼓励居民以各种身份前往外星定居，实际输出的主要身份是奴隶；监狱中的奴隶训练和身体改造揭示这套文明最本质的用途。
- 公共空间几乎看不到真正变老的女性，这与居民被持续筛选、改造或向外输出有关；准确机制留给监狱模块及后续节点确认。

# 推荐主线阶段

1. 入境分类与紧缚学校：璃落从游客/定居申报开始认识这里的制度逻辑。
2. 拘束具店铺：在完成或脱离学校流程后进入消费体系，体验规则如何被商品与 AI 服务进一步放大。
3. 反向移民监狱：璃落因干涉持证人口贩运被捕，进入奴隶训练体系，看见学校、消费、审美执法和居民外输共同服务的制度核心。
4. 后续节点再展开仿生技术、身份权限和被改造者的长期去向。

# 主题参考

律序乐园的控制不只来自强制机关，也来自“人人都这样生活”的社会常识、可以花钱绕开的规则，以及将排外和歧视包装成安全、适应与公共美学的行政语言。璃落需要不断区分自愿体验、制度要求与被算法替她作出的选择。

# 留待正式主线设计时确认

- 璃落以什么身份和预计停留时间完成入境申报，以及是否存在改报身份的机会。
- 审美法律的评分机关、申诉方式和监狱/矫正体系在后续哪个普通节点展开。
- 一年学校在游戏时间中如何压缩，以及身体改造最终会留下哪些长期影响。
- 女性为何几乎不会在公共社会中自然变老：是被外输、被永久改造、被身份注销，还是多种机制共同造成。

以上未决事项在相关普通节点中分别确定，不在主线备忘中提前写成可执行规则。
