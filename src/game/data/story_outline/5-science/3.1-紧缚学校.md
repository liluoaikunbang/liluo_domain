# 模块定位与体验目标

《紧缚学校》是《律序乐园》的第一个普通主线模块。它不从商店或娱乐设施介绍世界，而是先让璃落在入境窗口面对一个看似普通的问题：“您是游客，还是准备定居？”

预计停留不超过一年的游客只需接受简短规则说明；预计停留超过一年的外来者则被视为潜在居民，原则上必须进入为期一年的紧缚学校。学校声称课程是为了保障外来者安全、避免错误使用拘束具并帮助身体适应当地生活，但漫长学制、每周身体改造与严格审美法律共同传达出更深的意思：这里愿意接待游客，却并不真正欢迎不愿被同化的移民。

# 故事体量与核心差异

本模块覆盖入境审核和一年学校生活的代表性片段，不逐日演完整学年。玩家通过开学、数次课程抽样、阶段评估和结业审查逐步认识制度。

与后续《拘束具店铺》的消费陷阱不同，本模块重点是公共制度如何定义“合格居民”。付费豁免并不证明学校是自愿服务，反而表明规则对普通外来者严格、对富裕者可以协商。

# 玩家进入与离开

璃落从律序乐园入境大厅进入。审核终端要求她选择游客或定居，并填写预计停留时间。申报超过一年会自动生成紧缚学校入学通知；系统同时展示一笔高额豁免费，允许申请人直接取得课程豁免。

主线默认需要让玩家实际接触学校内容。最终采用“璃落主动就读”“因资金或审查被迫就读”，还是“先尝试豁免后发现附加条件”，保留在 `missingItems` 中。无论具体路线如何，玩家都应在离开模块前理解学校制度，并取得进入后续城市区域的通行资格。

# 游戏流程

## 阶段一：游客还是定居

玩家阅读入境条款，比较游客身份的停留限制、长期居留的学校义务和付费豁免。大厅里的本地工作人员始终礼貌，把一年教育解释为常识培训；周围居民也不觉得这项要求有什么异常。

条款深处同时出现“公共形象合格标准”：定居申请人需要接受外貌评估，低于法定貌美程度者可能被转交监狱或矫正体系。它不是隐藏黑市规则，而是正式法律的一部分，窗口人员只会提醒璃落按时参加检查。

## 阶段二：被缚生活常识

学校教授拘束具安全、日常行动、求助信号、公共场所礼仪、紧急解除权和如何在双手受限时完成基础事务。课程表面具有真实实用性，因此制度不会显得只为折磨外来者；问题在于它把长期受缚视为每个居民必须适应的默认生活。

本地学生从小接触这些内容，对外来生的惊讶反而感到奇怪。部分教师会真诚照顾璃落，却仍认为拒绝适应等同于拒绝文明。

## 阶段三：受限书写课

书写训练依次改变可用部位和包裹程度：

1. 用袜子包住双手写字，先适应手指无法分开时握笔。
2. 用胶带把双手包裹后写字，限制进一步加重，只能依靠手腕和前臂控制笔迹。
3. 完全不用手，改为赤脚夹笔写字。
4. 穿着袜子后用脚写字，摩擦和触觉反馈发生变化。
5. 双脚被进一步包裹后写字，只能利用脚掌整体、脚踝或固定在包裹外侧的书写工具完成作业。

评分不只看字迹是否漂亮，还看学生能否在受限状态下稳定表达、遵守姿势要求并在需要时发出正确求助信号。课程可以表现得略带荒诞与校园日常感，但其强制性始终存在。

## 阶段四：每周身体适应

每周一次的轻度改造用于提高关节、皮肤、平衡与受压状态下的耐受，使学生更适合长期紧缚生活。校方反复强调改造强度轻微、按标准执行，但具体项目、是否完全可逆及学生真正拥有多少拒绝权仍待确定。

玩家在评估室看到本地学生习以为常地讨论本周调整，也会发现付费豁免者不必承受同样过程。这里进一步揭示学校既是教育机构，也是筛选愿意接受身体同化的外来居民的门槛。

## 阶段五：结业与城市准入

结业审查综合课程成绩、身体适应记录、规则服从与公共形象评估。璃落取得临时或长期通行资格后离开学校，首先接触后续《拘束具店铺》：学校把受缚训练定义为居民常识，商店则把这种常识转化为消费需求。

# 地图与探索设计

模块至少包含入境大厅、教学走廊、普通教室、书写训练室和身体适应评估室。入境大厅负责展示身份分流与豁免条款；教学区域通过课程表、学生储物柜、公告栏和审美法规宣传材料补充制度信息。

一年时间采用若干代表周次切换。每次阶段跃迁后，校园公告、璃落的课程权限和学生对她的态度发生变化，不需要制作十二个月完全重复的地图。

# 角色与 NPC 安排

- 璃落：以外来者视角识别学校课程中真实有用的安全常识，以及被“适应当地生活”话术掩盖的强制同化。
- 入境审核员：始终礼貌、熟练地解释游客与定居规则，把学校、豁免费和审美审查当作普通行政流程。
- 紧缚学校教师：负责安全常识、书写训练和身体适应评估；可以真诚关心学生，但通常不会质疑制度本身。
- 本地学生：对课程习以为常，从不同角度表现顺从、羡慕付费豁免者、好奇外来生活或从未思考规则是否合理。

# 事件与状态变化

入境申报结果决定璃落暂时获得游客权限，还是进入长期居留审核。学校阶段记录她是否正式就读、完成哪些代表课程、是否接受身体适应评估，以及最终通过结业还是采用付费豁免。

这些状态在模块结束时汇总为城市通行资格，并开启《拘束具店铺》。身体改造的具体长期字段、审美评分数值和违规处置状态仍属于已登记缺口，在规则确认前不虚构名称或数值。

# 玩法设计

核心玩法是受限书写与规则阅读。书写训练不追求真实模拟书法，而让玩家在不同输入限制下保持笔迹路径、控制压力并及时使用求助信号。袜子包手、胶带包手、赤脚、袜脚和包脚五种状态应产生明显不同的控制反馈。

入境与结业条款采用可检索文本和 NPC 对话呈现。玩家可以发现学校义务、付费豁免、外貌评估和违规后果之间的制度关系，而不是只听旁白说明“这里排外”。

# 对话与玩家选择

关键选择包括申报游客或定居、是否询问付费豁免、是否质疑审美法律，以及如何回应本地学生对学校制度的习以为常。选择首先改变璃落获取信息的方式和人物态度，不在规则尚未确定前直接承诺完全跳过主线模块。

教师与学生不统一写成恶人。有人真心认为训练保护了居民，有人羡慕能付费豁免的人，也有人从未想过外貌不合格者为何应该入狱。这种日常化态度承担“这里不欢迎外来移民”的暗示。

# 前后章节与世界状态衔接

前接《律序乐园》主线备忘与入境场景。模块落实主线确认的游客/定居分流、一年学校、每周轻度改造、付费豁免、审美法律和制度排外方向。

后接《拘束具店铺》。店铺不再承担律序乐园的首次介绍，而是在璃落已经理解当地基本规则后展示消费系统、AI 代决策与债务陷阱。

# 最小可玩版本

1. 在入境大厅阅读游客、定居、学校和付费豁免条款。
2. 进入学校并完成一次被缚生活常识课。
3. 从五种书写限制中实现至少三种具有不同控制反馈的训练。
4. 观看或参与一次每周身体适应评估，明确其轻度改造与阶层豁免性质。
5. 完成结业审查或豁免分支，取得城市通行资格并开启《拘束具店铺》。
