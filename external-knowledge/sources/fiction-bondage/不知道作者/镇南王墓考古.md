# 镇南王墓考古

       在这巨大的石质大厅里，在四周火把的照耀下，整个大厅清晰可见，四周除了壁画，顶部还有一片犹如星空的顶部，黑色的背景里显示着星星点点的光亮，这就很神奇，正常情况应该是火把的光亮照在大厅顶上反射回来才对，而真实情况是大厅的顶部就像是要吸收这些光亮然后在零星的闪耀一些光芒就像是星空一样。

　　这是禁魔屏障，可以隔绝一切魔法的探查，不仅装饰了墓室，更是保护了墓室，如果不是在机缘巧合之下，我得到了这张地图，那么即使是现代拥有各种魔法手段也无法在几十米的山体外发现墓室的存在，星空之下没有其他东西，除了壁画和火把，没有任何其他陪葬品，就只剩下在大厅中央的五阶高的石台，五这个数字再一次显示了墓主人的身份的显赫，毕竟在多就是六阶属于帝王专用了。

　　台阶上层有十多个平方大小，上面摆着一个巨大的棺椁，棺椁外层是白色是石质材料，由于保存完好，上面雕刻的花纹犹如刚刚雕刻完毕一样，只是让人觉得奇怪，按照古坨国的习俗，凡是掌权者死亡基本不会使用白色的棺椁，连颜料也不会使用白色的，在古坨国的习俗里，死亡是重生，是一件喜庆的事情，应该采用深色为主，跟别说是白色，除非是奴隶只能用白色。

　　难道，棺椁里的是一个奴隶？但是奴隶怎么可能拥有这么大的棺椁呢？而且根据石壁上的文字记载这位董姓的将军由于军功卓越被封为镇南王，虽然不知道具体是哪一位镇南王。但是一路走来，巨大的墓室里面居然没有任何像样的随葬品，这就让诸位考古学者百思不得其解。

　　由于棺椁太过于巨大，不便于运输，最后我决定，就在现场开棺，虽然我已经通过帝国政府买下了这片山区，但毕竟这不属于正规考古，多少还是有盗墓的嫌疑在里面，免得夜长梦多。在布置好防御阵法后，并且用魔法仪器检测了并没有发现棺椁里面有什么机关后，几人慢慢的用起重设备开启了棺椁，最外面层白色棺椁打开后，露出的是一个金色的满身浮雕的棺椁，这下大家心落下来了，不管外面为什么用白色石料，至少里面这个金色魔金肯定不是一个奴隶所能享用的，甚至是一般的官宦人家也不能使用。

　　随着一层金色魔金过后是一个银色秘银的棺椁，再往里面是一个楠木的棺椁，这些都是价值连城的材料，让各位考古学家越发肯定，墓主人绝非一般富贵。

　　最后小心翼翼打开楠木棺椁后，大家傻眼了，大家都以为楠木里面应该装的就是遗体了，可是现实是在这个宽三米长四米的巨大楠木棺椁里面居然还有一个长两米宽一米五的白色金属做成的密封的盒子，对的就是盒子，一个巨大的盒子，没有任何花纹，四四方方的，棱角分明。

　　在金属盒子旁边空余的地方整齐的摆放的一些随葬品，很快这些东西吸引的考古学家的注意力，其中最显眼的是一把长两米五的金属长枪，和壁画上对比，这果然就是墓主人的武器，枪头上还散发着寒光，通体刻画着魔法符文，显然是一把极品的魔法武器，旁边摆放着一套魔法盔甲，但是奇怪的是样式却是女性的，难道墓主人是一名女性？

　　接着大家发现了跟多的已经腐朽的女性衣服，不由得让人相信，墓主人应该就是一名女性，不然就是一名特殊的爱好者。

　　最后在清理完这些物品后在衣服下面发现了两个魔法记录牌，以及一个六角星形状的戒指。其中一个记录牌和戒指应该是放在衣服里面的，看样子是有人故意藏起来的，另外一块是放在楠木棺椁角落的，众人的心一下活络起来，几个学者连忙把记录牌清理干净，让学徒去找来兼容性最强的读取器。

　　通过读取器的翻译，我们被震惊了，其中单独放在角落的记录牌中的信息说明了棺椁里面是镇南王，但是也的确是以为女子，是不存在于史书上的，这位镇南王是古坨国最后以为镇南王，本是因为长期镇守南方边关，并且多次大败入侵者，在帝国几次危难之中都力挽狂澜，所以哪怕是为女子也被封为世袭镇南王。

　　奈何，后来镇南王反叛了古坨国逃到敌国，而且还被敌方遣送了回来，古坨国国王一气之下下令处死了镇南王，但念在镇南王战功卓越，没有连累家族并且准其按照王爵下葬，但是除了生平贴身之物不准使用随葬品。而另外一块记录牌就是另外一个说法了。

　　另外一个记录牌上是通过一个宫廷太监的口吻说的，内容本来是要告诉镇南王府的其他人所谓的真相的，这为宫廷太监因为当年镇南王有恩与他，就把真相记录到了记录牌里，并且悄悄放到了镇南王的贴身衣服里，可是镇南王府的人好像并没有发现。

　　记录牌里面的内容说的是镇南王是被古坨国国王陷害的，因为古坨国迷恋镇南王的美色，多次想要纳她为妃子，可是她都没有同意，加上古坨国王怕她功高震主，于是就定计在她日常巡防的时候陷害了她，但是还是被她逃脱了，但是巧的是在逃亡的过程中被敌国给抓住了，并且为了羞辱古坨国，把她变成了一个下贱的女nu，而后遣送会古坨国，而古坨国王也将计就计，以投敌罪名，以极刑处死了她。

　　所以才有了棺椁最外层用白色石料包裹的原因。而那个六角星的戒指就是最后一个盒子的钥匙，钥匙是被宫廷太监掉包拿出来的并且仿制了一把。

　　这个故事确实震撼到了我们，根据现有的资料显示，古坨国就是在这一年被南边的南楚国灭掉的，而本来强大的南境边防军在这次被入侵的时候被打的落花流水，想来这跟古坨国国王有很大关系吧，真是自毁城墙。

　　我觉得反正都到了这一步了，就干脆打开看看，根据资料我找到了金属盒子上的隐藏钥匙孔，拨开金属片，露出六角星的凹口，刚好和戒指上的六角星对应，我缓缓插入钥匙，试着旋转可一圈，只听到好多声咔嚓声，接着整个盒子一阵魔力涌动，盒子慢慢变得透明起来，里面的样子把我们愣住了。

　　只见变得透明后，居然在没有人力的情况下自己居然漂浮起来，接着直立起来了，整个盒子里面清晰可见，只见里面躺着一个浑身被锁链锁住的裸体女人，身体完全没有腐烂的样子，紧闭的双眼好像只剩睡着了一样。

　　亚麻色的长发压在身后具体多长看不清楚，但是可以从正面看见这些头发全部是从头顶上的拘束的金属网里面的网眼里面长出来的，整个头部被严实的拘束着，衔接头顶的金属网的是一圈围绕头部的宽两厘米的银色金属镂空头箍，头箍下沿离眉毛只有一厘米左右，占领了整个额头，微微散开长发可清晰的看到在太阳穴位置除了后面耳朵位置露出来，往下到脖子都被金属包裹着，紧紧的贴着皮肤。

　　从耳根到颧骨位置有一根金属条向前到嘴巴衔接在嘴巴上的类似长方形金属片上面，这个金属片刚刚包裹了整个嘴巴，露出鼻孔，金属片的四个方向分别从两边颧骨到耳根有金属条衔接，下面两个角衔接这两根扁平的金属条绕到下颌骨和从项圈下巴位置上延伸上来的金属条合二为一最后在耳垂下面的项圈上衔接。

　　金属片紧紧的贴着嘴巴，正下方下巴位置还延伸出一根金属条绕过下巴和项圈衔接，而上方鼻孔位置吊着一个大大的鼻环，鼻环上还吊着一个小小的金铃。

　　整个头部的拘束让女人活着的时候是根本不可能有一点活动空间的，加上脖子上五厘米宽一厘米后的项圈，死死的焊接在头套上面，让她转头也成为一种奢望。

　　往下项圈前面分出三根一公分左右散发着金属光芒的细链，其中两根分别连接在ru头上的Ru头锁上面，ru头锁是一个宽一厘米左右的金属环做成的，金属环被一个D型环贯穿在ru头上，严实合缝没有一点余地。两个D环上各自吊着两个一厘米左右的铃铛。ru头锁上四周有几个小环，向上是连接在项圈上的链子上，两边还各自延伸出两根链子锁在手臂上的臂环上面，看着绷紧成度，想来两只上臂是没有什么活动空间的，ru头锁下面也有两根链子往檀中下面的鸠尾穴位置汇集连接在一个内径4厘米的圆环上面，两只ru头相对的两个小环之间有一根链子绷得紧紧的，链子中间和项圈上的三根中的中间根十字链子相交，在往下延长刀鸠尾穴上的圆环上，两个ru头做顶点胸前被几根链子分割成了四个三角形。

　　鸠尾穴位置的圆环上还有向下的三根链子，两边两根分别连接在双手手腕上的四厘米宽的金属环上，长度不过20厘米，严重限制了她手腕的活动范围，另外一根链子往下在肚脐下面点连接在另外一个四厘米内径的圆环上面。

　　在腰部位置有一根宽五厘米厚一厘米的金属腰带，紧紧的肋着她的腰部好在看起来她的腰部本就十分纤细，好像只有20尺左右，虽然腰带肋了些进去，也不至于太狠，腰带上左右有两根链子向下锁在了她的YinDi上面，而肚脐下面的圆环上也延伸出两根链子连接在这左右两根链子上。

　　YinDi上跟两个ru头一样的处理方式，被一个D型环贯穿的环形YinDi锁紧紧的锁在YinDi根部，并且向上被腰带上的链子连接在一起，D环上还吊着一个银白色的铃铛。Yin道位置被封锁了的，被自己的小Yin唇上左右两边的四个共8个Yin唇环锁住，这八个Yin唇环相互重叠然后被YinDi上的YinDi锁上延伸出来的一根链子贯穿通过会Yin位置的穿环延伸到后面了，并且后面两腿之间还吊着一根白色的毛茸茸的尾巴。

　　两片大YinChun还是粉红色的，上面也每边被穿了四个小环，四个小环被四根链子分别连接在两边大腿上的大腿环上，绷的紧紧的，两个四厘米宽的大腿环分为两层，内层紧紧的肋进肉里，外层是镂空的可以转动，连接在YinChun上的链子就连接在外层上面，并且外层大腿环之间被一根10厘米长的细链连接着，试想一下，走起路来一定很刺激。

　　赤足上没有多余的配饰，只是每个脚指头上都带了一个足戒，紧紧的箍在指节上面，脚腕位置有一个四厘米宽的脚环，也是内外两层，外层也是可以转动的，外层上面还吊着一圈细小的铃铛，并且两个脚环被一根三十多厘米的链子连接着，在脚后跟位置被一根金属条直接穿透皮肤进入脚后跟钉在骨头上，这根金属大概有12.3公分那么长，虽然双脚没有绷直，但走路还是很辛苦的，而且永远跟鞋子告别了。

　　我慢慢绕到身后去，发现后面也是有东西的，菊花位置插着一根金属，应该是gang塞，gang塞后面是毛茸茸的尾巴，并且gang塞插在一个镶嵌入菊花的金属环上面深入菊花，具体多少就不得而知了，内径有4厘米左右，但是外径起码有5厘米，而前面YinDi上的链子穿过小YinChun环在穿过会Yin后焊接在这个金属环上面，并且尾骨往上还有一个链子连接着腰带后面和这个菊花里的金属环，看来这个gang塞是可以取下来的。

　　项圈上面还有一根背镣向下连接在腰带上面蹦的直直的，而且在背部位置还和两个臂环之间的30多厘米的链子十字相交连接在一起，进一步的固定了手臂的活动。

　　正当我们感叹这个悲剧的镇南王的悲惨的时候，以及1000年前古坨国的彪悍的炼金技术的时候，突然整个盒子开始抖动起来，而女子身上这些拘束道具开始闪闪发光，强大的魔法波动荡漾开来，链条上面一阵魔法符文闪过，突然又归于平静，正当我们好奇的时候，想要上去查看的时候，突然碰的一声，整个盒子炸裂开来，强大的魔法能量形成一道冲击波，把众人向外推去，撞击在刚刚布置好的魔法结界上面，有些实力低微的人当场就吐血而亡，而没死的深受重伤！只得死死的支撑着。

　　而我虽然被震飞了，除了手上拿着戒指的手受了点皮外伤其他好想没有什么问题，正当我以为我实力上涨的时候，突然听到一个女子的声音仿佛从虚空中传来：“是你们唤醒了我吗？那么你们都该死！”不知道什么时候，我们以为早该死去的女人却睁开了眼睛！
