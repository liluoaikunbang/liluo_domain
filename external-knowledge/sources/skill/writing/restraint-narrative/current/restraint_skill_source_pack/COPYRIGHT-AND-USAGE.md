# 版权、许可与使用边界

## 本包包含

- 原始来源链接；
- 来源类型和访问状态；
- 项目自行撰写的中文研究摘要；
- 可吸收的方法；
- 风险与过滤要求；
- Codex 后续处理建议。

## 本包不包含

- 商业网页全文；
- 小说和 AO3 作品正文；
- 用户角色卡完整定义；
- 长篇提示词的整段复制；
- 成人论坛和数据集原始语料；
- Danbooru / e621 图片；
- 现实紧缚操作教程。

## 原始文件保存门槛

只有具备明确兼容许可证、明确再分发授权、公共领域或用户所有权时，才考虑保存原始文件。其余来源采用：

- `metadata-only`
- `catalog-only`
- `research-summary-only`

正式项目内容不得使用：

- `unknown-origin`
- `reference-only`
- `license-unclear`
- `external-rag-raw`
- `close-paraphrase-risk`
