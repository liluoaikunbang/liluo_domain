# 故事缺口候选工作台

这里仅保存用户明确要求持久化的故事缺口候选，不属于正式故事数据，也不进入正式故事索引。

- `active/`：正在评审的 `proposed` 候选。
- `held/`：用户暂存、暂不写入的候选。
- `approved/`：已接受但尚未成为正式故事节点的候选。
- `archived/`：已拒绝、合并、被替代或已写入后的历史候选与概念指纹。

候选使用结构化 JSON 或 Markdown，必须包含稳定 ID、目标 key、状态、证据、评分、制作规模和来源依赖。`rejected` 候选可保留概念指纹以抑制原样重复推荐；一次拒绝不自动禁止整个题材。`written` 必须记录真实 story key。

普通即时分析只在对话中展示，不默认保存。禁止存放完整分析日志、隐藏推理、大段外部原文或未经批准的正式故事节点。
