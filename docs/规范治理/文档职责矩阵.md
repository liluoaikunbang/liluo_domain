# 文档职责矩阵

| 文档类型 | 保存内容 | 不保存内容 |
| --- | --- | --- |
| `AGENTS.md` | 最高层长期规则、底线与路由 | 详细系统实现 |
| 根 `README.md` | 项目入口与最高频命令 | 大段规范 |
| `docs/项目概览.md` | 项目定位、技术与目录概览 | 每次更新历史 |
| `docs/系统说明/` | 当前有效结构、契约与用法 | 历史开发流水 |
| `docs/技能说明/` | Skill 用途、边界、入口与验证 | 完整系统事实副本 |
| `docs/智能体说明/` | Agent 角色、权限与输出合同 | 通用项目规则副本 |
| `docs/用户命令目录.md` | 用户可触发工作流与命令摘要 | 内部实现细节 |
| `docs/功能更新/` | 某次实现内容、问题与验证 | 当前系统完整规范 |
| `docs/设计记忆/` | 重要决定的理由、代价与重评条件 | 当前操作手册、聊天原文 |
| `project-index/` | 导航、摘要与关系 | 正式事实替代品 |

同一规则跨越多类文档时，在一处完整维护；其他位置只保留本类文档需要的局部合同和引用。
