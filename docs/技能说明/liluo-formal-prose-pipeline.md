# 正式正文写作管线（liluo-formal-prose-pipeline）

用开放权重双模型按写作合同生成正式小说段落候选，经自然表达检查与用户批准后，再由现有故事 Skill 写入正式内容。

## 你可以说

- “用 DSR1 按合同写这段正式正文候选”
- “两个写作模型对照生成，我来盲评”
- “检查写作模型 API 状态”
- “归档这篇为黄金正文 / 记录修改对照”
- “导入我的个人旧作（先登记，不自动当黄金范文）”

## 不会做的事

- 不把候选直接写入正式故事/对话
- 不实现 StyleRAG / 向量检索
- 不自动下载模型权重、不创建付费云资源
- 不要求你把 API Token 粘贴进聊天
- 不替你在 Hugging Face 启动付费 endpoint；live 前请先把要用的 endpoint 启到 Running，默认两边都 Running 后再等约 5 分钟做双模型健康检查
- 不把「待添加」成人向模型自动接进生产双模型槽；相关候选见写作资产模型归档
