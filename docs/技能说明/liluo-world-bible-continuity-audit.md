# liluo-world-bible-continuity-audit

## 故事缺口候选接入

对已接受并展开的候选核验人物、时间线、世界规则与长期影响；外部知识只能说明灵感来源，不能作为连续性事实证据。

## 项目索引协作

story/graph 索引用于缩小证据集，不替代原始节点；摘要未出现某事实不等于设定矛盾。

## 用途与边界

只读审查角色、组织、地点、物品、能力、时间线、命域、伏笔、跨世界信息和长期成长。默认不写回。

## 路径与输入输出

- Skill：`.agents/skills/liluo-project/liluo-world-bible-continuity-audit/`
- reference：`continuity-audit-framework.md`
- 输入：来源 JSON/Markdown、人物组织与玩法资料
- 输出：已确认、矛盾、疑点、缺证、合理差异、补充位置和用户决策项，均附路径/key

## 流程、限制与验证

建立主张与证据，区分矛盾和未解释，不抹平世界差异或改写核心人设。抽查每项引用路径与 key 可定位。写回交对应故事撰写 Skill。

复杂审查可直接委派只读 `liluo_continuity_reviewer`；默认只报告证据，不写回。
