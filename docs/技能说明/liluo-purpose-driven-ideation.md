# liluo-purpose-driven-ideation

## 用途与触发

为已有或待设计的璃落内容产生少量有实际效用的候选，并主动淘汰空泛、无依据、高成本或后果重复的方案。触发语义包括“想几个方案”“补充一些细节”“设计几个选项”“给节点增加变化”“这里还能怎么写”“事件能加入什么”“给地图增加互动”“设计玩法变化”“根据已有素材反推剧情”“找灵感”“比较可行方案”“检查候选价值”。

不用于已确定内容的纯格式修改、错别字、代码报错修复、数据迁移、Schema 校验、素材哈希扫描或原样机械修改。

## 路径、输入与输出

- Skill：`.agents/skills/liluo-project/liluo-purpose-driven-ideation/`
- 上游方法：同级四个 `brainstorm-ideas-existing`、`identify-assumptions-existing`、`prioritize-features`、`opportunity-solution-tree`
- 当前说明：`docs/系统说明/效用导向灵感与细节构思系统.md`
- 示例：`references/examples.md`

输入是当前范围、现有事实和允许变更范围。输出按任务规模保留 0—3 或 0—5 个候选，或明确“不建议新增”；不保存内部草稿或推理链。

## 核心流程与边界

先分级并定义具体内容工作和真实缺口，再从既有角色、地图、状态、玩法、素材和线索生成单变量候选；随后检查价值、可理解性、世界契合与制作可行性，最后按目标契合、差异、因果、复用、成本和风险筛选。每项要通过删除、替换、差异、因果、成本、依据六项测试。

它不直接写入 canon，不自动修改故事、地图或代码，不扩张世界观，不凑数，不替代故事缺口、故事大纲、连续性或内容验证。最终表达阶段才调用自然表达；表达润色不能替代效用判断。
