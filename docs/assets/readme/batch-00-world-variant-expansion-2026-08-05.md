## 本轮共用约束

- 人物身份以 `Batch 00 v2` 为唯一主锚点，不再沿用旧 `22 years old / petite and slender` 口径
- 六界差异允许进入服装和背景，但都必须让位于璃落的人物一致性
- 默认继续保持：
  - 18 岁刚成年的成年女性
  - 偏绯红的浅红棕发与红瞳
  - 娇小体型、自然曲线、轻微丰润感
  - 柔和鹅蛋脸
  - 五官比例读成柔和的年轻成年女性，而不是幼态化
  - 服装简洁但有设计感，不走繁琐复杂路线

## 快速观察

- `浮光掠影`：
  - 最接近“可以直接继续做 poster 系列底板”的状态
  - 日常感、校准感和世界辨识度三者比较平衡
- `尘寰问道`：
  - 世界气质收得比较自然，生活感成立
  - 相比旧版，更像“璃落在古旧生活场景里”而不是“古风换装”
- `星宇织梦`：
  - 未来感与生活性并存，没掉进重科幻装备化
  - 仍可继续收一收鞋靴和设备细节
- `寂土挽歌`：
  - 营地感成立，但人物服装仍偏干净，后续可补一点更可信的长期驻留痕迹
- `慕妮卡帝国`：
  - 整体方向正确，但局部仍略带“帝国礼制服”倾向
  - 如果要作为最终替代图，建议再压一轮繁饰感
- `咒缚回响`：
  - 学院高塔氛围明确，但仍带一点“学院制服化”惯性
  - 若继续打磨，应优先减少制服感，保留长期停留的学习气息
