# 协作参与与团队扩展路线

这份页面不负责把项目讲得神乎其神，只负责回答三个更实际的问题：现在适合从哪里加入、AI 和人工各自守什么边界、接下来最值得继续往前推的是哪几段。

## 适合加入的位置

![璃落宇宙协作角色星图底图](docs/assets/readme/generated/collaboration-role-star-map-base.png)

这个项目最适合的协作，不是只丢一张宣传图，也不是只写一段孤立设定，而是接入同一条生产链的某一环：

- 叙事设计：把既有世界、大纲和情节群继续拆成真正可执行的章节、地图目标、对话节奏和分支压力。
- 地图与玩法：把已经定义用途的设计继续转成 Phaser 地图、事件触发、交互点和局部循环。
- 视觉与 UI：围绕真实世界结构、真实玩法入口和长期角色一致性建立稳定风格，而不是做脱离项目的单张海报。
- 资料治理与验证：继续补统计、证据页、路线验证、截图清单和公开协作文档，让项目始终知道自己做到哪里、还没做到哪里。

## AI 与人工的边界

![璃落宇宙 AI 与人工协作边界底图](docs/assets/readme/generated/ai-participation-boundary-base.png)

这里已经明确守住几条边界：

- GPT Image 2 概念图只负责世界、角色和气质的公开表达，不冒充游戏截图。
- 文件数量、图数量和设定数量，都不能冒充“已经可玩”。
- AI 可以帮助提案、整理、验证、统计、视觉扩编和协作治理，但正式 canon、完成判断和真实证据仍然要由人工确认。
- README 里所有“可玩、完成、已验证”的说法，都必须有真实截图、代码路径、构建结果或自动统计作证。

## 生产路线怎么往前推

![璃落宇宙公开路线图底图](docs/assets/readme/generated/project-roadmap-base.png)

如果从公开协作的角度看，接下来最值得补的不是再做一批脱离运行面的空图，而是以下几条真正能推进项目状态的路线：

1. 补齐 README 缺失的真实运行截图，把对话、存档、关系图谱和互动小说模式都纳入可公开展示的证据层。
2. 继续把浮光掠影、慕妮卡帝国等已具备骨架的叙事域往地图事件和可玩循环推进，而不是只停在大纲或概念海报。
3. 让世界图册、生产体系、统计看板与代码里的真实可运行入口持续同步，避免“文案比项目更快”。

## 生产链不是一句口号

![璃落宇宙五层生产系统底图](docs/assets/readme/generated/five-layer-production-system-base.png)

这个项目真正有意思的地方，不在于它叫自己“宇宙”，而在于它试图把同一叙事稳定生产成多种正式体验：

- 来源层保留世界、角色、关系和长期约束。
- 设计层把这些内容拆成任务、地图、对话、事件和副本。
- 运行层把其中一部分真正接进当前旗舰像素 RPG。
- 证据层持续用真实截图、构建结果和脚本统计校准公开表述。

如果你希望加入的是一个还能继续长的项目，而不是一套已经定死、只剩包装的设定集，这里就是现在的真实状态。
