# 六界视觉 bible

## 归档原则

- 世界风格评价进入账本后，必须明确归入 `palette`、`materials`、`atmosphere` 或 `liluoLooks` 这类绝对字段。
- 不能把“再轻一点”“更亮一点”“少一点压迫感”这类无基线相对词直接沉淀成长期世界规则。

## 慕妮卡帝国

- 定位：秩序、仪式与帝国边疆的日常肌理
- 公开状态：概念规划
- 公开证据等级：概念视觉
- 重点材质：磨损石阶、旧铜饰件、麻布旗面、河港木结构、蜡封纸件
- 重点生活节奏：晨间点名、河运交接、集市讨价还价、夜间巡灯、档案誊录
- 视觉禁忌：不把概念图写成可玩，不把同质站姿图堆成该世界主体
- 空间种子：外城关门、石阶集市、河港码头、档案庭院、驻防营地、风塔观景台
- 分支种子：河誓与边检、档案错页、风塔巡灯、集市口风
