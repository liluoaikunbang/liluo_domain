# GitHub Pages 官网截图补拍计划

日期：2026-08-02

## 当前策略

本轮不补拍新截图，只复用既有 7 张已验证实机截图与 README 图组。后续补图时，每批截图先进入 `docs/assets/readme/` 或对应公开图床流程，再由 `src/content/site/siteData.js` 注册进入官网。

## 下一批优先级

| 优先级 | 目标 | 用途 |
| --- | --- | --- |
| P0 | 首页首屏横幅候选 2-3 张 | 替换当前复用主视觉，形成稳定官网封面 |
| P0 | 六个世界各 1 张代表图 | 支撑 `/worlds` 与世界详情页 |
| P1 | 游戏探索、对话、图库、关系图各 1 张 | 强化 `/evidence` 的可玩证据 |
| P1 | 璃落角色状态图 2-3 张 | 支撑角色页与图库筛选 |
| P2 | 生产体系流程图或编辑器截图 | 支撑 `/production` 与协作页 |

## 拍摄要求

- 保留游戏 UI 或可验证上下文，不只截纯氛围图。
- 文件名使用稳定语义，不使用临时编号作为唯一含义。
- 公开图必须经过敏感信息检查，再进入 R2 或 Pages。
- 截图进入官网前运行 `npm run site:content:validate`。
