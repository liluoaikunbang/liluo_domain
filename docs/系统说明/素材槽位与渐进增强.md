# 素材槽位与渐进增强

## 目标

素材不应再被理解成“等所有美术都齐了再开始做”。在新体系里，素材首先是叙事生产包中的槽位：它们可以先占位，再逐步增强。

## 槽位思路

常见槽位包括：

- 角色立绘与分层表情。
- 地图与场景资源。
- CG 与关键镜头。
- 音频、环境声和提示音。
- UI 装饰、章节卡、资料卡和其他辅助视觉。

## 渐进增强原则

- 先保证叙事成立，再提高素材精度。
- 先补足会影响理解和推进的素材，再补观感增强。
- 相同叙事的素材应尽量复用到多种输出，而不是每种输出各自重做。

## 与资产治理的关系

素材槽位不是绕开资产治理的理由。真正新增到 `src/assets/game` 的图片，仍要进入素材清单；只是在更早阶段，项目允许先记录“应该有这类素材”而不是强迫一次做完。

## 对实现层的要求

- 缺素材时允许灰盒或占位，但必须明确记录缺口。
- 不用假完成掩盖空槽位。
- 产线升级优先解决高复用、高叙事价值的槽位。
