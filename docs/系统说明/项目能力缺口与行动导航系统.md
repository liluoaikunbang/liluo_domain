# 项目能力、缺口与行动导航系统

`project-navigation/` 是项目知识索引之外的行动层：索引负责定位，导航负责回答用户可调用什么、项目缺什么，以及有限时间内可推进什么。机器注册表为事实源，`docs/项目能力、缺口与行动总览.md` 与 `docs/我现在可以做什么.md` 是生成物。

扫描只发现正式 `.agents/skills/`、`.codex/agents/` 与 `package.json` 中真实命令；外部原始 Skill 只能作为来源。故事缺口来自原始来源派生的 `missingItems`，玩法覆盖来自 `catalog.json`，并保守从 `catalogued` 起步。可执行工作流定义位于 `project-workflows/definitions/`，扫描时投影合并进 `workflows.json`，细则见 [机器可读工作流与可视化执行规范系统](./机器可读工作流与可视化执行规范系统.md)。任务改变能力、用户入口、缺口、工具/来源或玩法证据时运行 `project:navigation:changed`；无关任务不更新。完整工作流见 `liluo-project-capability-navigation`。
