# 地图系统

地图系统是当前 RPG 主流程的核心，负责地图加载、出生点、渲染、碰撞、寻路、镜头和环境表现。

## 当前入口

- `src/game/scenes/BootScene.ts`
- `src/game/scenes/MapLoadingScene.ts`
- `src/game/scenes/WorldScene.ts`
- `src/game/systems/map/`
- `src/game/systems/character/`
- `src/game/systems/animation/`
- `src/game/systems/environment/`
- `src/game/data/registry.ts`
- `src/game/data/maps/<mapId>/`

## 场景职责

- `BootScene`：只处理启动期全局资源。
- `MapLoadingScene`：按 `mapId` 动态加载地图资源。
- `WorldScene`：组织场内流程，不承载过多细节逻辑。

具体运行逻辑应优先下沉到 `systems/`，原始数据应优先留在 `data/`。

## 地图数据目录

单张地图使用：

```text
src/game/data/maps/<mapId>/
  map.json
  events.json
  dialogues.json
  meta.ts
  assets.ts
  animations.ts
```

`animations.ts` 只在地图需要专属动画时添加。

新增地图内容时，优先补齐 `data/maps/<mapId>/` 并接入 `data/registry.ts`，不要并行再造一套入口。

## 地图体验优先级

地图系统的改动优先保证：

- 玩家能在地图中移动
- 能发现新地点
- 能触发事件
- 能推进剧情
- 不破坏已有地图和事件
