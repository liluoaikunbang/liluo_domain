# 寂土挽歌故事大纲选项

适用于 `world: 2-寂土挽歌`、正文目录 `2-apocalypse/`。当前已有 21 篇 Markdown，但稳定使用的 `storyTag` 只有“废城求生”。其他分组依据现有主线节点归纳，均标记为建议候选。

## 已使用 storyTags

### 废城求生

现有使用集中在尸潮噬世相关内容。

- 推荐体量：短篇、中篇、主线章节、大型副本。
- 推荐 `moduleType`：探索、生存、潜行、战斗、护送、脱困。
- 内容方向：丧尸压力、废城路线、补给、避难点、幸存者协作和撤离。
- 典型结构：进入危险城区 → 搜集补给/线索 → 尸潮或封锁改变路线 → 救援/守点/撤离 → 更新据点和区域状态。
- 玩家状态重点：负伤、感染、负重、噪声、受限移动与补给消耗。
- 防重复检查：每座废城必须改变资源压力、敌群规则、路线结构或撤离目标。

## 建议 storyTags

### 异诡侵界

依据：异诡临界、诡雾迷城。

- 推荐 `moduleType`：探索、调查、解谜、生存、追逐。
- 体验重点：规则未知、雾中辨路、异常征兆、认知或地图失真。
- 完成方向：确认规则、标记安全路线、取得异常证据或封闭源头。

### 天灾绝境

依据：天灾异像、深海漂陆、永冬白境、沙海孤途。

- 推荐 `moduleType`：生存、探索、护送、经营、综合。
- 体验重点：天气与地形持续改变路线，补给和避难成为核心决策。
- 环境候选：洪水/漂陆、极寒、沙暴、极端天象。
- 防换皮检查：不同天灾必须改变移动、视野、温度、补给或地图生命周期。

### 生态灾变

依据：疫病残城、生态吞城、异兽踏陆、虫巢边境。

- 推荐 `moduleType`：调查、生存、战斗、潜行、护送。
- 体验重点：感染、生态扩张、异兽领地、虫巢网络和安全区退缩。
- 状态候选：感染阶段、污染区域、样本、巢穴活性、居民撤离。

### 机械方舟

依据：机械余晖、方舟幽笼。

- 推荐 `moduleType`：探索、调查、解谜、经营、生存。
- 体验重点：旧机械系统、封闭方舟、能源与权限、设施故障。
- 典型结构：恢复系统 → 获取权限 → 发现方舟规则/历史 → 决定修复、关闭或撤离。

### 末日秩序

依据：废土王庭、末日圣裁。

- 推荐 `moduleType`：调查、互动小说、潜行、战斗、经营。
- 体验重点：灾后权力、资源分配、审判规则、聚落关系。
- 防偏离检查：政治和对话必须落实为地图权限、物资、阵营或任务变化，不能只写会议剧情。

### 时梦裂界

依据：梦城沉眠、循时终日、忘川灰世、裂界灾临。

- 推荐 `moduleType`：探索、解谜、调查、互动小说、综合。
- 体验重点：梦境、循环时间、记忆消失、世界边界裂解。
- 必填边界：循环重置什么、永久保留什么、玩家如何判断进展、最终如何退出。

## 世界通用候选

- 常用活动：废城探索、补给搜集、据点防守、人员救援、环境生存、异常调查、撤离。
- 画面方向：破败城市、临时据点、极端天气、污染生态、巨型载具和异常天幕。
- 状态方向：补给、感染、温度、污染、据点安全、幸存者、路线开放和循环记忆。
- 内容警告候选：灾难、感染、饥饿、封闭空间、追逐、群体伤亡；只按实际内容选择。
