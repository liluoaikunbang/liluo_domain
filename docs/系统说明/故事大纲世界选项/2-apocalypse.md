# 寂土挽歌故事大纲选项

适用于 `world: 2-寂土挽歌`、正文目录 `2-apocalypse/`。本文件采用固定 `storyTags` 词表，不再提供或自动推导建议标签；最终一个来源 JSON 节点仍只对应一个 Markdown 大纲文件。

## 固定 storyTags

### 灾难前夕

- 内容范围：灾变征兆、秩序尚未完全崩溃、预警失效、物资抢购、人员疏散和最后的正常生活。
- 推荐 `moduleType`：调查、探索、职业体验、护送、综合。
- 玩法候选：征兆搜集、时间限制、物资选择、通知关键人物、规划撤离路线。
- 状态候选：灾变倒计时、社会秩序、物资、已通知人员、可用出口。
- 区分要点：重点是“玩家能否在信息不完整时提前行动”，不能直接写成灾后求生。

### 废城求生

- 内容范围：废弃城区、尸潮、断水断电、补给搜索、临时避难点和幸存者协作。
- 推荐 `moduleType`：探索、生存、潜行、战斗、护送、脱困。
- 玩法候选：搜集补给、控制噪声、标记安全屋、处理感染、救援与撤离。
- 状态候选：负伤、感染、负重、噪声、补给、据点安全。
- 区分要点：每座废城必须改变资源压力、敌群规则、路线结构或撤离目标。

### 灾区突围

- 内容范围：正在崩坏的城区、洪水火灾、封锁线、交通瘫痪、追逐和紧急撤离。
- 推荐 `moduleType`：追逐、护送、生存、驾驶、综合。
- 玩法候选：动态路线选择、障碍突破、保护同行者、载具维护、限时抵达。
- 状态候选：撤离时间、道路开放、同行者状态、载具耐久、灾害强度。
- 区分要点：地图应持续变化并迫使玩家移动，不与偏搜集经营的“废城求生”混同。

### 异变侵临

- 内容范围：疫病、异兽、虫巢、诡雾、生态吞城和未知异常进入现实区域。
- 推荐 `moduleType`：调查、生存、战斗、潜行、追逐。
- 玩法候选：观察异变规律、采集样本、规避污染、封锁扩散点、寻找安全时机。
- 状态候选：感染、污染、样本、巢穴活性、认知异常、区域沦陷度。
- 区分要点：异变必须拥有可观察、可试错、可利用的规则，不只作为怪物换皮。

### 禁区囚笼

- 内容范围：隔离区、地下设施、方舟封闭舱、实验区、检疫营、末日监狱和无法自由离开的安全区。
- 推荐 `moduleType`：脱困、潜行、调查、解谜、生存。
- 玩法候选：权限获取、监控规避、设施恢复、受限移动、秘密通道和多阶段逃离。
- 状态候选：权限、警戒、拘束层级、氧气、能源、隔离等级、出口状态。
- 区分要点：囚禁条件必须实际限制玩家的移动、互动或资源获取，并存在清晰的突破路径。

### 灾变溯源

- 内容范围：灾难起因、旧实验记录、污染源、异常遗迹、责任组织和被掩盖的历史。
- 推荐 `moduleType`：调查、探索、解谜、互动小说。
- 玩法候选：证据链拼合、时间线还原、样本分析、档案权限、源头定位与最终处置。
- 状态候选：证据完整度、真相层级、组织关系、样本可信度、源头稳定度。
- 区分要点：结论必须来自玩家取得并关联的证据，不由剧情直接宣布真相。

### 废土重建

- 内容范围：据点建设、资源循环、人口安置、生产恢复、派系协调、区域净化和长期秩序重建。
- 推荐 `moduleType`：经营、探索、护送、调查、综合。
- 玩法候选：设施升级、人员分工、资源路线、区域清理、居民事件和发展方向选择。
- 状态候选：人口、食物、水、能源、治安、士气、设施等级、区域控制。
- 区分要点：建设结果必须反映到地图、NPC、可用服务和后续事件中，不能只变化数字。

## 世界通用候选

- 常用地图：灾前城区、废弃街区、动态灾区、隔离设施、污染生态区、灾源遗迹、幸存者据点。
- 常用状态：补给、感染、污染、温度、警戒、据点安全、幸存者、路线开放和灾变进度。
- CG / 像素演出候选：灾变初现、城市崩塌、尸潮压境、封锁门闭合、源头显现、据点阶段性复苏。
- 内容警告候选：灾难、感染、饥饿、封闭空间、追逐、群体伤亡；只按实际内容选择。

## 使用边界

- 本世界只从以上 7 个 `storyTags` 中选择，不再自行补充近义标签。
- 多标签条目以第一项为主风格；若各标签分别形成完整地图流程，应拆成独立节点。
- 候选玩法和状态只按实际采用内容写入正式大纲，不得整段复制作为占位。
