# 星宇织梦故事大纲选项

适用于 `world: 5-星宇织梦`、目录 `5-science`。本文件提供世界内风格和玩法候选，不拆分最终成品；一个 JSON 节点始终对应一个完成后的 Markdown 文件。

## 已有 storyTags

### 律序乐园

- 现有内容倾向：高度规训的理想都市、制度化生活、消费设施与隐性控制。
- 适合节点：`律序乐园`、`拘束具店铺`。
- 推荐 `moduleType`：调查、潜行、职业体验、解谜、综合。
- 场景候选：中央广场、居民区、服务店铺、通行闸机、监控中心、维护通道。
- 玩法候选：身份权限、行为评分、监控盲区、规则服从与规避、店铺互动。
- 状态候选：社会信用、权限等级、监控警觉、装备限制、居民信任。
- 区分要点：制度压力要通过通行、交互、追踪或资源限制呈现，不能只靠 NPC 描述。
