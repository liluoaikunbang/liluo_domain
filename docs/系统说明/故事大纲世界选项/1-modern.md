# 浮光掠影故事大纲选项

适用于 `world: 1-浮光掠影`、正文目录 `1-modern/`。当前世界已有 57 篇 Markdown 和 7 个稳定 `storyTags`，候选项主要从现有条目整理，可直接用于选择，但具体引用仍必须核对真实数据。

## 已使用 storyTags

### 街景一隅

现有内容最丰富，覆盖重返校园、紧缚社团、柔韧练习、游轮、温泉酒店、深夜城市职业、模特、女仆酒店、电影绑替、充气城堡、雪城列车、真人秀和婚礼事件。

- 推荐体量：微型事件、短篇、中篇、长期开放模块。
- 推荐 `moduleType`：职业体验、探索、小游戏、互动小说、脱困、综合。
- 已有地点候选：荆江市、市医院、江湾广场、翡翠岛、火车卧铺、充气城堡。
- 已有标签方向：职业、夜间职业、都市夜行、社死、团宠、模特、游戏、挠痒、气味系、感官刺激。
- 已有玩法方向：短篇职业体验、普通绑架脱困、紧缚比赛、紧缚斗地主、演员/模特/乘务员体验、城市街头事件。
- 典型结构：正常日常或工作 → 环境互动 → 意外受困或游戏规则变化 → 利用职业场景完成应对 → 返回城市日常。
- 防换皮检查：不同职业必须改变任务目标、工作场所互动和脱困方式，不能都写成“发现犯罪后被绑进仓库”。

### 诡影侵临

现有内容覆盖舞蹈教室、舞台表演、镜中人、绳仙游戏、宿舍旧楼、满怨古树、夜校怪谈、异常灾害处理组织、诡物收录、荆江堪舆和综艺惊魂。

- 推荐体量：短篇、中篇、主线章节、大型副本。
- 推荐 `moduleType`：探索、调查、解谜、追逐、互动小说、综合。
- 已有地点候选：荆江市、荆南大学、舞蹈教室、宿舍旧楼。
- 内容方向：校园怪谈、异常规则、时间或记忆层、诡物调查、灵异受害记录、异常处理任务。
- 典型结构：现实征兆 → 主动调查 → 异常规则显现 → 地图或玩家状态改变 → 找到证据/规则漏洞 → 回到现实并写入长期状态。
- 画面与音频：旧校舍、异常灯光、镜面、广播、远处脚步、静默、重复空间。
- 防换皮检查：每个异常必须拥有独立规则、调查方式和解除条件，不能只替换怪谈外观。

### 禁域长廊

现有内容覆盖感官试炼、旧案、人贩子、槐湾村、监狱风云、黑槲夜猎、黑蔷薇疗养院、静默矫治中心、阈限空间、永拘迷宫和高危囚犯运输。

- 推荐体量：短篇、中篇、大型副本、长期开放模块。
- 推荐 `moduleType`：探索、潜行、调查、脱困、生存、互动小说。
- 已有地点候选：安和精神病院、荆南大学、槐湾村、海顿联邦、灰巷、荆江市。
- 已有标签方向：监禁、迷宫、永久拘束、霸凌、胶水、石膏、镣铐、感官刺激。
- 典型结构：被制度/组织/空间限制 → 认识监管规则 → 在受限操作下调查 → 寻找漏洞或外援 → 脱离/改变规则 → 保存后续影响。
- 玩家控制重点：移动、调查、开门、道具和菜单权限必须随状态明确变化。
- 防膨胀检查：每个设施或迷宫要有确定出口、完成条件和返回规则，不能依靠无限房间拖长内容。

### 暗痕追迹

现有内容覆盖水泥鞋、失联、锈盐和沉默见证。

- 推荐体量：短篇、中篇、主线章节。
- 推荐 `moduleType`：调查、潜行、追逐、脱困、互动小说。
- 已有地点候选：荆江市、南堤老码头、海顿联邦、格兰港、灰巷。
- 已有标签方向：犯罪、失联、社死、DID、活埋、胶水、拘束生活、水泥鞋。
- 典型结构：线索中断或人员失联 → 城市暗面调查 → 犯罪势力施压/控制 → 留证、求援或脱困 → 线索继续指向更大组织。
- 画面方向：暗巷、港区、废墟、地下场所、潮湿与锈蚀环境。
- 防换皮检查：必须改变犯罪动机、调查入口、证据链和脱困结果，不能只更换控制手段。

### 幻域回声

现有内容包括浮华剧场和幻想世界冒险。

- 推荐体量：短篇、中篇、大型副本。
- 推荐 `moduleType`：探索、互动小说、解谜、小游戏、综合。
- 内容方向：类型片段、狗血叙事污染、幻想世界、被规则强制分配的角色身份。
- 典型结构：进入拟典/幻域 → 获得临时身份与规则 → 按规则推进或寻找破局方式 → 完成/打破剧目 → 带着状态或记忆返回现实。
- 防失控检查：必须定义剧目边界、退出条件和对现实主线的影响，不能把所有无法归类的幻想都塞入此标签。

### 遗迹残片

现有内容包括雾海孤岛探险和天坑雨林远征。

- 推荐体量：中篇、大型副本。
- 推荐 `moduleType`：探索、调查、生存、解谜、护送、战斗。
- 内容方向：科考远征、遗迹路线、陌生生态、补给和团队协作。
- 典型结构：远征准备 → 区域推进 → 环境阻断/遗迹发现 → 风险升级 → 取得样本或真相 → 撤离与报告。
- 防换皮检查：孤岛、雨林和后续遗迹必须拥有不同的移动、环境危险和调查机制。

### 浮世奇人

当前代表条目为小小女仆团，内容仍较少。

- 推荐体量：微型事件、短篇。
- 推荐 `moduleType`：互动小说、小游戏、探索、综合。
- 体验方向：由独特人物、群体或体型关系驱动的城市奇遇。
- 使用边界：先明确核心角色、交互规则和完整结局；内容不足时不要扩展成长期人物收容标签。

## 多标签边界

默认只选择一个主要 `storyTag`。需要跨风格时将主标签放在列表第一项，例如“街景一隅 + 诡影侵临”表示日常职业事件被异常规则打断；若两个风格各自拥有独立地图主流程和结局，应拆成两个节点。
