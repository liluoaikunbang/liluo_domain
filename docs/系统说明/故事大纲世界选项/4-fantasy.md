# 咒缚回响故事大纲选项

适用于 `world: 6-咒缚回响`、目录 `4-fantasy`。候选项用于选型与补全思路，最终一个来源节点仍只生成一个 Markdown 大纲文件。

## 已有 storyTags

### 异族风物

- 现有内容倾向：非人种族、地域习俗、身体差异与文化规则。
- 推荐 `moduleType`：探索、调查、职业体验、综合。
- 场景候选：异族聚落、集市、祭场、边境驿站、族群禁地。
- 玩法候选：习俗观察、语言或礼仪判断、身份伪装、族群关系、特殊移动能力。
- 状态候选：族群信任、禁忌触犯、伪装暴露、地区声望、特殊体质影响。
- 区分要点：异族差异应落实为地图通行、交互规则或能力变化，不能只停留在外观设定。
