# 咒缚回响故事大纲选项

适用于 `world: 6-咒缚回响`、目录 `4-fantasy`。本文件采用固定 `storyTags` 词表，不再提供或自动推导建议标签；最终一个来源节点仍只生成一个 Markdown 大纲文件。

## 固定 storyTags

### 炉边烟火

- 内容范围：魔幻日常、旅店酒馆、冒险者公会、炼金铺、集市、营地、低冲突生活片段。
- 推荐玩法：探索、职业体验、经营、小游戏。
- 设计重点：日常委托、制作交易、熟客关系、营地准备和可操作的低冲突循环。

### 律誓成笼

- 内容范围：贵族礼仪、骑士誓言、学院校规、教会戒律、契约身份、种族禁忌带来的规训。
- 推荐玩法：潜行、调查、职业体验、互动小说。
- 设计重点：规则应实际影响身份权限、通行、互动、能力、服装或任务条件。

### 咒影侵临

- 内容范围：诅咒、魔物、邪教、亡灵、深渊污染、禁忌魔法侵入正常世界。
- 推荐玩法：调查、生存、战斗、潜行、追逐。
- 设计重点：侵蚀应有可观察、验证和应对的规则，并逐步改变地图和角色状态。

### 秘案追痕

- 内容范围：魔法犯罪、失踪案、遗物追查、贵族阴谋、教会秘档、学院疑案。
- 推荐玩法：调查、解谜、探索、潜行。
- 设计重点：通过魔力痕迹、证词、遗物、档案和时间线组成可验证的证据链。

### 禁塔囚域

- 内容范围：地牢、古堡囚室、魔塔、审判所、实验室、奴隶矿坑、封印牢笼等囚禁空间。
- 推荐玩法：脱困、潜行、调查、解谜、生存。
- 设计重点：囚禁必须真实限制移动、互动或能力，并提供分阶段突破路径。

### 迷宫试炼

- 内容范围：魔塔层级、遗迹机关、地下城、试炼房间、谜题锁、DND 式关卡挑战。
- 推荐玩法：探索、解谜、战斗、生存、综合。
- 设计重点：不同楼层或房间应改变规则、资源和路线决策，不能只是重复战斗。

### 奇旅远征

- 内容范围：航海、荒原、山脉、地下城、星界裂隙、远方大陆探索。
- 推荐玩法：探索、生存、护送、战斗、综合。
- 设计重点：路线规划、补给、营地、环境变化、地标发现和新区域开放。

### 剑火争锋

- 内容范围：决斗、追杀、佣兵任务、竞技场、战争、攻城、骑士与军团冲突。
- 推荐玩法：战斗、追逐、护送、探索。
- 设计重点：胜负应来自操作、战术、队伍协同和地图目标，不能全部由剧情判定。

### 异族风物

- 内容范围：精灵、妖精、兽人、龙裔、吸血鬼、亡灵、地底种族等异族社会与习俗。
- 推荐玩法：探索、调查、职业体验、互动小说。
- 设计重点：种族差异应落实为地图通行、交互规则、习俗禁忌或特殊能力。

### 命契回响

- 内容范围：真名契约、恶魔交易、神谕、龙契、灵魂债务、命运代价。
- 推荐玩法：互动小说、调查、解谜、战斗、综合。
- 设计重点：契约代价必须改变能力、路线、关系或结局，并在签订前提供判断依据。

## 世界通用候选

- 地图方向：魔幻城镇、学院教会、污染区、秘案现场、囚禁设施、迷宫层级、远征路线、战场、异族聚落和契约异境。
- 状态方向：法力、诅咒、身份权限、誓约、地区声望、补给、警戒、拘束层级和灵魂债务。
- CG / 像素演出方向：酒馆集会、宣誓仪式、咒影扩散、魔法痕迹显现、封印闭合、魔塔换层、远征启航、军团交锋、异族庆典、契约烙印。

## 使用边界

- 本世界只从以上 10 个 `storyTags` 中选择，不再自行补充近义标签。
- 多标签条目以第一项为主风格；若各标签分别形成完整地图流程，应拆成独立节点。
- 候选地图、玩法、状态和演出只按实际采用内容写入正式大纲。
