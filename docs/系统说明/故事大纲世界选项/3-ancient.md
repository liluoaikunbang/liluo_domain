# 尘寰问道故事大纲选项

适用于 `world: 3-尘寰问道`、目录 `3-ancient`。本文件采用固定 `storyTags` 词表，不再提供或自动推导建议标签；选中的内容最终仍整合进一个条目 Markdown。

## 固定 storyTags

### 檐下烟火

- 内容范围：古风日常、市井生活、宅院琐事、茶楼客栈、庙会绣房。
- 推荐 `moduleType`：探索、职业体验、经营、小游戏、综合。
- 地图候选：街巷、宅院、茶楼、客栈、庙会、绣房、作坊。
- 玩法候选：日程安排、跑腿委托、生活互动、手艺小游戏、熟客关系和小范围探索。
- 状态候选：时辰、银钱、熟客度、家务进度、节庆进度、地区声望。
- 区分要点：日常活动应形成可操作的小循环和地图变化，不能只有闲谈片段。

### 礼法成笼

- 内容范围：家法、宫规、宗门戒律、婚约、契书、身份规训。
- 推荐 `moduleType`：潜行、调查、职业体验、互动小说、综合。
- 地图候选：深宅、宫苑、宗门、祠堂、礼堂、内院禁区。
- 玩法候选：礼仪规则判断、身份权限、违禁行为规避、契书条件、有限行动时段。
- 状态候选：礼法压力、身份等级、家族或宗门声望、违纪记录、婚约或契书状态。
- 区分要点：规训必须影响通行、互动、服装、日程或任务条件，而非只写人物感到压抑。

### 帷幕暗局

- 内容范围：宅斗、宫斗、权谋、门派内斗、替身、密信、套话。
- 推荐 `moduleType`：调查、潜行、互动小说、解谜。
- 地图候选：后宅、宫廊、书房、密室、宴席、门派议事堂。
- 玩法候选：偷听、密信交换、证词试探、身份伪装、关系网判断、阵营选择。
- 状态候选：嫌疑、暴露度、人物关系、掌握秘密、阵营声望、替身身份稳定度。
- 区分要点：权谋结果要落实到 NPC 立场、地图权限、资源或后续任务变化。

### 疑案残灯

- 内容范围：旧案、失踪、县衙、仵作、秘账、冤案、追查。
- 推荐 `moduleType`：调查、解谜、探索。
- 地图候选：案发宅院、县衙、义庄、夜巷、客栈、卷宗房。
- 玩法候选：现场勘验、证词矛盾、时间线拼合、验尸线索、秘账比对和指认选择。
- 状态候选：线索、嫌疑、官府信任、时限、证据链、误判风险。
- 区分要点：关键结论必须能追溯到玩家取得的线索，而不是由主角自动揭晓。

### 妖祟临门

- 内容范围：狐鬼、冥婚、山神、祠堂、妖物、邪祟侵入现实。
- 推荐 `moduleType`：调查、解谜、探索、生存、战斗。
- 地图候选：荒村、古宅、祠堂、坟山、夜渡、废庙、山神领域。
- 玩法候选：昼夜线索差异、禁忌验证、真假异象识别、仪式步骤、驱邪或谈判。
- 状态候选：时辰、邪祟侵蚀、护符、村民信任、禁忌触犯、仪式进度。
- 区分要点：妖祟规则应可观察、试错和利用，不只作为气氛描写。

### 幽牢深锁

- 内容范围：柴房、水牢、地牢、思过崖、祠堂禁闭、别院软禁。
- 推荐 `moduleType`：脱困、潜行、调查、生存。
- 地图候选：牢房、水牢、思过崖、祠堂偏室、软禁别院、狱卒值房、暗道。
- 玩法候选：观察巡逻、藏匿工具、忍耐管理、证据搜集、分阶段解除限制。
- 状态候选：拘束层级、寒冷、饥饿、伤势、看守警觉、活动范围。
- 区分要点：囚禁状态必须实际影响移动、互动范围或操作方式，并给出恢复与替代路径。

### 锁途危行

- 内容范围：押送、逃亡、和亲车队、镖车、囚车、山路遇袭。
- 推荐 `moduleType`：护送、追逐、脱困、生存、战斗。
- 地图候选：官道、山路、驿站、关隘、车队营地、峡谷、渡口。
- 玩法候选：车队路线、行进时段、伏击应对、受限脱逃、保护或争取同行者。
- 状态候选：行程、车队完整度、看守警觉、同行者关系、补给、道路封锁。
- 区分要点：核心压力来自持续移动中的限制与危险，不与静态牢狱内容混同。

### 刀影惊鸿

- 内容范围：武打、追杀、劫道、山寨、侠盗、门派冲突。
- 推荐 `moduleType`：战斗、探索、护送、追逐。
- 地图候选：驿道、城门、屋顶、竹林、山寨、门派演武场。
- 玩法候选：格挡闪避、追踪敌人、地形利用、路线选择、保护目标和有限补给。
- 状态候选：体力、伤势、通缉度、同伴状态、门派关系、追击距离。
- 区分要点：冲突结果应由移动、交锋、护送或路线判断产生，不能全部收束为对白胜负。

### 因果问命

- 内容范围：命格、天道、心魔、誓约、轮回、劫数。
- 推荐 `moduleType`：探索、解谜、互动小说、战斗、综合。
- 地图候选：问心境、轮回幻境、天机阁、祭坛、渡劫地、因果回廊。
- 玩法候选：因果选择、誓约条件、心魔试炼、记忆保留、命格能力和代价交换。
- 状态候选：命格、因果债、誓约、心魔、劫数进度、轮回记忆。
- 区分要点：选择代价必须改变能力、路线、关系或结局，不能只用抽象旁白表达宿命。

## 世界通用候选

- 角色身份：平民、侍女、贵族、弟子、侠客、官差、囚徒、仵作、商旅、和亲使团成员。
- 地图结构：城镇街巷、深宅宫苑、宗门分层、官署牢狱、山野官道、祠庙与异境。
- 常用状态：时辰、体力、伤势、声望、通缉、人物关系、证据、拘束层级、因果与誓约。
- 已有专用玩法值可按实际内容复用：`监禁-水牢`、`监禁-冤罪`、`社死-无鞋`、`刑罚-寒冷`。
- 已有角色或地点只有在确实沿用同一对象时才能填写，不得作为通用占位。

## 使用边界

- 本世界只从以上 9 个 `storyTags` 中选择，不再自行补充近义标签。
- 多标签条目以第一项为主风格；若各标签分别形成完整地图流程，应拆成独立节点。
- 候选地图、玩法和状态只按实际采用内容写入正式大纲。
