# 尘寰问道故事大纲选项

适用于 `world: 3-尘寰问道`、目录 `3-ancient`。本文件是创建条目时的候选库，不是另一份大纲模板；选中的内容最终仍合并进一个条目 Markdown。

## 已有 storyTags

### 玄途炼心

- 现有内容倾向：受挫、废除修为、转入异宗、重新修炼与心境选择。
- 适合节点：`缚身反杀`、`无人收徒`、`陷害，入魔宗`、`魔宗历险`、`重新修炼`。
- 推荐 `moduleType`：探索、战斗、调查、综合。
- 地图候选：玉衡宗、血影门、山门、思过崖、试炼地、修炼洞府。
- 玩法候选：修为阶段门槛、功法选择、宗门关系、资源取舍、受限状态下脱困。
- 状态候选：修为、宗门声望、正邪倾向、伤势、关键功法、师门关系。
- 区分要点：每个修炼阶段都应改变玩家可进入区域、可用能力或解决事件的方法，不能只用文字宣布“变强”。

### 刀影惊鸿

- 现有内容倾向：乱世游历、武人交锋、围城与护送。
- 推荐 `moduleType`：战斗、探索、护送、追逐。
- 场景候选：驿道、城门、屋顶、竹林、边塞、围城街区。
- 玩法候选：格挡与闪避、路线选择、保护目标、追踪敌人、有限补给。
- 状态候选：体力、伤势、通缉度、同伴存活、城防进度。
- 区分要点：冲突结果应由移动、交锋、护送或路线判断产生，不能全部收束为对白胜负。

### 幽牢深锁

- 现有内容倾向：水牢、冤罪、监禁、刑罚与拘束生活。
- 推荐 `moduleType`：脱困、潜行、调查、生存。
- 场景候选：牢房、水牢、刑房、狱卒值房、暗道、放风区。
- 玩法候选：观察巡逻、藏匿工具、忍耐值管理、证据搜集、分阶段解除限制。
- 状态候选：拘束层级、寒冷、饥饿、伤势、狱卒警觉、证据量。
- 区分要点：受限状态必须实际影响移动、互动范围或操作方式，并给出恢复与替代路径。

### 疑案残灯

- 现有内容倾向：古代案件、线索比对、人物证词与冤情。
- 推荐 `moduleType`：调查、解谜、探索。
- 场景候选：案发宅院、县衙、义庄、夜巷、客栈、卷宗房。
- 玩法候选：现场勘验、证词矛盾、时间线拼合、物证组合、指认选择。
- 状态候选：线索、嫌疑、官府信任、时限、误判风险。
- 区分要点：关键结论必须能追溯到玩家取得的线索，而不是由主角在剧情中自动揭晓。

### 幽案志异

- 现有内容倾向：志怪、灵异案件与真假难辨的民间传闻。
- 推荐 `moduleType`：调查、解谜、探索、生存。
- 场景候选：荒村、古宅、祠堂、坟山、夜渡、废庙。
- 玩法候选：昼夜线索差异、禁忌规则验证、真假异象识别、仪式步骤、理智或侵蚀管理。
- 状态候选：时辰、灵异侵蚀、护符、村民信任、禁忌触犯记录。
- 区分要点：怪异规则应可观察、试错和利用，不只作为气氛描写。

### 幕府异闻

- 依据节点：`樱岚幕府`。
- 推荐 `moduleType`：探索、调查、潜行、战斗。
- 核心体验：异域制度、城下町探索、派系关系与隐秘任务。

## 世界通用候选

- 角色身份：弟子、散修、侠客、官差、囚徒、侍女、贵族、医者、商旅。
- 地图结构：宗门分层、城镇街巷、山野路径、官署牢狱、宫苑禁区、边塞驿路。
- 常用状态：修为、体力、伤势、声望、通缉、宗门关系、证据、拘束层级、时辰。
- 已有专用玩法值可优先复用：`监禁-水牢`、`监禁-冤罪`、`社死-无鞋`、`刑罚-寒冷`。
- 已有内容中出现的角色或地点（如妙桐、茯丝、顾文若、玉衡宗、血影门）只有在确实沿用同一对象时才能填写，不得当作通用占位。
