# 角色成长与关系长期记忆系统

权威记录为 `src/game/data/story_outline/long-term-memory.json`。它保存跨章节仍然成立的角色能力、代价、立场和关系阶段，不保存每场戏的情绪流水，也不替代 `GameSaveData`。

## 写入门槛

记录必须包含角色或关系类型、主体、连续性范围、`lasting: true`、变化、生效节点和正式证据；关系另需对方角色。只有 `world`、`series` 或 `cross-world` 范围可以进入。候选、猜测、外部参考、临时敌意、当场服装/状态和未批准的解释全部拒绝。

当前首批记录只提炼已经在《病房苏醒》中明确成立的两项长期事实：璃落掌握基础灵异辨识；沈芷转为主要照护者并保留不污染记忆恢复的保护边界。它们引用原始 Markdown，没有反向改写故事。

校验命令：`npm run character:memory:validate -- --input <record.json>`。如果某项成长需要读档后恢复，必须另行扩展并迁移存档 schema；本系统不写浏览器存档。
