# 视觉资产图床与R2管理系统

这套系统只负责公开展示资产，不负责离线私有游戏资源。

它把“公开展示图片”从代码仓库里拆出来，改成：

- 代码仓库存：索引、用途分类、发布状态、公开 URL
- Cloudflare R2 存：实际对外展示的 WebP 变体和缩略图

## 适用范围

适合：

- README 海报图
- 官网 Hero / 角色 / 世界 / Gallery 图
- 路线图、证据板、开发日志公开配图
- 明确选入公开展示的游戏截图

不适合：

- 运行时 CG
- 地图源、PSD、参考图
- 离线版敏感资源

这些不适合的对象，统一走 [公开展示资产与离线私有素材双轨分发系统](./公开展示资产与离线私有素材双轨分发系统.md) 里的离线私有线。

## 当前权威文件

- `.env.assets.example`
- `.env.assets.local`
- `docs/assets/registry/website-r2-manifest.json`
- `scripts/assets/visual-asset-manager.mjs`

## R2 路径约定

按用途分类，不按随手文件名分类：

```text
liluo-universe-assets/
├── website/
│   ├── hero/
│   ├── worlds/
│   ├── characters/
│   ├── gallery/

│   └── concept/

```

## 命令入口

### 检查配置

```powershell
npm run assets:r2:status
```

### 预处理图片

```powershell
npm run assets:r2:prepare -- --asset readme-hero-v03
```

### dry-run 上传

```powershell
npm run assets:r2:upload -- --asset readme-hero-v03
```

### 正式上传

```powershell
npm run assets:r2:upload -- --asset readme-hero-v03 --live
```

### 清理旧对象

```powershell
npm run assets:r2:prune
npm run assets:r2:prune -- --live
```

## 本地配置

复制：

- `.env.assets.example` -> `.env.assets.local`

填写：

- `LILUO_ASSET_R2_ACCOUNT_ID`
- `LILUO_ASSET_R2_ACCESS_KEY_ID`
- `LILUO_ASSET_R2_SECRET_ACCESS_KEY`
- `LILUO_ASSET_R2_BUCKET`
- `LILUO_ASSET_R2_REGION`
- `LILUO_ASSET_R2_PUBLIC_BASE_URL`

`LILUO_ASSET_R2_ENDPOINT` 可以留空，脚本会按 `ACCOUNT_ID` 自动推导。

## 行为边界

1. 默认先 `status` 或 dry-run，再 `--live`。
2. 不要求把密钥贴进聊天，只认本地 `.env.assets.local`。
3. 替换同一路径图时，R2 直接覆盖。
4. 只有改路径、改 slug 或删条目时，才额外跑 `prune`。
5. 私有运行素材不进入这条线。
