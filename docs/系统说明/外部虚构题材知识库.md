# 外部虚构题材知识库

本系统为璃落创作提供文学表达、画面结构、场景灵感、虚构状态与题材模式的外部参考，不是项目正式设定库。所有派生记录均为 `knowledgeScope: external-fiction-reference`、`canonical: false`。

## 来源与结构

用户只持续维护本机权威目录；当前机器由被 Git 忽略的 `external-knowledge/source-sync.local.json` 保存绝对路径。`external-knowledge/sources/fiction-bondage/` 是受控仓库镜像，构建器只索引镜像且从不反向修改权威源。Markdown/TXT 等纯文本进入分段索引，图片等不支持格式只编目。

- `sources/`：原始输入；`catalog/`：稳定来源 ID、哈希、元数据和重复组。
- `sync-manifest.json` / `sync-status.json`：受控镜像清单、最近同步计划与安全状态；绝对路径只存在本机 `.local.json`。
- `index/`：按 500 段分片的定位索引、关键词、标签与来源反向定位。
- `cards/`：五类抽象卡；`reports/`：质量、重复、缺失元数据与直接照搬风险。
- `schemas/`：来源、分段和卡片契约；`scripts/external-knowledge/`：本地确定性工具。

数据链路为：原始来源 → 来源目录 → 文本分段 → 关键词/标签索引 → 抽象知识卡 → 结合项目正式知识原创转化。来源路径、sourceId、segmentId 与行号贯穿全链路。

## 知识卡

- `expression`：表达维度、语气、视角和节奏。
- `visual-structure`：姿态轮廓、视觉重心、道具/空间关系与镜头。
- `scene-pattern`：环境、氛围、场景功能与可适配世界。
- `fictional-state`：剧情行动边界、视觉反馈和事件/玩法/CG 功能，不记录现实可执行教程。
- `trope`：起点、推进、变化、反转、转场、重复套路与原创变体位置。

自动卡只标 `candidate`；经明确抽象审核后才标 `reviewed`。卡片必须跨回 `sourceRefs`，正文不得复制来源句子。

## 查询与维护

```powershell
npm run external:knowledge:query -- --query "古堡 逃脱" --mode and --limit 8 --format markdown
npm run external:knowledge:query -- --card-type visual-structure --query "封闭空间"
npm run external:knowledge:check
npm run external:knowledge:sync
npm run external:knowledge:update
npm run external:knowledge:build
npm run external:knowledge:validate
```

增量更新先比较权威源与镜像的路径和 SHA-256，识别新增、修改、删除与同哈希重命名，只复制变化内容；普通删除自动传播到清单管理的镜像文件，一次删除超过 20% 时自动阻止，防止盘符或目录异常被误判。随后只重解析变化来源，并如实重建全局关键词/标签索引。全量构建先写临时产物，再逐文件安全发布。重复来源只报告，不删除。

## 项目使用与原创性

唯一底线是：不直接照搬原文表达。先检索多个参考、抽象共同机制、去除专名和独特事件顺序，再读取项目正式索引与权威文件，围绕璃落世界、角色、地图、玩法和事件重新设计。外部知识不能反向覆盖项目事实。

正式写入前运行：

```powershell
npm run external:knowledge:copy-check -- --input "待检查文件.md"
```

检查连续相同字符、长短语与 n-gram 重叠，返回来源路径/行号和 `low`、`medium`、`high`。报告不复制长原文，也不构成法律版权判断；中高风险应改写后复检。

## 状态、恢复与 Git

`current` 可直接使用；`stale` 先增量更新；`partial` 表示部分格式/来源未索引；`error` 先修生成器或数据契约；`not-indexed` 需首次构建。索引损坏、schema/分段变化或大量移动时运行安全全量重建，不手改生成文件。

建议提交通用配置、同步清单、schema、工具、卡片、目录/索引、报告与状态，以便可复现查询；含本机绝对路径的 `source-sync.local.json` 必须忽略。原始语料是否进入 Git 由仓库内容策略决定。不得提交 `.build-*`、`.publishing`、`.syncing`、备份和其他临时发布文件。

未来可按真实需求增加 SQLite FTS、本地全文增强、本地语义 Embedding、混合 RAG、MCP 查询、卡片候选生成和可视化浏览器；当前不接在线向量库、外部模型 API、云 RAG 或常驻服务。
