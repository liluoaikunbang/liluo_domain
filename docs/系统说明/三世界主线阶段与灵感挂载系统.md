# 三世界主线阶段与灵感挂载系统

本系统的权威故事源仍是 `src/game/data/story_outline/sources/2-apocalypse.json`、`4-fantasy.json`、`5-science.json` 及其同目录 Markdown。`mainline-restructure-preservation.json` 只保存本次重构前旧节点的受保护内容哈希与迁移去向，用于验证，不替代故事源。

## 关系分层

- 世界与地区归属：由 `world` 和故事树容器表达。
- 主线阶段：由新增的 `status: 主线任务` 阶段容器及其主线备忘表达。
- 必经程度：在阶段备忘与保全清单的 `destination.type` 中表达；它不是普通节点的成熟度或原文设定。
- 时间和前置：只在已有原文或后续正式设计确认后写入普通节点，不能从阶段排序反推具体因果。

## 三条世界线

### 寂土挽歌

正史按灾变爆发、城市沦陷、荒野迁徙、残存文明、废土新秩序、裂界终局和后日谈组织；异常灾域与末日轮回是并列的独立容器。新末日灵感先判断能否自然延续正史、是否重置世界规则、是否为灾域或独立轮回；无法确认时只挂阶段并保留待办。

### 咒缚回响

绝对主线是璃落从高天赋登顶、古咒触发、带咒远行到夺回咒缚主权的进展。地区卷进入“带咒远行”池，默认不是固定必经顺序；新灵感先标记诅咒阶段及其提供的知识、压制、治疗、误导、盟友或终局准备，未确认的效果不得写成 canon。

### 星宇织梦

采用以身份、航路、移动据点和自主选择下一站为核心的航程弱主线。星球、空间站、飞船、方舟、边境和深空内容按篇章容器归属，不要求立即获得精确星球顺序。新灵感先挂航程阶段与篇章类型，长期变化、返回权限和锚点关系未知时登记缺口。

## 维护

新增末日类型、西幻地区/解咒方法、星球/空间站/飞船事件，或确认、否决一个候选锚点时，先更新对应主线备忘和正式故事结构；再更新 `project-navigation/manual-gaps.json`，运行导航增量更新与原文保全测试。不得把阶段结构推断为已确认剧情。
