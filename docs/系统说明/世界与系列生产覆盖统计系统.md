# 世界与系列生产覆盖统计系统

本系统按请求从故事、Markdown、地图、事件、对话、玩法、素材、正式入口和验证证据派生世界/系列覆盖，不维护主观百分比，也不向每个故事节点塞进度字段。

阶段依次为 `concept`、`outline`、`productionDesign`、`skeleton`、`graybox`、`partiallyPlayable`、`playable`、`validated`。每个正向结论都要列真实证据：有很多文件不能证明入口可达，有地图不能证明剧情可玩，有测试文件不能证明浏览器流程已验证。

运行 `npm run production:coverage` 获取 JSON。世界来自六个正式来源 JSON；系列按世界根节点的直接子树统计。当前脚本能保守识别节点、Markdown、生产条件/引用和真实注册资源；灰盒、可玩和验证必须有明确路线、正式入口、完成/持久化和验证证据，首版不会从文件数量自动抬高。

在升级后的体系里，覆盖统计不只回答“这个世界做了多少地图”，也要回答“这个世界是否已经具备进入叙事生产、体验编排和多形态输出的真实证据”。覆盖结果仍是导航和排期依据，不是 canon。
项目故事索引当前为 `partial`：160 个 JSON 节点中只有 80 个 Markdown。报告必须披露这一事实，并以原始文件核验结论。
