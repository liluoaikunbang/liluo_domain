# 事件与对话系统

事件与对话系统负责把地图交互、剧情文本、选项分支和运行时动作串起来。

## 当前入口

- `src/game/core/EventRunner.ts`
- `src/game/data/maps/<mapId>/events.json`
- `src/game/data/maps/<mapId>/dialogues.json`
- `src/game/views/`

## 数据职责

- `events.json`：描述地图事件入口、触发方式和事件动作。
- `dialogues.json`：描述对话节点、说话人、文本、选项和后续跳转。
- `EventRunner`：统一推进事件和对话流程，把数据层动作转成运行时效果。

## 设计原则

- 地图事件优先服务探索和剧情推进。
- 对话数据应尽量保持可扩展，不把临时逻辑硬写进 UI。
- 分支对话需要保证事件流安全，避免在关键选择中被错误强退。
- 对话表现可以有立绘、场景图、说话人高亮等增强，但不应把项目变成纯 GalGame。
