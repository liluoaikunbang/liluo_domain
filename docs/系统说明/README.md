# 系统说明

这里记录项目当前系统应该如何理解和维护。

## 维护方式

- 当一次功能改动只影响历史追踪时，更新 `docs/功能更新/` 即可。
- 当一次功能改动改变了当前系统用法、目录职责或扩展方式时，同时更新本目录对应说明。
- 不确定应该放哪里时，优先把“为什么这么改”放到功能更新，把“以后怎么用”放到系统说明。
