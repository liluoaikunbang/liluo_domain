# 大纲关联图谱系统

关联图谱是「大纲」模块内的统一可视化投影层，用于浏览与校准璃落宇宙中故事、情节、玩法、人物、组织、地点、物品、普通 Tag、紧缚 Tag、细节概念、普通 RAG 与 Style-RAG 之间的**多对多**联系。

它不是第二套主数据，也不会因为打开图谱、拖动节点或自动推断而改写正史。

## 入口

游戏内旅途菜单 → 侧栏「大纲」→ 顶部分栏 **关联图谱**。

既有「故事｜情节｜玩法｜人物/组织」分栏保持不变。

## 四种模式

| 模式 | 用途 | 节点显示 |
|---|---|---|
| 全图 | 宏观宇宙关系网，强调整体感与规模 | **只显示名称**（可带极少量状态角标） |
| 聚焦 | 选中节点 + 一层/两层邻域，用于校准 | 名称 + 短摘要 + 类别 |
| 筛选 | 按类别、关系、校准状态或快捷组合过滤 | 名称 + 受控摘要 |
| 汇总 | 统计卡与质量缺口 | 列表/统计为主 |

硬性规则：全图模式不得渲染摘要文本。

## 节点类别

故事、世界、系列、情节、玩法、普通 Tag、紧缚 Tag、细节概念、人物、组织、地点、物品、普通 RAG、Style-RAG。

全图泳道上「世界」与「系列」合并为同一列「世界 / 系列」（节点类型仍可区分）；图例与筛选同步折叠。

细节概念（如「后手观音」）可设 `visibility.primaryTag=false`，不进入主 Tag 筛选器，但必须可搜索、可进图谱与详情。

### Style-RAG 投影规则

- **主视觉**：`style-taxonomy` 展开的**写法名词**（场景功能、紧缚写法功能、视角、节奏、感官优先等）+ 写法维度父节点。
- **文章证据**：`article-registry` 中的小说/文章名作为次级挂点（`meta.role=evidence`），挂到适用域与已标注写法名词上；**全图默认隐藏**。
- 图例提供「文章证据：显示/隐藏」；聚焦邻域与搜索跳转可临时露出证据。
- 不再把 `restraintFunction` 英文枚举写成紧缚 Tag 节点。

### 普通 RAG

仍是抽象知识卡（术语 / 情节模式 / 表达 / 画面结构等）。图谱装载 `external-knowledge/cards/`，并对尚未落盘的 `card-rules.json` 规则做候选投影；不改变 RAG 定位。

## 关系语义与颜色

每条边含：`relationType`、起终点、来源、置信度、审核状态、是否自动生成。

常见颜色（与紫色主题协调，深色底可读）：

| 关系族 | 颜色倾向 |
|---|---|
| 层级 / 包含 / parent | 浅紫白 |
| Tag 关联 | 青 |
| 紧缚 Tag / 概念 | 金 |
| 人物 / 组织 / 地点 / 物品 | 蓝 |
| 普通 RAG | 绿 |
| Style-RAG | 洋红 |
| 时间 / 前后 | 橙 |
| 待校准 / 冲突 | 红 |

图例支持：单击只看某类关系、再次恢复、全部显示、隐藏全部关系、隐藏节点类别。

## 交互

- 幕布：`GameScrollArea` 显示横向/纵向滚动条；鼠标拖拽平移；滚轮滚动；Ctrl/⌘ + 滚轮缩放。
- 图例：左侧栏，可隐藏；图例与详情正文均使用项目 `GameScrollArea` 自制滚动条。
- 节点位置只读：不支持拖拽节点或修改布局。
- 点击节点：右侧详情面板（不跳转其他页面、不自动切到聚焦模式）；同时高亮该节点相连关系线，并压暗其余连线。
- 详情标题旁「聚焦模式」：显式切换为当前节点邻域聚焦；「取消聚焦」回到全图并保留详情。
- 详情内关联节点：画布定位 + 高亮关系 + 详情切换；支持上一节点 / 下一节点 / 返回初始。
- 搜索：名称、别名、稳定 ID、Tag、概念、情节、RAG、Style-RAG、人物等地名。
- 布局种子缓存于转换层；视口滚动与缩放可写入 `localStorage`。

## 数据层

权威源仍是现有 JSON / 注册表：

- 故事：`src/game/data/story_outline/sources/`
- 情节：`plot_outline/catalog.json`
- 玩法：`gameplay_outline/catalog.json`
- 人物/组织派生：`storyCharacterOutline.js`
- 普通 RAG：`external-knowledge/cards/`（可补充 `card-rules.json` 候选）
- Style-RAG：**写法名词**来自 `project-navigation/style-taxonomy.json`；**文章证据**来自 `docs/写作资产/外部风格研究/article-registry.json`
- 抽查状态：`docs/知识检索校准/registry.json`
- 概念种子：`src/game/data/outline_relation_graph/conceptRegistry.js`

转换入口：`buildOutlineRelationGraph()`。运行时由 `loadOutlineRelationGraph.js` 记忆化装载；CLI 可随时重建投影统计。

## 校准闭环

1. 在图谱中发现孤立、缺来源、低置信度、有概念无 RAG、有情节无 Style-RAG 等缺口  
2. 打开详情查看来源与关联  
3. 使用既有 `rag:audit:*` / `style-rag:audit:*` 记录问题  
4. 按既有流程升级 Skill / 重建受影响索引  
5. 图谱「重建」刷新投影后再抽查

- 导出高清图 / 演示模式
- 更复杂的力导与时间轴动态图
- 图谱快照对比与多人批注
