# 玩法适配与体验编排

## 目标

体验编排回答的是：同一段正式叙事，当前更适合被做成什么，以及应该按什么顺序逐步长出来。

## 编排原则

- 先问体验价值，再选载体。
- 先做最能验证核心张力的形态，再做成本更高的扩展。
- 先保证玩家能进入、推进、完成并留下记忆点，再谈包装完整度。

## 常见适配方向

### 像素风 RPG

适合强调空间感、探索感、移动、地形关系、场景氛围和玩家主动接近事件的内容。

### 互动小说

适合强调阅读节奏、分支张力、内心变化、局部高压情境和低成本灰盒验证的内容。

### 桥段稿与资料表达

适合在还未进入正式运行时前，先固定桥段、情绪逻辑、CG 需求、道具说明和后续制作边界。

## 渐进路线

一段叙事可以采用如下路径：

1. 先整理成叙事生产包。
2. 用互动小说或桥段稿验证节奏与情绪。
3. 再进入地图、事件、对话和正式状态接入。
4. 最后补足 CG、音频和更高成本增强。

这不是唯一顺序，但默认比“直接把所有内容压成地图最终态”更稳。

## 编排失败时的判断

如果某段内容迟迟无法决定形态，优先说明它缺的是哪一类信息：

- 正史事实不稳。
- 叙事目标不清。
- 玩法入口不成立。
- 素材成本过高。
- 需要先用更轻的形态试错。
