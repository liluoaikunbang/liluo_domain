# 外部文章清单与用户评权系统

## 目的

把本地外部文章镜像登记为**可审计的风格证据**，由用户评权后方能进入生产文风包。清单服务表达参考，不写入正史。

## 来源根目录

配置：`project-navigation/external-style-sources.json`

| ID | 路径 | 初始 themeDomain |
| --- | --- | --- |
| restraint-articles | `external-knowledge/sources/fiction-bondage` | restraint-themed |
| zhihu-articles | `external-knowledge/sources/zhihu-novels` | general-prose |

文件夹分类是**初始提示**；单篇可在评权时改 `themeDomain`。

## 注册表

| 文件 | 内容 |
| --- | --- |
| `docs/写作资产/外部风格研究/article-registry.json` | 文章 ID、标题、作者、元数据、用户分数 |
| `docs/写作资产/外部风格研究/author-registry.json` | 作者 prior、关联文章、派生统计 |
| `docs/写作资产/外部风格研究/duplicate-groups.json` | 重复组（inventory 生成） |

**文章数量与统计以 `writing:external:inventory` 输出为准**；文档不硬编码总数。

## 工作流

### 1. 建清单

```bash
npm run writing:external:inventory
```

扫描来源、提取标题/作者/元数据、重建作者索引、检测重复。

### 2. 浏览

```bash
npm run writing:external:authors
npm run writing:external:validate
```

列出作者、标题、review 状态；校验 registry 与策略一致。

### 3. 批量评权

```bash
npm run writing:external:review:export
# 用户离线填写
npm run writing:external:review:import -- --input docs/写作资产/工作区/external-review/<file>.json
npm run writing:external:validate
```

导出目录：`docs/写作资产/工作区/external-review/`。

### 4. 进入文风包

已评且权重 ≥ `minimumArticleOverallWeightForProduction` 的文章才可被 `writing:style:search` 选中。默认表示形式为 `source-only`（pack 不粘贴整篇）。

## 分数规则

- **仅用户导入**产生 article weight 与 author prior
- 文章分权重 0.7 + 作者 prior 0.3（策略可调）
- 未评项用中性 0.5，不视为低质或高质
- `themeDomain` 是领域匹配维度，**不是**质量分

## 阅读向说明与自然表达

向用户解释评权结果、撰写评权旁白、或把已评文章抽象进 Style Pack / 写作表文案时，先应用 `liluo-natural-expression` light；分数字段、ID、路径与命令输出不润色。详见 [璃落自然表达与文气塑形系统](./璃落自然表达与文气塑形系统.md)。

## 禁止

- 模型或 Agent 伪造 `reviewed` 状态
- 未评文章自动进生产 pack
- 把外部全文贴进聊天或 Git

## 与外部虚构知识库区别

| 系统 | 用途 |
| --- | --- |
| 本系统 | 已评外部文章的表达参考与 pack |
| liluo-external-fiction-knowledge | 抽象灵感卡、桥段机制、照搬风险 |
