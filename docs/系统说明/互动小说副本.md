# 互动小说副本

互动小说副本是当前游戏视图中的一种覆盖模式，用于承载偏文字冒险的副本内容。

## 当前入口

- `src/game/data/interactive_fictions/registry.ts`
- `src/game/data/interactive_fictions/<scenarioId>/`
- `src/game/views/modes/`
- `src/game/views/components/base/GameScrollArea.vue`

## 数据目录

单个副本使用：

```text
src/game/data/interactive_fictions/<scenarioId>/
```

副本通过 `data/interactive_fictions/registry.ts` 汇总。

## 体验原则

- 互动小说是 RPG 世界的一部分，不应变成独立的资料页或完全脱离地图的主系统。
- 副本打开时覆盖地图，离开后回到地图。
- 副本 UI 应阻断底层地图点击。
- 剧情栏滚动状态应在切换节点或重开时恢复到合理位置。
- 结局状态应尽量沉淀为 flags，方便后续地图、剧情或状态系统复用。
