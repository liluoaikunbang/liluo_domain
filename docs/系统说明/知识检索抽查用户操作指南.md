# 知识检索抽查用户操作指南

## 快速开始

### 综合抽一批（推荐）

```bash
npm run knowledge:audit:sample -- --mode low-confidence --batch-size 8
# 或 --mode graph-gap|random|hit-frequency
```

打开 `docs/知识检索校准/batches/` 下最新 Markdown。其中紧缚 RAG 项默认是**知识卡**（含 definition / 邻居 / 卡审三问）。按每条的 `channel` 协商修正后再 record。

### Style-RAG 抽一批

```bash
npm run style-rag:audit:sample -- --mode low-confidence --batch-size 8
```

```bash
npm run style-rag:audit:record -- --asset ea-... --issue "..." --correct "..." --category author-info-error --general-rule false
```

### 紧缚 RAG 抽一批（默认只抽知识卡）

```bash
npm run rag:audit:sample -- --mode low-confidence --batch-size 8
# 需要源条目时：
npm run rag:audit:sample -- --mode low-confidence --batch-size 8 --include-sources
# 或 --asset-kind source|all
```

人工卡审重点：描述是否够用、是否有独立存在价值、与邻居是否该分层/合并。不必以读原文为主。协商与改稿说明须先走 `liluo-natural-expression` light，说具体、可对照，不用口号。

定性评价（如「太抽象」）不要立刻 `record`：先谈修改方向 → 改稿计划（含原文/拟改）→ 你确认改好或说「暂时这样」后再写卡并 `rag:audit:record`。

```bash
npm run rag:audit:record -- --asset <cardId> --issue "..." --correct "..." --category wrong-summary
```

### 细节概念抽一批

```bash
npm run concept:audit:sample -- --mode graph-gap --batch-size 8
npm run concept:audit:related -- --asset restraint.pose.houshou-guanyin
npm run concept:audit:record -- --asset restraint.pose.houshou-guanyin --issue "..." --correct "..." --category missing-rag-link --related rag:rag.restraint.effect.tickling:adjusted --related-complete
```

### 情节抽一批

```bash
npm run plot:audit:sample -- --mode graph-gap --batch-size 8
npm run plot:audit:record -- --asset <plot-id> --issue "..." --correct "..." --category wrong-tag
```

### 查看状态

```bash
npm run knowledge:audit:status
npm run rag:audit:status
npm run style-rag:audit:status
npm run concept:audit:status
npm run plot:audit:status
npm run writing:gaps:remind -- --topic rag-accuracy
```

### 受影响重建 / 校验

```bash
npm run style-rag:rebuild:affected          # dry-run
npm run style-rag:rebuild:affected -- --commit
npm run rag:rebuild:affected               # dry-run
npm run rag:rebuild:affected -- --commit
npm run concept:rebuild:affected           # 人工改概念后校验图谱
npm run plot:rebuild:affected              # 人工改目录后校验图谱
```

## 注意

- 不要一次要求处理全部文章/情节。
- 不要因为一条错误就改 Skill。
- 重建不会修改 `external-knowledge/sources/**` 原文。
- 细节概念与情节只抽查校准，不合并进 RAG 主库。
- **改一处必查关联**：record 前先跑 `npm run concept:audit:related -- --asset <id>`（或其他通道 `*:audit:related`）；有需要同步改的概念/RAG/情节/Style 邻居，与主条目一起改完再记 `relatedAdjustments`（或 `--related channel:id:adjusted --related-complete`）。
