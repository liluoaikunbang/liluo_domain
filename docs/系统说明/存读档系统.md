# 存读档系统

## 当前定位

存读档系统用于恢复冒险 RPG 主流程中的关键进度。当前版本使用浏览器 `localStorage` 暂存，不写入项目根目录文件。

当前保存内容包括：

- 人物运行时状态：外观、立绘、状态、拘束、背包、装备。
- 地图位置：`mapId`。
- 地图内世界坐标：`x` / `y`。
- 地图会话 flags。

## 入口

- 游戏内菜单：
  - “存档”栏目保存当前进度。
  - “读档”栏目读取已有本机存档。
  - “存档”栏目底部可以导出全部存档 JSON。
  - “读档”栏目底部可以导入本地 JSON，导入前必须二次确认。
- 首页：
  - “新的旅程”创建新流程。
  - “继续旅程”打开存档选择面板。
  - 选择具体存档后进入对应地图和坐标。

## 维护边界

- 存档结构维护在 `src/game/core/saveData.ts`。
- 浏览器暂存、导出、导入维护在 `src/game/core/saveStorage.ts`。
- 人物运行时状态来源于 `src/game/core/playerRuntime.ts`。
- 地图坐标恢复通过 `MapLoader`、`WorldSceneRuntime`、`WorldScene` 串接。
- Vue 入口和 UI 只负责组织流程，不应在组件里临时制造独立存档结构。

## 扩展规则

新增需要持久化的状态时：

1. 先扩展 `GameSaveData`。
2. 在 `createGameSaveData()` 中写入该状态。
3. 在 `applyGameSaveData()` 中恢复该状态。
4. 为新增字段补充测试。
5. 如果字段依赖某个系统 registry，优先在入口层校验，不要让 `saveData.ts` 直接依赖大型地图或剧情 registry。

## 当前限制

- 存档存在浏览器本机，清理浏览器数据会导致丢失。
- 导出 JSON 是备份方式，不会自动同步。
- 导入 JSON 会覆盖当前浏览器里的全部存档，因此 UI 必须保留二次确认。
