# 项目描述性上下文打包系统

把「能最大程度描述璃落城堡、但对运行时实现意义不大」的材料同步到本地临时目录并压缩，方便上传给其他 AI 分析。

## 用途

- 纳入：项目配置、`docs/`、`project-index/`、导航注册表、Schema、Skill 说明、故事/情节/玩法大纲 JSON 与 Markdown、地图事件/对话 JSON 等。
- 排除：运行时实现、素材与音视频、`map.json`、外部小说全文、`node_modules` 与构建产物。
- 输出目录 `.local/project-context-pack/` 为纯临时文件，已 gitignore，不上传 GitHub。

## 正式文件 ↔ 临时副本

- 清单：`scripts/project-context-pack/catalog.json`（入库）
- 关联：`.local/project-context-pack/LINK-STATE.json`（临时；记录 source、staging、mtime、size）
- 打包默认写：`.local/project-context-pack/liluo-project-context-latest.zip`
- **默认只保留最新 zip**：同目录旧版压缩包会删除；仅当用户明确要求保留历史时使用 `--keep-previous`。
- **省 token**：Agent 只跑 npm 并读命令 JSON，不打开 LINK-STATE / staging / 文件清单；包内不含外部 `sources` 全文与 `docs/功能更新` 历史；清单详情在 `FILE-LIST.txt`，不进大 JSON。

每次打包**不做全量重扫**，只做三件事：

1. **删除**：清单里已不存在的路径删掉；临时侧已无正式源的副本删掉。
2. **重复**：同路径重复、已被父树覆盖的子条目、已有更细条目时的宽泛 auto 父条目，去重。
3. **新增**：只探测 `watchParents` 下**尚未被清单覆盖**的直接子项，适合则追加条目；已在清单中的条目不再重新评分。

文件同步按 `LINK-STATE`：变更才复制，未变更跳过。

## 入口

- Skill：`liluo-project-context-pack`
- 打包：`npm run project:context-pack`
- 预览：`npm run project:context-pack:dry-run`
- 测试：`npm run project:context-pack:test`

## 与离线发行的边界

可玩离线包与 GitHub Release 仍走 `liluo-offline-release-pipeline`。本系统只打包描述性上下文，不构建游戏。
