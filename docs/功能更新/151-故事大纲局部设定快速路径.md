# 151-故事大纲局部设定快速路径

- 更新日期：2026-07-30
- 当前摘要：保留局部设定快速路径，但将主线与世界类别趋势核对设为主线子节点不可跳过的门槛。

## 已实现

`liluo-story-outline-authoring` 现先区分局部设定补丁与完整撰写。已确认的世界观关系、摘要、标签、伏笔或少量既有节点正文，只要不改变成熟度、主线方向、玩家流程、地图、事件、玩法、资源或进入完成条件，即可仅读取目标 JSON、Markdown 与必要的直接关联节点。

涉及新增或移动 `side` 时，仍交由故事树维护流程核对直接父子关系。结构化写入保留 JSON/Markdown 同步、来源门槛、一次直接校验和一次索引刷新；一旦发现冲突或需求升级为设计决策，自动回到完整撰写路径。

### 2026-07-30：主线与世界趋势核对门槛

局部设定快速路径不再允许主线子节点跳过方向判断。目标属于主线时，必须读取管辖主线备忘和所属世界类别趋势来源，提取趋势锚点，确认新增内容保持或推进既定趋势。趋势来源缺失、含义不明，或内容会冲突、削弱趋势时，先向用户确认；交付时说明核对来源与结论。
