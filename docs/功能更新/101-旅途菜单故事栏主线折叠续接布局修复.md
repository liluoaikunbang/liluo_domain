# 旅途菜单故事栏主线折叠续接布局修复

## 本次实现思路

本次修复的是旅途菜单“故事”栏中，主线任务节点收回后的画布续接布局问题。

用户在实际测试中发现：收回“浮光掠影”里的第一个主线任务“荆锁会事件”后，后续主线“都市异闻”虽然能显示出来，但它内部的单元链接方式会变化，随后又出现“都市异闻”和紧挨着的“小囚犯出圈记”横向错位一格的问题。

这次没有改动故事大纲 JSON，也没有移动任何故事节点。修复范围只在 `StoryMenuPanel.vue` 的画布布局计算里：

- 主线任务收回后，仍然显示省略占位节点。
- 如果被收回的主线后代中还有下一个主线任务，则把下一个主线任务作为续接节点显示出来。
- 续接出来的主线节点本身可以固定在占位节点之后，但它的子树必须继续按正常树状布局计算，不能使用侧向分支的固定行展开方式。
- 当续接主线使用固定行时，子树布局要从这个固定行重新起算，避免主线节点和第一个普通子节点错位一格。

这样收回“荆锁会事件”后，“都市异闻”会自然接在 `...` 占位节点之后，同时“都市异闻”内部仍保持原本的主线链条关系。

## 相关代码路径

- `src/game/views/components/base/StoryMenuPanel.vue`
  - 调整 `createNodeLayout()` 内部的 `walk()` 函数。
  - 为 `walk()` 增加可选的 `fixedRow` 参数，用于主线收回后的续接节点定位。
  - 收回主线节点时，续接的下一个主线任务不再调用 `walkFixedRow()` 展开，而是调用正常的 `walk()`。
  - 当 `fixedRow` 存在时，先把 `rowCursor` 临时拉回固定行，让续接主线的子树从同一主线行开始布局；子树排完后再恢复到安全的最大行游标。

本次没有修改：

- `src/game/data/story_outline/storyOutlinePlaceholder.json`
- `src/game/data/story_outline/1-modern/*.md`
- 各地图目录下的 `map.json`
- `src/assets/game` 下的素材图片

## 开发过程中遇到的问题

### 1. 收回第一个主线任务后，第二个主线任务内部链接变乱

**现象：**

在故事栏画布中收回“荆锁会事件”后，代码会尝试找到后代中的下一个主线任务“都市异闻”，并把它接到收回占位节点后面。但原实现使用 `walkFixedRow()` 来绘制这个续接主线。

`walkFixedRow()` 更适合处理侧向分支或明确固定行的节点，它会把后续子节点按固定行策略展开。用于“都市异闻”这种仍然应该保持树状主线链条的节点时，会让内部单元之间的连接方式看起来被重排。

**解决方法：**

把主线续接节点从：

```js
walkFixedRow(nextMainQuestNode, continuationDepth, continuationParentKey, continuationRow)
```

改为：

```js
walk(nextMainQuestNode, continuationDepth, continuationParentKey, continuationRow)
```

也就是：只固定“都市异闻”这个续接节点本身的位置，后续子树仍交给正常树布局处理。

### 2. “都市异闻”和“小囚犯出圈记”错位一格

**现象：**

第一次修复后，单元之间的链接关系不再混乱，但“都市异闻”和它紧挨着的第一个普通子节点“小囚犯出圈记”会错位一格。

原因是省略占位节点 `...` 创建后已经推进了 `rowCursor`。随后“都市异闻”虽然固定在占位节点所在行，但它的第一个子节点仍从推进后的下一行开始排，于是视觉上错开。

**解决方法：**

在 `walk()` 中处理 `fixedRow` 时，先保存旧的 `rowCursor`：

```js
const previousRowCursor = rowCursor;
```

如果当前节点使用固定行，则先把 `rowCursor` 临时设置为固定行，让它的子树从这条主线行继续排：

```js
if (fixedRow !== null) {
  rowCursor = fixedRow;
}
```

等子树布局完成后，再把游标恢复到安全位置：

```js
if (fixedRow !== null) {
  rowCursor = Math.max(rowCursor, previousRowCursor, fixedRow + 1);
}
```

这样可以同时保证：

- “都市异闻”和“小囚犯出圈记”保持同一条主线行。
- 后续其他分支不会因为游标回退而重叠到已经占用的位置。
