# 162-机器可读工作流与可视化执行规范系统

创建日期：2026-07-26

## 摘要

建立以工作流 JSON 为唯一事实来源的可执行流程基建：定义与运行记录分离、节点任务书、Skill/Agent 调用证据与采用门禁、Markdown/Mermaid 生成，并以「故事主线重构」dry-run 试点验证漏调用会被阻塞。小修与探索保留简化路径，不强制流程化。

## 变更范围

- `project-workflows/` 定义、注册表、生成物、模板与示例运行
- `schemas/workflows/` 定义与运行 Schema
- `scripts/project-workflows/` 运行时与 `scripts/tests/project-workflows.test.mjs`
- Skill `liluo-executable-workflow` 与 npm `project:workflow:*`
- 能力导航投影合并、`project:routine -- workflow`、质量门禁分类
- 系统说明、ADR-011、用户命令与治理注册

## 后续补充（同日）

- 新增本地交互大图：`project-workflows/viewer/index.html`（少用；仅用户点名时打开）。
