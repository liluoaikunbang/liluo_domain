# 游戏视图模式分层与互动小说覆盖修复

这次调整的目标，是整理 `src/game/views` 的文件结构，让游戏 UI 从“所有组件平铺在 views 根目录”改成更适合长期扩展的模式分层。

当前项目虽然主要只有地图和互动小说副本两类界面，但后续还会继续增加更多 RPG 界面。为了避免 `GameView.vue` 继续变成所有状态、所有布局、所有玩法 UI 都混在一起的大组件，这次先把现有内容整理成：

- `shell/`：通用游戏外壳与三栏舞台组件；
- `modes/map/`：地图模式专属界面；
- `modes/interactive-fiction/`：互动小说副本模式专属界面；
- `composables/`：继续保留 Vue 侧桥接逻辑。

本次没有新增尚未正式接入的 battle / cg mode，避免提前制造空结构。

## 实现思路

### 1. 通用外壳下沉到 shell

原来 `GameStageLayout.vue`、`GameSidePanel.vue`、`GamePortraitPanel.vue` 都直接平铺在 `src/game/views` 根目录。

这类组件并不属于某一个具体玩法，而是所有游戏模式都会复用的舞台外壳，因此统一移动到：

- `src/game/views/shell/GameStageLayout.vue`
- `src/game/views/shell/GameSidePanel.vue`
- `src/game/views/shell/GamePortraitPanel.vue`
- `src/game/views/shell/GameShell.vue`

其中 `GameShell.vue` 负责统一装配三栏结构和左侧主角立绘，让具体 mode 只需要提供中间区域、右侧区域和 overlay。

### 2. 地图模式独立成 MapMode

地图模式从 `GameView.vue` 中抽出，集中到：

- `src/game/views/modes/map/MapMode.vue`
- `src/game/views/modes/map/GameInfoPanel.vue`

`MapMode.vue` 负责地图相关 UI：

- `#phaser-game-container`
- 剧情图覆盖层
- cutscene 黑屏过场层
- 地图通知栏
- 地图右侧信息面板
- 对话期间右侧 NPC 立绘面板

这样以后地图模式继续扩展时，相关 UI 不需要继续挤回 `GameView.vue`。

### 3. 互动小说模式独立成 InteractiveFictionMode

互动小说副本相关组件移动到：

- `src/game/views/modes/interactive-fiction/InteractiveFictionMode.vue`
- `src/game/views/modes/interactive-fiction/GameInteractiveFictionView.vue`
- `src/game/views/modes/interactive-fiction/GameInteractiveFictionPanel.vue`

`InteractiveFictionMode.vue` 负责装配副本文本区和右侧任务/线索面板，`GameView.vue` 只负责根据 `activeInteractiveFiction` 决定是否显示这个模式。

### 4. GameView 收口为入口与调度层

调整后 `GameView.vue` 主要保留：

- 入口页 `GameEntryScreen`
- 当前地图、对话、cutscene、互动小说状态
- Phaser / 对话 / 通知 bridge
- 当前 mode 的装配与覆盖层控制

它不再直接持有地图中间区域、右侧面板、互动小说正文等具体 UI 细节。

## 遇到的问题与解决

### 问题 1：离开互动小说后地图框黑屏

最初重构时，`MapMode` 和 `InteractiveFictionMode` 使用互斥渲染。

这会导致进入互动小说时 `MapMode` 被 Vue 卸载，`#phaser-game-container` 和 Phaser canvas 一起从 DOM 中移除。离开副本时虽然新的地图容器重新出现，但 Phaser 实例仍然挂在旧容器上，结果地图框只剩黑底。

解决方法：

- 让 `MapMode` 在游戏运行期间常驻；
- 不再通过卸载地图 mode 来切换到互动小说；
- 保持 Phaser canvas 的 DOM 连接不被打断。

### 问题 2：使用 v-show 后离开副本有明显黑屏闪烁

第一次修复黑屏时，改成 `v-show` 隐藏地图层。这样虽然避免了 DOM 卸载，但从 `display: none` 恢复时，Phaser / WebGL 仍可能需要一帧重新绘制，用户能看到明显黑屏闪烁。

解决方法：

- 改为叠层结构；
- 地图层始终在底层可见；
- 互动小说作为绝对定位覆盖层盖在地图上；
- 离开副本时只移除覆盖层，底下地图已经处于可见和绘制状态。

对应结构在 `GameView.vue` 中由 `.game-mode-stack` 和 `.game-mode-stack__overlay` 承担。

### 问题 3：覆盖层可能导致点击穿透到地图

互动小说盖在地图上后，需要确保鼠标点击不会穿透触发地图事件。

解决方法分成两层：

1. Vue 覆盖层显式拦截交互：
   - `@click.stop`
   - `@contextmenu.stop`
   - `@pointerdown.stop`
   - `@pointerup.stop`
   - `@touchstart.stop`
   - `@touchend.stop`
   - `@wheel.stop`
   - `.game-mode-stack__overlay { pointer-events: auto; }`
2. 原有 Phaser 输入门控继续生效：
   - `watch([showDialog, isMenuOpen, activeInteractiveFiction], ...)`
   - 当互动小说开启时调用 `setUiOverlayOpen(true)`，让 Phaser 侧也知道当前有 UI 覆盖层。

这样即使地图画面仍在底下常驻，互动小说期间也不会触发地图点击事件。

- 互动小说覆盖地图期间不会触发底层地图事件。
