# 075-图鉴 CG 卡片与物品材料分类

## 实现思路

本次围绕旅途菜单补了两块内容展示：

1. 图鉴里的 CG 分类不再使用文字详情栏，而是改成图片卡片网格。每张卡片使用长方形比例展示图片，底部显示 `CG001` 这类序号，点击后放大预览。
2. CG 图片暂时统一使用 `src/assets/game/backgrounds/Liluo_bed.png` 占位。图片使用 `object-fit: contain`，保持原比例；卡片未填满区域使用黑色底色。
3. 物品栏在“消耗品”和“贵重物品”之间新增“材料”分类，为后续采集、制作、事件掉落等 RPG 内容预留入口。

CG 卡片数量临时扩充到 12 张，用于观察多列换行和分段效果；后续接入真实 CG 时，可以逐步把占位条目替换为真实解锁数据与图片路径。

## 相关代码路径

- `src/game/views/components/base/CompendiumMenuPanel.vue`
  - CG 分类单独渲染为图片卡片网格。
  - 点击 CG 卡片后打开放大预览层。
  - 导入 `Liluo_bed.png` 作为当前统一占位图。
  - 非 CG 图鉴分类仍保留原有文字条目和详情栏。

- `src/game/views/components/base/gameMenuOverlay.css`
  - 新增 `.codex-gallery-grid`、`.codex-cg-card`、`.codex-cg-preview` 等样式。
  - CG 网格从固定两列改为 `auto-fill` 自适应多列，并增加间距和内边距，避免卡片边框或焦点态看起来重叠。
  - 物品栏分类标签增加三列覆盖，使“消耗品 / 材料 / 贵重物品”保持在同一行。

- `src/game/data/global/gameMenuData.js`
  - CG 图鉴占位条目扩充到 12 个。
  - 物品栏新增 `materials` 分类，放在 `consumables` 与 `valuables` 之间。
  - 材料分类先加入草药、丝线、矿石、木料等占位条目。

## 遇到的问题与解决方法

### 1. CG 分类仍显示详情栏

问题：原图鉴组件对所有分类都使用“条目列表 + 详情栏”，不符合 CG 只展示图片卡片的预期。

解决：在 `CompendiumMenuPanel.vue` 中按 `activeCodexCategory.key === 'cg'` 分支渲染。CG 分类使用图片网格和放大预览；其它分类继续使用原本的文字详情结构。

### 2. CG 卡片一行只有两张，且卡片之间显得贴得太紧

问题：初版 CG 网格沿用了两列布局，卡片数量稍多时不够紧凑；同时网格边缘留白较少，焦点边框和卡片边框容易产生“重叠”的观感。

解决：将 CG 网格改为 `repeat(auto-fill, minmax(148px, 1fr))`，让可用宽度足够时自动排出更多列；同时增加 `gap` 和网格内边距，让卡片之间、卡片与滚动区域边缘都有稳定空隙。

### 3. 物品栏新增第三个分类后自动换行

问题：`.inventory-category-tabs` 默认是两列，新增“材料”后，“消耗品 / 材料 / 贵重物品”会分成两行。

解决：增加 `.inventory-card .inventory-category-tabs` 的三列覆盖，物品栏三个分类固定在同一行显示；技能栏和图鉴栏继续使用各自已有列数设置。
