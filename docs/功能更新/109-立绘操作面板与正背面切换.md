# 立绘操作面板与正背面切换

## 本次实现思路

本次在地图模式的菜单按钮旁新增“立绘”操作按钮，用来临时选择主角左侧立绘中要显示的 partial 图层。按钮打开后会弹出立绘操作面板，面板中列出所有正面图层，也就是不属于后背版本的图层；玩家勾选哪些图层，左侧主立绘就叠加显示哪些图层，不勾选则不显示。

为了避免后续立绘素材越来越多时继续把规则堆在单个对话立绘文件里，本次把主角立绘数据整理到 `src/game/data/portraits/` 目录下：

- `types.ts` 负责立绘数据类型。
- `layerRules.ts` 负责文件名解析、关键词清洗、图层排序、正背面匹配。
- `liluo.ts` 负责璃落当前立绘素材、预设和 partial 资源收集。
- `registry.ts` 作为立绘数据统一入口。

后背图层不需要改文件名，当前规则是：去掉文件名末尾的 `(x-x)` 层级标记后，基础文件名必须以 `-后背` 结尾，才会被视为后背版本。正面图层和后背图层的匹配关键词根据 `-` 拆分；用于匹配后背时，会把 `+脖颈` 这种后缀去掉，只保留前面的关键词。立绘操作面板里显示的关键词也同步使用清洗后的结果，避免显示已经不参与匹配的 `+脖颈`。

当用户勾选的正面图层发生变化时，系统会重新根据这些正面关键词查找对应的后背图层。只有当前正面图层都能找到对应后背版本时，右上角才显示后背小立绘；如果缺少任意一个对应后背图层，就不显示后背预览。

右上角小立绘现在可以点击切换：默认主立绘显示正面，小栏显示后背；点击后主立绘显示后背，小栏显示前身；再次点击切回。小栏下方会根据当前小栏内容显示“后背”或“前身”，标签放在预览框外侧下方，不占用小立绘画面空间。

打开立绘操作面板时，左侧立绘栏保持正常亮度，方便一边勾选一边观察效果；遮罩仍保留在右侧区域，维持弹窗层级和关闭体验。

## 开发过程中遇到的问题

### 问题 1：后背版本不能只靠“包含后背”判断

**现象：**

如果只判断文件名中是否包含 `后背`，后续素材命名一复杂，就可能误判普通素材或说明性文件名。

**解决方法：**

改为解析基础文件名，也就是去掉扩展名和末尾 `(x-x)` 层级标记后，要求文件名以 `-后背` 结尾。这样既符合当前素材规律，也不需要重命名现有后背素材。

### 问题 2：`+脖颈` 会干扰头部正背面匹配

**现象：**

正面头部素材里可能带有 `+脖颈`，但后背头部素材不一定带这个尾缀。直接用完整关键词匹配会导致明明有对应后背素材，却匹配不到。

**解决方法：**

在 `layerRules.ts` 中使用专门的后背匹配关键词变量，生成关键词时把结尾的 `+脖颈` 去掉，只保留前面的头部关键词。立绘操作面板也使用同一套清洗结果展示关键词，避免显示和实际匹配规则不一致。

### 问题 3：弹窗遮罩会挡住左侧立绘观察

**现象：**

立绘操作本身需要一边勾选一边看左侧立绘效果，如果弹窗打开后左侧立绘也被遮罩变暗，反馈会很差。

**解决方法：**

把立绘操作面板的遮罩范围限制在左侧立绘栏之外，左侧舞台保持正常亮度，右侧仍保留 mask 和弹窗层级。

### 问题 4：正背面切换后小栏内容需要明确

**现象：**

右上角小栏可点击切换后，它有时显示后背，有时显示前身。如果没有文字提示，容易不知道当前小栏里到底是哪一面。

**解决方法：**

根据 `isBackPortraitActive` 推导小栏标签：主立绘是正面时，小栏标签为“后背”；主立绘是后背时，小栏标签为“前身”。标签放在预览框外侧下方，不占用小立绘画面。
