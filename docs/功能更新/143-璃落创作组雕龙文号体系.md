- 创建日期：2026-07-22

## 实现摘要

创作组成员统一采用“姓名｜雕龙文号｜职司”三层身份。文号取自刘勰《文心雕龙》五十篇篇名；以公版古籍目录和公共文化机构资料核验作者、时代、篇数与篇次，并明确原典关联和项目适配不可混同。

roster 升级到 schema 2，移除含义模糊的 `penName`，将原“寻迹、经纬、机枢”等迁移为 `dutyTitle`，新增 `literaryName` 与 `literaryNameSource`。当前 8 个 active 文号、1 个 planned/reserved 文号和 41 个 available 篇名已进入机器池；书晴仍无真实 Agent，不标记 active。

## 验证与限制

确定性验证覆盖五十篇、篇次连续、文号唯一、来源 ID、active/planned 状态、roster/篇名池映射和旧 `penName` 清除。在线来源可验证书目和篇名，但项目没有收录现代校注本；未分配篇名的原典关联仍须在实际分配时逐项复核并由用户审批。
