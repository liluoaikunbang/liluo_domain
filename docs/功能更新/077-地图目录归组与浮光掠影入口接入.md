# 077-地图目录归组与浮光掠影入口接入

## 实现思路

本次调整围绕地图内容继续整理，目标是让地图数据更符合“长期扩展的像素风冒险 RPG”结构。

1. `src/game/data/maps` 下除 `modern` 外的现有地图，统一归入 `munika` 分组，表示它们属于慕妮卡/璃落当前主世界地图内容。
2. `modern/city_Jingjiang_school` 保留在 `modern` 分组下，并补齐地图注册需要的资源、meta、事件与对话入口文件。
3. `city_jingjiang_school` 使用已有 `role` 图层作为默认出生点，不直接修改 `map.json`。
4. 庄园右上角平行世界传送门从“暂未接入”改成章节入口：先选择“开始冒险”，再选择章节“浮光掠影”，最后传送到 `city_jingjiang_school`。

这次没有把章节入口做成独立功能页，而是继续放在地图传送门事件与对话里，让新内容从场景探索自然进入。

## 遇到的问题与解决方法

### 1. 地图目录多一级后相对路径失效

问题：`city_desire`、`liluo_estate`、`liluo_room` 等地图从 `maps/<mapId>` 移到 `maps/munika/<mapId>` 后，地图目录内部的 `assets.ts`、`dialogues.ts` 到 `src/game/data/assets.ts`、`dialoguePortraits.ts` 和 `src/assets/game` 的相对路径都多了一层。

解决：统一修正这些相对 import 与 `new URL()` 资源路径，并用现有地图相关测试和 `npm run build:web` 验证资源仍能被 Vite 正确打包。

### 2. Windows 写入编码导致部分中文测试文案乱码

问题：路径批量替换时，`scripts/tests/event-runner.test.mjs` 中部分中文断言文案被 PowerShell 默认编码写坏，出现语法错误或断言期望变成乱码。

解决：修复测试文件里受影响的中文字符串，并尽量将测试期望改成真实数据中当前使用的中文或更稳定的英文说明，避免后续因为编码问题干扰功能验证。

### 3. 新学校地图已有 `role` 图层，但不是普通 `data` 图层

问题：`city_Jingjiang_school/map.json` 中已有 `role` 图层，且有效出生格放在 chunk 数据里。测试如果只检查 `layer.data` 会误判没有出生点。

解决：不改 `map.json`。`meta.ts` 设置 `defaultSpawnId: "role"`，运行时仍走已有图层出生逻辑；测试改为检查 `role` 图层的 `chunks[].data` 中是否存在有效 tile。

### 4. 新地图接入应先可加载，不急着补完整剧情

问题：学校地图目前只有地图图层和出生标记，还没有具体事件、对话和场景剧情。如果强行填充假事件，会让后续剧情扩展变得混乱。

解决：只补空的 `events.json` 与 `dialogues.json`，先让地图作为“浮光掠影”章节目标可注册、可加载、可进入。后续剧情再沿地图事件系统逐步增加。
