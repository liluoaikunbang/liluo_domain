# 063-物品技能条目详情与内部滚动

## 实现思路

本次继续完善旅途菜单里的“物品”和“技能”栏目，让它们更接近 RPG 菜单里的条目浏览体验。

物品和技能的具体条目不再只是静态占位格，而是可以被鼠标点击或键盘聚焦选中。选中条目后，下方详情框显示对应标题和段落式说明；没有条目被选中时，详情框保留为空白占位，不额外显示提示文字。

为了验证真实内容增多后的表现，本次临时增加了更多占位物品、占位技能和多段占位详情文本。条目列表和详情区域都限制在各自框内滚动，避免大量条目或长段落把整个旅途菜单撑高。

## 相关代码路径

- `src/game/views/components/base/GameMenuOverlay.vue`
  - 将物品和技能占位条目整理为带 `key`、`title`、`summary` 的可选数据。
  - 新增 `activeInventorySlot`、`activeSkillSlot`，用于根据当前选中 key 解析详情条目。
  - 新增 `placeholderItemDetailParagraphs`、`placeholderSkillDetailParagraphs`，用多段占位文字测试详情框滚动。
  - 新增 `createPlaceholderSlot()`，用于批量生成临时占位条目。
  - 新增 `resolvePlaceholderDetailParagraphs()`，让详情区优先使用条目自身段落，缺省时使用占位段落。
  - 给物品/技能条目添加点击选中逻辑，保留键盘聚焦即选中的菜单操作方式。
  - 给 `.inventory-placeholder-grid` 和 `.inventory-detail-panel` 添加内部滚动与滚动条样式。

## 开发过程中遇到的问题

### 1. 详情字段一开始偏表格化

早期详情里包含“类型 / 状态 / 用途”这类结构化字段，但当前物品和技能还没有真实系统数据，这类字段会显得重复，也容易让后续真实内容被迫套进固定分类。

解决方法：

- 移除详情区里的 `dl / dt / dd` 结构。
- 删除占位数据里的 `details` 字段。
- 详情区改为标题加段落，后续可以直接写物品来历、技能效果、剧情线索或探索用途。

### 2. 分类名在详情区重复出现

条目已经位于“消耗品 / 贵重物品 / 职业技能 / 通用技能”等分类下，详情里再显示分类名会增加噪音。

解决方法：

- 移除详情标题上方的分类标签。
- 保留分类按钮和分类说明，让层级关系由菜单结构本身表达。

### 3. 占位内容增多后会挤压菜单布局

为了模拟未来真实背包和技能列表，临时增加了较多占位条目和多段详情文本。若不限制高度，内容会把菜单主体撑开，影响旅途菜单整体稳定性。

解决方法：

- 给条目网格 `.inventory-placeholder-grid` 设置 `max-height` 和 `overflow-y: auto`。
- 给详情框 `.inventory-detail-panel` 设置 `max-height` 和 `overflow-y: auto`。
- 为两个滚动区域补充轻量滚动条样式，使滚动发生在对应框内部。

## 后续维护建议

1. 后续接入真实物品系统时，建议把占位 `inventoryCategories` 替换为背包数据来源，但保留“分类 -> 条目 -> 详情段落”的展示层级。
2. 后续接入真实技能系统时，建议让技能条目提供自己的 `descriptionParagraphs`，避免继续依赖占位段落。
3. 如果未来详情区需要展示数值、冷却、消耗等规则信息，可以在段落说明之外再单独设计轻量信息行，不要回到固定的“类型 / 状态 / 用途”占位分类。
4. 如果条目列表数量继续增加，需要确认键盘方向导航在滚动容器里仍能自然进入列表尾部。
