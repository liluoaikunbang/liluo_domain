# 050-醉欲之城地图接入与帝国入口跳转

## 实现思路

本次把 `city_desire` 地图正式作为慕妮卡帝国下的城市“醉欲之城”接入游戏主流程。

接入分为三部分：

1. 地图资源接入：按 `city_desire/map.json` 中的 tilesets，为地图补齐 `assets.ts` 与 `meta.ts`，让 `MapLoadingScene` 能按地图动态加载素材，并让运行时渲染能把 Tiled tileset 匹配到 Phaser texture key。
2. 出生点接入：沿用地图里的 `role` 图块层作为默认出生点，通过 `defaultSpawnId: 'role'` 保持和现有地图一致。
3. 帝国入口接入：四季花园下方原本“去往慕妮卡帝国”的事件不拆成新入口，而是改为帝国目的地选择。当前可选目的地为“醉欲之城”，选择后跳转到 `city_desire`。

后续如果继续接入帝国其他城市，可以继续在这个帝国入口对话下追加目的地选项，不需要额外再造一套入口。

## 相关代码路径

- `src/game/data/maps/city_desire/map.json`
  - 用户更新后的醉欲之城地图数据。
  - 地图内 `role` 图层作为玩家出生点。
  - tilesets 中包含 `train.png` 等醉欲之城地图素材。
- `src/game/data/maps/city_desire/assets.ts`
  - 新增 `cityDesireAssetBundle`。
  - 注册 `building_school`、`Farm_tileset`、`building_hospital`、`stall`、`outdoors_1`、`outdoors_2`、`medieval_building_*`、`guard`、`building_church`、`mine`、`house_indoor_7`、`train`、`tiled_2` 等 tileset 素材。
- `src/game/data/maps/city_desire/meta.ts`
  - 新增 `cityDesireMeta`。
  - 地图名设为“醉欲之城”。
  - `defaultSpawnId` 设为 `role`。
  - 在 `worldRender.tilesets` 中维护 Tiled tileset 与 texture key 的匹配关系。
- `src/game/data/registry.ts`
  - 注册 `city_desire` 地图数据、资源 bundle 与 meta。
- `src/game/data/maps/liluo_estate/dialogues.json`
  - 将四季花园下方帝国入口对话改为目的地选择。
  - 新增“去往醉欲之城”选项，并通过 `mapTransition` 跳转到 `city_desire` 的 `role` 出生点。
- `docs/游戏素材图片清单.md`
  - 补充 `src/assets/game/sucai/train.png` 素材登记。

## 开发过程中遇到的问题

### 1. `city_desire/map.json` 的资源需要单独映射

`city_desire/map.json` 直接引用了多张 `src/assets/game/sucai` 下的 tileset 图片。地图运行时不会自动按 JSON 中的相对路径直接加载图片，而是依赖地图自己的 asset bundle 与 `worldRender.tilesets` 匹配规则。

解决方法：

- 为 `city_desire` 新增 `assets.ts`，把地图中引用到的图片统一注册为 Phaser spritesheet。
- 为 `city_desire` 新增 `meta.ts`，通过 `textureKey + match.name/imageIncludes` 显式匹配 Tiled tileset。
- 接入 `registry.ts`，让地图加载流程能找到这张地图的资源与渲染配置。

### 2. 出生点应使用地图里的 `role` 图块位置

这张地图没有额外新增对象出生点，而是已经在地图数据里用 `role` 图层标记了玩家出生位置。

解决方法：

- 在 `cityDesireMeta` 中设置 `defaultSpawnId: 'role'`。
- 跳转选项也显式传入 `spawnId: 'role'`，确保从四季花园进入醉欲之城时落在同一出生点。

### 3. 醉欲之城不是独立入口，而是帝国下的城市

最初容易把“去往醉欲之城”理解成和“去往慕妮卡帝国”并列的入口。但用户确认：醉欲之城是慕妮卡帝国里的一个城市，帝国是总称。

解决方法：

- 保留四季花园下方的帝国入口语义。
- 把帝国入口对话改成目的地选择。
- 当前目的地只提供“醉欲之城”，后续帝国其他城市可以继续追加到同一分支。

### 4. 地图后续新增了 `train.png`

用户更新 `city_desire/map.json` 后，tilesets 中新增了 `train.png`。如果只更新地图 JSON，不补 `assets.ts` 和 `meta.ts`，运行时会出现对应 tileset 无法渲染的问题。

解决方法：

- 在 `city_desire/assets.ts` 中新增 `trainUrl` 与 `train` spritesheet manifest。
- 在 `city_desire/meta.ts` 中新增 `train` tileset 匹配。
- 因为 `train.png` 属于 `src/assets/game` 下新增并实际使用的素材，同步更新 `docs/游戏素材图片清单.md`。

## 验证结果

已执行：

```powershell
npm run build:web
```

结果：

- Vite 构建通过。
- 构建产物中出现 `train-*.png`，确认 `train.png` 已进入资源构建链路。
- 用户实际测试确认：从四季花园帝国入口选择“去往醉欲之城”可以正常跳转，无报错。

## 后续维护建议

1. 后续新增慕妮卡帝国城市时，优先继续复用四季花园的帝国入口对话，在目的地选项中追加城市。
2. 每次更新 `city_desire/map.json` 的 tilesets 后，同步检查 `city_desire/assets.ts` 与 `city_desire/meta.ts` 是否缺少新增素材。
3. 如果新增 `src/assets/game` 下的新图片并投入使用，继续同步维护 `docs/游戏素材图片清单.md`。
