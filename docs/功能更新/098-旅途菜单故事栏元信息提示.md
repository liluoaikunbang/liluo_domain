# 旅途菜单故事栏元信息提示

## 本次实现思路

本次围绕旅途菜单“故事”栏补充节点元信息查看能力。

故事画布里的节点空间有限，标题、简介、故事线与玩法标签已经占用了主要展示区域。如果把角色、地点、伏笔、参考来源等字段全部直接铺在块内，画布会迅速变得拥挤，也会削弱故事树本身的结构阅读。

因此本次采用“块内保持简洁，右上角提供元信息入口”的方式：

- 普通故事节点右上角显示“元信息”标记。
- 鼠标悬停或键盘聚焦标记时，显示该节点的扩展信息。
- 分类节点和主线任务这类结构性虚节点不显示元信息标记。
- tooltip 不重复展示外层已经可见的分区信息。
- `大纲`、`大纲草稿` 等整理状态保留在数据层，但不再作为卡片、表格或 tooltip 的可见状态显示。

这样故事栏仍然优先表达“世界、章节、任务与事件之间的关系”，额外信息则作为按需查看的辅助层。

## 相关代码路径

- `src/game/views/components/base/StoryMenuPanel.vue`
  - 为故事节点生成 `metaItems`。
  - 增加 `getMetaItems()`，从节点数据中整理可展示的元信息。
  - 增加 `getDisplayStatus()`，只让 `分类` 和 `主线任务` 进入可见状态展示。
  - 在画布卡片中渲染“元信息”标记与 tooltip。
  - 表格视图同步使用 `displayStatus`，避免普通节点展示整理状态。

- `src/game/views/components/base/gameMenuOverlay.css`
  - 为“元信息”标记增加更醒目的亮色样式。
  - 增加元信息 tooltip 的定位、层级、滚动与文本布局。
  - 调整节点顶部元信息行右侧留白，避免和“元信息”标记重叠。

- `src/game/data/story_outline/storyOutlinePlaceholder.json`
  - 继续作为故事栏节点元信息的数据来源。
  - 本次只记录数据结构与展示字段的使用方式，具体故事内容不在本文档展开。

## 具体实现说明

### 1. 元信息入口只挂在真实故事节点上

组件通过节点状态判断虚节点：

- `分类`
- `主线任务`

这两类节点主要用于组织故事树结构，不承担具体剧情块信息展示，所以不渲染“元信息”标记。

普通故事节点如果整理出了至少一项 `metaItems`，才会显示入口。这样未来新增空节点或占位节点时，不会出现点开后没有内容的提示框。

### 2. tooltip 只展示块内放不下的信息

元信息 tooltip 主要承接：

- 世界
- 简介
- 伏笔
- 玩法标签
- 特殊玩法
- 主要角色
- 需要异能
- 所在地点
- 参考
- 文件标签

分区信息已经在卡片外层用故事线标签展示，因此不再重复放进 tooltip。

整理状态也不进入 tooltip。这样“元信息”更像剧情块的补充信息，而不是数据维护表。

### 3. 状态展示收口为结构状态

节点数据里可以继续保留 `status` 字段，方便后续整理或导出。

但 UI 通过 `displayStatus` 控制可见状态，只显示：

- `分类`
- `主线任务`

普通故事块即使数据里有 `大纲` 或 `大纲草稿`，也不会再在卡片、表格或 tooltip 中展示。这能减少临时整理状态对玩家阅读故事结构的干扰。

### 4. “元信息”标记改为明确文本入口

初版使用小型 `i` 标记，占位少但辨识度不足。

本次改为“元信息”三字，并使用更亮的青绿与紫色叠加样式。颜色仍然沿用旅途菜单的暗紫、柔粉、青绿体系，不额外引入跳脱的按钮风格。

## 开发过程中遇到的问题

### 1. 单字母标记不够清楚

**现象：**

右上角的小 `i` 标记尺寸较小，在故事画布缩放和节点较密时不够明显。

**解决方法：**

改为“元信息”文本标记，并增加宽度、亮色边框和轻微高亮背景，让入口更容易被发现。

### 2. tooltip 信息与卡片可见信息重复

**现象：**

分区信息已经在卡片顶部作为故事线标签展示，如果 tooltip 再显示一次，会增加阅读噪音。

**解决方法：**

从 `getMetaItems()` 中移除分区字段，只保留块内展示不下的扩展信息。

### 3. 整理状态干扰故事阅读

**现象：**

`大纲`、`大纲草稿` 这类状态更像创作整理阶段信息，不适合在玩家视角的故事栏里持续出现。

**解决方法：**

保留原始 `status` 数据，但新增展示层的 `displayStatus`。只有 `分类` 和 `主线任务` 会进入可见状态标签，普通故事块状态不显示。

### 4. 元信息标记可能遮挡顶部标签

**现象：**

“元信息”从单字标记变成三个字后，右上角占用空间变大，可能和状态、故事线标签挤在一起。

**解决方法：**

给 `.story-node-meta-row` 增加右侧留白，确保顶部标签不会和右上角入口重叠。
