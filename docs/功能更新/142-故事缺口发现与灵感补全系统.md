# 故事缺口发现与灵感补全系统

创建时间：2026-07-22

当前摘要：建立节点、系列与世界三级故事缺口分析，结合项目证据和按需外部抽象参考，生成受审批门禁保护的原创候选卡，并由只读成员星弥负责专业分析。

## 更新时间记录

- 2026-07-22：完成首版故事缺口工作流、星弥 Agent、候选合同、确定性测试和文档治理接入。

## 实现说明

新增 `liluo-story-gap-discovery` Skill，覆盖结构、叙事功能、场景、角色、玩法、视觉制作、题材覆盖与重复冗余八类缺口。支持局部节点、系列、世界三种模式；世界模式先给缺口报告，再限制为 8—12 个高价值方向。

新增只读 `liluo_story_gap_analyst`，并将星弥｜补阙从创作组规划成员转为 active。星弥只负责证据化分析、候选卡、排序和风险，不拥有正式故事写入权限。

候选卡使用六项 1—5 分、制作规模、项目差异和来源抽象；`proposed` 不能写入，接受后才交故事撰写流程。外部知识默认按需 `light`，候选不保存原文，正式长文本继续使用照搬风险检查。`planning/story-gaps/` 仅在用户要求时保存候选，不进入正式故事索引。
