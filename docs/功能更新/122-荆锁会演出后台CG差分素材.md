4. 同步更新图片素材清单中的总量、目录数量、文件类型和适用场景。

## 开发过程中遇到的问题

### 旧文件名与新主题不一致

原文件 `src/assets/game/mode/舞蹈表演结束后的束缚.jpg` 属于候选概念图，文件名与新增 CG 的稳定主题不一致，也不适合作为图鉴成品直接收录。

解决方法：核对文件内容哈希后确认新制作源与旧文件完全一致，将其作为一次迁移和重命名处理，保留内容并删除失效旧路径。

### 成品差分与制作源需要分层

同主题文件同时包含图鉴可直接使用的成品和更高分辨率制作源。如果全部放进 `cg/`，制作源也会被 `import.meta.glob` 自动收入图鉴。

解决方法：五张成品放入 `cg/`，高分辨率制作源放入 `sucai_cg_standee/`；素材清单分别标记为运行时成品和制作源。

## 验证结果

- 五张 CG 均为可读取的 PNG 或 JPEG，尺寸与格式有效。
- 默认图与四张括号差分使用同一基础标题，可由现有图鉴规则归为同组。
- 新制作源与删除的旧候选图 Git Blob 哈希一致，确认迁移没有改变图片内容。
- 素材清单统计更新为 668 张、约 454.74 MB。
