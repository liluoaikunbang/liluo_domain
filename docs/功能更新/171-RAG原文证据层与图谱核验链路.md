# 171-RAG原文证据层与图谱核验链路

- 创建时间：2026-07-28
- 更新时间：2026-07-28

## 摘要

升级紧缚 RAG 为「原始来源 → 原文证据片段 → 知识陈述/RAG 卡」三层；与 Style-RAG 共用来源/证据基础设施；关联图谱新增可折叠证据层与详情核验；公开导出剥离私有原文；抽查对用户确认无问题的卡降权但不移出池。

## 实现要点

- 共享证据库：`external-knowledge/evidence/`（excerpts / reviews / registry）
- Schema：`evidence-excerpt`、`rag-claim`、`evidence-review`、`source-record`；卡 Schema 增加 `claims` / `evidenceRefs` / `retrievalPolicy`
- 迁移：`npm run external:knowledge:evidence:migrate`；候选证据默认 `pending`，不自动确认
- 图谱 schemaVersion=2：节点 `evidence` / `source`，关系 `supported_by` / `excerpt_of` / `derived_from` 等；全图默认折叠证据层
- 详情抽屉：知识陈述、证据列表、原文预览、返回 RAG / 上下条证据
- 检索：`retrievalMode=writing` 排除未确认与 stub；公开导出 `publicSafe` 省略私有 excerpt
- 抽查：`confirmed-ok` 类别；确认无问题的卡保留在池中但降权
