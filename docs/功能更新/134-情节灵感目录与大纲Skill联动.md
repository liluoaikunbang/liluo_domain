## 实现思路

在大纲页的“故事”和“玩法”之间新增“情节”页签，用独立 JSON 保存可跨世界复用的情节。大情节归纳场景、制度或风格母题，小情节保存可关联具体故事节点的桥段；每条小情节具有稳定 ID、所属大情节、标题、摘要、世界偏向、标签、使用状态、应用节点和备注。界面采用“大情节 / 小情节 / 详情”三栏只读展示，并提供搜索、使用状态、世界偏向、普通标签和紧缚标签筛选。普通标签与紧缚标签可以独立选择并叠加，不再使用“紧缚情节：是/否”作为主要索引。

2026-07-22 起，每条正式小情节还保存 `development`：核心前提说明事件为何成立，升级链说明压力如何变化，关键转折说明控制权或理解发生何种改变，持续后果说明事件如何影响关系、状态或后续主线。外部知识库只在后台辅助抽象与照搬检查，运行界面不显示知识卡 ID、来源或转换过程，用户只查看原创化后的正式情节。

“封闭规训机构”作为首批跨世界大情节，先收纳病房保护与辨灵、静默矫治中心、黑蔷薇疗养院三个小情节，后续可以继续加入古风闺秀教育、西幻中世纪礼仪教育等变体。“都市 DID”作为容量较大的都市绑架母题，统一收纳招聘诱捕、误认人质、状态固化绑架、折返救人和运奴船互助等小情节；拇指女仆夜袭因核心是微型族群与尺度差异，独立归入“小人国”。“狩猎游戏”统一收纳古风权贵禁苑、现代豪门夜猎和科幻直播穹顶，保留三个时代各自的规则与反猎方式。游乐场按场地分组：邮轮观光归入室外游乐场，温泉竞赛和充气城堡归入室内游乐场。

“童话改编”作为可跨拟典幻域、魔幻、梦境与末日分支复用的大情节，当前收纳黑暗童话、寓言绘本与末日童话迷城。寓言绘本以“故事必须有结局”为核心法则，把公主、祭品或坏女孩等身份写成强制剧本，并可作为进入上游黑暗童话世界的剧本入口；末日童话迷城保留独立的末日化童话方向。

黄毛女孩相关灵感作为一个上下关联的完整情节保存：宿舍旧楼的手写保护费收据救援已经应用并关联真实故事节点；《水泥鞋》中的后续救援尚未想好，因此整个条目标记为“部分使用”，待定部分不升级为既定剧情。

随机访谈和故事撰写 Skill 会读取情节目录，将匹配的未使用条目或部分使用条目的待定部分作为可选灵感。只有用户明确采用并完成大纲同步后，才更新使用状态并记录故事节点；具有明确前因与回收关系的内容不得机械拆分。

新增零散灵感不再默认新建小情节。系统先判断它是否延续已有条目的核心冲突、因果链、前因回收，或是否属于该小情节计划持续收纳的段落；符合时扩写原条目并保留稳定 ID 与使用状态。仅有相同世界、人物、标签或宽泛主题不构成合并依据，边界不清或与现有结构冲突时先询问用户。
