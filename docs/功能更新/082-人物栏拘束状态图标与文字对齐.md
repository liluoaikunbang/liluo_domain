# 082-人物栏拘束状态图标与文字对齐

## 实现思路

本次围绕旅途菜单“人物”栏中的状态展示做了一次收口。

原本人物栏右侧属性行只显示纯文字“当前状态”，这次改为“拘束状态”，并在每个状态文字旁边紧贴显示对应的人物状态图标。状态展示仍然复用 `src/game/data/playerStatus.ts` 中已有的状态定义和 `iconUrl`，不新增任务图标、不新增素材，也不单独维护另一套状态图片映射。

最终显示形式为：

```text
[图标] 未穿鞋 / [图标] 双手被缚 / [图标] 双腿被缚
```

这样每个图标都和自己的状态文字保持一一对应，中间继续保留 `/` 分隔，方便玩家快速区分多个拘束状态。

## 相关代码路径

- `src/game/views/components/base/GameMenuOverlay.vue`
  - 引入 `resolvePlayerStatusDefinitions()`。
  - 从当前运行时人物状态中解析带图标的状态列表。
  - 将人物栏属性行 label 从“当前状态”改为“拘束状态”。
  - 把 `playerStatusIcons` 传给 `CharacterMenuPanel`。

- `src/game/views/components/base/CharacterMenuPanel.vue`
  - 在 `stat.key === 'status'` 时，不再只渲染一整段状态文字。
  - 改为逐个状态项渲染，每项包含对应图标和状态名称。
  - 在状态项之间保留 `/` 分隔符。

- `src/game/views/components/base/gameMenuOverlay.css`
  - 增加人物栏状态项、状态图标、状态文字和分隔符样式。
  - 图标固定为 `16px`，保留 `image-rendering: pixelated`，保证状态图标仍符合像素风表现。
  - 状态列表支持换行，避免多个状态在窄宽度下挤出人物栏。

## 遇到的问题与解决方法

### 1. 一开始误以为是任务状态图标

问题：需求里的“菜单中的任务的当前状态”容易被理解成任务栏里的任务进度状态，因此最初尝试新增任务进度图标。

解决：根据后续确认，实际目标是人物菜单里的“人物状态”。已删除误建的任务图标文件和空目录，最终没有新增 `src/assets/game` 下的素材。

### 2. 图标和文字对应关系不清晰

问题：第一版把所有图标放在一起、所有状态文字放在一起，视觉上无法判断哪个图标对应哪个状态。

解决：把状态列表改成逐项渲染，每个状态对象同时提供 `iconUrl` 和 `label`，模板中直接渲染为“图标 + 文字”的成组结构。

### 3. 删除 `/` 后多个状态区分不明显

问题：状态项成组显示后，如果去掉原本的 `/`，多个状态之间的边界不够清楚。

解决：在每个状态项后追加分隔符，最后一项不显示。这样既保持“图标 + 状态文字”的贴合关系，也保留多个状态之间的区分。
