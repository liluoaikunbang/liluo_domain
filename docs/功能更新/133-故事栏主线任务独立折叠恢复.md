# 故事栏主线任务独立折叠恢复

创建时间：2026-07-21

## 更新时间记录

- 2026-07-21：恢复主线任务容器的折叠入口，使每个主线只收回自己的后代故事块，并保留下一段主线的续接显示。

## 实现思路

故事栏原有的折叠状态、收回占位节点、后代计数和“寻找下一主线任务继续显示”逻辑仍然存在，但统一的可折叠状态判断只包含“分类”和“支线任务”，导致“主线任务”节点不再生成折叠按钮，原有主线续接代码也无法执行。

本次只把“主线任务”恢复到可折叠状态集合。点击某个主线任务后，该节点自身继续显示，其所属后代块被收回并显示省略占位；如果其后代链中存在下一段主线，则下一主线及其内容继续显示，不会把整个世界或其他主线一起隐藏。表格与画布共用同一状态判断，因此同时恢复。

## 相关路径

- `src/game/views/components/base/StoryMenuPanel.vue`
- `scripts/tests/story-main-quest-collapse.test.mjs`

## 开发过程中遇到的问题

画布内部已经保留了专门处理主线折叠续接的 `findNextMainQuestNode()` 调用，单看布局代码容易误以为功能仍可使用。实际入口在更前面的 `isCollapsibleStatus()`；主线被排除后，按钮、折叠状态和续接逻辑全部不可达。

## 对应问题的解决方法

先增加回归测试，确认当前代码没有把“主线任务”列入可折叠状态，同时验证折叠后只隐藏当前节点的 `children`，并保留下一主线续接判断。随后对可折叠状态集合做一行最小修复，不改故事 JSON、树结构或布局算法。
