# 175-RAG增量提议与来源关联图谱

## 更新时间

2026-07-31

## 本次实现

- 所有 RAG 卡统一固定知识与表达双分支，并以领域区分紧缚专业、通用创作与正史事实。
- 新增写入前 RAG 候选提议、历史故事补扫和按需来源扫描命令；默认只生成待确认记录。
- 独立通用 Style-RAG 与其自动生成条目已退役；所有表达信息回归每张 RAG 卡的表达分支，必须经用户确认后写入。
- 「RAG 网络」提升为与关联图谱同级的自由画布分栏，可筛选仅 RAG、含证据来源，或纳入直接关联的项目节点；关联图谱回归全宇宙结构浏览。网络工具栏新增「层级树」，按 RAG 卡 `parentCardIds` 支持不限层级的递归浏览；多父卡不复制，额外父级作为跨枝关系保留。
- 新增 `liluo-rag-source-interview`：在 Codex 对话中逐段展示外部原文，由用户确认既有/新建 RAG 或不入库处置；指定来源时按 40% 当前、60% 其他来源随机。新建卡在同轮确认后即可检索，旧自动关联仅生成待批准的基线重置审包。
