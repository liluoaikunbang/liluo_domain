# 080-旅途菜单人物栏与状态行走预览

## 实现思路

本次在旅途菜单最上方新增“人物”栏目，用来承载主角璃落的当前人物详情。

人物栏不是独立资料页，而是地图冒险流程里的状态查看入口：左侧展示当前立绘与当前状态下的行走图预览，右侧用紧凑属性行显示地点、坐标、当前状态和移动速度。这样玩家打开菜单时可以快速确认璃落当前处境，而不会把菜单做成脱离地图探索的资料库页面。

行走图预览复用 `resolvePlayerRuntimeCharacterDefinition()`，因此会跟随当前运行时状态切换实际外观。例如：

- `hands_bound` 会显示双手被缚对应行走图。
- `legs_bound` 会显示全身拘束行走图，并播放跳着走的垂直位移动画。
- 普通状态继续显示默认行走图循环。

## 相关代码路径

- `src/game/data/global/gameMenuData.js`
  - 在 `menuTabs` 最上方新增 `character` 栏目。

- `src/game/views/components/base/CharacterMenuPanel.vue`
  - 新增人物栏面板。
  - 左侧显示主角立绘和当前状态行走图预览。
  - 右侧显示“璃落”标题和紧凑属性行。

- `src/game/views/components/base/GameMenuOverlay.vue`
  - 接入 `CharacterMenuPanel`。
  - 为人物栏整理当前地点、坐标、当前状态和移动速度。
  - 通过 `resolvePlayerRuntimeCharacterDefinition()` 生成当前行走图帧、帧序列和 hop 表现参数。
  - 为人物栏补充方向键导航入口。

- `src/game/views/components/base/gameMenuOverlay.css`
  - 新增人物栏布局样式。
  - 为属性列表增加内部滚动，避免菜单高度不足时内容被裁掉。
  - 为左上角行走图增加帧循环动画和 `hop` 状态下的跳动/阴影表现。

## 遇到的问题与解决方法

### 1. 人物栏内容一开始过于松散

问题：最初属性信息使用卡片式双列排布，地点、坐标、移动速度等内容在菜单高度不足时容易放不下，并且外层裁剪导致看不到被挤出去的内容。

解决：将属性改为紧凑单列行，数值右对齐；属性列表和人物卡片本身都允许滚动，保证小窗口下也能查看完整内容。

### 2. 人物信息存在重复和说明性文案

问题：初版同时显示“主角 / 璃落”和额外说明句，视觉层级不统一，也让人物栏更像资料页。

解决：标题收口为“璃落”，删除说明句；“当前状态”合并到属性行里，不再单独占用一个详情框。

### 3. 行走图预览只显示静态帧

问题：左上角最初复用存档预览单帧，只能显示站立帧，不能体现当前状态下的原地行走。

解决：从当前角色动画 bundle 中读取向下行走帧，使用 CSS 分帧循环展示；如果某个状态只有单帧，则稳定显示该帧。

### 4. 双腿被缚缺少跳着走表现

问题：`legs_bound` 的跳着走在地图中不是额外帧，而是 `movementStyle: 'hop'` 触发的垂直位移。因此菜单预览虽然切到了全身拘束图，但看起来仍像静止站立。

解决：人物栏行走图额外读取 `movementStyle` 和 `hopAmplitude`，当状态为 `hop` 时给预览增加上下跳动动画和地面阴影变化，使菜单预览和地图移动表现一致。
