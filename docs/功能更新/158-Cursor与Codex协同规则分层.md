# 158-Cursor 与 Codex 协同规则分层

- 更新日期：2026-07-26
- 当前摘要：建立共用权威文件与工具专属适配层，为 Cursor 新增按路径附加的规则，并规定大段双端派生配置须先提示用户采用源文件加生成/校验脚本。

## 已实现

新增 `.cursor/rules/`：一条项目入口 Always 规则、游戏架构、内容撰写、文档治理三条路径规则，以及一条手动验证与 Git 边界规则。它们只指向根 `AGENTS.md`、项目 Skill 和系统说明，不复制 Codex 配置或大段项目规则。

新增当前契约《AI 协同文件与规则分层》与 ADR-010。两端共用普通权威文件，`.cursor/`、`.codex/` 只保存各自原生适配；文件系统链接不作为兼容方案。

后续若需要大段、必须派生到双端的配置，必须先主动提示用户：指定一个普通源文件，使用生成脚本产出双端适配，并提供校验脚本或 CI/显式检查防止漂移；未经确认不得建立该生成链或双端大段副本。
