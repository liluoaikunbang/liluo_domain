## 实现说明

本次没有把全部历史文档搬入新数据库，而是在现有文档分层和项目索引之上增加轻量治理层。普通任务只判断是否产生长期影响；明确长期或用户可调用的变化才进入治理 Skill。当前规范、历史实现、用户入口与设计理由分别保存在系统说明、功能更新、用户命令目录和设计记忆中。

建立项目宪章、设计原则、2 条 ADR 与 2 条 CDR；注册表仅覆盖项目级权威文档和跨系统规则。6 个 Node 命令提供影响分析、注册表验证、设计记忆验证、用户命令验证、组合审计与只读重复报告。分类、影响映射、注册表和设计记忆逻辑由单元测试覆盖。
