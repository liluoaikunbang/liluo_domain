# 灰巷历险失联至锈盐剧情衔接

创建时间：2026-07-20

## 更新时间记录

- 2026-07-20：首次补充《失联》至《锈盐》的连续剧情，明确璃落本可独自逃生，却因看见欣雨而折返救人并被抓回；补充运奴船女孩分享食物、照顾负伤且唯一持续被捆绑的璃落。

## 实现思路

保持来源 JSON 中现有的《失联》直接连接《锈盐》，不新增过渡节点。《失联》负责交代璃落取得逃生机会、认出欣雨、主动折返和再次被捕；《锈盐》从运奴船上的互助接续，并将这段经历作为璃落逃船夺证、之后要求缄枷会优先救下女孩们的情感动机。

没有从现有资料确认的细节不擅自补写。璃落的具体脱逃方式、欣雨被捕原因、折返营救失败过程、伤势和加重约束方式均保留为具体 `missingItems`，供后续继续完善。

## 开发过程中遇到的问题

《锈盐》原本直接从璃落逃离盐坞帮押货船开始，没有说明她为何已经受伤、为何只有她被持续捆绑，也缺少她与同船女孩之间的关系基础。首次细化待补项时，又把原有整体故事体量缺口替换成了更窄的首段边界问题，导致模板迁移检查无法确认该灵感条目的体量状态。

## 对应问题的解决方法

把新增信息拆到两个相邻节点：前因写在《失联》结尾，船上关系和后续动机写在《锈盐》开场。恢复《锈盐》的整体故事体量待补项，同时额外保留首段边界、逃船过程和负伤约束等具体问题，使旧缺口与新暴露的下一层缺口并存。
