# 062-旅途菜单分栏与方向键导航

## 实现思路

本次围绕旅途菜单继续向 RPG 菜单形态收口：技能栏不再只是通用占位，而是拆成“职业技能 / 副职业技能 / 通用技能”三个栏目；同时补齐菜单内的方向键控制，让左侧主栏目、右侧分栏、物品/技能格子和存档按钮都可以通过键盘移动与确认。

交互规则最终收束为：

1. 左侧主栏目是菜单第一层，打开菜单时默认聚焦当前主栏目。
2. `↑ / ↓` 在左侧主栏目之间切换，`→` 进入当前栏目内容。
3. 物品栏和技能栏的右侧分类在鼠标点击或键盘聚焦时即为选中；鼠标悬停只提供视觉提示，不改变实际内容。
4. 回到左侧主栏目时，清空右侧分类和下方格子的选中状态。
5. 存档页按钮按实际按钮顺序移动，避免因为单张存档卡里有两个按钮而出现跳转丢失。

这次没有引入新的菜单数据入口，也没有改动各地图 `map.js` 或地图内容数据；所有修改都集中在 `src/game/views/components/base/` 下的菜单基础组件内。

## 相关代码路径

- `src/game/views/components/base/GameMenuOverlay.vue`
  - 技能栏新增“职业技能 / 副职业技能 / 通用技能”三类。
  - 为左侧主栏目、物品分类、技能分类、占位格、存档页按钮补充 `data-menu-nav` 和 `data-menu-group` 标记。
  - 新增 `handleMenuKeydown()` 统一处理菜单内方向键、确认键和空格键。
  - 新增焦点移动工具：`getNavigationElements()`、`focusNavigationElement()`、`focusNavigationElementByKey()`、`moveLinearGroup()`、`moveGridGroup()`。
  - 将物品/技能分类的焦点与选中合并：键盘焦点进入分类时即切换选中内容，鼠标 hover 不触发数据变化。
  - 存档列表按钮改用线性移动，不再按固定二维网格推算。
- `src/game/views/components/base/SaveSlotList.vue`
  - 为覆盖、删除、读取存档按钮补充菜单导航标记，使父级菜单可以统一接管方向键移动。

## 开发过程中遇到的问题

### 1. 技能栏原本只有通用占位

用户希望技能栏像物品栏一样有内部栏目，并明确分成职业、副职业、通用三个方向。

解决方法：

- 在 `GameMenuOverlay.vue` 中新增 `skillCategories`。
- 技能栏使用与物品栏一致的分类按钮和占位格结构。
- 文案最终调整为“职业技能 / 副职业技能 / 通用技能”，避免只写“职业 / 副职业 / 通用”时语义不够明确。

### 2. 分类标题和内容区标签重复

分类按钮已经能表达当前栏目，内容区再显示一个类似“消耗品”的小标签会重复。

解决方法：

- 删除物品栏和技能栏内容区顶部重复的小标签。
- 保留分类说明文字和下方格子，让界面信息更轻。

### 3. 焦点与选中状态一度拆分得过细

早期实现里把“键盘焦点”和“实际选中”拆开，导致方向键浏览分类时页面内容不一定同步，和 RPG 菜单直觉不一致。

解决方法：

- 将右侧分类的焦点与选中合并。
- 方向键进入或移动到某个分类时，该分类立即成为选中项并显示内容。
- 鼠标悬停仍然只走 CSS hover，不改 `activeInventoryCategoryKey` / `activeSkillCategoryKey`。
- 回到左侧主栏目时清空右侧选中，保持菜单层级清楚。

### 4. 存档页方向键导航会跳丢部分按钮

存档页每张卡在保存模式下有“覆盖存档 / 删除存档”两个按钮，原先按两列网格推算方向键位置，会和真实 DOM 顺序、卡片视觉布局不一致，导致部分按钮怎么也选不中。

解决方法：

- 将 `save-list-actions` 从二维网格导航改为线性导航。
- `→ / ↓` 移动到下一个可操作按钮，`← / ↑` 移动到上一个可操作按钮。
- 到列表末尾继续向后进入底部按钮，到列表开头按 `←` 回左侧主栏目；在存档页按 `↑` 回到“新增一个存档条目”。

## 后续维护建议

1. 后续如果物品、技能接入真实数据，建议继续沿用当前“分类 -> 条目”的导航层级，不要让 hover 改变实际内容。
2. 新增菜单栏目时，应为可操作元素补齐 `data-menu-nav` / `data-menu-group`，让方向键导航可以统一发现。
3. 如果未来存档卡片按钮继续增加，优先保持线性导航，避免再次用视觉网格推算内部按钮位置。
4. 当菜单内容变成真实技能或物品后，可以再把占位格从 `article role="button"` 收束为真实按钮或详情项。
