# 都市线病房苏醒与重返校园游戏大纲

创建时间：2026-07-20

## 更新时间记录

- 2026-07-20：首次拆分病房苏醒模块，重构重返校园游戏大纲，并补充关键缺口主动询问规则。

本次把都市线开场原本混在《重返校园》中的医院剧情拆成独立模块《病房苏醒》，形成“荆锁会事件 → 病房苏醒 → 重返校园 → 加入紧缚社团”的单向主链。《病房苏醒》负责获救、身体原主记忆、梦境种子和医院 CG；《重返校园》从荆南大学校门口开始玩家控制，结束于浏览校园论坛并抵达社团招新区域。

## 实现思路

1. 跳过“荆锁会事件”主线任务容器，只整理其后的普通剧情模块。
2. 将医院内容拆为 `1.0.1-病房苏醒.md`，使用 CG 与线性互动小说，不为一次会诊虚构可移动医院地图。
3. 将《重返校园》收口为真实校园地图上的探索序章，复用 `city_jingjiang_school`，不编造尚未存在的事件和对话 key。
4. 新增稳定节点 key `world-1-glimmering-glance-hospital-awakening`，把原《重返校园》的 `parentKey` 改到新节点下，原后继《加入紧缚社团》保持不变。
5. 明确年轻主治医生“许知遥”；后续资料中的治安官顾棠同时承担灵异受害者与异常案件处理成员身份，不另造重复角色。
6. 将“缺少关键材料时主动询问用户”写入主模板，作为以后整理所有条目的固定要求。

## 开发过程中遇到的问题

### 1. 医院剧情与可操作校园流程混在同一节点

问题：原《重返校园》从市医院醒来写到复学，但玩家实际从校门口才获得控制。若按一个模块整理，会同时出现医院身体限制和校园自由探索两套不连续的控制规则。

解决方法：将医院剧情拆成线性互动小说模块，身体限制只作为 CG 与演出状态；校园模块从校门口正常状态开始，职责与完成条件保持单一。

### 2. 精神病院 CG 与安全市医院场景容易混淆

问题：现有真实 CG 的基础标题为“精神病院-病房约束”“精神病院-放风时间”和“精神病院-外出放风”，不能把它们直接描述成当前安全医院的环境。

解决方法：三组 CG 只表现身体原主在荆锁会设施中的记忆碎片，播放后回到光线稳定的市医院会诊，不混淆过去与当前地点。

### 3. 后续处理成员的姓名不明确

问题：原文写“来自专门处理灵异受害者的成员”，但全项目检索没有发现另一名已登记角色；后续《舞蹈教室》持续由顾棠以治安官身份处理异常。

解决方法：确认会诊成员就是顾棠。主治医生在现有资料中确实没有姓名，新增“许知遥”，避免把后续未命名的医生小姐姐误认为同一人。

### 4. 故事树既有测试存在无关失败

问题：完整 `story-outline-tree-builder` 测试当前还有其他世界状态和旧链路断言失败，不能把这些既有问题混入本次都市线调整。

解决方法：新增只验证医院插入关系的定向测试，并使用测试名称筛选单独验证；保留完整测试的既有失败供后续任务处理。

## 验证结果

- 新增医院链路测试由失败转为通过。
- 新节点只插入原主线容器与《重返校园》之间，没有移动其他节点。
- 医院模块引用的三组 `cgRefs` 均有真实图片文件。
- 《重返校园》只填写真实 `mapId`，未给空的 `events.json` 和 `dialogues.json` 编造引用。
- 两篇大纲均达到“游戏大纲”最低章节要求。
