# 图鉴 CG 括号差分与大图差分列表

## 实现思路

本次调整的是旅途菜单图鉴 CG 栏的差分归组规则和预览交互。

旧规则把 `-body` 后缀当作同一张 CG 的纯人物版本。这个规则不再适合后续 CG 资源维护，因为差分不一定只有“人物版”一种，也不应该要求文件名固定写成某个英文后缀。

新规则改为：

- `src/assets/game/cg` 下的图片继续由 `import.meta.glob` 自动收集。
- 文件名去掉扩展名后，如果末尾带全角或半角括号，就把括号内容识别为差分名。
- 括号前面的部分作为同一组 CG 的标题。
- 没有括号的文件作为这一组 CG 的基础图。
- 例如 `玩偶笼车.png` 和 `玩偶笼车（赤脚）.png` 会归为同一个 `玩偶笼车` 条目，第二张差分名为 `赤脚`。
- 例如 `镜头营业-舞蹈教室-人体五角星（body）.png` 会作为 `镜头营业-舞蹈教室-人体五角星` 的 `body` 差分，不再使用旧的 `-body` 特判。

缩略图列表不再提供差分切换按钮，只在 CG 卡片左上角显示差分数量，例如 `2 差分`。这样图鉴列表更像“回看目录”，不会在小卡片上堆过多操作。

大图预览层保留左右翻页与简介遮罩，同时在图片左侧增加差分缩略图列表。点击差分缩略图后，右侧大图切换到对应差分。

## 遇到的问题

1. 旧规则只能表达一种特殊差分。

   `-body` 适合“纯人物版”，但后续可能出现赤脚、表情、道具、光照等多种差分。继续写死后缀会让资源命名越来越绕。

2. 缩略图卡片空间不适合继续承载差分切换。

   图鉴网格主要用于快速浏览 CG 条目。如果每张卡片都放切换按钮，图片数量增加后视觉会变杂，也容易误触。

3. 大图预览层已有翻页、简介和关闭按钮。

   新增差分列表时，需要避免遮挡大图和简介遮罩，也不能影响左右翻页按钮的边缘操作。

4. 中文文件名与括号规则需要保持 UTF-8。

   本次涉及全角括号、中文差分名和中文文档，保存时必须避免编码错乱。

## 解决方法

1. 在数据层统一解析文件名。

   `parseCgAssetName()` 只识别文件名末尾的括号内容，避免误伤标题中间可能出现的括号。解析结果集中写入 `variants`，界面层只消费结构化数据，不再关心文件名细节。

2. 缩略图列表只保留数量提示。

   `getCgVariantCount()` 读取差分数量，只有多于 1 张时显示角标。点击卡片仍然只负责打开大图预览。

3. 大图预览内增加左侧差分栏。

   差分栏放在 `figure` 左侧，右侧图片和简介收进独立的图片舞台中。这样简介遮罩只覆盖当前大图，不会压到左侧缩略图列表。

4. 切换 CG 条目时重置差分索引。

   `openCgPreview()` 每次打开新条目都会把 `previewCgVariantIndex` 设回 `0`，避免从上一张 CG 的差分序号误套到下一张 CG。

5. 使用构建验证。

   已执行：

   ```bash
   npm run build:web
   ```

   构建通过。构建过程中仍会出现既有的 partial 旧路径与 `student1.png` 路径 warning，不是本次 CG 差分改动引入的问题。
