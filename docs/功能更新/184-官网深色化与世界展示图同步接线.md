# 184-官网深色化与世界展示图同步接线

## 背景

这一轮 `浮光掠影` 都市世界补图已经正式收录，但站点里仍然看不到对应的分区展示图。问题不在素材本身，而在“归档完成”只覆盖了文件升位，没有把网站展示位同步接线列成硬性完成条件。

同时，线上官网主入口仍在使用偏浅的页面壳与卡片体系，和当前图片批次的整体气质不够一致。

## 本次调整

1. 把 `浮光掠影` 六个一级展示分区图补进正式站点数据源：
   - `校园（普通与灵异）`
   - `都市（白天与晚上）`
   - `世界旅行风景（雨林与金字塔）`
   - `混乱罪恶都市`
   - `过去时间线`
   - `特殊场景`
2. 在线上使用的 `SitePosterPage.vue` 世界详情页新增“世界展示分区”段落，正式展示图不再只停在归档目录里，而是能直接在网站中看到。
3. 把官网公共外壳、卡片、徽章与筛选控件统一收紧到深色视觉体系，减少浅色底卡带来的割裂感。
4. 在《项目图像生成判层与治理系统》中补上长期规则：官网正式展示图的归档，必须同时完成网站展示位同步接线，否则不算完成。
