# GameView 三栏布局与地图贴合

## 本次实现思路

这次 `GameView` 的调整，目标不是继续做整页铺满地图，而是先把游戏主界面整理成更适合冒险 RPG 扩展的三栏结构：

1. **左侧：竖向立绘区域**
   - 先作为角色立绘预留位使用。
   - 当前只放占位框，后续可以接立绘、状态信息或者剧情演出内容。

2. **中间：方形地图区域**
   - 中间保留 Phaser 地图区域。
   - 页面整体使用 `20:9` 比例，并居中显示。
   - 在布局完成后，继续让 Phaser 挂载在中间区域，不改原有游戏初始化方式。

3. **右侧：介绍 / 按钮区域**
   - 先建立一个竖向信息栏框架。
   - 暂时只保留占位块和已有测试按钮，方便之后继续补剧情说明、交互按钮、角色说明等内容。

在完成三栏布局之后，又根据用户反馈继续处理了一个关键问题：

- **地图没有贴满中间框**

这次没有去改地图内部 tile 数量，而是通过调整 Phaser 主相机的缩放逻辑，让地图按中间容器大小自动放大，尽量贴合中间方形区域。

### 1. 主舞台比例

`GameView` 现在使用一个统一的 `game-stage` 容器承载三栏内容：

- 整体比例：`20:9`
- 布局方式：三列网格
- 页面定位：屏幕中央

这样做的目的，是先把游戏主界面的“舞台感”搭出来，而不是继续让地图单独占满整个页面。

这更符合后续冒险 RPG 的扩展方向：

- 左侧可逐步接入角色立绘
- 中间保持地图探索体验
- 右侧承载介绍、按钮、状态、剧情补充等内容

---

### 2. 左右侧区域处理

当前左右两侧都先使用比较轻量的占位结构：

- 左侧：`立绘区域`
- 右侧：`介绍 / 按钮`

右侧目前保留了：

- 标题占位块
- 文本占位块

- 一个额外功能位预留框

这样后续继续补 UI 时，不需要再先改主布局骨架。

## 地图贴合方案说明

### 问题背景

三栏布局完成后，中间地图虽然已经进入了新的方形区域，但用户实际测试发现：

- **地图没有占满整个中间框**

也就是 Phaser 画面虽然在中间区域里，但视觉上还显得偏小，没有贴合中间方框。

### 处理原则

用户明确提出：

- **不要调整地图内部的块数量**
- **只把地图框做成和中间框贴合**

因此这次没有去修改地图 JSON 的尺寸，也没有增删 tile，而是直接改 Phaser 相机显示方式。

### 实现方式

在 `WorldScene` 中新增了：

```ts
private updateMainCameraLayout(mapWidth: number, mapHeight: number): void {
  const worldWidth = mapWidth * this.tileSize;
  const worldHeight = mapHeight * this.tileSize;
  const camera = this.cameras.main;

  camera.setViewport(0, 0, this.scale.width, this.scale.height);
  camera.setBounds(0, 0, worldWidth, worldHeight);

  const zoomX = this.scale.width / worldWidth;
  const zoomY = this.scale.height / worldHeight;
  const coverZoom = Math.max(zoomX, zoomY);

  camera.setZoom(coverZoom);
}
```

核心思路是：

- 读取当前容器宽高
- 计算地图世界宽高
- 分别求出横向和纵向需要的缩放比
- 取较大的缩放值作为最终 zoom

这样地图会尽量铺满容器，而不是按原始显示比例缩在中间一块。

同时还监听了：

```ts
this.scale.on('resize', () => {
  this.updateMainCameraLayout(mapWidth, mapHeight);
});
```

这样在页面尺寸变化时，中间地图区域也能重新适配。

## 开发过程中遇到的问题

### 问题 1：第一次样式补丁把 `style` 结构打乱了

**现象**：

- `GameView.vue` 的样式段在第一次修改后出现了结构混乱
- 部分 CSS 规则跑到了 `<style scoped>` 外面
- 文件内容虽然被写入，但已经不是有效的 Vue 单文件组件结构

**原因**：

- 第一次补丁在替换模板和样式时命中范围不够稳定
- 原文件较短，样式块整体替换时出现了上下文错位

**解决方法**：

- 重新整体整理 `GameView.vue`
- 把 `template / script / style` 三个部分按完整结构重写
- 确保最终文件恢复为合法的单文件组件格式

---

### 问题 2：地图区域没有贴满中间方框

**现象**：

- 页面三栏结构已经正确
- 但中间 Phaser 地图视觉上没有铺满地图区

**原因**：

- Phaser 仍按原有世界大小与默认显示方式渲染
- 中间 DOM 容器变大后，地图内容没有同步按容器尺寸放大

**解决方法**：

- 不改地图块数量
- 改为在 `WorldScene` 中根据容器尺寸动态计算主相机 zoom
- 让地图以“贴合容器”为目标进行显示

---

### 问题 3：默认 `npm run build` 无法验证

**现象**：

- 尝试使用 `npm run build` 验证时，命令报错：缺少 `build` 脚本

**原因**：

- 当前项目 `package.json` 中并没有 `build`，只有：
  - `build:web`
  - `build:offline`

**解决方法**：

- 改用 `npm run build:web` 完成构建验证
- 构建通过，说明这次调整没有引入新的编译错误

## 当前代码实现要点

### 1. 游戏界面从单地图页面改成了三栏舞台

现在 `GameView` 不再只是一个全屏地图容器，而是开始具备 RPG 主界面的基础形态。

### 2. Phaser 挂载方式保持不变

虽然页面布局改了，但 Phaser 仍然挂载在 `#phaser-game-container` 上，避免额外破坏已有游戏进入流程。

### 3. 地图显示适配从 DOM 尺寸和相机缩放两层同时处理

- DOM 层：中间区域固定在三栏结构中
- Phaser 层：相机根据容器尺寸自动调整 zoom

这样页面结构和地图显示逻辑分层更清晰，后续扩展也更稳。
