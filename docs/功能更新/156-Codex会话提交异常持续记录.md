# 156-Codex 会话提交异常持续记录

- 更新日期：2026-07-25
- 当前摘要：建立消息提交异常的单一问题档案与复发处理入口，使既有证据可跨会话复用，后续补充可持续追加。

## 已实现

建立 `docs/运行规范/未解决问题/Codex会话提交异常与上下文预算问题.md`，区分已确认现象、排除项、工作假设、已实施缓解和带来源的观察更新。它只记录可复核的诊断事实，不保存聊天流水账或未验证推理。

根规则与用户命令目录加入短路由：用户再次报告消息提交失败、`Error submitting message`、数轮后卡住或异常工具等待时，先读取该档案，不要求重复既有描述；仅询问会改变诊断的新事实，并把有价值的补充追加到档案。
