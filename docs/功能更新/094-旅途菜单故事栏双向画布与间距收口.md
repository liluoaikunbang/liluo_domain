# 旅途菜单故事栏双向画布与间距收口

## 本次实现思路

本次围绕旅途菜单里的“故事”栏继续整理画布浏览体验。

目标有两点：

- 保留原本从左到右延伸的横向故事画布。
- 新增从上到下延伸的纵向故事画布，并将纵向作为默认展示模式。

后续根据实际查看反馈，又继续收紧了画布节点间距。处理范围只在故事栏 UI 内部，没有改动 `src/game/data/global/storyOutlinePlaceholder.json`，也没有新增另一套故事数据源。

这次调整的重点是让故事大纲更适合在旅途菜单里查看：既能保持树状分支的结构感，又能在默认视野里看到更多节点，减少频繁拖拽画布的成本。

## 相关代码路径

- `src/game/views/components/base/StoryMenuPanel.vue`
  - 新增 `layoutMode` 与 `layoutModeOptions`，支持 `vertical` / `horizontal` 两种画布模式。
  - 默认模式设为 `vertical`。
  - `createNodeLayout` 根据模式切换节点坐标轴和 SVG 连线路径。
  - 收紧横向、纵向模式下的节点间距与画布外圈留白。
  - 新增 `ROOT_BRANCH_GAP`，单独控制不同顶层分支之间的额外间隔。

- `src/game/views/components/base/gameMenuOverlay.css`
  - 为故事栏顶部增加展示模式切换按钮样式。
  - 调整故事栏头部布局，让模式切换与缩放控件并列显示。
  - 在窄屏下让头部控件纵向排列，避免按钮挤压。

## 具体实现说明

### 1. 横向与纵向共用同一套故事树数据

故事栏仍然接收同一份 `outline` 数据。不同展示模式只影响布局计算：

- 横向模式：父子节点沿 X 轴推进，分支沿 Y 轴展开。
- 纵向模式：父子节点沿 Y 轴推进，分支沿 X 轴展开。

这样后续继续补 `storyOutlinePlaceholder.json` 时，不需要为不同模式维护两份坐标或两份结构。

### 2. 连线路径跟随展示方向切换

原横向画布的连线从父节点右侧连到子节点左侧。

纵向模式新增后，连线改为：

- 从父节点底部中点出发。
- 连到子节点顶部中点。
- 使用纵向贝塞尔曲线保持画布的树状阅读感。

这样纵向模式不是简单把卡片挪成上下排列，而是让节点关系的视觉方向也一起变成从上到下。

### 3. 默认展示模式改为纵向

`layoutMode` 默认值设置为 `vertical`。

进入故事栏时，用户会先看到从上到下延伸的结构；如果需要保留原来的阅读习惯，可以点击“横向”切回原有方向。

切换模式后会重新回到画布起点附近，避免保留上一种模式的滚动位置导致画面停在空白区域。

### 4. 节点间距分两轮收紧

第一轮收紧的是同一分支内部的父子层距和同层节点间距：

- `COLUMN_GAP`
- `ROW_GAP`
- `VERTICAL_COLUMN_GAP`
- `VERTICAL_ROW_GAP`
- `CANVAS_PADDING`

这让单条故事链路里的卡片更紧凑，默认视野里能看到更多节点。

第二轮处理的是不同顶层分支之间的额外空白。

原本布局在每个顶层分支之间额外推进 `1` 格，导致即使单分支卡片变近，不同大分支之间仍然显得很空。现在新增：

```text
ROOT_BRANCH_GAP = 0.35
```

不同顶层分支之间只保留较小间隔，不会完全贴死，也不会继续占用过多画布空间。

## 开发过程中遇到的问题

### 1. 只改变坐标不够，连线也需要跟着方向变化

如果只把节点坐标从横向改成纵向，连线仍然从左右两侧连接，就会出现视觉方向不一致的问题。

解决方法：

- 在 `createNodeLayout` 中用 `isVertical` 分支计算连接点。
- 横向继续使用右到左连线。
- 纵向改为下到上连线。

### 2. 切换模式后可能停留在旧滚动位置

横向画布和纵向画布的宽高分布不同。如果切换后沿用旧的 `scrollLeft` / `scrollTop`，视口可能停在空白区域或偏离起点。

解决方法：

- 监听 `layoutMode`。
- 模式变化后执行 `centerCanvasStart`。
- “重置”按钮也继续回到画布起点附近。

### 3. 单分支间距缩小后，不同顶层分支仍然太远

第一次只调整了布局常量，父子节点之间确实更近，但顶层分支之间仍由额外的 `rowCursor += 1` 拉开。

解决方法：

- 新增 `ROOT_BRANCH_GAP` 常量。
- 将顶层分支间隔从整格缩小为 `0.35` 格。
- 保留一点分支呼吸感，同时提升同屏信息密度。
