# 051-醉欲之城中心城区离开列车选项

## 实现思路

本次为 `city_desire` 地图中的 3 个离开事件点补齐“离开醉欲之城中心城区”的手动交互。

地图本身已经在 `map.json` 中提供了 3 个隐藏事件图层：

- `leave_event_1`
- `leave_event_left`
- `leave_event_right`

实现时没有改动 Tiled 地图瓦片数据，而是按现有事件系统约定新增地图专属 `events.json` 与 `dialogues.json`：

1. `events.json` 负责把 3 个隐藏事件图层注册成手动事件。
2. `dialogues.json` 负责提供离开列车的目的地选择。
3. `registry.ts` 负责把 `city_desire` 的事件与对话并入全局事件/对话注册表。

三个离开点都提供共同选项“回到四季花园”，并通过 `mapTransition` 实际跳转到 `liluo_estate` 的 `role` 出生点。其他目的地先按占位处理，点击后只显示“线路暂未接入”的提示，不跳转到不存在的地图。

用户确认后，又将“回到四季花园”统一调整为倒数第二项，放在“暂时不离开”之前，避免它压过各方向专属目的地。

## 相关代码路径

- `src/game/data/maps/city_desire/events.json`
  - 新增 `city_desire_leave_north`、`city_desire_leave_west`、`city_desire_leave_east`。
  - 分别绑定 `leave_event_1`、`leave_event_left`、`leave_event_right`。
  - 面板动作统一显示“离开醉欲之城中心城区（Space）”。
  - 描述中说明是通过列车离开中心城区。

- `src/game/data/maps/city_desire/dialogues.json`
  - 新增 3 组离开列车对话。
  - `leave_event_1` 额外提供“去往北沙滩”占位。
  - `leave_event_left` 额外提供“去往西部郊区”“去往工业区”“去往深渊幽狱”占位。
  - `leave_event_right` 额外提供“去往东部郊区”占位。
  - 三组对话都提供“回到四季花园”，并实际跳转到 `liluo_estate`。
  - “回到四季花园”统一放在“暂时不离开”之前。

- `src/game/data/registry.ts`
  - 引入 `city_desire/events.json` 与 `city_desire/dialogues.json`。
  - 将 `cityDesireEvents` 合并进 `eventRegistry`。
  - 将 `cityDesireDialogues` 合并进 `dialogueRegistry`。

## 开发过程中遇到的问题

### 1. `city_desire` 之前没有地图专属事件与对话文件

`city_desire` 目录原本只有 `map.json`、`assets.ts`、`meta.ts`，没有 `events.json` 或 `dialogues.json`。如果只在 `map.json` 里依赖图层名称，事件系统无法知道这些图层应该触发什么行为。

解决方法：

- 新增 `src/game/data/maps/city_desire/events.json`。
- 新增 `src/game/data/maps/city_desire/dialogues.json`。
- 在 `src/game/data/registry.ts` 中显式接入这两个文件。

### 2. 其他目的地暂时还没有真实地图

北沙滩、西部郊区、工业区、深渊幽狱、东部郊区暂时都没有接入地图。如果给这些选项直接配置 `mapTransition`，会产生跳转到不存在地图的风险。

解决方法：

- 这些选项只配置 `next`，跳到对应的占位说明节点。
- 占位节点说明列车线路暂未正式接入。
- 只有“回到四季花园”配置真实 `mapTransition`。

### 3. 共同选项的位置需要更符合目的地菜单的阅读顺序

最初“回到四季花园”放在第一项。用户确认后，希望它作为共同兜底路线，放在“暂时不离开”之前，也就是倒数第二项。

解决方法：

- 调整 3 组对话的 `choices` 顺序。
- 各方向专属目的地放在前面。
- “回到四季花园”放在倒数第二项。
- “暂时不离开”保持最后一项。


结果：

- Vite 构建通过。
- 新增 JSON 文件可以被正常导入与打包。
- 用户实际测试确认无报错，并确认“回到四季花园”选项顺序符合预期。

## 后续维护建议

1. 后续接入北沙滩、西部郊区、工业区、深渊幽狱、东部郊区时，优先把对应占位选项从 `next` 改为真实 `mapTransition`。
2. 如果新增这些区域的地图，按 `src/game/data/maps/<mapId>/` 结构补齐 `map.json`、`events.json`、`dialogues.json`、`meta.ts`、`assets.ts`，再接入 `registry.ts`。
3. 继续避免直接修改 `city_desire/map.json` 中的瓦片数据，离开点逻辑优先通过事件和对话数据维护。
