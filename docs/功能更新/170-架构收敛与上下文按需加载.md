# 170 - 架构收敛与上下文按需加载

- 创建时间：2026-07-28
- 更新时间：2026-07-28

## 摘要

明确旧页面式游戏为低优先级可运行参考；索引和行动导航改为按需薄投影；对话与地图注册收敛为单一契约并拒绝重复 ID；GameView 菜单绑定和 WorldScene 出生点纯规则已拆分。

## 本次收敛

- 旧页面式游戏继续保留为可运行的迁移参考，不作为近期迁移项目，也不删除其路由、组件或素材；新增玩法仍优先进入 Phaser 地图、事件和对话体系。
- 跨文件定位先使用项目索引查询，再按命中项读取原始权威文件；不再把完整 `project-index/INDEX.md` 当作默认上下文。
- 行动导航的 `capabilities.json` 改为薄投影，避免把 Skill、Agent 和命令的完整合同重复写入派生表。人工维护的缺口投影会记录来源，区分人工事实与自动派生结果。
- 对话选项的运行字段收敛到 `dialogueExecution.ts` 的执行契约；UI 侧只追加展示标签。
- 地图事件和对话注册改为受检合并。若两个地图复用同一 ID，启动时会报出冲突 ID 与两个地图，而非按导入顺序静默覆盖。
- `GameView` 的三种模式共用一份菜单 props / 事件绑定，不再维护三套同样的菜单接线；`worldSceneRuntime` 只保留场景装配，出生点回退和最近可通行格搜索进入可独立测试的纯规则模块。
