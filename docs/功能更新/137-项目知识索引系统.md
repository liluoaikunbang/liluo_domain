# 项目知识索引系统

创建时间：2026-07-21

当前摘要：建立覆盖故事、玩法、游戏内容、代码、素材、文档与关系的确定性分层索引，并提供构建、增量更新、查询、新鲜度检查和验证流程。

## 更新时间记录

- 2026-07-21：补充索引适合当前多世界、多系统、大素材仓库的原因，以及“复杂任务优先查询、明确单文件直接读取”的 token 优化边界。
- 2026-07-21：完成第一版项目知识索引系统、维护 Skill、Agent/Skill 路由与长期说明。

## 实现说明

新增 `project-index/` 的 L0/L1/L2 导航与分片数据，以原始仓库文件作为 L3 权威来源。Node ESM 工具使用 SHA-256、稳定排序、领域级增量、临时目录和逐文件替换；查询默认限制结果与字符数。首次全量构建基于当前真实工作树完成，未引入外部服务或依赖。

世界观实体领域因缺少独立稳定资料库暂标 `not-enabled`，不从故事正文编造实体。故事源中没有 Markdown 对应项的分类/占位节点保留在解析问题清单，因此总体状态为 `partial`，其他已启用领域保持可用。
