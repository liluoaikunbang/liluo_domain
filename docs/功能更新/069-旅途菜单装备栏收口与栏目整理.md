# 069-旅途菜单装备栏收口与栏目整理

## 实现思路

本次围绕旅途菜单里的装备栏做了一轮收口：装备页不再展示人物立绘，回到更直接的 RPG 装备信息结构；装备分类保留“武器 / 副手 / 防具 / 饰品”，把上衣、下装、袜子、鞋子合并为一个“防具”分类，避免栏目过碎。

装备栏布局从原本的立绘预览加装备列表，调整为左侧分类、右侧装备列表、下方详情操作区。装备列表标题下新增固定的“当前装备”行，下面的候选装备列表继续独立滚动；如果某个分类已有已装备条目，固定行会显示该装备并支持选中查看详情。

同时清理了菜单里的占位说明文字：分类级“之后放置……”说明、装备分栏缺省提示不再直接露出。拘束栏入口也从菜单栏目中移除，底层拘束数据和组件暂时保留，避免影响后续剧情状态或恢复需求。

  - 将已装备条目从可滚动候选列表中排除，避免重复显示。

  - 装备栏改为无立绘的两列网格布局。

## 遇到的问题与解决

### 1. 装备栏立绘占位压缩了装备信息区域

问题：装备页已经承担分类、当前装备、候选装备和详情操作，继续保留人物立绘会让右侧列表和详情区域显得拥挤。

解决：移除装备面板内的立绘预览 section，并将 CSS 网格改为两列布局，让分类与列表占据上方，详情横跨下方。

### 2. 装备分类过碎

问题：上衣、下装、袜子、鞋子作为独立装备分类时，当前阶段内容密度不足，菜单切换成本高。

解决：将这些服饰类防护装备合并为“防具”分类，保留代表性的占位条目，后续真实装备系统扩展时再继续细分。

### 3. 当前装备需要固定展示

问题：只在滚动列表里标记“已装备”，玩家扫视时不够直接。

解决：在二级分类标题下增加固定“当前装备”行，下面列表继续滚动；已有装备时固定行可选中查看详情，没有装备时仅显示“未装备”。

### 4. 占位说明影响菜单质感

问题：分类说明中的“之后放置……”和缺省提示“先在左侧选择……”更像开发占位文案，直接出现在菜单里会削弱 RPG 菜单感。

解决：删除分类级占位说明；面板仅在真实 `description` 存在时显示说明。
