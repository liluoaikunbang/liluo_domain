# 169 - 大纲关联图谱视图

- 创建时间：2026-07-27
- 更新时间：2026-07-28

## 摘要

大纲关联图谱：故事通过 `plotRefs`、`ragRefs`、`gameplayRefs` 直连情节、紧缚 RAG 与玩法；紧缚 RAG 以 `parentCardIds` 建立上位类别与具体概念两层；空内容、缺来源、待补故事和未关联情节使用橙色缺口框；支持投影 JSON 导出。已删除空泛的旧 `fb-*` 孤立卡；用户可见名称由「普通 RAG」改为「紧缚 RAG」。大纲访谈每次必问紧缚 RAG 标签（CDR-009）。

## 内容

- 入口：游戏内菜单 → 大纲 → **关联图谱**（不进入左侧一级导航）。
- 数据：`buildOutlineRelationGraph()` 从现有大纲 / 情节 / 玩法 / 人物派生视图 / 外部知识卡 / Style taxonomy / Style-RAG 文章清单 / 抽查登记生成节点与边；不复制正史正文，不强制 Tag↔RAG 一一对应。
- Style-RAG：全图主节点为 taxonomy **写法名词**；小说/文章为 `evidence` 挂点，默认隐藏，可图例开关或聚焦邻域显示。
- **紧缚 RAG**：以 `restraint/` 两级事实卡为主；`card-rules` 仅在有证据时生成候选，不再自动播种空泛表达/场景占位卡。故事节点展示由 `ragRefs` 派生的一级标题标签。
- **访谈须选项（CDR-009）**：随机提问 / 指定完善 / 情节安置批准后访谈每次必问「设置紧缚 RAG 标签」；确认后查找或建骨架空卡写入 `ragRefs`，stub/缺正文登记 `missingItems`。
- **概念分层**：紧缚 RAG 卡带 `ragLayer`（上位类别 / 具体概念）和 `parentCardIds`；图谱边在 RAG↔RAG；**不投影细节概念节点**。
- **退役旧 Tag**：普通 Tag 与紧缚 Tag 的节点、泳道、筛选和权威字段均已删除；旧名词只保留在迁移追溯记录中；CDR-008 已被 CDR-009 取代。
- **直连**：大纲 / 情节按正式引用直连 RAG、情节与玩法，不再经由 Tag 中转。
- **RAG 挂接**：知识卡可选 `linkedConceptIds`（分层种子）；禁止把情节推进句写入 `concepts`。
- **缺口提示**：空内容、缺来源、含 `missingItems` 的故事、未被故事引用的情节以及孤立节点统一使用橙色框，并计入图谱缺口统计。
- 渲染：Canvas 2D 无限画布 + 类别泳道布局；不新增 d3/cytoscape 依赖。
- **导出 JSON**：工具栏「导出JSON」下载当前投影快照（`liluo-outline-relation-graph.json`）；复用 `jsonDownload`；不改写正史。
- 校准：图谱只做发现与定位；正史修改与抽查记录仍走既有编辑与 `rag:audit:*` / `style-rag:audit:*`。
- CLI：`npm run outline:graph:stats|validate|find-orphans|find-unreviewed|rebuild|test`（`validate` 禁止概念节点投影）。
