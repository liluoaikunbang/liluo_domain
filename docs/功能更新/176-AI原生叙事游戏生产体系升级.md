## 实现说明

这一轮的核心不是继续往首页堆概念，而是把“项目门户”真正收束到用户想要的呈现方式上。

前一版虽然已经把 README 从架构说明页改成了更像独立游戏门户的入口，但世界展示仍然停留在草案级 SVG 卡片，角色展示也还误用了游戏内像素代替立绘。第三轮修正之后，根 README 的前半段彻底改成了以正式宣传图和真实运行截图为主的表达层：

- 璃落角色展示改为单独生成的正式角色图，不再使用游戏内像素代替立绘。
- 六大世界全部替换为世界优先的 AI 宣传图，不再用简化 SVG 卡片顶替世界氛围。
- 新增一张“璃落在不同世界中的融合图”，承担世界总览横幅，强化项目门户的整体意境。
- 原型段落接入两张真实运行截图，明确区分“宣传图”和“当前已跑起来的可见原型”。

这轮也把素材说明与清单同步收口到新的正式资产集，避免旧草案再次被 README 误引用。继续扩编之后，README 不再只是“有一张海报和几张旧图”的门户，而是拥有可持续扩展的公开展示骨架：

- 六大叙事域从单张世界卡升级成每域三联图：总海报、局部场景、事件落点。
- 璃落角色段补齐新的公开基准立绘、六域服装变体和“不变身份 / 可变状态”说明图。
- `art-manifest.json` 从首版轻量登记扩到 `45` 项，提示词记录扩到 `6` 份，可追溯到每批次新图。

除此之外，README 也被拆成了三条公开证据线：

- 概念视觉：只负责传达世界、角色与气质。
- 真实截图：只使用真实运行中的现有证据，不能拿概念图冒充。
- 自动统计：由脚本直接从仓库数据回算地图、节点、Schema、Skill、截图归档状态与视觉元数据。

这让根 README 从“漂亮入口”真正升级成了“可公开展示、可招募协作者、可自证边界”的项目海报页。

继续扩编之后，这个“海报页”开始更接近原始目标里的整套公开门户，而不是只在首页加几张世界图：

- 首屏主视觉升级到 `hero-liluo-universe-v3.png`，六域总览横卷 `six-domains-panorama-v2.png` 负责把“同一个璃落贯穿六域”说得更直观。
- `docs/readme/生产体系.md` 不再只靠一张脚本流程图，而是补进五层生产体系、角色状态网络、成熟度阶梯、故事到可玩案例、关系图谱治理等多张 GPT Image 2 无字底图。
- 新建 `docs/协作参与与团队扩展路线.md`，把协作角色星图、AI 与人工边界图、路线图与收尾招募横幅集中放到单独扩展页，避免 README 只像一个孤立海报。

最后一轮收束的重点，不是再增加零散图数，而是把已经补出来的素材真正转成“可公开展示的最终板式”，并且把真实证据缺口直白地呈现出来：

- 根 README 与 `docs/readme/世界图册.md` 不再直接堆 `18` 张原始世界分层图，而是改为 `6` 张单图三联整板；原始图仍保留在 `docs/assets/readme/generated/` 供扩展页继续引用。
- `docs/readme/可玩证据.md` 与根 README 都接入了 `runtime-evidence-board-v1.png`，现在这张整板已由 `6` 张真实核心截图填满，不再保留待补占位。
- `docs/readme/生产体系.md` 把抽象案例底图替换成 `十三号病院` 的真实链路板：旧页面流程、正式 `scenario.json`、功能文档、运行入口与最终补回的副本截图被放进同一张证据板里。
- 公开规模看板改成 `project-scale-dashboard-v2.png`，由程序把真实统计数据叠加到 GPT Image 2 无字底图上，而不是让图片模型直接写复杂中文信息。
- 角色展示区额外补进一张真实“紧缚状态差分组合”面板截图，专门用来证明项目里已经存在运行中的状态切换与图层组合能力，而不只是在 README 中做概念宣称。

在这之后，根 README 还继续向原始任务书中“不是十几张图，而是接近完整公开海报页”的目标再推进了一步：

- 根页原先仍在使用的 `readme-evidence-boundary.svg` 与 `story-production-pipeline.svg` 已从首页展示退场，改由 GPT Image 2 的 PNG 概念板承担公开表达；复杂信息继续通过正文文字、真实截图和自动统计来校准，不再依赖程序风格 SVG 维持首页观感。
- 在此基础上，`readme-evidence-boundary-board-v2.png`、`story-production-pipeline-board-v2.png` 与 `relationship-graph-real-evidence-board.png` 也已经落成正式 PNG 整板：前两张由 GPT Image 2 底图叠加准确标题和说明，后一张则把真实 `README-SHOT-05` 图谱截图装裱成公开证据板。
- 新接入 `one-story-many-forms-v2-base.png`、`five-layer-production-system-base.png`、`universe-state-event-network-base.png`、`relationship-graph-display-base.png`、`production-maturity-ladder-base.png`、`ai-participation-boundary-base.png`、`collaboration-role-star-map-base.png` 与 `project-roadmap-base.png` 等系统层视觉，使首页不只展示世界图和角色图，也能公开说明生产链、状态网络、分工边界和推进路线。
- 自动统计脚本现已额外记录根 README 的 Markdown 图片数、HTML 图片数与总视觉单元数；校验脚本也会强制检查根页图像引用是否存在，以及可见视觉单元是否仍保持在任务书要求的 `28–36` 区间内。
