# 147-内容生产与可玩化基础系统

- 更新日期：2026-07-22
- 当前摘要：建立故事到可玩内容、叙事路线验证、角色与关系长期记忆、正式来源门槛及世界/系列覆盖五项基础能力，并保留音频声景待定设计。

## 已实现

新增四个项目 Skill、五份当前系统说明、一个音频待定设计、统一 Node ESM 合同与六项自动测试。故事 Markdown 的制作字段现可进入运行时故事节点；`long-term-memory.json` 以两条已有证据建立角色与关系长期记录。路线支持静态、模拟和隔离存档重入；覆盖按六世界真实来源派生且不会从文件数量推断可玩。

统一来源门槛允许项目原创、用户拥有、项目生成、已许可第三方、公版及经逐项核验的兼容开源；未知、仅参考、许可不清、受限、外部 RAG 原文、近似改写风险与未核验第三方 fail-closed。该门槛不构成法律保证。

## 边界

没有批量转化故事、没有新增 Agent/API/MCP、没有修改真实存档、没有建立统一任务状态、没有生成正式图片或音频，也没有把任何世界误报为已可玩。浏览器层仍为人工可选；既有五个 SFX 的来源/许可登记留待公开发布前审计。
