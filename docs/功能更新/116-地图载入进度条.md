# 地图载入进度条

本次为地图载入流程增加了前端进度条，用来缓解角色图层动态拼接变多后，进入地图时短暂停顿但界面没有反馈的问题。

实现重点不是改变资源加载策略，而是把已有 Phaser 加载阶段和角色图层准备阶段的进度同步到 Vue 侧，让玩家能看到“正在载入 / 正在生成角色图层 / 正在整理地图”的状态。

## 实现思路

1. `BootScene` 在全局资源加载时上报进度。
2. `BootScene` 在执行角色图层动态生成前上报“生成角色图层”，避免同步拼图期间画面像卡死。
3. `MapLoadingScene` 在地图资源加载和地图整理阶段继续上报进度。
4. `createPhaserGame` 和 `usePhaserGameBridge` 增加 `onLoadingProgress` 回调，把 Phaser 侧进度传到 Vue 侧。
5. `GameView` 保存当前加载进度，`MapMode` 在地图中心区域显示像素风进度条。
6. `MapMode` 对进度条增加 1 秒显示阈值：短于 1 秒的加载只保留黑屏载入，超过 1 秒仍未完成时才显示详细进度条。

## 相关代码路径

- `src/game/core/loadingProgress.ts`
  - 定义 `GameLoadingProgress`、`GameLoadingProgressHandler`、进度裁剪函数和详细进度条显示阈值。
- `src/game/scenes/BootScene.ts`
  - 上报全局素材加载进度。
  - 在角色动态图层准备前显示“生成角色图层...”。
- `src/game/scenes/MapLoadingScene.ts`
  - 上报地图资源加载、整理和进入地图阶段。
- `src/game/core/createPhaserGame.ts`
  - 接收并向 Phaser 场景传递 `onLoadingProgress`。
- `src/game/views/composables/usePhaserGameBridge.ts`
  - 把加载进度回调纳入 Vue / Phaser 桥接参数。
- `src/game/views/GameView.vue`
  - 保存加载进度状态，并传给地图模式。
- `src/game/views/modes/map/MapMode.vue`
  - 显示地图载入进度条、百分比和当前阶段文案。

## 处理过的问题

### 1. 延迟不只来自网络资源加载

问题：角色图层变多后，部分停顿来自浏览器端 Canvas 动态合成角色帧，不完全是图片下载。

解决：除了监听 Phaser Loader 的 `progress` 事件，还在 `BootScene.create()` 中进入角色资源准备前上报“生成角色图层...”。这样即使同步生成期间无法细分每一帧进度，玩家也能知道当前不是无响应。

### 2. 加载条不应破坏地图层级

问题：地图中心已经有 Phaser canvas、运行时错误条、事件场景图、过场和通知栏。

解决：进度条放在 `MapMode` 中心区域，层级高于黑色 canvas，低于事件场景图和过场表现；同时设置 `pointer-events: none`，不拦截地图或 UI 交互。

### 3. 进度值需要防御异常输入

问题：Loader 或未来扩展回调可能传入非有限数字。

解决：通过 `clampLoadingProgress()` 统一限制到 `0..1`，Vue 侧再转换为百分比显示。

### 4. 进度条颜色需要保持统一

问题：早期进度条填充使用了黄粉条纹，虽然有像素感，但在地图载入遮罩上会显得花，容易抢走玩家对当前载入状态的注意力。

解决：`MapMode` 中的进度条填充统一改为单一黄色，保留像素风边框、暗色底和阶梯式宽度过渡，让整体更干净，也更符合当前游戏 UI 的朴素风格。

### 5. 短加载不应闪一下进度条

问题：如果资源很快载入完成，立即显示进度条会造成界面短暂闪烁，观感反而比黑屏切换更明显。

解决：详细进度条增加 `1000ms` 延迟阈值。加载开始后先保持原本的黑色地图容器；如果 1 秒内完成，就不显示进度条；如果超过 1 秒仍在加载，再显示进度条和当前阶段文案。阈值集中放在 `loadingProgress.ts`，后续可按实际体感统一调整。

## 当前结论

地图载入现在会显示一个符合现有像素风 UI 的进度条：

- 初始进入游戏时显示全局素材和角色图层准备进度；
- 切换地图时显示地图资源载入和整理进度；
- 小于 1 秒的短加载只黑屏过渡，不显示详细进度条；
- 进度条填充使用统一颜色，不再使用多色条纹；
- 加载完成后自动隐藏；
- 加载异常仍继续走原有运行时错误提示。

后续如果角色动态图层继续增多，可以再把角色图层合成改成分批异步处理，让“生成角色图层”阶段也能更细地刷新百分比。
