# 168 - 知识检索抽查校准闭环

- **创建时间**：2026-07-26
- **更新时间**：2026-07-27

## 摘要

知识检索抽查覆盖普通 RAG、Style-RAG、细节概念与情节；普通 RAG 默认只抽知识卡；卡文与协商须走自然表达；人工评价先协商改向再落盘；修正时共查共改；按阈值升级 Skill 并仅重建受影响范围。

## 内容

- 策略与类别：`project-navigation/rag-audit-policy.json`、`rag-audit-categories.json`
- 通道：`rag`｜`style-rag`｜`concept`｜`plot`（可用 `knowledge:audit:sample` 综合抽样）
- 记录目录：`docs/知识检索校准/records/{rag,style-rag,concept,plot}/`
- CLI：`rag|style-rag|concept|plot:audit:*` / `*:audit:related` / `*:rebuild:affected` / `knowledge:audit:sample`
- **普通 RAG 默认只抽知识卡**（`ragSample.defaultAssetKinds=["card"]`）；源条目须 `--include-sources` 或 `--asset-kind source|all`
- 卡审批次展开 definition / distinctions / concepts / 同类型邻居与三问；不以原文为主审材料
- **人工定性评价**（如「太抽象」）不得原样 `record`：先协商修改方向与改稿计划，用户确认改好或明确「暂时这样」后再写卡/归档
- **自然表达**：撰写或改写 RAG 知识卡、Style-RAG 抽象说明、抽查协商与向用户解释结论前，先应用 `liluo-natural-expression` light；说清用途与邻居差别，避免口号空话（ID/路径/命令不润色）。权威路由在自然表达系统；工作流入口在两 Skill 与抽查/Style-RAG/外部知识库系统说明；用户命令与 CDR-005 / ADR-014 已对齐。
- **关联共改**：改主条目时用 `related` 列出邻居，有需要则一并调整并写入 `relatedAdjustments`
- 缺口：`gap-rag-manual-audit-calibration`、`gap-style-rag-manual-audit-calibration`
- concept/plot 重建以人工修正 + `outline:graph:validate` 为主

## 边界

- 单次错误不升级 Skill（阈值见策略）
- 重建默认 dry-run、禁止全库、不改外部原文
- 细节概念与情节不并入 RAG 库，只共用抽查闭环
- 禁止只改单点、留下关联命名/挂接矛盾
