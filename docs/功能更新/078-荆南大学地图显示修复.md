# 078-荆南大学地图显示修复

## 实现思路

本次围绕 `modern/city_Jingjiang_school` 地图做显示修复，目标是让这张现代校园地图先稳定地作为可探索 RPG 场景运行，而不是让数据配置或通用过滤规则挡住地图内容。

修复内容包括：

1. 将地图显示名从“静江学校”改为“荆南大学”。
2. 将地图相机模式改为跟随玩家，避免大地图探索时镜头固定在中心。
3. 补齐地图 `map.json` 中引用但未注册的 `farm_object_2` tileset，使树木等物件能正常渲染。
4. 收窄 tilelayer 隐藏规则：不再因为图层名以 `_event` 结尾就强制跳过渲染，而是尊重 `map.json` 中的 `visible` 字段；目前只继续强制隐藏 `collision` 图层。

这次没有直接修改地图原始 `map.json` 数据，而是优先从地图 meta、资源注册和通用渲染规则上修复，减少后续 Tiled 地图重新导出时产生冲突。

## 相关代码路径

- `src/game/data/maps/modern/city_Jingjiang_school/meta.ts`
  - 将地图名更新为“荆南大学”。
  - 将 `viewport.cameraMode` 改为 `follow-player`。
  - 为 `farm_object_2` 增加 tileset 到 Phaser texture key 的匹配配置。

- `src/game/data/maps/modern/city_Jingjiang_school/assets.ts`
  - 注册已有素材 `src/assets/game/sucai/farm_object_2.png`。
  - 新增资源 key：`modern_school_farm_object_2`。

- `src/game/systems/map/runtimeMapNormalizer.ts`
  - 调整 `shouldHideRuntimeTileLayer()`。
  - 保留 `collision` 图层隐藏。
  - 移除 `_event` 后缀图层的强制隐藏逻辑，让是否可见回到 `map.json` 的 `visible` 字段。

## 遇到的问题与解决方法

### 1. 地图镜头不跟随角色

问题：荆南大学是可探索的大地图，但 `meta.ts` 中 `viewport.cameraMode` 使用了 `static-centered`，运行时不会执行 `camera.startFollow(player)`，因此镜头固定在地图中心。

解决：将该地图的 `cameraMode` 改为 `follow-player`。房间类小地图仍可继续使用 `static-centered`，大地图探索则使用跟随玩家模式。

### 2. 地图显示名不符合当前设定

问题：地图显示名仍是“静江学校”，和当前想表达的地点名称不一致。

解决：只修改 `meta.ts` 中的 `name` 为“荆南大学”，不改 `mapId`，避免影响已有传送、注册表和存档引用。

### 3. 部分树木没有体现

问题：`map.json` 中存在 `farm_object_2` tileset，图片路径为 `src/assets/game/sucai/farm_object_2.png`，但该 tileset 没有在荆南大学地图的 `assets.ts` 和 `meta.ts` 中注册。渲染器找不到对应 texture 时会跳过这些图块。

解决：在 `assets.ts` 注册 `farm_object_2.png`，并在 `meta.ts` 中补充 `farm_object_2` 到 `modern_school_farm_object_2` 的匹配关系。该图片是已有素材，不属于本次新增图片，因此不需要更新 `docs/游戏素材图片清单.md`。

### 4. `old_in_event` 图层明明可见却不渲染

问题：`old_in_event` 是 `map.json` 中 `visible: true` 的 tilelayer，里面使用了 `farm_object_2` 的图块。但通用渲染过滤规则曾把所有名字以 `_event` 结尾的 tilelayer 都当成事件标记层跳过，导致这个图层不会显示。

解决：调整 `shouldHideRuntimeTileLayer()`，不再通过 `_event` 后缀决定渲染隐藏。事件层如果需要隐藏，应在 Tiled/JSON 中设为 `visible: false`；可见图层即使名字包含 `_event`，也应按地图数据渲染。
