## 摘要

把紧缚 RAG 升级为「知识 + 表达」双分支专业 RAG；通用 Style-RAG 降为辅助；图谱采用详情页签（原文证据可展开段落、原始来源只列小说名，均不进大图）；日常靠抽查闭环（抽查过/confirmed-ok 分层降权且不移出池）。已批量迁移全部紧缚卡为双分支骨架；不另开维护页。

## 实现要点

1. Schema 增加 `knowledge` / `expression` / `overallStatus` / `evidenceBindings` 与分枝检索门禁。
2. 图谱 schemaVersion=4：主节点仍为单一 RAG；知识/表达/原文证据只在详情页签；证据段落与小说名挂在 RAG `meta`，不投影 `evidence`/`source` 画布节点。
3. 日常维护走 `rag:audit:*`：每卡抽一次（含双分支）；抽查过降权、confirmed-ok 再降权，仍留池中。
4. CLI：`restraint-rag:*`（含 `migrate-all` / `writing-context`）。
5. 批量迁移：全部 `cards/restraint` 均为单主 ID + 双分支骨架；概念专属写法进入表达分支，不另建重复卡。
