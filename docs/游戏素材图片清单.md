## 后续维护规则

每次新增 `src/assets/game` 下的素材图片后，在确认该素材已经实际使用或准备投入使用时，都应及时同步更新本清单，补充：

1. 素材文件路径
2. 素材文件名
3. 素材类型
4. 素材用途或适用场景

这样可以避免素材堆积后难以追踪，也方便后续地图、事件、角色和场景资源统一管理。
