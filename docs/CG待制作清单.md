## 维护规则

1. 只有故事条目 `missingItems` 中以 `CG｜` 开头、且已说明所属模块与具体画面的缺口才能入表。
2. 每次新增、修改或移除这类 CG 缺口时，同步更新本表；没有已确认的缺口时保留表格结构并注明“当前无已确认 CG 待制作项”。
3. 单张 CG 制作完成后，先确认正式资源已进入 `src/assets/game/cg/` 并可被图鉴读取，再补入该故事条目的 `cgRefs`、`cgSequence`，最后删除对应 `missingItems` 和本表条目或已完成画面。
4. `src/assets/game/sucai_cg_standee/` 中的构图参考或制作源不是 CG 成品；除非对应故事明确缺少该画面，否则不以文件存在与否推断新的待制作项。
