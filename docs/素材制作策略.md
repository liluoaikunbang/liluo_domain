# 素材制作策略

这份文档整理自旧根目录 README 中仍有价值的素材规划内容，用于指导后续美术资源扩展。

## 角色立绘

核心角色优先制作高质量标准立绘母版，先确定身体比例、脸型、发型、眼睛、配色、线条粗细和阴影方式。

后续变化不要每次重画整张图，优先拆成可替换图层：

- 表情
- 眼睛
- 嘴
- 眉毛
- 脸红
- 服装
- 饰品
- 手臂
- 小动作

普通变化用图层差分解决，大幅动作再单独约稿。为了减少后续风格漂移，应逐步整理角色美术规范，包括标准立绘、配色表、分层规则、线条和上色要求。

## 像素地图行走图

使用 AI 根据角色参考图生成 `5 列 × 4 行` 地图行走图时，统一使用 [像素行走图生成提示词模板](./系统说明/像素行走图生成提示词模板.md)。模板要求同时提供精灵表版式参考图和角色外观参考图，并固定方向、动作帧、原生像素风、纯绿背景及相对排布。

生成结果只能作为待验收素材。正式接入前必须检查帧数、方向、站位、脚底基线、角色比例、色板一致性和纯色背景；不得通过新增运行时代码去补偿错误的单帧排版。

## 瓦片地图素材

瓦片地图优先使用授权清晰、风格统一的公开商用素材。

建议先选定一套主 tileset，覆盖小镇、森林、室内、道路和建筑外观等基础场景。后续缺少特殊地块时，再少量补充或自行修改，例如特殊花园、传送门、家具、剧情地点等。

使用前重点确认：

- 是否允许商用
- 是否允许修改
- 是否需要署名

地图扩展时尽量沿用同一套素材逻辑，避免新建筑或新区域显得突兀。

## 剧情 CG

CG 不建议一开始按大量完整插图规划。成本应该集中在最重要、最能打动玩家、最适合宣传或形成记忆点的关键场景。

普通支线或过渡剧情优先使用：

- 背景图
- 立绘差分
- 表情变化
- 镜头移动
- 局部特写
- 文字演出

等项目稳定或预算增加后，再逐步补充更多完整 CG。

## 背景与场景图

景观、家具、战斗背景和文字剧情背景可以先用 AI 批量生成，再人工筛选、裁切、调色、加滤镜或做像素化处理。

只有反复出现、辨识度强、玩家会记住的核心地点，才优先考虑约稿精修。

## 对话头像和战斗小像

对话头像不建议单独重画一套。优先从角色立绘里裁切胸像或头像，再配合表情差分和统一头像框使用。

战斗小像可以建立固定尺寸模板，例如 48x48 或 64x64。先确定头身比例、轮廓粗细、阴影方式和边缘处理，再批量套用到不同角色。AI 可以用于参考或起稿，但最终最好手动修像素边缘、五官和配色。

## 素材清单同步

每次新增 `src/assets/game` 下的图片素材后，都应更新 [游戏素材图片清单](./游戏素材图片清单.md)，至少补充：

1. 素材文件路径
2. 素材文件名
3. 素材类型
4. 素材用途或适用场景
