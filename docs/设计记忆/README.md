# 设计记忆

这里保存“为什么这样决定”，与当前操作手册和历史更新分开。

- [项目宪章](./项目宪章.md)：最稳定的项目方向与边界。
- [设计原则](./设计原则.md)：用于未来取舍的简明原则。
- [架构决策](./架构决策/README.md)：技术、数据、工具与工作流决策（ADR）。
- [创作决策](./创作决策/README.md)：跨世界、角色与表达策略决策（CDR）。
- [待确认决策](./待确认决策.md)：已经影响后续但尚未最终确认的少量事项。

只记录结论、理由、代价和重新评估条件，不保存聊天原文或一次性调试过程。当前系统用法仍以 `docs/系统说明/` 为准。
