# CDR-001：像素冒险 RPG 作为核心体验载体

## 当前结论与创作背景

璃落宇宙通过 2D 像素冒险 RPG 承载长期体验，地图移动、探索、事件、剧情推进、角色与场景氛围处于中心。

## 决策与理由

文字、立绘、CG、家具、资料、收集和功能页面可以存在，但必须回到世界探索和角色经历中。该载体能把多年积累的多世界内容组织成可进入、可行动、可触发的体验。

## 不采用的方向

不把项目收缩为纯 GalGame、CG 浏览器或相互孤立的功能页面，也不让工具建设替代可玩内容。

## 后续影响与重新评估

新功能优先回答它如何服务地图、事件、对话、玩法或持久成长。只有用户明确改变项目核心载体时重新评估。
