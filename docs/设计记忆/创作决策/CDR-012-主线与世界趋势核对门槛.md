# CDR-012：主线与世界趋势核对门槛

## 当前结论

更新任何位于主线任务之下的节点前，都必须先核对管辖主线与所属世界类别的既定趋势。新增内容不能只做到“不明显矛盾”，还应当能说明自己如何保持、推进或必要地衔接至少一项趋势锚点。

主线备忘、仍有效的上层备忘，以及世界选项或世界根节点的已确认说明共同构成判断来源。来源缺失、含义不明，或新内容会削弱、冲突、改写稳定趋势时，必须先请用户裁决；不得自行补设定来填补趋势来源。

## 背景与理由

仅将主线备忘当作阅读背景，容易让局部补丁和新节点各自成立，却无法共同推动主线的阶段感与世界的长期取向。局部设定快速路径此前又允许跳过主线备忘和世界资料，进一步放大了这种风险。

## 代价与重新评估

此门槛会为主线下的微小更新增加一次定向读取，但只读取管辖主线、仍有效的上层主线和对应世界类别来源，不要求加载整套大纲。世界类别趋势资料尚未建立时，先使用世界根节点及其直接已确认说明；若仍不足以判断，暂停写入并向用户确认。若未来世界类别拥有独立、稳定的趋势文档，应将其替换为首选来源，而非并行维护多份趋势结论。
