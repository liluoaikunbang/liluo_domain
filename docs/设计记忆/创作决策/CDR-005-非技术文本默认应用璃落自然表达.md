# CDR-005：非技术文本默认应用璃落自然表达

## 当前结论

面向阅读体验的非技术文本默认应用 `liluo-natural-expression` 的 light 合同；正式章节、关键剧情和重要公开叙事可用 deep。任何强度都先保证动作、物体反馈和空间关系可信，再处理含蓄、节奏与文气。代码、数据合同、日志、路径和精确规范不文学化。

实际创作或修订虚构束缚场景时，先用一个定向查询轻量检索外部虚构知识，默认最多 5 条抽象结果，只有不足时才核验最多 2 段不同来源的短原文。检索只用于提炼一般表达机制，不改变项目事实，也不构成作者模仿或原文准入。角色年龄统一遵循项目“仅成年人登场”的全局规则，不在本流程重复判断。

## 背景与理由

故事大纲、游戏对话、项目组对话和手记被频繁生产，只在用户每次主动要求“去 AI 味”时处理，会让表达质量不稳定。默认 light 能以较低 token 成本保护节奏、人物声音和潜台词，同时通过事实锚点阻止润色改写设定。

没有采用固定禁词表、统一口语化、故意错字或对具体在世作者的模仿。这些做法会生成另一种模板腔，损伤不同文本用途和角色差异。

真实写作校准表明，单独强调“少解释”和“用具体动作暗示”可能诱发伪具体性：为了表现人物熟悉或聪明而临时制造无法自然执行的操作。因而确立“可信度先于文气”，并允许普通动作只承担眼前功能，不强迫每个细节同时证明人物经历。

束缚场景又容易在闭门写作中反复落入“器具与姿势罗列”或“挣扎—失败—无力”的单一骨架。一次小预算检索足以提醒创作者比较环境压力、人物感知、他人行动与关系后果，同时把读取范围压到不会挤占正式创作的程度。

后续都市线段落校准进一步确认：环境应简洁进入角色动作而非被删掉或拟人化铺陈；已确认的束缚状态应直说；关键救助动作必须写清接触点与结果；人物行为要选择风险允许的时机；没有逻辑的“却”、破折号和作者评价式收尾都会削弱角色中心。以上作为可信度门禁的具体执行标准。

再校准后，“写清接触点”收缩为“最小充分细节”：若“抱住璃落”已经让保护意图、空间关系和结果成立，就不拆成左右手、腋下路径与连续步骤。紧急场面允许用“一把”这类单个短促修饰词补足速度感，但不叠加更多动作说明。只有普通动作无法解释空间，或结果确实取决于接触位置时，才增加动作细节。可信度要求不能反过来制造操作说明式的繁琐。

“最小充分”随后进一步按场景核心分流：普通保护动作以结果成立为止，过程型桥段则必须保留过程。若故事重点就是“怎么绑”，应写起始固定、绳路推进、姿态变化与完成状态，也可以使用宽泛结法、圈数和松紧变化；不能因避免现实教程而把核心过程压成“绳索收紧”。数量和力度可以服务束缚程度，真正需要避免的是把每一步全部参数化，形成带角度、受力数值、完整结法和全部可复现参数的说明书。

用户进一步确认，叙事不能用无答案、无证据路径、无行动后果的设问伪造深意或神秘感。悬念必须落到角色可追查的对象、玩家的下一步目标或会改变判断的选择；否则直接写事实或具体待解项。该规则吸收 `hardikpandya/stop-slop` 的反模板写作提醒，但只保留与项目事实、调查与玩家体验相容的“意义门禁”，不采用其全局英文禁词或统一标点禁令。

后手观音试写暴露了另一类伪具体性：过程写得足够详细，但动作骨架属于欧式并肘，名称却写成后手观音。由此补充“术语先于细化”的门禁：固定名称必须先与识别姿态相符，再展开绳路、圈数和力度；细节越多，越不能掩盖基础姿态错误。用户在真实写作实验中确认的可复用校准，也必须在修正当前文案的同一任务进入自然表达权威规范，避免只留下孤立成稿而让后续重复犯错。

## 代价与重新评估

默认路由增加一次文本类型判断；文学质量仍不能由关键词脚本完全判定。若 light 明显增加篇幅、破坏制作信息，或用户形成新的稳定风格偏好，应调整快速合同或风格档案，而不是让外部 Skill 自动覆盖本地规则。
