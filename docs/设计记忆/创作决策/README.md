# 创作决策记录

CDR 记录会长期影响多个世界、角色或表达方式的创作选择。它不保存故事草稿、私人聊天或单个节点细节；格式与状态规则参照本目录已有记录。

- `CDR-003-将项目智能体组织为璃落创作组.md`：采用稳定成员身份与克制陪伴表达，同时固定现实工程边界。
- `CDR-004-将文心雕龙篇名作为璃落创作组统一文号来源.md`：采用《文心雕龙》篇名作为统一文号来源，并区分文号、职司与项目改编释义。
- `CDR-005-非技术文本默认应用璃落自然表达.md`：非技术读者文本默认应用 light，自然表达不改变事实或技术精度。
- `CDR-006-正式项目角色统一为成年人.md`：所有登场和参与情节的角色统一为成年人，年龄未单列时不另设未知分支。
