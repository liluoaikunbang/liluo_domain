# CDR-002：外部知识只作原创转化参考

## 当前结论与创作背景

外部小说和题材资料与璃落项目正式知识严格分离，只提供题材模式、画面结构和表达方法等抽象参考。

## 决策与理由

查询结果必须回到项目权威内容核验并进行原创转化，不能直接成为世界观事实，也不能长段照搬来源表达。这既保护项目原创性，也避免外部材料污染正式设定。

## 不采用的方向

不把外部语料并入项目索引，不用相似作品替代用户对角色、世界和剧情的最终判断。

## 后续影响与重新评估

外部知识工作流必须保留来源定位、抽象输出和复制风险检查。只有来源授权与项目知识边界发生根本变化时重新评估。
