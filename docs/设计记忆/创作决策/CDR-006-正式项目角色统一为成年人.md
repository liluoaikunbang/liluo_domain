# CDR-006：正式项目角色统一为成年人

## 当前结论

璃落正式项目中，所有登场、受描写或参与情节的角色均为成年人，不新增未成年角色。角色年龄没有单独写明时直接按成年人处理，写作与审核流程不再为“年龄不明”设置额外分支。

## 背景与理由

这是覆盖所有世界线的统一创作设定。把成年人前提放在项目全局规则中，可以避免每次写到特殊桥段时重复猜测年龄、重复降级表达或产生互相矛盾的局部声明。

## 代价与重新评估

涉及校园、体型变化、昵称或回忆场景时，也不能据此自动推断存在未成年角色；相关人物仍按成年人设定表达。只有用户以后明确修改这项全局设定时才重新评估。
