# CDR-004：将《文心雕龙》篇名作为璃落创作组统一文号来源

## 当前结论

项目组成员采用“姓名｜雕龙文号｜职司”。日常姓名保持不变；文号统一取自刘勰《文心雕龙》篇名并按长期职责分配；“寻迹、经纬、机枢”等原有称号明确为直观职司。原典来源、原典关联和项目内改编释义分开保存。

## 背景、决定与理由

原称号能说明职责，却缺少统一文化来源。项目需要一套可解释、可扩展并适合公开展示的长期命名。《文心雕龙》系统讨论构思、文体、材料、表达、组织、批评与作者修养，五十篇可以象征创作组在完整流程中的不同位置。

未采用随机古风词、多部古籍混用、诗句截取或只把职司当笔名，因为这些方向来源不统一、与创作流程联系较弱，扩展后也难以持续解释。

## 影响与代价

体系统一性和公开展示的设计感增强，同时增加了来源核验、篇名状态和消费者同步责任。项目必须持续避免把现代 Agent 职责冒充为原篇唯一含义，也不得复制现代校注或译文的大段内容。

## 重新评估条件

篇名池不足、新增职责无法合理匹配、用户决定更换统一体系，或公开展示产生严重理解障碍时重新评估。
