# ADR-013：开放权重双模型与人工校准写作管线

## 当前结论

采用两个固定开放权重创作模型（Zhi-Create-DSR1-14B 与 Zhi-Create-Qwen3-32B），通过 OpenAI-compatible Chat Completions 接入；候选正文只进非正式工作区，用户批准后由主智能体用现有故事 Skill 写入正式内容。个人旧作、黄金正文、修改对照分层存放。StyleRAG 暂缓。单次修改不自动升级 Skill。模型 revision 需 pin，权重下载另案授权。

## 背景与理由

1. **开放权重**：可迁移、可自托管、许可证明确（Apache-2.0），避免绑定单一闭源供应商。  
2. **双模型暂不选唯一主模型**：评测与校准前缺少真实分数；过早锁定会浪费对照信息。  
3. **OpenAI-compatible 抽象**：可用 HF Inference Endpoints、vLLM、SGLang 等，核心代码不依赖供应商 SDK。  
4. **不直接写 canon**：外部模型无权改写正史；事实门禁与故事 Skill 仍由主智能体执行。  
5. **三层文风资产**：个人旧作提供底色但不等于最高质量；黄金正文是项目文风权威；修改对照支撑规范演化。  
6. **StyleRAG 暂缓**：缺少语料与版权隔离策略时，自动检索会污染生产；显式样本足够当前阶段。  
7. **单次修改不自动升级 Skill**：避免把偶然偏好写成永久规则；需重复证据或用户明示。  
8. **revision pin**：served model name ≠ 权重 revision；无 pin 则评测不可复现。

## 主要替代方案与代价

- 闭源写作 API：迁移与隐私边界差，明确拒绝作为本次正式管线。  
- 自动 StyleRAG：未成熟，明确暂缓。  
- 模型直接写正式故事文件：破坏治理，明确拒绝。  
- 每次校订自动追加 Skill：规范膨胀，明确拒绝。

## 重新评估条件

- 用户批准启用 StyleRAG 或第三写作模型槽  
- 生产默认模型校准完成并需要锁定唯一主模型  
- 用户指定的待添加候选（见 `docs/写作资产/模型归档/pending-candidates.json`，当前含成人向 `Qwen3.5-27B-Writer-V2-uncensored-heretic`）完成评测并获准接入  

## 影响范围

- 新增 writing-models 注册表、写作资产目录、CLI、Schema、Skill、缺口登记与文档  
- 不新增写手 Agent，不引入向量库依赖  
- Cursor / Codex 仅薄适配引用共同权威
