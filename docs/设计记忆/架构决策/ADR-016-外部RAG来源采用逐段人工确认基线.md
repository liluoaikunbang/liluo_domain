# ADR-016：外部 RAG 来源采用逐段人工确认基线

## 当前结论

AI 扫描不得再成为外部小说片段与 RAG 概念的可用基础。每一条片段关联、分支归属、新关键词与来源元信息，均须经用户逐段访谈确认后才进入可检索知识层。

既有自动关联通过可审计的基线重置退役，不可恢复删除原文、片段定位、哈希或历史记录。未确认卡片/分支不得进入正式写作与内容检索。

## 理由与代价

- 用户决定使每项基础判断可追溯，并允许“无价值、待上下文、重切或排除”；代价是前期速度较慢。
- 留存定位与退役历史能复核、回退与检查工具偏差；代价是需维护决定账本。
- 抽象制作语义为未来 AI 制作工具提供可靠输入，但不构成自动生成正式游戏内容的授权。

## 重新评估条件

- 在覆盖足够来源并经人工抽样复核后，用户可单独批准特定低风险字段的辅助预填；关联仍不得自动确认。
- 若逐段处理不可持续，可设计经用户批准的聚类审包或优先级队列，但须保留逐段回退和定位。
- 只有不削弱数据契约、版权边界和正式内容审批链时，才可将已确认抽象接入更自动化的制作流程。
