# ADR-006：内容生产采用证据派生与最小持久化

## 当前结论

故事可玩化以单节点编排为单位；路线用隔离 fixture 确定性验证；角色/关系只持久化跨章节长期变化；世界与系列覆盖按请求从正式证据派生；所有正式写入先过统一来源门槛。首版复用现有 Agent，不新增 API/MCP/任务系统或音频生成管线。

## 理由与代价

现有故事模板比运行时和索引合同成熟，直接批量实现会制造假 ID、假进度与不可保存状态。证据派生使“已有文件”和“真正可玩”保持区分，最小持久化避免每个节点背负主观进度字段。代价是覆盖统计更保守，浏览器层和长期任务状态在拥有正式工具与存档迁移前会明确留空。

当统一任务状态、正式 E2E harness、稳定音频授权/工具或长垂直切片出现时，可以扩展验证和声景层，但仍需保留来源门槛、正式入口证据与不批量猜测的边界。
