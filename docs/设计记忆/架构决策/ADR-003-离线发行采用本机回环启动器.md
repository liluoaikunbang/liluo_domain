# ADR-003：离线发行采用本机回环启动器

## 当前结论

Windows 多文件离线发行包以 `启动游戏.bat` 为用户入口，通过系统自带 PowerShell 在 `127.0.0.1` 动态端口提供临时静态服务；不再承诺直接双击 `index.html` 游玩。

## 背景与决策

项目需要保留独立图片和音频，避免单 HTML 持续膨胀。真实 Chromium 验证表明，`file://` 下 Phaser 的 XHR/WebAudio 会被拦截；改用 DOM 图片后，WebGL `texImage2D` 仍拒绝跨源纹理，角色分层 Canvas 的像素读取也受同源策略限制。用户已确认将入口改为一键启动器。

## 核心理由与替代方案

本机回环 HTTP 保留多文件结构、浏览器缓存和 Phaser 正常加载行为，同时无需用户安装 Node.js 或 Python。未采用重新内联全部素材，因为会恢复大文件与加载压力；未要求用户手动执行服务器命令，因为会提高交付门槛。

## 安全、代价与重新评估

服务只绑定 `127.0.0.1`，使用动态空闲端口，拒绝发行目录外路径，关闭启动窗口即停止。代价是游玩期间必须保留一个命令窗口，并以 Windows 10/11 为默认平台。若未来浏览器稳定支持本地目录授权，或项目采用可签名的桌面壳，再重新评估直接文件入口。
