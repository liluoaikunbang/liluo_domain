# 架构决策记录

ADR 记录已经采用或明确讨论过的重大工程、数据、工具和工作流选择。编号三位递增；状态为 `proposed`、`accepted`、`superseded`、`deprecated` 或 `rejected`。只有用户确认或项目已有充分采用证据的决策标为 `accepted`。

- `ADR-004-外部Skill采用非可信三层演化架构.md`：外部原始层、派生检索层和正式项目 Skill 分离，更新只进入 staging。
- `ADR-005-命令授权采用项目规则与决定注册分层治理.md`：项目规则负责执行，脱敏注册表负责长期决定历史，不自动扩大或修改用户级授权。
- `ADR-006-内容生产采用证据派生与最小持久化.md`：故事转化、路线、长期记忆和覆盖统计以真实证据和最小持久化为准，音频延后。
- `ADR-007-结构合同采用JSON-Schema并与业务验证分层.md`：JSON Schema 统一单记录结构，跨文件引用与业务图关系继续由既有 validator 负责。
- `ADR-008-交互生命周期Hook与质量门禁分离.md`：交互生命周期 Hook 只做输入级策略判断；耗时验证由显式、pre-push 或 CI 入口执行。
- `ADR-009-取消项目级Codex生命周期Hook.md`：取消全部项目级 Codex 生命周期 Hook，避免客户端/插件调度链阻塞高频工具调用；异常耗时必须向用户闭环说明。
- `ADR-015-旧页面参考迁移与按需索引入口.md`：旧页面式游戏保持可运行的低优先级迁移参考；项目索引先查询命中，再读取原始权威文件，不默认装载完整索引。
- `ADR-016-外部RAG来源采用逐段人工确认基线.md`：外部来源片段与 RAG 关系均经用户逐段确认；旧自动关联可审计退役，未确认数据不得进入检索。
- `ADR-017-从单一像素RPG到AI原生叙事游戏生产体系.md`：项目升级为 AI 原生叙事游戏生产体系；像素 RPG 继续作为旗舰输出，互动小说与其他形态成为正式产线。
