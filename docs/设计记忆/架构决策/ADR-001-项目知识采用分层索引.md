# ADR-001：项目知识采用分层索引

## 当前结论

使用 `project-index/` 作为按领域生成的导航、摘要和反向关系层，重要判断与正式修改仍核验原始权威文件。

## 背景与决策

项目跨故事、玩法、地图、代码、素材和文档持续增长，全量读取成本过高。采用可增量更新的结构化索引先定位最小资料集，不引入在线向量服务，也不把生成摘要提升为事实源。

## 核心理由与替代方案

该方案本地、确定、可验证，并保留原文件权威性。未采用“每次全仓库扫描”，因为成本随项目增长；未采用外部检索服务，因为会引入额外依赖和知识边界。

## 影响与重新评估

被索引源修改后需增量更新并验证；索引 stale、partial 或 error 时不得单独据此决策。只有当前生成方式无法维持准确性、性能或关系表达时重新评估。
