# 项目宪章

## 项目身份

“璃落的城堡 / 璃落宇宙”是一个长期生长的个人像素风冒险 RPG，不是一次性 Demo、纯 GalGame、CG 浏览器或功能页面集合。

## 核心体验

地图移动、探索、事件、剧情推进、角色和场景氛围是核心。文字、立绘、地图、玩法、收集与功能页面只有在增强“身处世界并展开冒险”的体验时才有价值。

## 长期方向

- 先保证可玩主流程，再补边角；允许粗糙但可持续推进的阶段成果。
- 多世界、多题材和多玩法应扩展同一宇宙体验，不做只换外观的重复内容。
- 用户拥有创作方向和重大取舍的最终决定权；AI 负责检索、分析、提案、实现、维护与验证，不替代最终审批。
- 工具、文档、Skills、Agents 和索引必须服务游戏与内容生产，不得成为项目目的本身。
- 正式项目知识与外部参考知识分离；外部素材只做抽象、原创转化，不直接成为璃落宇宙事实。

## 变更边界

改变技术栈、核心体验载体、正式知识边界或用户最终审批权，需要用户明确确认并记录新的决策。
