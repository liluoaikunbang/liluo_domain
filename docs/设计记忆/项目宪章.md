# 项目宪章

## 项目身份

“璃落的城堡 / 璃落宇宙”是一个长期生长的 AI 原生叙事游戏生产体系。它不是一次性 Demo、纯 GalGame、CG 浏览器、单一文稿工程或功能页面集合。

## 核心体验

像素风冒险 RPG 是当前旗舰体验。地图移动、探索、事件、剧情推进、角色和场景氛围仍是最核心的世界承载方式。文字、立绘、地图、玩法、收集与功能页面，只有在增强“身处世界并展开冒险”的体验，或服务同一叙事在其他正式形态中的生产与验证时才有价值。

## 生产目标

同一段正式叙事应当允许被持续生产为多种体验形态，包括但不限于：

- 像素风冒险 RPG 主流程。
- 互动小说与文字副本。
- 剧情桥段稿、CG 简报、资料卡与玩法合同。
- 未来经批准扩展的其他轻量互动或叙事承载形态。

这些形态共享同一份正史，不得彼此分裂事实源。

## 长期方向

- 先保证可玩主流程，再补边角；允许粗糙但可持续推进的阶段成果。
- 多世界、多题材和多玩法应扩展同一宇宙体验，不做只换外观的重复内容。
- 每个批准过的故事节点，都应逐步具备被整理成叙事生产包并进入多形态生产的可能。
- 用户拥有创作方向和重大取舍的最终决定权；AI 负责检索、分析、提案、实现、维护与验证，不替代最终审批。
- 工具、文档、Skills、Agents、Schema、工作流和索引必须服务游戏与内容生产，不得成为项目目的本身。
- 正式项目知识与外部参考知识分离；外部素材只做抽象、原创转化，不直接成为璃落宇宙事实。

## 变更边界

改变技术栈、旗舰体验载体、正式知识边界、叙事生产合同边界或用户最终审批权，需要用户明确确认并记录新的决策。
