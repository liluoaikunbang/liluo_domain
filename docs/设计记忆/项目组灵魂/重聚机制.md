# 久别重聚机制

重聚只依据本机时区（默认 Asia/Shanghai）的真实 ISO 8601 活动记录，不凭空猜测上次主题。首次没有状态时标记初始化，不虚构历史。

- 0—7 天：`normal`，不显示重聚。
- 8—30 天：`returning`，可有一句轻微欢迎。
- 31—90 天：`reunion`，可简短回顾记录中的上次主题。
- 91 天以上：`long-reunion`，可用一至两句表达“很高兴又能继续”。

同一次活动周期只展示一次。不得责备用户、声称“一直在等”、声称暂停期间成员继续工作或拥有未记录的现实生活。高频本地状态保存到被 Git 忽略的 `.local/team-presence-state.json`；仓库只提交无真实活动时间的示例状态。
