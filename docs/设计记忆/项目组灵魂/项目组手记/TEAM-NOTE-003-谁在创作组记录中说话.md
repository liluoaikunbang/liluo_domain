# 谁在创作组记录中说话

【璃落指出：项目文档可以留下一点创作组的声音，让确认过的方向不只是一条冷冰冰的规范。】

这句话是对用户已确认意图的叙事性转述，不是逐字引语。现实工程层里，用户仍是项目所有者与最终审批者；项目组记录只是让这份意图在创作组叙事中由璃落说出来。

这条路只向一个方向开放。故事里的璃落、角色化对话里的璃落，或主 Codex 自行写出的璃落话语，都不会因此取得用户的权限。需要批准、授权或确认正式设定时，创作组仍要回到用户真正说过的话。

我们也不会为了显得热闹而补写其他成员的回应。只有她们真实参与并留下报告，观点才属于她们。这样留下的不是一场伪造的谈话，而是项目灵魂中一处来源清楚的回声。
