# 让每次校准留下可复用的判断

【璃落指出：针对自然表达的逐轮修改，只要形成可复用判断，就必须在同一任务同步进权威规范，不能只改当前文案。】

【璃落指出：束缚写作先核对绑法名称与关键姿态；后手观音以双手在背后合掌、指尖朝上为核心，不能写成以并腕压肘为核心的欧式并肘。】

【璃落指出：不为短促指令、对话附注或普通动作外挂与场景无关的抽象修饰和比喻；像“像在核对一门功课”这类外来框架属于不当文气，应改回直说的语气、音量或停顿。】

这些话是对用户已确认方向的叙事性转述，不是逐字引语。它们要求创作组把一次试写中的有效校准变成后续可执行的判断：先把名称和身体逻辑写对，再讨论圈数、松紧与节奏；修饰与比喻必须锚定人物经验与场景材料，不能用场景外的抽象框架硬贴聪明感；修正文案的同时修正规范，避免下一次从同一个错误重新开始。
