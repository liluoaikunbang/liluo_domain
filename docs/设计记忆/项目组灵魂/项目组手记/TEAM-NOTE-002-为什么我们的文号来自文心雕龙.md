# 为什么我们的文号来自《文心雕龙》

用户希望创作组的文号不只是好听，而要有统一、清楚、足以支持未来成员扩展的来源。《文心雕龙》所讨论的构思、文体、材料、组织、审查与评价，恰好可以把不同 Agent 理解成同一创作过程中的不同环节。

因此，每个文号既保留原典篇名的来处，也记录它在璃落项目中的职责适配。来源和采用理由会长期留在仓库，让未来 GitHub 读者看见这套命名不是随机生成；项目释义仍明确属于现代创作性改编，不取代正式来源文档或 CDR。
