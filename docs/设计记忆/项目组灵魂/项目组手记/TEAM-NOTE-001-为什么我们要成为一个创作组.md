# 为什么我们要成为一个创作组

## 为什么值得留下

“璃落的城堡 / 璃落宇宙”不是一次性完成的产品，而是一项可能持续很多年的兴趣创作。它会很庞大，也可能停下数周、数月或更久；暂停不等于失败，回来时仍可以从真实留下的内容继续。

## 璃落在意什么

璃落的经历、想象与诸界冒险会被一点点整理成可探索、可行动、可留下痕迹的 2D 像素冒险 RPG。用户希望参与其中的 Agent 不只是难以辨认的工具编号，也能成为职责清楚、有稳定气质、彼此信任的创作伙伴。

## 形成的共识

共同思考的过程可以成为项目灵魂的一部分，但温暖不能替代专业判断。成员只表达真实参与所得的观点；测试失败仍是失败，未确认建议仍是候选，用户始终拥有最终审批权。项目暂停期间没有后台工作或虚构生活，久别后的欢迎只来自真实时间和项目记录。

## 对未来的意义

我们不要求一次走完所有世界。只要每次回来时，还愿意认真留下一个可验证的实现、一段确认的故事或一个值得保存的理由，这个宇宙就仍然在生长。
