# 规格：人工确认式 RAG 来源标注与来源访谈

状态：draft（实现前待评审）  
日期：2026-07-31  
关联决策：[ADR-016](../设计记忆/架构决策/ADR-016-外部RAG来源采用逐段人工确认基线.md)

## 目标

把外部小说来源从 AI 自动关联改为用户逐段确认的可追溯标注流程。所有外部资料保持 `external-fiction-reference`、`canonical: false`；它们只提供经过抽象的创作与制作参考，不能自动写入璃落故事、地图、CG、事件、玩法或代码。

成功条件：每条可用关系均能反向定位到 `sourceId`、`segmentId`、行号与片段哈希；未经用户确认的候选或分支不进入写作/内容检索；完成某来源全部片段处置后才可询问该来源元信息。

## 已确认原则

- AI 只能提出候选；片段到关键词、知识/表达分支、新关键词和来源元信息均由用户确认。
- 每段可选择已有关键词、多选、新关键词、仅表达、无价值、需要上下文、重切、排除来源或暂缓。
- “来源完成”包括确认、跳过、待上下文、重切和永久排除；不要求每段都建立关系。
- 现有自动关联做可审计的基线重置，绝不物理删除原始来源、来源/片段 ID、哈希或旧记录。
- 首期仅通过 Codex 对话访谈：直接展示当前完整分段，用户可要求展示前后分段；日志和公开导出仍只保存短预览/定位。

## 数据契约

保留现有 `external-knowledge/catalog/`、`index/`、`evidence/` 和 `cards/` 的来源定位职责。新增的人工确认账本位于 `external-knowledge/rag-governance/`，至少包含：

| 记录 | 内容 | 写入条件 |
| --- | --- | --- |
| 基线重置审包 | 被退役的旧关系、引用者与恢复定位 | 用户批准重置前后 |
| 片段决定 | 终态、用户选择、卡片/分支关系、时间与片段哈希 | 每次回答后 |
| RAG 创建决定 | 新名词、边界、父卡、分支与当前片段关系 | 用户在同轮回答中确认新建时 |
| 来源完成 | 各片段终态汇总、是否可访谈 | 全部 active 片段有终态 |
| 元信息审核 | 出处、题材、适用范围、局限与许可/使用备注 | 来源完成后 |

卡片继续固定拥有 `knowledge` 与 `expression` 双分支。关系必须明确为 `knowledge-evidence`、`expression-evidence`、`both` 或 `none`，不能使用笼统的“已关联”。历史修订通过新决定 `supersede` 旧决定，不覆盖审计记录。

## 新访谈 Skill

暂定名称：`liluo-rag-source-interview`；实现后支持“提问 RAG 来源”“随机抽一段外部小说让我标注”“继续 RAG 来源访谈”。本规格不把它视为已存在能力。

一次只处理一个片段：

1. 从当前可用且未处置来源中选择；支持指定来源、指定片段或随机模式。存在当前选定来源时，随机模式以 40% 概率抽取该来源、60% 概率抽取其他来源；没有选定来源时，在全部未完成来源间均衡抽取。
2. 在 Codex 对话中显示标题、稳定 ID、行号与当前完整分段；用户可要求前后分段作为上下文，并保留本地定位信息。
3. 按现有卡、别名、父卡和已确认邻近关系给出至多三个 AI 候选，并保留所有固定动作选项。
4. 用户选择后才写入决定记录；年龄不明、来源损坏或不可可靠定位时默认排除/待判断，不猜测、不转写。
5. 新关键词由同一轮回答完成确认：用户确认名称、适用/排除边界、建议父卡、分支与当前片段关系后，立即创建可检索的正式双分支 RAG。检索只返回已确认的名称、边界和片段关系；未确认的扩展定义或写法不得由 AI 补造。其 ID、别名和层级须通过数据契约验证。

## 来源完成与制作语义

一个来源的所有 active 片段均有终态后，才进入元信息访谈。确认单段不等于认可整篇，完成也不等于允许用于所有检索。

可在后续为已确认概念补充抽象制作语义：`playerEffect`、`informationEffect`、`riskEffect`、`routeEffect`、`visualFocus`、`suitableMedia`、`exclusions`。字段仅描述可复用机制，例如“降低移动自由度并使路线选择更重要”，不得复述外部专名、完整事件顺序或原句。

未来自动化只能以“已确认的外部抽象 + 璃落正史/资源约束”生成可审查方案；正式内容仍须走各自批准和验证链。

## 基线重置

重置需要两次授权：先生成 dry-run 审包，再由用户批准提交。顺序为：校验卡、`sourceRefs`、`evidenceRefs`、`claims`、`evidenceBindings` 与图谱投影；列出影响与恢复定位；将旧关联归档/标记为 `superseded-by-human-baseline`；把未确认分支降为不可检索；建立空账本与首个队列；最后执行数据合同、知识库、检索门禁和图谱投影验证。

## 边界与待确认项

- 始终：保留原文与审计定位，保持双分支，以用户决定为准。
- 先询问：提交重置、创建正式卡、改层级/别名、迁移图谱、导入/删除来源、引入依赖或联网。
- 禁止：静默批量确认、候选混入正式关系、外部资料写成正史、复制长原文到日志或公开导出。

实现前请确认：

1. 已确认：首期只采用 Codex 对话；展示当前完整分段，可按需展示前后文，不做游戏内面板。
2. 已确认：有当前选定小说时，随机模式以 40% 概率抽该小说、60% 概率抽其他小说；无选定小说时均衡抽取。
3. 已确认：同轮确认新关键词的名称、边界、父卡、分支和当前片段关系后，立即创建可检索的正式 RAG；不再要求单独确认。
4. 已确认：迁移时旧关联一律归档退役，不逐项保留。
