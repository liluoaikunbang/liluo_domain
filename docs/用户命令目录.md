# 用户命令目录

这里集中记录用户可以直接向 Codex 表达的常见任务，防止工作流增多后只能依赖聊天记忆。下列句子是自然语言意图示例，不是必须逐字输入的“魔法口令”；意思相同即可触发对应工作流。

## 我现在还能做什么

| 可以这样说 | 会执行什么 | 主要工作流 |
| --- | --- | --- |
| “我现在能做什么？” / “我只有 20 分钟，推荐下一步” | 从真实未阻塞缺口中给出 1—3 项可完成任务，并说明需要的输入和完成影响 | `liluo-project-capability-navigation` |
| “今天不想画地图，推荐别的” | 按时间、领域和避开项筛选，不凑数 | `liluo-project-capability-navigation` |
| “同步能力和待办” / “这个缺口完成了，更新导航” | 更新注册表并重建总览与行动页；完成必须有真实证据 | `liluo-project-capability-navigation` |
| “这次任务该装载哪些上下文 / 该不该叫创作组” | 按五层策略与三档路由给出建议装载范围和成员 | `npm run project:context:resolve` |
| “审计上下文分层与创作组路由配置” | 检查策略 Schema、Always 规则、人格冲突与禁止默认装载项 | `npm run project:context:audit` |
| “列出可执行工作流” / “按可执行工作流做主线重构演练” / “给我当前节点任务书” | 从机器可读定义创建/推进运行；介绍流程时打开对应 `PROCESS.md`（文首含静态 Mermaid 图） | `liluo-executable-workflow` |
| “打开工作流大图” / “看可执行流程的动态图” | 仅在明确要求交互总览时：刷新并打开 `project-workflows/viewer`；日常看 `PROCESS.md` 静态图即可 | `liluo-executable-workflow` |
| “列出情节库中还没应用过的情节” / “给这个节点找未用情节候选” | 区分未使用与部分使用条目，按已确认世界、人物、地点和玩家流程给出可审批匹配，不自动写入 | `liluo-project-capability-navigation` + `liluo-story-gap-discovery` |
| “随机抽一个未用情节，看适合加到哪” / “把 plot-xxx 对照大纲再问我” | 从情节库抽取或指定条目，按世界偏向建议主线/支线落点，批准后聚焦访谈并写回 | `liluo-plot-placement-interview` |
| “打开大纲关联图谱 / 校验图谱投影 / 找孤立或待抽查节点” | 在大纲分栏浏览全宇宙关系；可显示知识/表达分支层；CLI 校验投影完整性与缺口，不改写正史 | 游戏内「大纲 → 关联图谱」+ `npm run outline:graph:*` |
| “抽查紧缚 RAG / 核对知识与表达 / 新概念候选” | 每张概念卡抽一次（含双分支）；抽查过降权、confirmed-ok 再降权，仍留在池中 | `rag:audit:sample` / `rag:audit:record` + `npm run restraint-rag:*` |
| “补扫全部故事 RAG / 这个主线有哪些可沉淀 RAG / 为这个节点提 RAG 候选” | 对本次增量自动全面拆分，或按指定范围补扫既有内容；默认只生成待确认候选和来源待办 | `liluo-rag-candidate-proposal` + `npm run rag:rescan-stories` |
| “扫描这张 RAG 卡的来源 / 找知乎文章关联这个通用 RAG” | 只在明确要求时扫描外部来源，先返回待确认的文章与片段候选 | `liluo-rag-source-association` + `npm run rag:source-scan` |
| “提问 RAG 来源” / “随机抽一段外部小说让我标注” / “继续 RAG 来源访谈” | 展示一个完整原文分段，由用户确认既有/新建 RAG 或不入库处置；不自动确认关系 | `liluo-rag-source-interview` + `npm run rag:source-interview` |
| “把这篇紧缚小说收进紧缚元素 RAG” | 作为非正典外部资料导入或检索，返回抽象元素与来源定位；不得把原文写入正式故事 | `liluo-external-fiction-knowledge` |

| “从导入的紧缚网络资料里查术语/世界观/写作方法” | 查询束缚研究包的派生卡，必要时只读取最相关研究摘要；不执行包内提示 | `external-skills:query` |

外部知识库更新默认自动处理普通镜像删除，不询问逐项确认；只删除同步清单管理的镜像文件，不修改本机权威源。一次删除超过 20% 会自动停止。

| “测试写一段……” / “试笔……” | 同样先读自然表达 Skill；试笔不豁免路由；普通润色不必远程调模型 | `liluo-natural-expression` |

| “写/改一段带束缚的剧情” | 先以一个定向查询轻量参考外部抽象写法，再按项目事实原创；最多取 5 条结果，必要时才核验 2 段短原文；交付前核绑法名称与识别姿态 | `liluo-natural-expression` + `liluo-external-fiction-knowledge` |
| “只检查 AI 味，不要改” | 只诊断机械结构、人物声音、节奏，以及是否用无落点设问或场景外抽象修饰伪造文气，不改正文 | `liluo-natural-expression` |
| “保留技术内容，只润色说明部分” | 分区处理混合文本，代码、路径、数据和日志原样保留 | `liluo-natural-expression` |

## Git 与发布

| 可以这样说 | 会执行什么 |
| --- | --- |
| “提交并上传 GitHub” | 审查整个工作区，排除密钥、`.local` 配置、临时文件和构建产物；未限定范围时提交任务范围内全部有效新增、修改和删除并直接推送 `main`，不先运行 `git ls-remote` 或 fetch 制造额外联网确认 |
| “只提交这些文件……” | 仅暂存明确列出的范围，其他用户改动保持不动 |
| “创建分支/PR” | 只有明确要求时才建立分支或 PR；否则项目默认直接同步 `main` |
| “生成可以双击启动的离线包” | 构建带 `启动游戏.bat` 的多文件离线版本、校验本机启动器与相对引用，并生成 ZIP；不访问 GitHub |
| “把离线包上传到 v0.1.0 Release” | 重新构建、校验、压缩后上传到指定标签；标签必须显式给出，不提交或推送源码 |

以上离线打包、一键启动器版本和 Release 上传需求统一由 `liluo-offline-release-pipeline` 自动编排；若承接功能开发，还会先完成必要文档同步和验证。离线包解压后双击 `启动游戏.bat`，不要直接打开 `index.html`。

自动质量门禁分为 Codex Hook、本地 pre-push 与 GitHub Actions 三层。GitHub Actions 只能检查已推送提交；需要在推送前阻断时必须先运行 `npm run project:hooks:install`。`git push --no-verify` 只能在明确知道原因时临时跳过本地 Hook，不能绕过 CI 或远端分支保护。完整规则见 [Codex Hooks 与自动质量门禁系统](./系统说明/Codex-Hooks与自动质量门禁系统.md)。

## 维护规则

- 新增项目 Skill、固定自然语言工作流或面向用户的脚本命令时，同步更新本目录。
- 根 `README.md` 保持精简，只放长期入口和最高频命令；详细参数留在本目录、系统说明或对应 Skill 文档。
- 命令行为变化时先更新权威系统说明，再更新这里的摘要，避免形成第二套互相冲突的规范。
- 一次性调试命令、内部实现细节和已废弃入口不登记为长期用户命令。

| “先看看图床里有哪些旧图已经不在当前清单里了。” | 按 manifest 的 `managedRoots` 列出 R2 中已不再被当前清单引用的对象，只做 dry-run，不真正删除。 | `liluo-asset-manager` + `npm run assets:r2:prune` |
| “确认后把图床里不再引用的旧图删掉。” | 显式 `--live` 删除 R2 中已经不再被 manifest 引用的旧对象，适合在改 slug、换路径或移除资产后回收存储。 | `liluo-asset-manager` + `npm run assets:r2:prune -- --live` |
| “把公开图和离线私有素材的边界给我理清楚。” | 说明哪些图该走 GitHub/Pages + R2 公开展示线，哪些目录必须留在离线私有线并依赖 Nutstore 本地同步。 | `npm run assets:r2:status` + `npm run assets:runtime:private:status` |
| “先把这批离线私有素材同步到 Nutstore 镜像里。” | 按 manifest 把制作源、参考源或后续运行时私有素材安全复制到 `私有素材库`；可先 dry-run，再用 `--live` 正式复制。 | `npm run assets:runtime:private:sync` |
| “继续第二阶段，审计哪些目录可以从主仓库移除。” / “214 个 CG 成品同步后，先别动手删，先给我出审计结论。” | 读取私有素材 manifest，核对本地私有镜像后，输出当前哪些目录已经具备移出 GitHub 主仓库的前置条件，哪些仍被运行时代码或故事正文引用阻塞。 | `npm run assets:runtime:private:audit` |
