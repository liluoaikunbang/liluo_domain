- `慕妮卡帝国`：综合型主世界，当前已确认到 `缚神领地` 系列，最高证据阶段为 `outline`。
- `浮光掠影`：都市异常与校园悬疑线，当前已确认到 `荆锁会事件` 系列，最高证据阶段为 `skeleton`。
- `寂土挽歌`：末日与灾后秩序线，当前已确认到 `尸潮噬世` 系列，最高证据阶段为 `outline`。
- `尘寰问道`：古风悬案与礼法因果线，当前已确认到 `丫鬟难为` 系列，最高证据阶段为 `outline`。
- `咒缚回响`：学院、契约与古堡海路线，当前已确认到 `逐梦大陆` 系列，最高证据阶段为 `outline`。
- `星宇织梦`：轨道城、殖民边疆与文明边界线，当前已确认到 `星门港区` 系列，最高证据阶段为 `productionDesign`。

以上阶段来自 `npm run production:coverage`，反映的是“仓库中已经有证据支撑到哪里”，不是对外宣传时人为拔高的成熟度。

## 六大叙事域图册

### 慕妮卡帝国

这是目前最像“母世界”的公开入口。它能容纳宫阙、城市、住宅区、仪式秩序，也能承载璃落作为主角最稳定的长期关系网。

![慕妮卡帝国三联世界板](../assets/readme/composites/world-munika-triptych-board.png)

- 适合继续推进的方向：主世界地图扩展、长期主线节点、角色关系沉淀、地图事件和世界生活感。
- 当前短板：生产设计之后的灰盒、部分可玩与验证证据还不够。

### 浮光掠影

这是现在最接近“故事已开始向玩法转化”的都市线。荆江校园与异常传闻已经不只停留在概念或大纲层，开始拥有生产设计与骨架化证据。

![浮光掠影三联世界板](../assets/readme/composites/world-fuguang-triptych-board.png)

- 适合继续推进的方向：校园地图事件、都市悬疑支线、互动小说副本、可重复探索的异常点位。
- 当前短板：还缺真实已验证的完整章节循环。

### 寂土挽歌

这是灾后生存与秩序重建的世界。它现在已经具备明确题材和轮廓，但更多仍停留在大纲层。

![寂土挽歌三联世界板](../assets/readme/composites/world-jitu-triptych-board.png)

- 适合继续推进的方向：营地、补给、迁徙路线、求生规则与队伍关系。
- 当前短板：需要从纯轮廓进入更具体的生产设计和玩法落地。

### 尘寰问道

这是古风礼法、旧案和因果选择最浓的世界。它的优势是叙事味道很强，弱点是地图和可玩证据还没真正铺出来。

![尘寰问道三联世界板](../assets/readme/composites/world-chenhuan-triptych-board.png)

- 适合继续推进的方向：旧城街巷、衙署与宅院场景、调查式任务、礼法约束下的角色关系。
- 当前短板：还缺地图灰盒、事件流程和运行验证。

### 咒缚回响

这是最适合做学院、古堡、海路、誓约和高气质幻想视觉的世界。它很适合吸引美术、UI 和叙事设计协作者。

![咒缚回响三联世界板](../assets/readme/composites/world-zhoufu-triptych-board.png)

- 适合继续推进的方向：学院区块、契约系统、古堡探索、角色路线差异化视觉。
- 当前短板：故事与世界气质已经成立，但制作证据仍偏前期。

### 星宇织梦

这是六大叙事域里最靠近中期制作设计的科幻线。它已经进入 `productionDesign`，说明不只是“有想法”，而是开始形成可执行的结构。

![星宇织梦三联世界板](../assets/readme/composites/world-xingyu-triptych-board.png)

- 适合继续推进的方向：轨道港、学校与监狱区块、未来约束装置、远行与边疆支线。
- 当前短板：还缺进入骨架化与灰盒后的真实运行证据。

## 适合公开协作的切口

根 README 现在只展示这 `6` 张最终单图整板；三联板背后的 `18` 张原始 GPT Image 2 世界概念图仍保留在 `../assets/readme/generated/`，方便后续扩展页继续拆开使用。

- 叙事设计：把已成形世界继续拆成真正可执行的任务、事件和章节。
- 地图与玩法：把生产设计转成 Phaser 地图、交互点和事件流。
- 视觉与 UI：为每个世界建立更稳定的风格层，而不是只做孤立插图。
- 资料整理：把世界、系列、角色、玩法与约束维护成长期可复用的生产资产。
