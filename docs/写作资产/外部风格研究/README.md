# 外部风格研究

- 文章清单：`article-registry.json`（由 `npm run writing:external:inventory` 增量生成）
- 作者先验：`author-registry.json`
- 重复组：`duplicate-groups.json`
- 抽象风格卡：`抽象风格卡/`（用户批准后才可生产使用）
- 来源映射：`project-navigation/external-style-sources.json`

原始文章仍在 `external-knowledge/sources/`，本目录不复制全文。禁止把未评审文章送入生产 Style Pack。通用情节灵感检索仍用 `liluo-external-fiction-knowledge`，与 Style-RAG 隔离。
