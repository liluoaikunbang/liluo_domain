# 正式正文写作合同说明

写作合同是发给开放权重模型的**唯一结构化输入**。模型不自行查询仓库；主智能体先核验正史，再填写合同。

## 必填要点

- `canonSources`：仓库相对路径，禁止绝对路径与 API Key。
- `immutableFacts`：外部模型不得改写。
- `forbiddenAdditions`：禁止新增组织、能力、物品、关系或世界规则。
- `stateAfter`：供后验连续性检查。
- `expression.targetChineseCharacters`：正文目标字数，与 API `maxTokens` 分离。
- `styleReferenceIds`：只能由用户或主智能体**显式**填写 0–3 个已批准样本 ID；空列表不得自动替换为伪范例；不触发 StyleRAG。

## 流程

1. 核验相关故事/连续性事实  
2. 填写合同并 `validate`  
3. `writing:prose:draft --model dsr1|qwen3` 或 `writing:prose:compare`  
4. `liluo-natural-expression` 检查  
5. 用户选择/修改/批准  
6. 主智能体用现有故事 Skill 写入正式内容，并按需 `writing:golden:sync`
