# 写作资产

本目录承载正式正文生产所需的文风与校准资产。Style-RAG 为 **V0 显式引用 + V1 元数据检索**（见 `liluo-style-rag`）；**不实现** embedding / 向量库（V2–V4 暂缓）。

## 分层

| 目录 | 定位 |
| --- | --- |
| 个人历史作品 | 用户个人底色参考，不自动视为黄金范文 |
| 璃落黄金正文 | 项目最高文风权威；当前数量为 0，待逐步形成 |
| 修改对照 | 模型原稿与人工修订的对照，供后续规范升级判断 |
| 璃落写作表 | 用户批准的抽象文风原则；当前 awaiting-assets |
| 外部风格研究 | 外部文章清单、作者先验、抽象风格卡；原文仍在 external-knowledge |
| 模型评测 | 题集、人工评分与已批准基线 |
| 模型归档 | model-lock、模型卡与许可证快照（不含权重） |
| 工作区 | 非正式候选正文、评权导出与 run manifest；默认 gitignore |

权威注册表：`registry.json`。当前确认：**仓库内现有大纲/设定/占位文本都不是正式正文，也不是黄金正文**；不扫描、不迁移。
