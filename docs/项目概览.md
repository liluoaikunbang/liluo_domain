# 项目概览

“璃落的城堡”是一个长期生长的个人作品，目标是做成一个像素风冒险 RPG。

它不是一次性 Demo，也不是功能页面集合。主角、地图、事件、探索、场景氛围、文字和立绘都应该服务于“在世界中冒险”这个核心体验。

## 核心方向

- 冒险感
- 探索感
- 事件驱动
- 角色与场景氛围
- 文字、立绘、地图共同表达内容

家具、布置、收集、资料页和功能页可以存在，但应当作为世界的一部分，而不是压过 RPG 主流程。

## 技术栈

当前项目主要使用：

- Vue 3
- Vite
- Phaser，用于 2D 地图、移动、碰撞和事件
- Pinia
- Vue Router

旧 README 中还记录过 Arco Design Vue、Vant、Lodash、Clipboard、File Saver、Pinyin、Segmentit 等依赖。当前是否继续使用，以 `package.json` 和实际代码为准。

## 运行命令

```powershell
npm install
npm run dev
npm run build:web
npm run build:offline
npm run preview
```

常用说明：

- `npm run dev`：启动 Vite 开发服务。
- `npm run build:web`：普通 Web 构建。
- `npm run build:offline`：离线单文件构建。
- `npm run preview`：预览构建结果。
- `npm run map:trim-empty-border`：地图空白边界修剪脚本。

## `src/game` 职责

- `core/`：跨场景基础能力，包括游戏创建、场景 key、事件/对话运行、玩家运行时状态。
- `scenes/`：Phaser 场景本体，目前按 `BootScene -> MapLoadingScene -> WorldScene` 串主流程。
- `systems/`：可复用运行逻辑，不直接承担场景生命周期。
- `systems/map/`：地图加载、出生点、碰撞、寻路、镜头、运行时整理、地图渲染等地图核心逻辑。
- `systems/character/`：玩家移动、输入、路径预览等角色控制逻辑。
- `systems/animation/`：角色与世界动画注册、资源准备和复用逻辑。
- `systems/environment/`：昼夜、天气、雾层等地图环境表现。
- `data/`：游戏数据、资源清单、配置与注册表。
- `data/maps/<mapId>/`：单张地图自己的数据目录，常用 `map.json`、`events.json`、`dialogues.json`、`meta.ts`、`assets.ts`。
- `data/interactive_fictions/<scenarioId>/`：单个互动小说/副本数据目录。
- `views/`：Vue 侧游戏挂载容器、模式 UI 与桥接逻辑。

## 开发原则

- 先保证可玩，再补细节。
- 先保证主流程，再补边角功能。
- 地图、事件、对话、存档是核心。
- UI、说明页、资料页是辅助。
- 新内容优先服务地图移动、发现地点、触发事件、推进剧情和形成记忆点。

## 文档原则

功能真正完成，并且经过用户实际测试确认无报错后，需要补充功能更新文档。

文档至少记录：

- 实现思路
- 相关代码路径
- 开发过程中遇到的问题
- 对应问题的解决方法
- 验证结果

历史记录保留在 `docs/功能更新/`，当前系统说明沉淀到 `docs/系统说明/`。
