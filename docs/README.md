# 璃落的城堡文档入口

这里是项目文档的统一入口。

这个项目首先是一个长期生长的像素风冒险 RPG。文档也按这个目标来整理：一部分记录历史，一部分说明当前应该怎么理解和维护系统。

## 推荐阅读顺序

1. 先看 [项目概览](./项目概览.md)，了解项目目标、技术栈、运行命令和当前目录职责。
2. 需要查当前系统设计时，看 [系统说明](./系统说明/README.md)。
3. 需要追溯某次改动原因时，看 [功能更新目录](./功能更新目录.md)，再进入对应编号文档。
4. 涉及 `src/assets/game` 下图片素材时，看 [游戏素材图片清单](./游戏素材图片清单.md)。
5. 需要补充视觉资产规划时，看 [素材制作策略](./素材制作策略.md)。

## 文档分层

### 当前说明

当前说明用于回答“现在项目应该怎么用、怎么扩展、哪些路径负责什么”。

- [项目概览](./项目概览.md)
- [系统说明](./系统说明/README.md)
- [素材制作策略](./素材制作策略.md)
- [游戏素材图片清单](./游戏素材图片清单.md)

### 历史记录

历史记录用于保留每次功能完成后的实现思路、相关路径、问题和解决方法。它们有时间顺序，不建议合并、重命名或删除。

- [功能更新目录](./功能更新目录.md)
- [功能更新](./功能更新/)

## 维护规则

- 新功能完成并经过用户实际测试确认无报错后，继续在 `docs/功能更新/` 新增下一编号文档。
- 如果改动影响了某个长期系统的当前用法，同时更新 `docs/系统说明/` 下对应文档。
- 如果新增了 `src/assets/game` 下的图片素材，同时更新 `docs/游戏素材图片清单.md`。
- 根目录不再维护 README，项目说明统一收口到本目录。
