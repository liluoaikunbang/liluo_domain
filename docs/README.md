## 推荐阅读顺序

1. 先看根 [README](../README.md)，快速理解璃落宇宙是什么、为什么值得长期建设。
2. 再看 [项目愿景](./项目愿景.md) 与 [项目概览](./项目概览.md)，把项目目标、运行形态和目录职责接起来。
3. 需要系统契约时进入 [系统说明](./系统说明/README.md)。
4. 需要自然语言入口、脚本命令与协作边界时看 [用户命令目录](./用户命令目录.md)。
5. 需要了解团队扩展方向时看 [协作参与与团队扩展路线](./协作参与与团队扩展路线.md)。
