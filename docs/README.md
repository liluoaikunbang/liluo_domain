# 璃落的城堡文档入口

这里是项目文档的统一入口。

这个项目首先是一个长期生长的像素风冒险 RPG。文档也按这个目标来整理：一部分记录历史，一部分说明当前应该怎么理解和维护系统。

## 推荐阅读顺序

1. 先看 [项目概览](./项目概览.md)，了解项目目标、技术栈、运行命令和当前目录职责。
2. 不确定该如何向 Codex 下达任务时，看 [用户命令目录](./用户命令目录.md)。
3. 需要查当前系统设计时，看 [系统说明](./系统说明/README.md)。
4. 需要选择项目 Skill 或 Agent 时，看 [技能说明](./技能说明/) 和 [智能体说明](./智能体说明/项目子智能体体系.md)。
5. 需要了解重要设计为什么这样决定时，看 [设计记忆](./设计记忆/README.md)；追溯某次实现时再看 [功能更新目录](./功能更新目录.md)。
6. 需要维护长期规范或检查文档影响时，看 [规范治理](./规范治理/README.md)。
7. 想在空闲时间制作剧情 CG 时，先看 [CG 待制作清单](./CG待制作清单.md)；涉及 `src/assets/game` 下图片素材时，看 [游戏素材图片清单](./游戏素材图片清单.md)。
8. 需要维护故事、地图、事件、存档或素材结构合同时，看 [JSON Schema 数据契约系统](./系统说明/JSON-Schema数据契约系统.md)。
9. 修改 Skill、Agent 或项目规则后，需要防止能力退化时，看 [Skill / Agent 能力回归评测系统](./系统说明/Skill与Agent能力回归评测系统.md)。
10. 需要运行按改动范围选择的 Hook、推送前检查或 CI 时，看 [Codex Hooks 与自动质量门禁系统](./系统说明/Codex-Hooks与自动质量门禁系统.md)。
11. 同时使用 Cursor 与 Codex、或需要处理两端规则与派生配置时，看 [AI 协同文件与规则分层](./系统说明/AI协同文件与规则分层.md)。
12. 需要控制任务默认装载哪些配置/索引/历史，或决定是否调用创作组成员时，看 [项目上下文装载与配置分层系统](./系统说明/项目上下文装载与配置分层系统.md)。
12. 需要核验外部 Skill 来源与许可证时，看 [外部来源](./外部来源/Skill来源目录.md)。
13. 需要查看项目命令允许、询问与禁止边界时，看 [Codex 命令批准分级表](./运行规范/Codex命令批准分级表.md)。
14. 尚未采用但保留重新评估条件的方案放在 [待定设计](./待定设计/)；其中当前包含音频、音乐与场景声景管线。

## 维护规则

- 新功能完成并经过用户实际测试确认无报错后，继续在 `docs/功能更新/` 新增下一编号文档。
- 如果改动影响了某个长期系统的当前用法，同时更新 `docs/系统说明/` 下对应文档。
- 如果新增了 `src/assets/game` 下的图片素材，同时更新 `docs/游戏素材图片清单.md`。
- 故事条目的 `missingItems` 新增、修改或移除 `CG｜` 缺口时，同时更新 [CG 待制作清单](./CG待制作清单.md)。
- 新增固定用户指令、Skill 或长期脚本命令时，同时更新 `docs/用户命令目录.md`。
- 新增长期规则或重要设计决策时，使用 `liluo-project-governance-memory` 更新唯一权威源、必要消费者和设计记忆。
- 根 `README.md` 只维护项目总入口和最高频命令，详细文档继续收口到本目录。
